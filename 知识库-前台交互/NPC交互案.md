# NPC交互案
NPC点击后按唯一业务功能打开原系统面板、单任务简易面板或多任务面板；说话表现与业务状态独立。

## 1. 一次点击做什么
1. 玩家点击有效NPC，检查本次交互资格、场景、存活和距离。
2. 只派发该NPC唯一的业务功能；没有业务功能时只呈现说话。
3. 只产生一次“点击交互”说话事件，将主表默认对白和挂载的点击说话合为候选，筛选后随机一条。功能面板随后打开不再播放第二次。
4. 独立功能直接开原面板；简单技能/BUFF和单任务使用一个NPC简易面板。
5. 业务办理按真实结果更新，已提交结果不因关窗而取消，也不因重开重复执行。

NPC对白和业务界面分别工作。随机选择话语不改变调用哪个功能，任务正文、目标、奖励和业务按钮不会因随机对白消失或替换成闲聊。

## 2. 面板承接
| 情况 | 当前界面 |
| --- | --- |
| 强化、炼化、打造、仓库、炼丹、制符 | 对应原系统面板及必要子页 |
| 商店 | 交易系统面板，商品与结算由交易系统提供 |
| 传送 | 独立传送面板 |
| 简单技能/BUFF | 单个NPC简易面板，显示说明、资格和办理按钮 |
| 单个任务 | 单个NPC简易面板，完整显示任务与当前状态 |
| 一个NPC多个任务 | 直接开任务面板，不限定宗门分类，不先弹NPC任务列表 |

不保留综合服务选择、多功能选项菜单、A/B双框、吸附和联动拖动。独立面板沿用原系统拖动、关闭与业务按钮，不增加“返回NPC/结束交谈”。

走远、死亡或NPC失效使旧交互入口失效；独立业务面板是否关闭沿其系统规则处理。NPC交互时暂停游走/巡逻并面向玩家，结束后恢复；多人朝向和窗口边缘、位置记忆保留待定。

## 3. 单任务与任务面板
| 单任务状态 | 显示与操作 |
| --- | --- |
| 可接取 | 正文、目标、奖励和接取按钮 |
| 进行中 | 真实进度；目标未达成时不能完成领奖 |
| 可完成 | 目标已达成与完成/领奖按钮，检查提交条件；仅当面任务额外检查指定NPC交互 |
| 已完成 | 已完成/已领奖，禁止重复办理 |
| 办理中 | 保留内容，相关按钮禁用 |
| 失败或未知结果 | 不提前变成功；按真实结果恢复或查询 |

任务交付方式按每个任务分别配置，与“单任务简易面板/多个任务面板”的呈现方式独立：

| 交付方式 | 条件满足后的办理 | 提示 |
| --- | --- | --- |
| 必须当面交付 | 在指定交付NPC的有效交互中办理；从普通任务菜单不能远程交付 | 不满足当面条件时显示“须到【NPC姓名】处当面交付” |
| 允许面板交付 | 可从任务面板直接提交并领奖，不要求入口NPC上下文或处于NPC交互范围 | 显示“可直接交付”，不能套用当面交付提示 |

NPC姓名由交付NPC编号关联NPC主表npc_name取得；需要显示职能称谓时按统一名称组合规则处理。编号只供配置关联和内部判断，玩家可见提示、任务面板说明和对白不直接显示NPC编号。姓名缺失应作为配置问题处理，不用编号替代姓名。目标未完成、提交物不足、办理中和已交付分别显示对应原因；两种方式都保留业务资格与防重复领奖检查。

多任务列表在任务面板内显示、选择及办理。接取、重试、提交、交付NPC按任务配置分别判断；提交NPC遵守任务表与交付NPC的一致性要求。取消旧对白节点确认，不再出现“确认节点”按钮。

从NPC打开任务面板时，按本次实际交互的NPC判断哪些任务可当面办理。场内NPC有效性和交互距离变化时更新办理资格；走远、换场景、死亡或NPC失效后，不再满足该NPC的当面交付条件。从普通任务菜单打开时，不能办理要求当面完成的交付。此时禁用项必须显示指定NPC和当面要求，例如“须到师兄处当面交付”（按实际NPC姓名生成），不能仅显示“可交付”却不给禁用原因；与正确NPC有效交互但目标未达成时显示“目标未完成”。关闭或重开窗口不等于完成任务，提交前按最新状态复核。

NPC对话目标须在有效交互中由玩家主动确认完成；仅选择、靠近、打开或关闭面板不算。通用确认不要求存在对白节点，随机话语不影响任务完成。指定节点的目标不能以打开功能面板替代；无对应节点时不能显示完成。

## 4. 传送面板
按NPC引用的方案读取有序目标区域ID，名称、场景归属、等级和前置任务取目标区域。每个区域就是实际目的地，不再配置重复场景或传送点身份。

列表使用上一页、下一页和页码，不滚动。第一页禁用上一页，末页禁用下一页，页数按实际显示数量计算。已显示但不可用的目的地禁用并给出原因。独立展示等级的字段与显示规则在区域资料中核定，最低等级不自动当作隐藏条件。

选择并确认后进入办理中，防止重复点击；成功后显示实际到达结果，失败显示原因，未知结果不能当成功。关闭窗口不取消已提交操作。区域边界、落点安全、真实资源和费用由地图/业务侧验收。

## 5. 说话表现
| 显示方式 | 表现 |
| --- | --- |
| 面板 | 当前NPC简易面板内的NPC话语；任务正文仍来自任务系统 |
| 气泡 | 文字锚定NPC，用于招呼、自言自语、业务反馈等 |
| 主界面 | NPC姓名与话语显示在玩家界面下方，不依赖NPC窗口打开 |
| 仅语音 | 只播放音频，不要求文字 |

主表默认对白使用主表显示位置；额外点击候选使用被选说话记录的显示方式。一次事件只随机一条，不先固定播默认再追加。文字与语音均空的记录不生成空白提示。

范围、任务、传送和业务结果事件按字典解释一个触发参数。需要“本次交互后才触发”的记录直接勾选本行开关，不再关联共用条件组。冷却和持续时间均为毫秒。同一NPC、同一触发玩家、同一事件身份共用冷却起点；每条候选分别按自身冷却时长判断本次能否播放，播放后该范围的冷却重新起算。不同触发玩家之间不共用此冷却。

离开时新触发告别由对应事件处理；当前已播内容按本行继续/停止配置处理。范围事件使用参数距离，已有内容停止使用NPC交互距离。配置继续时自然播完，不无条件换成告别。传音保证离开NPC后不会仅因空间衰减而听不到。

不同事件竞争、个人传音接收与气泡共享表现仍待核定，不新增连续队列或优先级玩法。

## 6. 待定交互边界
通用交互完成确认的具体控件及其在单功能直开流程中的位置待定；不能把开窗当作确认。多人共享朝向仲裁、窗口位置记忆、个人传音接收及气泡共享表现按所属规则核定，不从原型演示补成决定。
