# 便捷辅助设置策划与交互案
便捷设置是自动拾取、宗门上交、自动服丹、挂机计划四页共用的窗口，主界面提供可打开面板的运行摘要。切页或收起不停止已开启的执行；各页保存与启停互相独立。所有自动执行总开关默认关闭。辅助操作沿用实际物品归属、贡献报价、地图准入、丹毒和突破条件；不提供自动购买补药、自动突破、自动复活或任意传送。

## 二、公共交互与保存
### 1. 操作入口
- 四页同一窗口，当前页醒目标记；每页标题旁显示“已停用/运行中/暂停及原因”。
- 每页独立草稿、保存和放弃，页脚写“保存本页”“放弃本页修改”“恢复本页默认”。保存服丹不能顺带启用上交。
- 切页、收起保留本次尚未保存草稿，并显示未保存标记；草稿不参与执行。放弃恢复该页最近已保存值，不改库存、贡献或计划已得收益。
- 开关关闭立即停止本局后续自动动作；已提交的交易仍等待实际结果，关闭不撤回或重新提交。停止状态另保存；保存失败时保持本局停止并说明，不能失败后自动恢复开启。
- 打开开关先进入草稿；保存时校验当前页。没有生效类别时提示原因，不能显示为运行中。上交保存启用先弹持续授权确认，其他页保存后生效但挂机仍须手动开始。
- 恢复默认须确认，只重置本页设置。恢复上交默认同时停用本局自动上交；恢复计划前须先停止，不清空资产。
- 设置属于当前角色。重进恢复保存内容，所有自动执行开关与计划运行状态先停用，玩家可一次确认后开启，避免断线后无声消耗。

### 2. 可见性和反馈
成功、失败、禁用都要有可见结果。不能只有按钮变色而没有说明。常见持续原因行内显示，重复提示合并，不反复弹窗打断战斗。提交中确认不可连点，关闭仍可用。结果未知显示“核对结果中”，不自行声称失败后再成交一次。

仅统计本次在线会话上交件数、贡献和最近原因；切页、收起不清零，重进可重置，不新建长期统计规则。演示工具与正式玩家控件分区，不能把“重置演示资产”等工具放进游戏功能。

## 三、自动拾取
### 1. 类别与独立规则
类别选择条配全类摘要，选择某类后编辑其规则，避免一次铺出几十个复选框。首批明确灵植、灵材、装备、丹药、符箓五类。未有实际分类或功能支持的成品列为“待开放”，不能放一个“其他全收”勾选把未知物品全纳入。未来增加类别默认关闭并提示新增，旧设置不无声扩大。

每类都有：是否拾取、境界范围、品质多选。规则摘要例如“装备 · 全部可拾取境界 · 凡品至道品”。品质使用凡品、灵品、玄品、仙品、神品、道品，支持全选、清空；清空表示不匹配，不把空集合解释为全部。可将当前规则复制到其他已明确类别，复制前显示目标，不能改上交规则。

境界支持“全部可拾取境界”“当前及以下”“仅当前”“指定境界”；指定境界取实际有效枚举，选择全部不增加拾取权。明确无境界/通用物品用独立“包含通用”选项；资料缺失不等于通用。凡境界0是合法对象境界时按其正式含义展示，不写成通用。全部、当前及以下的展开范围与当前角色境界同时显示。

首次子项：灵植、灵材、装备开启，丹药、符箓关闭；境界全部可拾取，品质全选。总开关关闭。关闭总开关保留子项。灵石只显示钱包规则说明，不作为占背包格的分类。

### 2. 检查顺序与空间不足
1. 仅针对已有拾取流程能够处理的真实地面物进行匹配；类别、境界、品质取交集。
2. 匹配后仍检查实际归属、存活、拾取范围和可容纳性。未匹配或无权限的物品留在地面，仍可手动拾取。
3. 拾取提交前预检空间不足且已开启快满上交时，先按已授权规则处理已有背包对象；得到明确结果、确有空间后，对原地面物重新核验并只继续尝试一次原拾取流程。若拾取已经执行而失败或结果未知，应先确认该次实际结果，不能当作未执行而再次拾取。不能把地面物直接换贡献。
4. 无可交对象、交易失败或仍不足时不循环重试、不放宽规则、不丢物；地面物保持原有规则，提示原因。挂机历练因持续无法拾取应暂停等待玩家整理。
5. 单笔拾取仍全部容纳或全部失败。自动上交与拾取各自成立；上交成功但地面物后来失效时，不回滚已成立的另一笔上交，也不虚构拾取奖励。

## 四、宗门上交
### 1. 范围编辑
与拾取分开一套类别条和规则摘要，每类独立开关、境界上限与品质。不能因开拾取而启用上交。默认只开装备子类，境界“当前及以下”、品质只凡品；灵植、灵材、丹药、符箓关闭；总开关关闭。

境界可选“当前及以下”“低于当前”“指定境界上限”，显示展开结果；明确通用物资是否参与为独立选择，默认不参与。固定上限不随突破扩大；相对上限扩大时自动上交暂停，展示扩大后的范围，重新授权保存后恢复。品质精确多选，品质全选/清空操作可见。

### 2. 两种触发模式
| 模式 | 何时检查 | 处理范围 | 首次启用 |
| --- | --- | --- | --- |
| 快满时上交（默认） | 保存启用后的背包入包完成事件，空格数小于或等于阈值；或一次匹配拾取在提交前预检空间不足时 | 扫描全部背包存量，批量处理符合已授权范围者，不只本次新获 | 确认授权包括已有存量，但不在点击启用/保存的瞬间执行；下次上述事件触发 |
| 拾取入包后上交 | 一次世界地面物拾取已明确成功并入包后（含手动拾取与自动拾取） | 仅本次世界拾取新增的物品和准确数量，不扫描整格旧存量；购买、任务领取、打造、移仓不触发此模式 | 启用不清旧包；旧存量可从手动预览处理 |

阈值是“剩余空格≤N格”，可选1—5，默认2格。只提供小于实际背包容量的有效值；容量变化导致保存值不再合法时暂停并提示重新设置，不暗改已保存值。阈值按全背包真实空格，分页不改变计数。满包还能并堆的入包仍遵守原有容量判定。

即时模式必须取得本次世界拾取成功所对应的准确物品对象和新增数量，合并入旧堆时只处理新增数量；无法确定者跳过并说明，不能从最终整格库存或数量差猜来源。快满模式的扫描范围仍是全部已授权背包存量，可能包含购买、任务领取、打造和移仓所得，启用文案必须明确两模式差别。

快满模式触发后按规则处理全部候选，不为“只清够两格”创造不可预期的部分清理顺序。一次有效触发只发起一笔明确交易；结果等待期间不重复发起。没有候选时合并提示“无符合规则的可交物品”，不是“已整理”。

### 3. 启用与修改
保存启用时弹出：模式、空格阈值、各类规则、软保护、处理全部存量或仅本次新获、当前匹配示例、贡献估算。关键句分别为“以后触发快满检查时，允许上交背包中符合这些规则的物品（含现有存量）”或“允许上交以后世界拾取成功新增的匹配物品；不含购买、任务领取、打造和移仓”。取消不启用、不扣物。

编辑已启用的模式、阈值、类别、境界、品质或保护项，立即暂停本局自动上交；原已保存内容保留用于放弃，但放弃不会无声重新开启消耗，须重新确认开启。确认后保存成功才恢复。

手动“预览本次上交”独立于总开关，按当前可见规则生成实际清单。每项可取消和调整数量，全选/取消全选覆盖全部匹配页，翻页保留；底部固定总件数、贡献。确认时再核验全部条件，任一失败整笔不成交。预览改变时不能仍按旧报价扣除。

### 4. 上交硬保护与锁定检查
- 自动候选以现有宗门权威可交资格为入口，再叠加保护，不能由本地库存自行拼出权威候选之外的交易。穿戴、被占用、快捷栏中、归属/分类/境界/报价无法确定、无有效正上交贡献者不自动交；已有强化或炼化而资格/实例定价未明确的装备也硬保留。
- 锁定道具在上交列表中仍显示并标锁，但不可选，不进入手动、批量或自动上交内容，可用数量不包含锁定数量。选择与提交前重新核对，发现已锁定道具时提示“物品已锁定，请先解锁”，停止该次上交，不沿用锁定前的旧选择；最终结算同样不得上交锁定道具。

### 5. 上交软保护与保留原因
- 灵蕴、道纹软保护分别默认开启；玩家可关闭，但须重新授权并明确影响，避免默认保护使所有装备都无法整理而无从修改。保护不是自动战力鉴定。
- 凡品不是垃圾判据。预览显示“被保留的原因”和数量汇总，帮助解释为什么一件也没清；不把硬保护对象做成可强选条目。

### 6. 上交报价与成交反馈
- 按宗门有效报价只增加贡献；丹药按实际杂质分别计价；不返还灵石、分解材料、强化成本或声望，不代交任务。
- 自动与手动共用宗门已有权威交易资格和结算，不另写第二套上交贡献报价。库存/报价变化整笔不成立；结果不完整时继续核对同一笔交易，不能当作未成交而再上交一次。
- 便捷自由上交允许在野外执行，不要求先到宗门NPC处，不增加到场要求或费用；这项操作不提供宗门传送或地图间移动。

## 五、自动服丹
两行分别为生命保护、灵力保护。每行可选主HUD实际已开放物品槽（当前1—6格）、启停、1%—99%整数阈值，默认生命格1/50%、灵力格2/30%、两行关闭。百分比同时提供滑杆和整数框便于精确调整；0不代表关闭，开关单独表达。

所选格只读展示当前实际图标、名称、数量、适用性、丹毒状态及本行运行/停止原因。普通服丹未设置独立冷却，界面不将缺失信息显示为“冷却0/已就绪”；有明确的冷却规则与实际状态时，才展示其冷却。玩家在主面板放换丹药，本页不另选药、不搜索背包替代、不补药、不自动买药。相同槽可被两行引用，但必须按各行用途判断，不能一次扣两枚。

“低于”严格小于；等于不触发。生命优先：检查生命行，无法执行可检查灵力行；一次判断至多成功服用一枚，结果明确后再依据新状态继续后续判断。两行同槽成功一次后不能在同轮重复用。生命槽空不阻塞其他合法灵力槽。

仅普通可服丹药，且有对应生命/灵力恢复的有效丹效、明确自动使用许可、满足境界、状态及丹毒条件时执行。突破丹、修为丹、技能书或打开面板道具不能仅因放进格子而自动使用。实际丹效判适用，不看名称。自动使用字段空值不得凭猜测放行，需核对现有明确规则。

普通服丹不增加独立冷却或自动间隔，不展示未经确认的“冷却中”“冷却0”或“药品已就绪”。半效仍按上游半效服用并显示，满池禁止；成功才扣药和增加杂质，失败不消耗。未触发、空槽、药尽、用途不符、丹毒和状态限制各有行内原因。

一次实际服丹执行返回业务失败或网络失败后，立即停止对应行在本局的自动运行，保留已保存偏好，显示具体失败原因和实际可得错误码，不伪造统一成功或冷却状态。玩家须明确重新开启该行并保存本页，才可解除其失败停止；只改另一行、保存其他页、库存变化、签名变化或时间流逝均不解除。另一行仍按其自身条件继续，成功仍一轮至多一枚。

执行前就已发现空槽、用途不符等情况时，不开始用药，显示其真实不可用原因；这不等于一次执行失败。已开始的用药结果未知时须继续核对同一次结果，不能按秒再次用药，也不能用库存变化假装自动恢复。实际失败明确后停止该行，结果未知期间不对同一行发起第二次用药。

## 六、挂机计划
### 1. 编排与启动
每步是“活动、地点、时长”，类型为历练打怪或打坐修炼。历练目标使用正式已配置区域，显示所属地图与区域名，并以该区域真实边界作为选怪和追击活动范围；不把地图grade或推荐境界当准入。未开放、未配置边界、无合法可达路线的目标灰显并说明。本设置打坐阶段固定为“就地打坐（不传送）”，在前一步结束后当前位置开始。现未有正式个人洞府到已配置区域的空间关系，故本计划不提供可点的洞府目标；不把灵气源编号当地图/区域，不把回宗门当回洞府。上游“回洞府打坐”入口自身规则保留，本设置不改它，也不补造缺失关系。

时长为时辰＋刻（刻0—7，合计至少1刻），同时显示现实分钟换算：1刻为现实37.5秒，1时辰为8刻、现实5分钟。可新增、删除、复制、上移、下移阶段；空清单有添加提示。默认执行一次，可选循环整套计划。模板“区域甲历练2时辰→就地打坐1时辰→区域乙历练2时辰”明确标模板，不是正式地图或默认自动执行。

保存本页不启动。点击开始先预览完整路线、各步时长、有效总时长和循环方式，说明赶路等待会延长实际完成时间。确认后才开始。运行与暂停时锁定计划编辑，提供“停止后编辑”，不让编辑草稿改变执行中的步骤。其他三页仍可编辑保存。

### 2. 有效计时与切换
历练实际到达所选区域后开始计本步活动时长，无怪等待仍计时；打坐在统一战斗状态为可安全进入的闲置态时，沿既有就地入口进入；实际进入打坐状态后才计时。受击战斗、死亡或状态不可用时不强行坐下，明确等待或暂停原因。赶路、等待安全切换、暂停不计。收起、切页不影响倒计时。显示当前步、下一步、当前剩时、循环次数及明确状态。

历练到时停止发起新战斗和重新选怪；仍处于既有受击战斗时不强制消除战斗状态。本步剩余显示0并依据统一战斗状态等待允许切换，不能提前扣下一步时长，不强行传送免伤，不反复进出打坐。确认可切换后，按原流程停止历练/出关/前往目标。路线仍受实际等级、任务及连接限制；没有已有可用导航或传送能力时阻断并说明，不创造任意瞬移。

暂停仅停止计划驱动的寻路、目标选择和新战斗指令，不强制清除已成立的受击战斗状态，冻结本步计划余时。当前已有打坐可以继续按真实规则获得收益，但暂停期间不计本步计划时间；恢复后继续剩余时长。受到攻击、手动移动等已经按原规则出关的，不由计划偷偷坐回。

停止清运行进度、保留编排内容，不回滚既得收益、不传送。单次完成停自动行动；末步为打坐则保持实际打坐，末步历练则停自动战斗。循环完成一轮后回第一步，仍经过合法切换。禁止自动突破、自动复活和自动选替代地图。

就地打坐不移动、不传送。收益只按当前位置真实有效灵气源与名额结算；无源或名额已满只有基础修为，不能在野外套用个人洞府的灵气收益。灵气源编号不是空间目标。打坐时受到攻击等仍按原规则结算后出关，计划暂停并保留余时，不反复自动坐回。下一历练阶段出关后走正式区域导航。

### 3. 自动选怪的最小行为
到达所选区域后，计划只对区域内、当前场景、有效存活且有合法敌对资格的怪物自动选取目标，并按既有玩家战斗规则行动。目标死亡、失效或离开合法范围后重新选择；无合格目标时在区域内等待，不跨区找怪，不自行追出所选范围。既有追击中将越界时停止计划驱动的追击并恢复区域内等待；不能为追怪创造传送。计划不改变伤害、神通施放及战斗结算规则。

统一战斗状态为不可用或死亡时不当作安全闲置，不直接切图/打坐。自动化自身指令不能误触人工接管，真正玩家指令也不能被吞掉。

### 4. 手动接管、打断与死亡
| 情景 | 明确行为 |
| --- | --- |
| 手动移动、攻击、神通、切图 | 暂停计划，显示手动接管；只开背包或设置不暂停 |
| 打坐被受击或其他行为打断 | 先按原规则结算并出关，计划暂停保留余时 |
| 无灵气/名额已满 | 可打坐并显示仅基础修为，不假装无收益 |
| 死亡 | 暂停，不自动复活或追回死亡地图 |

### 5. 地图、空间与重进异常
| 情景 | 明确行为 |
| --- | --- |
| 持续空间不足、已无可交对象 | 暂停历练，显示整理原因，物品留地面按原时效 |
| 入口不存在、条件失效、地图停用 | 暂停并标明具体阶段，不跳步不换图 |
| 达突破线 | 提示手动突破，修为继续允许溢出，计划不投入突破丹 |
| 掉线、退出 | 停止在线计划，按原有下线闭关，不离线刷图、拾取、上交、服丹 |
| 重连/重进 | 恢复设置供查看，在线计划不自动恢复，手动预览开始 |

## 七、默认模式与未开放边界
自动上交默认使用“快满时上交”，同时保留“拾取入包后上交”；该默认值是现行需求稿中的组内设计选择，不表示用户此前逐项确认。没有正式分类与功能支持的拾取类别显示“待开放”；没有合法区域边界、准入或路线的挂机目标不可用并说明原因。打坐固定为就地打坐，不提供未定义空间关系的个人洞府目标。
