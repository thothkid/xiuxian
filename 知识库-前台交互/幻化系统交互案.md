# 幻化系统交互案

本案面向策划、美术与前台程序，规定幻化界面中玩家看见什么、可以操作什么、操作后发生什么反馈。幻化资格、永久收益、消耗规则与各配置项含义见同目录[《幻化系统策划案》](幻化系统策划案.md)；页面布局与操作对应[单文件交互原型](E:/修仙项目讨论结束归档/幻化/最终交付_2026-10-15/幻化交互原型_单文件.html)。

界面沿用已确认的幻化UI与三栏原型，目标为PC横版。选中只预览，激活取得永久资格和收益，使用才切换实际外观。属性、技能及词条收益全部在激活后生效，穿戴只改变外观，没有单独的穿戴奖励；界面不能把当前预览项、当前使用项和已激活资格混成一个状态。

## 一 页面结构与区域联动

顶部标题为“幻化”，分类页签依次为“头像／称号／时装／坐骑”，右上角为关闭按钮。正文为左侧幻化列表、中间外观预览、右侧幻化详情。

| 区域 | 从上到下的内容 | 与其他区域的联动 |
| --- | --- | --- |
| 左侧幻化列表 | 分类列表标题与已激活数量、名称搜索与状态筛选、六条列表项、分页栏 | 分类、搜索、筛选决定当前可见列表；选中项驱动中间预览和右侧详情 |
| 中间外观预览 | “外观预览”标题、当前选中幻化的外观本体 | 跟随选中项，不以角色当前使用项覆盖预览 |
| 右侧幻化详情 | “幻化详情”标题及状态、名称、说明、激活收益、获得方式、底部按钮 | 与列表显示同一选中项；库存、资格或使用选择变化时同步更新相关内容 |
| 激活确认弹窗 | “激活幻化”标题、幻化名与全部消耗、取消和确认激活按钮、关闭按钮 | 始终针对打开弹窗时的那一件幻化，不随其他界面选择改成另一件 |
| 道具提示 | 道具名称、用途或说明、来源、持有数量和需要数量 | 跟随悬停或聚焦的那一个激活材料，不能沿用上一件材料的信息 |

详情内容较长时在右侧内容区内滚动，底部操作区保持可见。文字允许换行，材料图标可按数量换行；不得为放下更多内容删掉消耗项或奖励项。

## 二 打开 关闭与分类切换

### 首次打开与重开

通过主面板的“幻化”入口打开面板。入口图标采用82×82像素的古铜幻镜透明PNG，镜面包含衣袍与灵鹿倒影；正式文件名为 `huanhua_entry_82.png`，已交付到主面板图标目录。本资料保留[同图备份](E:/修仙项目讨论结束归档/幻化/最终交付_2026-10-15/主面板入口图标/幻化_古铜幻镜_v2/huanhua_mirror_82x82.png)。接入时登记到现有图标资源资料并引用。入口图标与每件幻化的 `icon_id` 分别承担系统入口和列表识别用途。首次打开按原型进入“时装”，搜索为空、筛选为“全部”、位于第一页，选中当前页第一件。选中第一件只决定预览，不自动使用，也不改变玩家当前外观。

各分类在本次会话内分别记住搜索文字、筛选条件、页码和选中项。关闭后重开保留当前会话的界面状态；角色重新进入游戏时，资格和实际外观选择按角色记录恢复，不能把原型的初始演示外观当作玩家存档。

### 分类页签

| 操作 | 页面响应 | 保持不变的内容 |
| --- | --- | --- |
| 点击另一分类 | 页签高亮、列表标题、收集数、列表、预览和详情一起切换；恢复该分类已记住的界面状态 | 角色各分类当前使用的外观与永久收益 |
| 第一次进入某分类 | 搜索为空、全部状态、第一页、选中该页第一件 | 其他分类的搜索和选择记录 |
| 点击当前页签 | 保持当前选择，不重复切换外观 | 全部角色状态 |

分类切换后，选中项若不再属于当前可见页，选中当前页第一件；没有结果时进入第八节的空列表表现。

### 关闭与ESC

没有确认弹窗时，右上关闭按钮或ESC关闭幻化面板。关闭不卸下外观、不隐藏称号、不撤销已激活资格。

激活确认弹窗打开时，ESC先关闭弹窗，按提交前取消处理，不同时关闭底层面板。点击弹窗关闭按钮或弹窗外遮罩同样取消本次未提交的确认。道具提示不单独占用一次ESC。

## 三 列表 搜索 筛选与分页

### 列表项的内容与操作

每行只显示幻化图标、幻化名称、状态。选中描边与状态文字分开：选中一件未拥有幻化后，仍显示“未拥有”；选中已激活幻化后，也不因此变成“使用中”。

| 操作 | 响应 |
| --- | --- |
| 悬停列表项 | 按已确认视觉反馈提亮，不直接使用或激活 |
| 单击任意状态的列表项 | 选中高亮，预览和详情同步切换到该件 |
| 连点或双击列表项 | 仍只选择，不增加快捷激活、快捷使用或卸下行为 |
| 单击已选中的列表项 | 保持该件预览和详情，不产生消耗或外观切换 |

未拥有、未激活的条目也显示真实名称和外观预览，不替换成问号或隐藏模型。名称超长时允许自动缩小字号、扩展文字显示空间或折行，具体由程序按实际布局处理；不设7字或10字的配置硬限制。列表保持目录原有顺序，不因材料凑齐或激活成功自动把条目置顶。

### 三种状态与收集数

| 列表和详情状态 | 玩家当前条件 | 主按钮 |
| --- | --- | --- |
| 未拥有 | 尚未激活，任一种所需材料数量不足；包括已经持有部分材料 | 激活，禁用 |
| 未激活 | 尚未激活，全部所需材料数量足够 | 激活，可点击 |
| 已激活 | 已获得永久资格，不受剩余材料和是否使用影响 | 按当前使用选择显示“使用”或禁用的“使用中” |

分类收集数显示“已激活 M／N”，M为该类已激活件数，N为该类全部启用件数。搜索、筛选和分页不改变N；激活成功增加M，使用或隐藏不改变M。

### 名称搜索与状态筛选

搜索框提示为“搜索幻化名称”，只搜索当前分类的幻化名称，支持名称的一部分。搜索与状态筛选共同生效；状态筛选项为“全部、已激活、未激活、未拥有”。

改变搜索文字或筛选条件后回到第一页。原选中项仍在当前页则保留，否则选中该页第一件。清空搜索只清除搜索条件，不重置状态筛选。

### 分页

当前结果每页六条。点击“上一页”或“下一页”后选中目标页第一件，预览、详情与按钮同步刷新。第一页禁用上一页，最后一页禁用下一页；结果只有一页时两侧均禁用。

库存或资格变化使结果条数减少时，页码收回到仍有效的最后一页。结果为空时页码显示第1／1页，两侧禁用，不保留无效页码。

## 四 四分类的预览与实际使用表现

| 分类 | 选中时中间预览什么 | 点击使用成功后改变什么 | 不应增加的内容 |
| --- | --- | --- | --- |
| 头像 | 该件幻化的图标大图；与列表使用同一图标资源，仅尺寸不同 | 角色头像的实际显示位置采用此图标 | 不增加主界面头像位置示意，不加载角色身体模型 |
| 称号 | 称号资源本体，包含资源已有的文字与装饰 | 角色显示此称号资源，替换原显示称号 | 不添加角色背景模型，不从幻化名称生成正式称号美术 |
| 时装 | 对应时装的角色外观模型 | 替换角色身体外观，其他分类选择保留 | 不增加身体部位选择或分件穿戴控件 |
| 坐骑 | 对应坐骑模型 | 改变坐骑外观选择，实际坐骑显示时采用该外观 | 不因使用而自动上马，不将坐骑模型替换到角色身体 |

中间预览始终跟随当前选中项。隐藏实际称号后，仍可在中间查看该称号；使用一件幻化后再选中另一件，也只是查看另一件。

头像读取图标ID；称号、时装、坐骑读取模型ID。挂点与缩放按策划案中的分类规则应用，预览不增加显示对象或挂点文字。幻化图标、模型的配置含义与必填条件以策划案为准，本案不新增资源字段。

预览区保留外观本体及已确认的场景装饰，不增加名字副标题、显示部位说明、“选中仅预览”提示或坐骑可预览提示。界面底部不增加当前装备汇总。

## 五 幻化详情 收益与获得方式

### 详情内容顺序

| 顺序 | 区域 | 展示规则 |
| --- | --- | --- |
| 1 | 幻化详情标题与状态 | 标题固定；状态与同一条列表项一致 |
| 2 | 幻化名称 | 显示选中幻化名称 |
| 3 | 幻化说明 | 显示该件说明，按内容换行 |
| 4 | 激活收益 | 全部属性，及配置了的奖励技能、奖励词条 |
| 5 | 获得方式 | 来源文字和全部激活材料图标同时显示 |
| 6 | 操作按钮 | 按第六节的状态决定内容与可用性 |

不添加激活后永久使用、外观无需再次消耗等常驻解释文案，也不增加升级区、模型可预览说明或重复的当前装备摘要。

### 激活收益

展示该件幻化的完整收益，不显示角色总属性，不显示与当前使用幻化的差值。未激活时可查看将获得的内容，激活后继续显示同一组收益。

属性按定义的单位展示，固定值显示数值，万分比前台一律换算为百分比并带百分号。生命值120显示“生命值＋120”；万分比1000显示10%、100显示1%、50显示0.5%、1显示0.01%。百分比最多保留两位小数并可去掉末尾无意义的0，不能把非零收益四舍五入成0.0%。不因是坐骑或未来宠物幻化而把收益标为给予坐骑、宠物。

奖励技能与奖励词条分别按对应配置ID读取名称，可同时出现，也可与属性同时出现。没有配置某类奖励时，不显示该类奖励行，不以“暂无”占位。它们均属于激活收益，不能把未穿戴标成技能或词条失效。同ID去重；同一种技能或BUFF存在不同等级时取当前有效来源的最高等级，不重复叠加，当前无等级的词条按ID去重。详情仍展示这一件幻化的配置收益，不展开跨来源比较或另加等级操作。

### 来源文字与材料图标

获得方式同时保留来源文字与材料图标。不同物品分别展示，需要更多种时全部展示，不把“多种同时消耗”画成任选一种的选项。同一物品ID在配置中出现多次时，先合计数量，再只显示一个该物品图标；材料提示、激活条件、确认清单和实际消耗都采用同一合计需求。

例如同一灵石分别配置30个和30个，实际共需60个。持有50个时只显示一个灵石图标，提示“持有：50／需要：60”，状态为未拥有、激活禁用；不能出现两个都写“持有50／需要30”的提示。这不改变多种道具同时消耗的规则。

材料图标读取各物品自己的图标，不能给所有材料套幻化图标。材料图标用于查看提示，点击不直接消耗、不替代激活按钮，也不增加未约定的商店跳转。

### 道具提示

鼠标悬停或键盘聚焦某个材料图标时，显示该材料提示；离开、移走焦点或选中另一件幻化时关闭旧提示。提示需完整显示，不能被面板边缘裁切。

| 提示内容 | 展示要求 |
| --- | --- |
| 道具名称 | 显示当前图标所对应物品的名称 |
| 用途或说明 | 说明它用于激活哪件幻化，或展示对应物品说明 |
| 来源 | 读取该物品自身的来源，不把一段幻化总来源复制给所有材料 |
| 数量 | 显示“持有：X／需要：Y”，实时反映库存与本次需求 |

材料不足时仍允许查看每个材料提示，玩家能据数量判断缺什么。即使幻化已激活，也可查看原激活需求，不再以材料数量决定幻化资格。

## 六 按钮状态 激活 使用与隐藏

### 按钮矩阵

| 选中幻化条件 | 主按钮文字与状态 | 称号副按钮 | 点击后的流程 |
| --- | --- | --- | --- |
| 未拥有 | 激活，禁用 | 不显示 | 不操作；通过材料提示查看缺口 |
| 未激活 | 激活，可点击 | 不显示 | 打开激活确认弹窗 |
| 已激活，未使用 | 使用，可点击 | 仅称号显示隐藏称号；当前没有实际显示称号时禁用 | 使用选中外观，成功后主按钮为使用中 |
| 已激活，正在使用 | 使用中，禁用 | 仅称号显示隐藏称号，可点击 | 主按钮不重复提交；称号可进入隐藏流程 |

头像、时装、坐骑只有主按钮。只有选中已激活称号时，出现“隐藏称号”副按钮；不增加“显示称号”或“卸下”按钮。

### 激活确认弹窗

点击可用的“激活”按钮后打开弹窗，标题为“激活幻化”。正文使用以下结构，其中全部材料都必须列出：

“消耗 {数量1} 个「{道具1名称}」、{数量2} 个「{道具2名称}」……，激活「{幻化名称}」？”

清单按不同物品ID列出，同一物品的重复配置先合计，不在确认框重复列成两项需求。

底部为“取消”和“确认激活”，确认按钮为主操作。弹窗打开期间，遮罩阻止底层列表、分类和操作按钮被点击。正文较长时允许换行，不省略最后一种成本。

| 操作或结果 | 弹窗与页面响应 | 材料 资格与外观 |
| --- | --- | --- |
| 提交前取消、关闭弹窗或ESC | 关闭弹窗，回到原选中项 | 无消耗、无激活、无外观切换 |
| 确认激活 | 针对弹窗中的幻化检查全部当前需求；同一次操作不重复提交 | 以实际处理结果更新，不预先扣图标数量或增加收集数 |
| 激活成功 | 关闭弹窗，提示已激活该幻化，刷新收集数、状态、详情和相关材料 | 完整扣除材料并获得资格及永久收益；不自动使用 |
| 确认时材料不足 | 关闭本次确认，提示所需道具不足，按剩余库存刷新 | 不发生部分消耗，不增加资格或收益 |
| 确认时已被激活 | 关闭本次确认，提示已激活，按实际资格刷新 | 不再次扣除或奖励 |

成功后如果该件仍在当前筛选和页码内，保持选中，主按钮变为“使用”。若原筛选为未激活等导致成功项被移出结果，按列表规则选择有效条目；不能为保持按钮而显示不符合筛选条件的项。

### 使用与替换

点击“使用”直接使用选中的已激活幻化，不再弹出材料确认或同类替换确认。成功后只更新该分类的实际外观选择，主按钮变为禁用的“使用中”，列表仍显示“已激活”。

同类原来使用的幻化保留资格与收益，仅停止作为当前外观；其他分类不变。不再次消耗材料，不重复给予激活收益。操作未成功时，不把预览结果当作实际使用成功。

### 隐藏与恢复称号

“隐藏称号”操作对象是角色当前实际显示的称号，可能与正在预览的称号不同。例如角色正在显示甲称号，玩家选中了已激活的乙称号，再点隐藏，隐藏的是甲的实际显示；中间仍预览乙。

隐藏成功后，角色没有实际显示称号；原已激活称号保持已激活，永久收益不变，其他称号的激活状态不变。选中的已激活称号主按钮为“使用”，隐藏副按钮禁用，中间预览保留。

再次点击“使用”即可显示当前选中的称号，也可以先选另一件已激活称号再使用。恢复显示沿用主按钮，不另做“显示称号”按钮；隐藏和恢复均不弹确认框。

## 七 数据变化与操作结果刷新

| 发生的变化 | 必须刷新的内容 | 不能发生的变化 |
| --- | --- | --- |
| 获得或失去某种激活材料 | 受影响条目的未拥有／未激活状态、筛选结果、材料提示和激活按钮 | 已激活状态不能因材料不足回退 |
| 某件激活成功，消耗共享材料 | 本件资格与收集数，以及其他共用材料幻化的状态和按钮 | 不只刷新成功的这一件而保留其他过期状态 |
| 使用某件成功 | 对应分类实际外观与当前详情按钮 | 不变更其他分类，不增加收集数或再次奖励 |
| 隐藏称号成功 | 实际称号显示、主副按钮 | 不清空称号预览，不失去资格或收益 |
| 数据变化使选中项移出当前结果 | 有效页码、该页选中项、预览、详情和按钮 | 不保留上一件的操作按钮去操作新的选中项 |
| 关闭后重新打开面板 | 用当前资格、库存和外观选择刷新原界面位置 | 不沿用关闭前已过期的数量和按钮状态 |

前台依据实际结果显示成功。同一笔操作处理中不重复提交；使用、激活、隐藏的反馈必须对应各自的目标幻化，不能因切换选择而把甲的成功提示写成乙。关闭面板或切换页面不撤销已经提交的操作；重新显示时采用实际结果。

## 八 空结果与异常反馈

### 空结果

搜索、筛选后没有条目时，列表显示“暂无符合条件的幻化”，页码为第1／1页，翻页按钮禁用。预览内容、详情状态、名称、说明、收益、来源和按钮清空，保留三栏框架与标题。

搜索框和筛选仍可操作，玩家可清空搜索或切回全部。不得显示上一件的模型、材料或激活按钮，也不新增清空角色外观的动作。

### 反馈文案与显示方式

成功和明确业务失败使用项目统一的短提示，不再弹一个结果确认框。常驻区域只保留已经确认的界面内容，短提示不转成新的说明栏。

| 场景 | 提示文字 | 后续界面 |
| --- | --- | --- |
| 激活成功 | 已激活「{幻化名称}」 | 刷新资格、材料、收集数与按钮；不自动使用 |
| 使用成功 | 已使用「{幻化名称}」 | 刷新该分类实际选择与按钮 |
| 隐藏称号成功 | 已隐藏称号 | 主按钮为使用，隐藏按钮禁用 |
| 确认激活时缺料 | 所需道具不足 | 按实际库存刷新；不部分扣料 |
| 重复激活已激活项 | 该幻化已激活 | 刷新为已激活，不重复消耗或奖励 |
| 使用资格不满足 | 该幻化尚未激活 | 恢复实际状态，不切换外观 |
| 配置或资源无法满足操作 | 幻化配置异常，暂时无法操作 | 不显示已使用或激活成功；保留实际资格与选择 |

数据尚未就绪时，不根据空数据把所有条目判成“未拥有”，不开放依赖资格和库存的操作。系统级错误沿用统一反馈，不把系统错误一律说明为材料不足，也不擅自宣告已经扣料或尚未扣料；取得实际结果后刷新。

## 九 界面数据对应与前后台交接

| 界面需要的信息 | 对应内容 | 用来解决什么问题 |
| --- | --- | --- |
| 幻化基础资料 | `id`、`category`、`name`、`icon_id`、`model_id`、`desc` | 分类、列表、选中项、预览和说明来自同一件幻化 |
| 模型表现资料 | `attach_point`、`scale`及分类显示规则 | 预览和实际显示采用正确资源、对象和比例 |
| 激活需求与来源 | `unlock_items`、`source_desc`及各物品资料 | 全材料展示、道具提示、状态与确认成本一致 |
| 激活收益 | `attrs`、`skill_id`、`affix_id`及相应名称和单位资料 | 详情不漏掉属性、技能或词条 |
| 角色永久资格 | 已激活幻化集合 | 区分永久资格与仅仅持有材料 |
| 角色外观选择 | 各分类当前使用项，以及称号是否无显示 | 决定使用中按钮和实际外观，不误用界面选中项 |
| 实际材料数量 | 各需求物品当前可用数量 | 计算三种状态与材料提示，及时刷新共享材料 |
| 本次操作结果 | 操作类型、目标幻化及实际结果 | 正确更新对应条目，防止切换选择后反馈错对象 |

资格、消耗、奖励与可用性由实际业务结果确定，前台负责展示、预检和反馈。具体接口名称、存储字段与程序结构由实现团队确定，本案不另造一套协议。

## 十 与原型和美术稿的对应边界

单文件原型用于确认分类、选择、预览、状态、激活确认、多材料消耗、使用、称号隐藏、筛选与分页。内嵌图片、称号文字效果、初始已激活项及材料库存都是演示内容，不能当作正式资源或角色初始资格。正式外观按策划案的图标与模型规则读取。

原型以本地即时变化演示操作；实际接入还要按本案处理数据未就绪、处理中与结果反馈，不用演示页面刷新后的数据重置替代角色保存。

美术面板系统标题统一为“幻化”，沿用既定布局。美术稿若仍保留单一道具或隐藏后“使用中＋显示称号”的旧状态，应按本案与最终原型表现：全部激活材料同时展示；隐藏后主按钮为“使用”，隐藏副按钮禁用。其余已经确认的整体风格与三栏布局沿用。

幻化界面不增加称号升级、分件穿戴、模型展示部位示意、底部当前装备汇总、上下马或坐骑养成功能。
