# 炼丹系统交互案
## 一、交互目标
玩家在同一个炼丹面板中完成两类操作：

一、交互目标：丹方炼丹：载入系统默认配方或玩家保存配方，直接自动炼制，可选择批量数量。

一、交互目标：手动炼丹：选择丹理或自由研制，逐份配置材料并形成真实入炉顺序，只能单枚炼制，可保存有效配方。

面板必须持续回答四件事：当前材料构成什么丹、为什么能或不能成丹、每份材料按什么顺序入炉、正式炼制将消耗多少材料。

## 二、界面结构
```text
炼丹主面板
├─ 顶部
│  ├─ 境界下拉
│  ├─ 标题：炼丹
│  └─ 丹炉下拉
├─ 左栏
│  ├─ 丹方炼丹 / 手动炼丹
│  ├─ 丹方列表
│  └─ 丹方翻页
├─ 中栏
│  ├─ 君、臣、佐、使、丹头
│  ├─ 丹炉
│  ├─ 实时炼丹状态
│  └─ 炼制数量
├─ 右栏
│  ├─ 材料背包
│  ├─ 手动炼丹筛选与药力排序
│  └─ 材料翻页
└─ 底栏
   ├─ 入炉顺序
   ├─ 保存配方（仅手动炼丹）
   └─ 开始炼丹
```

底栏横跨左栏至“开始炼丹”按钮的全部宽度。入炉顺序使用按钮左侧的全部可用宽度连续排列，不设置翻页。

## 三、公共规则
### 3.1 境界
三、公共规则：境界下拉包含：炼气、筑基、金丹、元婴、化神、炼虚、合体、大乘。

三、公共规则：面板首次打开及正常关闭后重开，境界筛选默认选择炼气；界面重建保留当前筛选，不自动切到角色当前境界。

三、公共规则：炼气当前只开放炼气聚元丹这一款平性凡品修为丹；取得丹方后可反复使用固定配方炼制，君、臣、佐、使、丹头各一份，不增加品质选择，不升品。丹方列表按一个基础丹方展示，不按品质拆分丹方道具。师父指导不另设专用炼丹入口。

三、公共规则：境界筛选控制左侧丹方和右侧材料；丹炉下拉始终显示玩家已拥有的全部丹炉。

三、公共规则：右侧材料显示所选境界的全部品质。

三、公共规则：切换境界后清空当前草稿、批量数量复位为 1、丹方和材料翻页位置复位到第一页。

### 3.2 丹炉
3.2 丹炉：丹炉使用下拉选择，不使用左右切换箭头。

3.2 丹炉：下拉列出玩家已拥有的全部丹炉；最高可炼境界低于当前所选境界的丹炉保留显示并置灰，悬停提示“最高可炼X，无法炼制Y境丹方”。

3.2 丹炉：丹炉品质低于当前基础丹方品质时保留显示并标明“丹炉品质不足”，说明最高可炼品质，禁止开始炼丹；不以降低成丹率代替禁止。目标品质由当前君材和丹方确定，未确定时不伪造品质判断。

3.2 丹炉：切换丹炉后重新校验境界、品质、神识门槛、可承受药性与入炉顺序，刷新目标品质基础除渣、匹配五行额外除渣、跨境影响、剩余杂质、纯度和成丹率。

3.2 丹炉：丹方炼丹使用系统默认配方时，切炉后重新搜索安全入炉顺序。

3.2 丹炉：使用玩家保存配方时，保留其已保存的入炉顺序并重新校验。

3.2 丹炉：丹炉按最高可炼境界向下兼容，不要求与目标丹药同境界。凡品青烟炉最高可炼筑基丹药，满足品质、神识和炉膛条件时，也可以炼制炼气凡品聚元丹，无需另配炼气专属丹炉。

3.2 丹炉：炼气角色不显示“需筑基开放”的限制。功能已开启但未持有丹炉时，提示“尚未拥有可用丹炉”并阻止开始炼制；持有后仍须通过最新配方预览。

3.2 丹炉：不自动赠送丹方、灵植或丹炉；第一只丹炉的任务、商店等获得渠道另行配置，不能把“持有后可炼”视为玩家已经能够取得。

### 3.3 品质
3.3 品质：左侧丹方不提供品质选项。

3.3 品质：系统默认配方使用该基础丹方当前开放的最低品质行。

3.3 品质：玩家保存配方使用保存时君材确定的品质。

3.3 品质：手动炼丹的基础成丹品质由君材品质确定。

3.3 品质：纯度不直接改变基础品质；成丹后若升品，展示实际最终品质。

### 3.4 配置阶段与正式炼制
3.4 配置阶段与正式炼制：配置、增减材料、切换丹炉、翻页、保存配方均不扣材料。

3.4 配置阶段与正式炼制：点“开始炼丹”后先进入确认弹窗。

3.4 配置阶段与正式炼制：玩家确认后一次性扣除本次全部材料和丹头，随后正式结算。

3.4 配置阶段与正式炼制：正式炼制失败不退材料。

3.4 配置阶段与正式炼制：前台预览只提供即时反馈，以正式校验和结算结果为准。

## 四、左栏
### 4.1 页签
左栏只有两个页签：

| 页签 | 内容 |
|---|---|
| 丹方炼丹 | 系统丹方及该丹方当前使用的自动配方 |

| 页签 | 内容 |
|---|---|
| 手动炼丹 | 置顶“自由研制”及全部已开放丹理 |

玩家保存配方归入对应丹方，并替换该丹方的系统默认配方。

### 4.2 丹方列表
4.2 丹方列表：列表按当前境界筛选。

4.2 丹方列表：按 `recipe_id` 归为基础丹方，每组只显示一次，不按 `id` 品质行拆成多条；同组只保留一套玩家配方。

4.2 丹方列表：列表支持左右翻页，翻页按钮位于列表标题右侧。

4.2 丹方列表：丹药不使用“一阶、二阶、三阶”等称呼。

4.2 丹方列表：点击丹方同时选中并展开；再次点击可收起详情。

### 4.3 丹方炼丹中的展开内容
```text
丹名
丹理：五行 X，五味 X，药性 X，药力 X
丹效：按 pill_effects 有效数组项的配置顺序展示
配方：君材、丹头、臣材、佐材、使材及各自数量
```

4.3 丹方炼丹中的展开内容：系统默认配方显示最低开放品质行的丹理和配方。

4.3 丹方炼丹中的展开内容：`head_id=0` 时配方文本显示“丹头：均可”；载入后由系统选择同境、同品质、容量足够的实际丹头，优先库存最多、同库存按 ID。

4.3 丹方炼丹中的展开内容：`head_id>0` 时配方文本和实际装入均显示指定丹头。

4.3 丹方炼丹中的展开内容：丹效按当前实际使用的丹方品质行读取。

4.3 丹方炼丹中的展开内容：无有效丹效时显示“丹效待配置”，不固定保留三个空槽，不从 `effect_desc` 推导药效。已填写但错误的效果不能被当作空项放行服用。

4.3 丹方炼丹中的展开内容：玩家已经保存配方时，显示玩家配方并标记“玩家配方”。

4.3 丹方炼丹中的展开内容：玩家配方失效时仍原样装入并显示具体失败原因，不自动切回系统配方。

4.3 丹方炼丹中的展开内容：玩家可执行“恢复系统配方”；恢复后删除该丹方的玩家配方，重新使用系统默认配方。

### 4.4 点击丹方炼丹中的丹方
点击后执行：

4.4 点击丹方炼丹中的丹方：1. 读取系统默认配方或玩家配方；普通系统方按当前丹头条件选择实际丹头。

4.4 点击丹方炼丹中的丹方：2. 按保存的入炉顺序装入正好炼制 1 枚所需的君、臣、佐、使和丹头。

4.4 点击丹方炼丹中的丹方：3. 中栏显示单枚材料数量。

4.4 点击丹方炼丹中的丹方：4. 底栏显示单枚入炉顺序。

4.4 点击丹方炼丹中的丹方：5. 重新计算全部炼丹状态。

4.4 点击丹方炼丹中的丹方：6. 右侧背包切为只读材料总览。

若材料不足，仍显示完整配方和缺少的材料，但“开始炼丹”不可用。

### 4.5 手动炼丹中的丹方
4.5 手动炼丹中的丹方：“自由研制”固定置顶。

4.5 手动炼丹中的丹方：其展开区只显示：`臣药应五行，使药应五味，药性合度，药力既足，则丹可成矣。`

4.5 手动炼丹中的丹方：自由研制不显示丹效、目标丹名或技术性配置说明。

4.5 手动炼丹中的丹方：其他丹方展开后显示丹理和丹效，不自动装入材料，也不清空或修改当前草稿。

4.5 手动炼丹中的丹方：“自由研制”与其他丹理的切换都只改变左栏阅读内容，不改动当前草稿。选择某条丹理只用于玩家参考，不锁定最终结果；实际成丹仍按当前材料真实形成的五行、五味、药性、君材品质与丹头定位。

## 五、右栏材料背包
### 5.1 丹方炼丹
五、右栏材料背包：显示当前境界全部材位、全部品质的材料和拥有数量。

五、右栏材料背包：不显示材位筛选、五行筛选、五味筛选、药性筛选、搜索框和药力排序。

五、右栏材料背包：材料卡不可点击、不可拖动、不可改变当前配方。

五、右栏材料背包：材料卡支持悬停 TIPS，显示名称、材位、境界、品质、五行或五味、药力、药性、绝对杂质、丹头承药份数和拥有数量中的适用字段。

五、右栏材料背包：支持左右翻页。

### 5.2 手动炼丹
第一行材位筛选：`君 / 臣 / 佐 / 使 / 丹头`。

第二、三行根据材位显示：

| 当前材位 | 第二行 | 第三行 |
|---|---|---|
| 君 | 无 | 无 |

| 当前材位 | 第二行 | 第三行 |
|---|---|---|
| 臣 | 五行：全部、金、木、水、火、土 | 药性：全部、−4 至 +4 |

| 当前材位 | 第二行 | 第三行 |
|---|---|---|
| 佐 | 无 | 药性：全部、−4 至 +4 |

| 当前材位 | 第二行 | 第三行 |
|---|---|---|
| 使 | 五味：全部、酸、苦、甘、辛、咸 | 药性：全部、−4 至 +4 |

| 当前材位 | 第二行 | 第三行 |
|---|---|---|
| 丹头 | 无 | 无 |

5.2 手动炼丹：不提供搜索框。

5.2 手动炼丹：只提供一个药力升降序箭头，不显示“药力排序”文字。

5.2 手动炼丹：筛选、排序和当前境界共同作用。

5.2 手动炼丹：支持左右翻页。

### 5.3 手动投料
5.3 手动投料：单击材料卡：将材料加入对应材位。

5.3 手动投料：拖动材料卡至对应材位：结果与单击相同。

5.3 手动投料：君材和丹头再次选择时直接替换原材料，数量恒为 1。

5.3 手动投料：臣佐使每次单击、拖入或点加号，在投药顺序末尾加入一份该材料。

5.3 手动投料：点减号删除该材料最后加入的一份。

5.3 手动投料：数量降为 0 后，该材料卡从中栏消失。

5.3 手动投料：达到丹头承药上限后，臣佐使不再允许增加，并提示“丹头承药已满”。

5.3 手动投料：达到背包拥有数量后不再允许增加，并提示“药材不足”。

## 六、中栏材料与丹炉
### 6.1 材位
中栏保留君、臣、佐、使和丹头五个材位。

六、中栏材料与丹炉：君材固定 1 份，不显示加减号。

六、中栏材料与丹炉：丹头固定 1 个，不显示加减号。

六、中栏材料与丹炉：臣佐使允许同时存在多种材料。

六、中栏材料与丹炉：每种材料显示名称和当前填入数量。

六、中栏材料与丹炉：手动炼丹时，每种臣佐使材料显示独立的减号和加号。

六、中栏材料与丹炉：当前操作材料置于其材位最前方并高亮，其他同材位材料顺次后排。

六、中栏材料与丹炉：丹方炼丹时，中栏数量随炼制数量同步放大，但入炉顺序仍只展示单枚模板。

### 6.2 丹炉表现
6.2 丹炉表现：丹炉位于中栏中央。

6.2 丹炉表现：当前药性偏寒、偏热、越界时可使用不同炉火表现，但表现不参与规则判定。

6.2 丹炉表现：炉火状态只能读取当前预览结果，不自行推断最终结果。

## 七、实时炼丹状态
状态区位于丹炉上方或与丹炉中央状态板同一视觉区域，不显示“炉内状态”标题。

每项必须单行展示：

| 行 | 显示内容 |
|---|---|
| 丹炉可承受药性 | `−2~+2（寒~热），当前 0（平）` |

| 行 | 显示内容 |
|---|---|
| 药力 | `当前 P / 达标 U`；不足时显示还差多少 |

| 行 | 显示内容 |
|---|---|
| 当前五行 | 当前臣材形成的五行 |

| 行 | 显示内容 |
|---|---|
| 当前五味 | 当前使材形成的五味 |

| 行 | 显示内容 |
|---|---|
| 当前杂质 | 剩余杂质 D、纯度 Q、最低纯度 Qmin |

| 行 | 显示内容 |
|---|---|
| 成丹率 | 全部成丹条件满足后显示；否则显示“不可成丹：原因” |

| 行 | 显示内容 |
|---|---|
| 预计成丹 | 丹名与品质、`？？？？` 或“此配法无法成丹” |

| 行 | 显示内容 |
|---|---|
| 炼制数量 | 数量减号、数值、加号及当前批量上限 |

### 7.1 状态颜色
7.1 状态颜色：满足条件：青玉色。

7.1 状态颜色：不满足条件：对应整行转暗朱红。

7.1 状态颜色：尚不能计算：灰色，不显示伪造数值。

7.1 状态颜色：成丹率只有在君材、丹头、五行、五味、最终药性、药力、纯度、丹炉和库存全部满足后显示具体数值。

### 7.2 过程反馈与首个失败原因
7.2 过程反馈与首个失败原因：投料操作先执行即时检查：材位不符时拒绝落位；库存已用尽或丹头容量已满时拒绝继续增加。每次加入材料都重新请求预览；完成前置检查后才计算投药轨迹。计算发现越界时保留当前草稿，将对应步骤标红；步骤格仍只显示材料自身药性，悬停错误提示显示“偏寒／偏热”。

玩家可通过减去某材料最后一份并按新顺序重新加入来修正。

预览遇到第一项错误就停止计算，显示首个失败原因，保留停止前已经返回的有效结果。后续项不继续推算，即使其中部分能够根据已有材料确定。未计算项显示灰色“—”或“待定位”，不能把未计算项的零值显示为实际药力、杂质、纯度或成丹率；修正该错误后重新预览，再展示下一项结果。

每次预览时，“成丹率”行按以下顺序显示当前首个阻断原因：

7.2 过程反馈与首个失败原因：1. 缺少君材。

7.2 过程反馈与首个失败原因：2. 缺少丹头。

7.2 过程反馈与首个失败原因：3. 缺少臣材。

7.2 过程反馈与首个失败原因：4. 缺少使材。

7.2 过程反馈与首个失败原因：5. 丹炉最高可炼境界不足。

7.2 过程反馈与首个失败原因：6. 丹炉品质不足。

7.2 过程反馈与首个失败原因：7. 神识不足以驱动丹炉。

7.2 过程反馈与首个失败原因：8. 投药过程药性越出丹炉范围。

7.2 过程反馈与首个失败原因：9. 臣材五行不唯一。

7.2 过程反馈与首个失败原因：10. 使材五味不唯一。

7.2 过程反馈与首个失败原因：11. 无法定位丹方。

7.2 过程反馈与首个失败原因：12. 指定丹头不符。

7.2 过程反馈与首个失败原因：13. 丹方炼丹的最终药性未精确命中。

7.2 过程反馈与首个失败原因：14. 药力不足。

7.2 过程反馈与首个失败原因：15. 纯度不足。

7.2 过程反馈与首个失败原因：16. 材料库存不足。

正式办理仍校验材料ID、材位、境界、品质、丹头容量和批次数量；这些正常前台不可构造的异常只使用兜底文案，不占用主面板状态行。所有条件的玩家文案见 §15.1。

“开始炼丹”按钮前不另设一块重复的红色失败原因区。

### 7.3 预计成丹
预计成丹按当前境界、臣材五行、使材五味、最终药性、君材品质与实际丹头定位对应丹方品质行。

7.3 预计成丹：已经炼制成功过：显示丹名和成丹品质。

7.3 预计成丹：从未炼制成功过：显示 `？？？？` 和成丹品质。

### 7.4 五行除渣与最新预览

前置条件全部通过的预览必须计入所有有效来源与适用倍率，不能只显示同境基础值，也不能把五行除渣率直接加到纯度或成丹率。旧预览不能覆盖当前配料结果；未取得最新有效预览时不能开始炼丹。

材料名称和图标经物品关联读取，成品取实际最终品质行 `wupin_id2` 对应物品；灵植 ID、丹效品质行 ID、丹方分组 ID 不直接当作物品 ID。标注“实际上交贡献”时展示本枚实际可得的宗门上交贡献，不直接显示基础贡献。

### 13.1.1 普通丹药与突破丹入口
使用“丹药”时，没有有效丹效则禁止直接服用，提示“无法直接服食”，数量保持不变，不增加杂质；丹效详情仍显示“丹效待配置”。已填写但错误的丹效显示配置异常，不能跳过错误后部分执行。

使用“突破丹”时进入突破准备面板，不立即消耗、不增加杂质、不提前获得加成，也不自动选入该枚丹药。后续材料填充、单枚额外丹药选择与正式消耗按突破交互执行；入口不得绕过当前突破条件。不能因普通丹效为空自动识别为突破丹。

三态服用展示只适用于具备有效普通丹效并通过配置校验的丹药；无有效丹效时不显示可确认的普通服药预览。

### 13.2 服用三态
| 状态 | 条件 | 表现 |
|---|---|---|

丹药详情显示实际剩余杂质；服用时按最终品质行 `toxin_factor` 折算本枚入池量，再按使味进入对应丹毒池，不能直接将剩余杂质显示为入池量。系数为 `0` 或负数时不产生丹毒，丹药自身的剩余杂质、纯度与上交贡献不因此改变。减半倍率及各行为取整按实际服药结果展示，不另改服药规则。

炼气同样显示按丹毒池配置读取的五味池容量、占用与消退；炼气聚元丹按正式服丹规则结算少量丹毒，不按境界显示为无毒池。
