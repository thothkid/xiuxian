# 炼丹界面交互
炼丹交互案负责面板信息、材料操作、配方选择、结果与服药反馈。固定设计分辨率为 1344×756；公式、配置字段定义与丹毒判定由炼丹规则拥有，界面展示实际预览和结算结果。

## 交互目标
玩家在同一个炼丹面板中完成两类操作：
- 丹方炼丹：载入系统默认配方或玩家保存配方，直接自动炼制，可选择批量数量。
- 手动炼丹：选择丹理或自由研制，逐份配置材料并形成真实入炉顺序，只能单枚炼制，可保存有效配方。

面板必须持续回答四件事：当前材料构成什么丹、为什么能或不能成丹、每份材料按什么顺序入炉、正式炼制将消耗多少材料。

## 界面结构
炼丹面板顶部保留境界、标题和丹炉选择。左栏为丹方炼丹与手动炼丹页签、丹方列表及翻页；中栏为君臣佐使、丹头、丹炉、实时状态与炼制数量；右栏为材料背包、手动筛选与药力排序。
底栏展示入炉顺序、仅手动可见的保存配方按钮及开始炼丹按钮。入炉顺序使用开始按钮左侧的全部可用宽度连续排列，不设置翻页。

## 公共规则·境界
- 境界下拉包含：筑基、金丹、元婴、化神、炼虚、合体、大乘。
- 境界筛选控制左侧丹方和右侧材料；丹炉下拉始终显示玩家已拥有的全部丹炉。
- 右侧材料显示所选境界的全部品质。
- 切换境界后清空当前草稿、批量数量复位为 1、丹方和材料翻页位置复位到第一页。

## 公共规则·丹炉
- 丹炉使用下拉选择，不使用左右切换箭头。
- 下拉列出玩家已拥有的全部丹炉；最高可炼境界低于当前所选境界的丹炉保留显示并置灰，悬停提示“最高可炼X，无法炼制Y境丹方”。
- 丹炉品质低于当前基础丹方品质时保留显示并标明“丹炉品质不足”，说明最高可炼品质，禁止开始炼丹；不以降低成丹率代替禁止。目标品质由当前君材和丹方确定，未确定时不伪造品质判断。
- 切换丹炉后重新校验境界、品质、神识门槛、可承受药性与入炉顺序，刷新目标品质基础除渣、匹配五行额外除渣、跨境影响、剩余杂质、纯度和成丹率。
- 丹方炼丹使用系统默认配方时，切炉后重新搜索安全入炉顺序。
- 使用玩家保存配方时，保留其已保存的入炉顺序并重新校验。

## 公共规则·品质
- 左侧丹方不提供品质选项。
- 系统默认配方使用该基础丹方当前开放的最低品质行。
- 玩家保存配方使用保存时君材确定的品质。
- 手动炼丹的实际成丹品质由君材品质确定。
- 纯度不直接改变基础成丹品质；成功后若发生升品，展示实际最终品质。

## 公共规则·配置阶段与正式炼制
- 配置、增减材料、切换丹炉、翻页、保存配方均不扣材料。
- 点“开始炼丹”后先进入确认弹窗。
- 玩家确认后一次性扣除本次全部材料和丹头，随后正式结算。
- 正式炼制失败不退材料。
- 预览提供即时反馈，正式炼制仍须按当前状态重新检查和结算。

## 左栏·页签
左栏只有两个页签：
| 页签 | 内容 |
|---|---|
| 丹方炼丹 | 系统丹方及该丹方当前使用的自动配方 |
| 手动炼丹 | 置顶“自由研制”及全部已开放丹理 |
玩家保存配方归入对应丹方，并替换该丹方的系统默认配方。

## 左栏·丹方列表
- 列表按当前境界筛选。
- 丹方列表按 recipe_id 分组，每组只显示一次，不按 id 品质行拆成多条；一组只保留一套玩家配方。
- 列表支持左右翻页，翻页按钮位于列表标题右侧。
- 丹药不使用“一阶、二阶、三阶”等称呼。
- 点击丹方同时选中并展开；再次点击可收起详情。

## 左栏·丹方炼丹中的展开内容
丹方展开区显示丹名、丹理、有效丹效、各材位材料与数量。丹理包含五行、五味、药性和目标药力；系统默认配方显示最低开放品质的有效模板。
丹效按实际使用品质行 pill_effects 数组的配置顺序展示，加属性显示效果值，技能、BUFF、词条使用对应效果说明。没有有效丹效时显示“丹效待配置”，不将白话作用说明当作实际效果。

## 左栏·丹头与玩家配方标识
丹方不指定丹头时，配方文字显示“丹头：均可”，实际投料展示选中的丹头；指定丹头时显示其名称。使用玩家配方时标记“玩家配方”；失效时仍显示原配方和具体原因，不自动换回系统配方。玩家执行“恢复系统配方”后再显示系统模板，缺失的默认投料不由界面补齐。

## 左栏·点击丹方炼丹中的丹方
点击后执行：
1. 读取系统默认配方或玩家配方；普通系统方展示已确定的实际丹头。
2. 按保存的入炉顺序装入正好炼制 1 枚所需的君、臣、佐、使和丹头。
3. 中栏显示单枚材料数量。
4. 底栏显示单枚入炉顺序。
5. 重新计算全部炼丹状态。
6. 右侧背包切为只读材料总览。
若材料不足，仍显示完整配方和缺少的材料，但“开始炼丹”不可用。

## 左栏·手动炼丹中的丹方
- “自由研制”固定置顶。
- 其展开区只显示：`臣药应五行，使药应五味，药性合度，药力既足，则丹可成矣。`
- 自由研制不显示丹效、目标丹名或技术性配置说明。
- 其他丹方展开后显示丹理和丹效，不自动装入材料，也不清空或修改当前草稿。
- “自由研制”与其他丹理的切换都只改变左栏阅读内容，不改动当前草稿。选择某条丹理只用于玩家参考，不锁定最终结果；实际成丹仍按当前材料真实形成的五行、五味、药性、君材品质与丹头定位。

## 右栏材料背包·丹方炼丹
- 显示当前境界全部材位、全部品质的材料和拥有数量。
- 不显示材位筛选、五行筛选、五味筛选、药性筛选、搜索框和药力排序。
- 材料卡不可点击、不可拖动、不可改变当前配方。
- 材料卡支持悬停 TIPS，显示名称、材位、境界、品质、五行或五味、药力、药性、绝对杂质、丹头承药份数和拥有数量中的适用字段。
- 支持左右翻页。

## 右栏材料背包·手动炼丹
第一行材位筛选：`君 / 臣 / 佐 / 使 / 丹头`。
第二、三行根据材位显示：
| 当前材位 | 第二行 | 第三行 |
|---|---|---|
| 君 | 无 | 无 |
| 臣 | 五行：全部、金、木、水、火、土 | 药性：全部、−4 至 +4 |
| 佐 | 无 | 药性：全部、−4 至 +4 |
| 使 | 五味：全部、酸、苦、甘、辛、咸 | 药性：全部、−4 至 +4 |
| 丹头 | 无 | 无 |
- 不提供搜索框。
- 只提供一个药力升降序箭头，不显示“药力排序”文字。
- 筛选、排序和当前境界共同作用。
- 支持左右翻页。

## 右栏材料背包·手动投料
- 单击材料卡：将材料加入对应材位。
- 拖动材料卡至对应材位：结果与单击相同。
- 君材和丹头再次选择时直接替换原材料，数量恒为 1。
- 臣佐使每次单击、拖入或点加号，在入炉顺序末尾追加一份该材料。
- 点减号删除该材料最后加入的一份。
- 数量降为 0 后，该材料卡从中栏消失。
- 达到丹头承药上限后，臣佐使不再允许增加，并提示“丹头承药已满”。
- 达到背包拥有数量后不再允许增加，并提示“药材不足”。

## 中栏材料与丹炉·材位
中栏保留君、臣、佐、使和丹头五个材位。
- 君材固定 1 份，不显示加减号。
- 丹头固定 1 个，不显示加减号。
- 臣佐使允许同时存在多种材料。
- 每种材料显示名称和当前填入数量。
- 手动炼丹时，每种臣佐使材料显示独立的减号和加号。
- 当前操作材料置于其材位最前方并高亮，其他同材位材料顺次后排。
- 丹方炼丹时，中栏数量随炼制数量同步放大，但入炉顺序仍只展示单枚模板。

## 中栏材料与丹炉·丹炉表现
- 丹炉位于中栏中央。
- 当前药性偏寒、偏热、越界时可使用不同炉火表现，但表现不参与规则判定。
- 炉火状态只能读取当前预览结果，不自行推断最终结果。

## 实时炼丹状态
状态区位于丹炉上方或与丹炉中央状态板同一视觉区域，不显示“炉内状态”标题。

每项必须单行展示：
| 行 | 显示内容 |
|---|---|
| 丹炉可承受药性 | `−2~+2（寒~热），当前 0（平）` |
| 药力 | `当前 P / 达标 U`；不足时显示还差多少 |
| 当前五行 | 当前臣材形成的五行 |
| 当前五味 | 当前使材形成的五味 |
| 当前杂质 | 剩余杂质 D、纯度 Q、最低纯度 Qmin |
| 成丹率 | 全部成丹条件满足后显示；否则显示“不可成丹：原因” |
| 预计成丹 | 丹名与品质、`？？？？` 或“此配法无法成丹” |
| 炼制数量 | 数量减号、数值、加号及当前批量上限 |

## 实时炼丹状态·状态颜色
- 满足条件：青玉色。
- 不满足条件：对应整行转暗朱红。
- 尚不能计算：灰色，不显示伪造数值。
- 成丹率只有在君材、丹头、五行、五味、最终药性、药力、纯度、丹炉和库存全部满足后显示具体数值。

## 实时炼丹状态·投料过程反馈
投料操作先执行即时检查：材位不符时拒绝落位；库存已用尽或丹头容量已满时拒绝继续增加。每次加入材料都重算投药轨迹；出现越界时保留当前草稿，将对应步骤标红；步骤格仍只显示材料自身药性，悬停错误提示显示“偏寒／偏热”。玩家可通过减去某材料最后一份并按新顺序重新加入来修正。

## 实时炼丹状态·阻断原因优先级
每次预览时，“成丹率”行按以下顺序显示当前首个阻断原因：
1. 缺少君材。
2. 缺少丹头。
3. 缺少臣材。
4. 缺少使材。
5. 丹炉最高可炼境界不足。
6. 丹炉品质不足。
7. 神识不足以驱动丹炉。
8. 投药过程药性越出丹炉范围。
9. 臣材五行不唯一。
10. 使材五味不唯一。
11. 无法定位丹方。
12. 指定丹头不符。
13. 丹方炼丹的最终药性未精确命中。
14. 药力不足。
15. 纯度不足。
16. 材料库存不足。

材料身份、材位、境界、品质、丹头容量或批量异常使用对应兜底提示，不另占主面板状态行。界面展示结果返回的失败原因，不从显示名称和编号推断错误。
“开始炼丹”按钮前不另设一块重复的红色失败原因区。

## 实时炼丹状态·预计成丹
预计成丹根据当前境界、臣材五行、使材五味、最终药性、君材品质和实际丹头取得对应结果。
- 已发现丹方显示丹名与成丹品质，未发现显示“？？？？”与成丹品质。
- 指定丹头产生不同丹方时，展示实际丹头对应的结果。
- 未定位到丹方时显示“此配法无法成丹”；指定丹头错误时，成丹率行提示“丹头错误”。
- 已定位但纯度不足时保留丹名或未知标记，杂质行标红，成丹率不显示数值。
丹方发现状态按基础丹方区分，界面不按相同名称或编号差值自行合并品质行。

## 底栏入炉顺序·展示
- 入炉顺序只包含臣佐使，君材固定先入炉，丹头不进入投药序列。
- 每个步骤显示：序号、材料名、该材料自身药性。
- 越出丹炉可承受药性的步骤标红；步骤格仍只显示材料自身药性，悬停错误提示显示偏寒或偏热，不显示累计药性数值。
- 不规定固定显示数量，不自动翻页。
- 入炉步骤使用按钮左侧全部可用宽度，尽量一次展示完整顺序。
- 正式界面的单格宽度与最大可见数量由最终 UI 布局确定；若布局需要调整，优先扩大或压缩顺序区，不增加自动翻页。

## 底栏入炉顺序·顺序生成
| 来源 | 顺序 |
|---|---|
| 系统默认配方 | 载入时由系统搜索安全顺序，本次炼制原样使用 |
| 玩家保存配方 | 读取保存的实际入炉顺序，原样使用 |
| 手动炼丹 | 按每次加入材料的先后形成实际入炉顺序 |

同一组材料的顺序只影响能否安全完成，不改变最终药力、杂质、纯度和丹效。界面不提供拖动重排或删除指定步骤；玩家通过减去某材料最后加入的一份，再按新顺序重新加入来调整顺序。

## 炼制数量·手动炼丹
- 数量固定为 1。
- 减号和加号均禁用。
- 提示“手动固定一枚”。

## 炼制数量·丹方炼丹
- 初始数量为 1。
- 点加号时，君材、丹头和全部臣佐使的中栏显示数量同步按模板倍增。
- 入炉顺序仍显示单枚模板，不将多枚顺序拼接为长列表。
- 批量上限取神识上限与材料可炼套数中的较小值。
- 再加一枚会导致任一材料不足时，加号禁用并提示“药材不足”。
- 点减号同步减少一套材料，最低为 1。

## 保存配方
- “保存配方”只在手动炼丹页签显示。
- 当前配法已定位丹方且所有成丹条件满足时按钮可用。
- 保存时保留所归属的基础丹方、实际君材与丹头、臣佐使投入顺序和君材品质。
- 每个基础丹方只保存一套玩家配方。
- 新保存配方覆盖该丹方原有玩家配方。
- 保存后，该配方进入“丹方炼丹”并替换系统默认配方。
- 玩家可在丹方展开区恢复系统配方。
- 保存不要求先正式炼制成功。
- 保存不扣材料，不直接触发炼制。

## 开始炼丹与确认·按钮
- “开始炼丹”位于右下角。
- 任一硬条件不满足时按钮禁用。
- 手动炼丹时，“保存配方”位于其左侧。
- 主面板不设置“取消”按钮。

## 开始炼丹与确认·确认弹窗
显示：
- 丹名；未发现丹方显示 `？？？？`。
- 基础品质。
- 炼制方式。
- 炼制数量。
- 单枚及总材料消耗，包含丹头。
- 药力与目标药力。
- 剩余杂质与纯度。
- 成丹率与升品率。
- “确认后立即扣除全部材料，失败不退。”
按钮：`返回 / 确认`。

## 开始炼丹与确认·正式结算
- 确认后再次完整校验库存和配置。
- 校验通过后扣除全部材料。
- 批量 N 枚分别判定成丹与升品，可能得到不同数量、不同品质的成品。
- 同一批只播放一次炼制演出。
- 请求处理中禁用重复确认，重复提交不得重复扣料或发放。

## 结果与丹方发现
结果页显示：
- 尝试数量、成功数量、失败数量。
- 按最终品质分组的丹药数量。
- 升品结果。
- 每组丹药的实际剩余杂质与纯度。
- 每组丹药的实际售价。

炼制成功使对应基础丹方变为已发现。之后相同丹方在自由研制的“预计成丹”和确认弹窗中显示真实丹名。
失败不写入发现记录。

## 丹药详情、服用与五味丹毒·丹药详情页
丹药详情可从背包、炼制结果或丹毒面板相关入口打开。顶部显示对应物品的图标、丹名、最终品质、境界和拥有数量。成色区显示该枚丹药的实际纯度、剩余杂质、五味归属与售价。
丹效区按最终品质行 pill_effects 有效数组项的顺序展示：加属性显示实际数值，技能、BUFF、词条显示对应说明。无有效丹效时显示“丹效待配置”，不得以 `effect_desc` 的文字补出效果。

## 丹药详情的服用预览
丹药详情的服用区显示对应毒池当前占用、服后占用、本枚入池量与效果倍率。底部保留“返回／服用”。点击服用后按最新状态取得预览，确认后执行服用；服用可用性按实际准入结果显示，不能因存在物品数量就自动启用按钮。

## 丹药详情、服用与五味丹毒·服用三态
丹药服用展示实际返回的准入状态与效果倍率，界面不另算阈值。
| 服用状态 | 界面表现 |
|---|---|
| 完整生效 | 正常显示效果与服用按钮 |
| 效果减半 | 橙色提示“当前丹毒较高，本枚药效按50%结算”，确认后服用 |
| 禁止服用 | 红色提示“对应丹毒已满”，服用按钮禁用 |
丹药的实际剩余杂质按使味进入对应毒池，详情页与五味丹毒面板展示同一次结算结果。

## 丹药详情、服用与五味丹毒·五味丹毒面板
面板并列显示酸、苦、甘、辛、咸五个毒池。每池显示当前占用、容量、占用万分比、每日消退量和状态色；达到效果减半线转橙，满池转红。面板提供丹毒规则说明和相关丹药入口，不在炼丹主面板重复铺开五个池子。

服用预览展示对应池服用前后占用与效果倍率。正式服用完成后，按实际结算的新五池状态刷新详情页与毒池面板。

## 五行除渣与最新预览
丹炉说明可以展示配置的五行额外除渣能力，本次丹药五行匹配时才计入预览。丹炉、丹方、材料或相关角色状态变化，凡影响五行、品质、境界、熟练度与材料属性的，均刷新预览。

预览必须计入所有有效来源与适用倍率，不能只显示同境基础值，也不能把五行除渣率直接加到纯度或成丹率。旧预览不能覆盖当前配料结果；未取得最新有效预览时不能开始炼丹。

材料名称和图标经物品关联读取，成品取实际最终品质行 `wupin_id2` 对应物品；灵植 ID、丹效品质行 ID、丹方分组 ID 不直接当作物品 ID。标注“实际售价”时展示本枚结算售价，不直接显示基础售价。

## 炼丹预览刷新
炼丹界面只展示与当前材料、丹炉、顺序和数量对应的最新预览结果；较早配置的结果不能覆盖当前显示。预览尚未返回或依赖不足时显示等待或不可计算状态，不保留为可提交的旧结论。材料和丹药的名称、图标取关联物品，不能依靠名称或编号推断规则。

## 异常与反馈·页面级异常
| 场景 | 处理 |
|---|---|

| 正式结算产生新状态 | 用实际结果刷新预览和界面 |

## 普通丹药与突破丹入口
使用“丹药”时，没有有效丹效则禁止直接服用，提示“无法直接服食”，数量保持不变，不增加杂质；丹效详情仍显示“丹效待配置”。已填写但错误的丹效显示配置异常，不能跳过错误后部分执行。

使用“突破丹”时进入突破准备面板，不立即消耗、不增加杂质、不提前获得加成，也不自动选入该枚丹药。后续材料填充、单枚额外丹药选择与正式消耗按突破交互执行；入口不得绕过当前突破条件。不能因普通丹效为空自动识别为突破丹。

三态服用展示只适用于具备有效普通丹效并通过配置校验的丹药；无有效丹效时不显示可确认的普通服药预览。
