# 炼器系统交互案

> 版本：v1.2｜日期：2026-10-17  
> 对应：《炼器交互原型_v0.11.html》。  
> 本案明确炼器四个页签、法宝入口及文档分工，详细解释装备强化、装备炼化及共用装备详情。法宝打造与法宝养炼的详细交互见法宝系统交互案。

## 1. 总体布局

### 1.1 一级页签

标题为“炼器”，一级页签从左到右固定为：**法宝打造／法宝养炼／装备强化／装备炼化**。

| 顺序 | 页签 | 功能与对象 | 详细内容归属 |
|---|---|---|---|
| 1 | 法宝打造 | 选择法宝类型与四种材料，打造法宝 | 法宝系统策划案第6.3节；法宝系统交互案第八章 |
| 2 | 法宝养炼 | 选择已拥有法宝进行祭炼，提升到所选目标境界；器灵、本命保留未开放入口 | 法宝系统策划案第6.2节；法宝系统交互案第七章 |
| 3 | 装备强化 | 消耗固定材料，逐级积累装备属性 | 本案装备强化章节 |
| 4 | 装备炼化 | 消耗固定材料生成一个候选词条，选择保留或替换 | 本案装备炼化章节 |

### 1.2 法宝页面与文档归属

- **法宝打造：**直接呈现法宝系统的打造板子。四材位、共用材料说明、右侧点选、翻页、品质联动及打造确认与结果，完整按《法宝系统交互案.md》第八章执行。
- **法宝养炼：**直接呈现法宝系统的养炼板子，保留祭炼／器灵／本命二级入口。已拥有法宝、目标境界、效果预览、材料费用、成功率、确认与反馈，完整按同一交互案第七章执行。器灵、本命维持未开放状态。
- 法宝两项的详细机制和配置以《法宝系统策划案.md》第6.3节“打造”、第6.2节“祭炼升境界”及相应公共规则为准。

“炼器→法宝养炼”与“法宝→养炼”是同一块操作面板的两个入口。除外层标题和导航归属外，内部结构、操作顺序、材料、按钮、提示和结果一致；不另设计一份炼器专用的祭炼流程。法宝打造同样复用法宝面板的打造板子。

两处入口读取相同的法宝、资源及操作结果。切换入口时刷新当前权威状态；已经提交或结果待确认的操作不因换入口而消失、重抽或再次扣费，详细状态恢复按法宝系统交互案执行。

### 1.3 装备页面三栏框架

以下第2～8章的具体布局与操作只适用于装备强化、装备炼化。两张装备页共用选中装备和三栏框架：

```text
左：选择装备
中：装备头部 → 当前装备信息 → 本次成长对比 → 操作反馈 → 两段说明
右：固定费用 → 本次规则 → 条件提示 → 主操作
```

沿用原型的玄青底色、旧金边框、青玉选中及可操作状态。没有额外的角色境界／炼器等级／总灵石横栏，没有步骤指引横栏，也没有材料自由选择区。

两页的装备列表、详情顺序、右栏费用和主按钮位置一致；右栏规则区分别显示成功率或炼化候选规则。“原型演示（仅供评审）”控件默认折叠。

## 2. 左栏：选择装备

顶部显示“选择装备”和件数。每项有图标、名称、品质、部位、强化等级；存在待选择炼化时显示“结果待确认”。选中项以青玉底和金边强调。

单击只切换装备，不执行强化或炼化；中栏详情、操作预览、右栏费用及状态一起更新。强化页切到炼化页保留当前装备。换装备或切页签时清理上一操作的局部反馈，避免把甲装备的结果显示在乙装备上。

六件演示装备承担以下观察场景，不是正式装备配置清单：

| 装备 | 可观察的内容或状态 |
|---|---|
| 青锋剑 | 灵蕴、器法、道纹、套装、已有炼化及中段强化 |
| 青纹法袍 | 另一种属性和词条组合，未强化、已有炼化 |
| 清心冠 | 有器法，无灵蕴、道纹、套装及炼化 |
| 温玉佩 | 强化＋7上限 |
| 镇灵印绶 | 无器法、无道纹、非套装，未开放炼化 |
| 流云履 | 有灵蕴、道纹，无器法和已有炼化 |

列表底部强化页提示“选择装备后直接强化”，炼化页提示“每件最多保留一条炼化效果”。本原型没有增加搜索、筛选、拖入或双击执行。

## 3. 中栏：装备当前信息

### 3.1 头部

图标固定 **84×84像素**，保留边框和周边留白。右侧依次为：

1. 境界、品质、部位。
2. 装备名称，后跟强化等级，如“青锋剑＋2”。
3. 强化摘要与炼化占用，例如“强化＋2·术法攻击＋2／已炼化·1／1”。

图标与名称是头部主体，长效果描述不挤入此处。无强化显示“未强化”，无炼化显示“未炼化·0／1”。

### 3.2 装备信息区

信息放在一张整体区域内，不为每条效果套一张大卡。

| 顺序 | 信息 | 空态 |
|---|---|---|
| 顶部并列 | 基础属性／灵蕴，分别列名称与数值 | 灵蕴为空显示“无” |
| 器法行 | 固定被动名、被动标识、效果说明 | 无器法 |
| 道纹行 | 掉落词条名、效果说明 | 无道纹 |
| 炼化行 | 当前已采用词条名、效果说明 | 无炼化 |
| 套装区 | 套装名、穿戴件数／总件数、各档奖励 | 非套装装备 |

器法、道纹、炼化按“标签→名称→说明”横向排列，内容过长在对应说明区域换行。套装已激活档点亮、未激活档降低亮度。青云剑装示例显示2／4件，2件档亮、4件档未亮。

这里显示**当前已经拥有的内容**。炼化待选候选不写入此处；采用之后才更新“炼化”一行。灵蕴与道纹不因操作炼化而改名或消失。

### 3.3 操作反馈与两段说明

装备信息之后是成长对比，再下方显示本次成功、失败或保留／替换的反馈。没有结果时不额外留一个大提示框。

底部“道具说明”第一段对应装备 `desc`，第二段对应 `desc1`，风味文字降低亮度。某段为空收起该段，均为空收起说明区。说明不代替上方效果数值。

详情内容超过可见高度时在中栏滚动；右栏操作保持稳定。失败反馈出现后可将说明往下推入滚动区域，不压缩84×84图标或挤窄操作卡。

## 4. 右栏：固定费用与操作规则

顶部“本次消耗”，附“自动扣除”，数量统一为“拥有／需要”。费用行包括图标、名称、材料或货币说明及数量。足够显示青玉色，不足显示暗红色，同时给出文字原因。

强化读取下一等级费用，炼化读取本装备方案费用。材料不可点击更换，没有材料库或“一键放入”。原型统一使用玄铁1＋灵石50的读法示例；正式运行按方案显示，不把这一示例写死到全部装备。

费用下方的规则区在两页保持同一位置：

| 强化页 | 炼化页 |
|---|---|
| 本次成功率，例如60% | 每次产出：1条候选 |
| 失败消耗材料与灵石，等级和累计属性不变 | 扣料后看结果，再选保留或替换；保留不退料 |

底部为条件提示和唯一主按钮。原型用于评审的控件收在主按钮下方折叠区，不占固定费用区域。

## 5. 装备强化

### 5.1 操作前

中栏标题“强化预览”，旁边显示最高等级。左卡“当前强化”列当前等级和累计属性；右卡“下一级预览”列成功后等级、累计属性及本次增量。

初始青锋剑为＋2、累计术法攻击＋2，下一档＋3、累计＋3，本次增加1，右侧成功率60%。＋5到＋6的增量为2，累计按完整等级链计算，不以当前等级乘固定值代替所有方案。

### 5.2 点击强化

1. 条件满足显示“材料齐备，可以强化”，按钮为“强化”。
2. 单击直接执行一次，无材料选择或前置确认弹窗。
3. 成功后更新等级、累计属性、列表、下一档预览、成功率及库存。
4. 失败后只更新库存和失败反馈，当前等级、累计属性、下一目标及成功率不变。

成功与失败都在对比区下方显示持续可读的反馈，并有简短浮动提示。失败使用暗红棕底、左侧标线及明确文字，不只靠颜色判断：

> 强化失败 · 等级仍为＋2，术法攻击累计＋2不变。玄铁×1、灵石×50已消耗。

失败不弹确认窗口，不要求再点击一次才完成扣费。成功后可继续点下一档；失败后可继续尝试同一档。

### 5.3 状态表

| 状态 | 页面与按钮 |
|---|---|
| 未开放强化 | `reinforcement_id`为0或空时，提示“此装备未开放强化”，按钮“不可强化”禁用；不显示下一级预览、成功率及需扣材料或灵石，不扣费 |
| 强化配置异常 | 非零强化方案引用无效或等级链异常时，提示“强化配置异常，暂不可强化”，按钮禁用；不显示无效的下一级预览、成功率及消耗，不扣费，不显示为未开放或已满级 |
| 未强化 | 显示未强化，当前＋0，预览＋1 |
| 可尝试 | 显示费用、下一档和本次成功率，按钮可用 |
| 强化成功 | 等级与累计值更新，显示成功及消耗，预览下一档 |
| 强化失败 | 等级、累计值不变，显示失败及已扣费用，仍预览原目标 |
| 材料不足 | 标红不足项，文字指出材料不足，按钮禁用 |
| 灵石不足 | 标红货币数量，提示灵石不足，按钮禁用 |
| 已满级 | 两卡保持最终等级，提示已达上限；不显示需扣材料，灵石需要数为“—”；按钮“强化已满”禁用 |

## 6. 装备炼化

### 6.1 操作前

中栏标题“装备炼化”，显示位置0／1或1／1。

- 左卡“当前炼化”：已有则列名称与说明；空位显示“尚未炼入”。
- 右卡“本次炼化”：显示问号及“随机产生一条词条，结果弹窗中选择保留或替换”。
- 右栏：固定费用、每次一个候选及保留不退料说明，按钮“开始炼化”。

未开始时不预告具体候选，也不让玩家选定词条再扣料。

### 6.2 点击后弹出结果

条件满足后扣本次材料与灵石，随机生成一个候选，保存后自动弹出“炼化结果”。这时上方当前炼化仍是旧结果，右侧资源已扣除。

弹窗显示装备名，左右分别为“原词条”和“本次结果”，两侧都有名称及完整说明。空位左侧显示“当前无词条”。下方明确提示“本次材料已消耗。保留原词条不退料，替换无需额外消耗”。

| 原状态 | 左按钮 | 右按钮 |
|---|---|---|
| 已有炼化 | 保留原词条 | 替换词条 |
| 没有炼化 | 保留空位 | 炼入词条 |

只有两个选择，没有重抽或关闭按钮。点击遮罩、按Escape不关闭；初始焦点在保留按钮，Tab在两个按钮间循环。弹窗遮住底层操作，先完成当前选择。

### 6.3 选择后的结果

| 选择 | 返回页面后的变化 |
|---|---|
| 保留原词条 | 旧炼化不变，清除候选，显示保留结果；资源不恢复 |
| 替换词条 | “炼化”行及当前卡改为候选，清除候选；不再次扣料 |
| 保留空位 | 仍无炼化，0／1不变，清除候选 |
| 炼入词条 | 显示新词条及说明，状态变1／1，清除候选 |

道纹始终显示在独立的“道纹”一行。候选与原结果相同仍可正常选择，不暗中重抽。选择结束后方可进行下一次炼化。

### 6.4 其他状态

| 状态 | 页面行为 |
|---|---|
| 未开放炼化 | 提示“此装备未开放炼化”，按钮“不可炼化”禁用 |
| 材料或灵石不足 | 显示具体不足项，按钮禁用，不扣费 |
| 结果待确认 | 装备列表有标记，按钮对应“查看炼化结果”；打开本件炼化页恢复同一弹窗，不再抽、不再扣 |
| 恢复会话 | 继续原候选的选择，不能以关闭页面获得免费重抽 |

原型以浏览器本地保存演示结果，刷新后再打开对应装备炼化页即可继续。正式产品由服务端持久保存，不把原型的本地存储当权威存档。

## 7. 评审控件及演示路径

右栏底部“原型演示（仅供评审）”默认折叠。以下控件不进入正式玩家界面：

| 控件 | 用途 |
|---|---|
| 强化演示结果 | 默认按成功率随机，可指定演示成功或失败，便于稳定复现 |
| 材料不足演示／恢复库存 | 模拟材料不足与恢复 |
| 灵石不足演示／恢复灵石 | 模拟货币不足与恢复 |
| 重置装备演示 | 确认后恢复装备、候选和库存；法宝打造不受影响 |
| 原型说明 | 解释固定费用、单候选、演示内容和正式玩法边界 |

推荐观察顺序：

1. 装备强化→青锋剑：核对84×84图标、全部装备内容和60%成功率。
2. 展开演示区，选择“演示失败”，强化一次：等级和累计值保持，玄铁与灵石减少。
3. 再选“演示成功”，强化一次：等级提升，下一档成功率和预览变化。
4. 选温玉佩观察满级；分别切换材料不足、灵石不足观察禁用。
5. 装备炼化→青锋剑：生成一个候选，先保留，再生成并替换，观察费用时点。
6. 选清心冠：观察空位下“保留空位／炼入词条”；选镇灵印绶观察未开放状态。

普通说明窗和重置确认窗可返回，不得把它们的关闭方式套用到待选择的炼化结果窗。

## 8. 显示与数据接入

装备及词条名称、图标、属性与套装内容从配置读取；原型内置样本用于说明本案中的界面与状态。

原型没有真实网络请求。正式接入应遵守项目已有的请求中禁用、错误提示和状态同步规范：未得到服务端确认不显示成功；配置或网络错误不伪装成已扣料的概率失败。此处是接入要求，不新增原型中不存在的弹窗和重试流程。

法宝打造与法宝养炼的具体数据展示、页面状态和操作反馈由《法宝系统交互案.md》第八章与第七章定义；相应机制、配置及结算由《法宝系统策划案.md》定义。炼器面板直接复用，不能将本案的装备费用区或炼化结果弹窗套入法宝页面。

## 9. 交互验收要求

1. 两张装备页的总体结构、选中装备和主按钮位置一致。
2. 装备图标84×84，名字、境界品质、全部当前内容及两段说明有固定归属。
3. 当前效果与未采用候选分清，灵蕴、道纹、器法、强化、炼化名称一致。
4. 右栏费用只读，拥有／需要完整；成功率按下一档显示，满级不提示继续付费。
5. 强化成功正确更新，失败明确显示扣费且不掉级，材料和灵石不足可辨识。
6. 炼化先扣费产出一个候选，再弹二选一；保留不退费、采用不重复扣费。
7. 空位和已有炼化的按钮文案正确，结果窗不能通过Escape或遮罩跳过选择。
8. 恢复的是原候选，不是新随机结果；评审辅助控件与玩家操作分清。
9. 炼器四个页签名称与顺序正确，法宝养炼直接打开已有养炼板子。
10. 法宝打造与养炼的详细交互按法宝系统交互案第八章、第七章验收，器灵、本命仍未开放。
11. 从两个面板进入同一法宝功能时，内部布局、费用、概率、提示和结果一致；切换入口不重复提交、不重扣、不丢失已受理结果。
