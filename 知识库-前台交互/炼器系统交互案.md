# 炼器系统交互案
炼器交互负责打造目录、材料选择、条件提示、确认与结果反馈；数值与消耗判定由炼器规则定义。
## 1. 选择目标
进入打造界面后，目录读取启用且有效的打造配方。

选择目标法宝后，展示：
- 目标名称、图标、境界、品质和效果说明。
- 角色境界、炼器等级要求。
- 成宝核心、主材、辅材、特性材料需求。
- 货币需求。
- 当前条件满足情况。
已拥有的目标明确标记，不能再次确认打造。
## 2. 材料展示与选择
核心和主材显示配置指定的物品及需求数量。

辅材、特性材料显示允许分类、要求境界、要求品质及需求数量。未配置的材料类别不产生缺料提示。

点击可选择的材料栏，打开材料选择界面。候选须同时满足：
- 分类属于本配方允许范围。
- 境界符合目标法宝要求。
- 品质与目标法宝相同。
- 玩家持有可用数量。
成宝核心只按指定物品和品质要求检查，不因其境界标记为通用而排除。
选择后显示实际材料及数量，确认打造前允许替换。
## 3. 库存联动与确认
材料栏中的选择只代表本次投入安排，不立即消耗。

任一材料替换后，刷新全部材料栏的可用数量与满足状态。同一份库存不能在两个栏位中重复占用。
材料、货币或角色条件不足时，明确显示具体原因，禁用确认打造。

确认前完整展示目标成品和本次消耗。确认后锁定本次选择；校验失败时不消耗，解除锁定并显示原因。打造成功后展示实际获得的法宝，并刷新库存与拥有状态。

打造处理中，相关法宝管理操作遵守共用的处理限制。关闭界面不表示取消已经受理的打造；结果未确认时展示处理中或待确认状态，不显示为打造失败，不引导再次扣料打造。
