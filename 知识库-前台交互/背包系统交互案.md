# 背包系统交互案
背包系统交互包括收纳法宝区域、普通分页、全背包分类筛选、锁定与解锁，以及底部操作入口；未另列的基础交互沿用现有规则。

## 一、界面范围
沿用现有背包的外框、格子表现、物品图标、数量显示、钱包和原有道具查看方式。本次调整范围如下：

| 区域 | 本次调整 |
| --- | --- |
| 左侧收纳法宝栏 | 显示已生效收纳法宝及对应已用格数／总容量；点击后查看对应区域 |
| 格子区 | 随当前法宝容量显示格数，增加普通分页与分类结果分页的联动 |
| 右侧分类栏 | 固定为装备、灵植、灵材、丹药、符文、全部 |
| 底部操作区 | 按原型保留仓库、整理、锁定、解锁、便捷设置、上交六个按钮 |
| 锁定操作时的遮罩 | 当前操作窗口之外压暗，明确区分锁定中与解锁中 |

背包总已用格数／总容量与当前法宝已用格数／容量分别显示，不能用其中一个替代另一个；法宝栏显示已有法宝数量。

不增加右上角的炼丹、炼器、宗门或便捷设置入口。原型中的场景切换、重置、操作说明、“移动人物”演示按钮，以及演示用详情和移动控件，不作为新增游戏功能要求。

## 二、收纳法宝与普通分页
### 2.1 自动生效与左侧入口
新收纳法宝进入背包后自动生效：增加背包容量，左侧出现该法宝入口，格子与页数同步反映增加后的空间。不提供“启用收纳法宝”按钮或启用确认弹窗。

初始法宝按相同规则生效；初始格数取实际获得法宝的容量，不固定为40格或80格。法宝名称和示例物品不作为正式发放内容。

点击左侧法宝入口，进入该法宝第一页，显示该区域的实际格子、所存物品及已用／总容量。不同类型收纳法宝均可放入背包允许存放的物品，不设专属物品限制。

### 2.2 翻页与左侧选中联动
每页最多80格。一个法宝不足80格时不补空格；超过80格时继续拆页；不同法宝不拼成一页。

| 操作 | 结果 |
| --- | --- |
| 点击左侧法宝 | 选中该入口，进入该法宝的第一页；若处于分类筛选，则退出分类汇总 |
| 下一页 | 按全部法宝的连续页序前进；当前法宝还有下一页时先翻其内部页，否则进入下一个法宝 |
| 上一页 | 按连续页序后退；当前法宝已经在第一页时，进入前一个法宝的最后一页 |
| 到达首／末页 | 对应方向的翻页按钮禁用，不循环翻页 |

页码表示全部普通页面中的当前位置。每次翻页，左侧选中入口自动对应当前页所属法宝。

以40、80、100格三个法宝为例：

| 页码 | 显示内容 | 格数 | 左侧选中 |
| --- | --- | ---: | --- |
| 第1／4页 | 第一个法宝 | 40 | 第一个法宝 |
| 第2／4页 | 第二个法宝 | 80 | 第二个法宝 |
| 第3／4页 | 第三个法宝前80格 | 80 | 第三个法宝 |
| 第4／4页 | 第三个法宝剩余格子 | 20 | 第三个法宝 |

物品可拖动到其他法宝对应区域，沿用原有移动方式。本案不新增“拖到左侧入口就自动放入首个空格”的落点规则，不改变已有堆叠、交换或拆分操作。

## 三、全背包分类筛选
右侧固定六类：装备、灵植、灵材、丹药、符文、全部。

| 操作或情况 | 显示结果 |
| --- | --- |
| 点击分类 | 从所有乾坤袋收集匹配物品，按分类汇总顺序显示，不只筛当前乾坤袋或当前页 |
| 点击全部 | 汇总所有乾坤袋内的物品，排序后按结果分页 |
| 切换分类 | 显示新分类结果的第一页，更新分类选中、结果数量和页码 |
| 筛选结果翻页 | 每页最多80个物品格，按汇总结果连续翻页，不受法宝边界限制 |
| 点击左侧法宝 | 返回该法宝的普通格子视图 |
| 没有匹配物品 | 显示“暂无对应物品”，页码1／1，翻页禁用 |

100个匹配物品格分为80个、20个两页；一堆物品只算一个结果格。锁定道具仍正常参与展示并标锁。汇总页不标成某一个法宝的专属页面。

分类汇总先显示装备，再显示其他道具。装备先按品质从高到低排列，同品质再按进阶从高到低排列；其他道具按道具编号ID从小到大排列。汇总与排序完成后再按结果分页。

分类只改变显示，不搬动物品，不改变实际位置、容量、数量和已有锁定状态。进入分类后，左侧保留当前选中的乾坤袋及其标识；切换分类或翻阅筛选结果不改选当前乾坤袋，点击整理仍只整理这个乾坤袋。

筛选状态下的拖放细节尚未确定，不以原型演示方式替代现有基础操作规则。

## 四、锁定与解锁
### 4.1 按钮与点击结果
背包、仓库分别提供“锁定”“解锁”两个按钮。进入某个窗口的操作模式后，仅对该窗口内道具执行对应操作。

| 操作模式 | 按钮显示 | 点击未锁定道具 | 点击已锁定道具 |
| --- | --- | --- | --- |
| 锁定中 | 锁定按钮显示“锁定中” | 加锁并显示锁标识 | 提示“已锁定”，不解锁 |
| 解锁中 | 解锁按钮显示“解锁中” | 提示“未锁定”，不加锁 | 解锁并撤去锁标识 |

两种操作不能同时进行；点击另一按钮切换到对应模式。操作模式下点击道具只执行加锁或解锁，不同时触发原有使用、移动或存取动作。点击空格不产生变化。

### 4.2 遮罩与退出
锁定或解锁时，当前操作窗口之外显示灰暗遮罩；物品、锁标识及当前操作按钮保持清晰，并显示当前模式。

| 退出条件 | 结果 |
| --- | --- |
| 玩家移动人物 | 退出操作模式，撤去遮罩，按钮恢复“锁定”“解锁” |
| 关闭当前操作窗口 | 退出操作模式，重开时不恢复为锁定中／解锁中 |
| 打开其他面板 | 退出操作模式，再进入目标面板 |

遮罩不能阻断上述退出操作。翻页和切换分类仍在同一面板内，不属于“打开其他面板”。

退出操作模式保留已经完成的加锁、解锁结果。已有锁在换页、分类展示及原有移动、整理、存取后继续跟随道具显示。

### 4.3 已确认的业务保护
| 业务 | 锁定道具的展示与限制 |
| --- | --- |
| 炼丹 | 仍显示并标锁，不可选为材料，也不参与自动投入 |
| 炼器，含装备强化、装备炼化、法宝打造 | 仍显示并标锁，不可作为消耗材料 |
| 宗门手动上交 | 仍显示并标锁，不允许选择上交 |
| 便捷操作中的手动、自动上交 | 同样保留锁定道具，不加入上交内容 |

相应可用数量不包含锁定道具，拥有数量仍如实显示。材料选择与最终确认时都重新核对锁定状态；发现锁定对象，立即提示“物品已锁定，请先解锁”，停止该次操作，不发起本次消耗或上交请求。物品在选中后或确认窗打开后被锁定的，也不能沿用旧选择提交。

手动选择、批量选择和自动投入均遵守同一保护。宗门手动上交、便捷手动及自动上交在提交前同样核对；已有锁随页面展示和道具位置变化保留。

最终结算仍需核对锁定状态，锁定道具不得被消耗或上交。宗门兑换购买沿用原有规则，不受这项锁定调整影响。

本次不额外规定直接服用、售丹、快捷栏、丢弃及其他业务的新限制。

### 4.4 保存与重新进入
锁定与解锁结果至少在当前电脑保存，并按账号、角色分别保留。成功后更新道具锁标识；保存未成功时明确提示，保留上次成功的结果，不显示为保存成功。

| 情况 | 交互结果 |
| --- | --- |
| 在同一电脑重新进入同一账号与角色 | 恢复已成功保存的道具锁标识，使用普通操作状态 |
| 切换账号或角色 | 展示当前账号、角色自己的锁定结果，不沿用其他账号、角色的结果 |
| 移动人物、关闭窗口或打开其他面板 | 只结束临时锁定／解锁模式，保存的道具锁继续保留 |

重新进入不会自动进入“锁定中”或“解锁中”，也不会因操作模式复位而解除已有的锁。

## 五、底部按钮与已有面板跳转
| 按钮 | 本次要求 |
| --- | --- |
| 仓库 | 保留已有仓库入口；仓库容量、分页、存取与关闭联动不重新设计 |
| 整理 | 重新排列当前选中乾坤袋的全部物品，并保存实际位置；其他乾坤袋不变 |
| 锁定 | 进入背包锁定模式 |
| 解锁 | 进入背包解锁模式 |
| 便捷设置 | 打开已有的便捷操作面板 |
| 上交 | 打开已有的宗门兑换面板 |

点击整理，装备排在最前面，先按品质从高到低排列，品质相同再按进阶从高到低排列；装备之后的其他道具按道具编号ID从小到大排列。整理不改变物品本身、数量、绑定及已有锁定状态。

整理后的排列保存为当前乾坤袋内的实际位置。玩家仍可手动拖动物品调整位置；再次点击整理时，按同一规则重新排列当前乾坤袋。分类筛选状态下整理也只作用于左侧标明的当前乾坤袋，不退出当前分类，不整理其他乾坤袋。

打开便捷操作、宗门兑换时，结束背包锁定／解锁模式。上交按钮不是直接扣除物品，也不另开自制“手动上交”弹窗。

两个目标面板沿用已有交互。本背包原型只标明跳转目标，不展开这两个面板，不新增其选择、确认、兑换或便捷设置流程。

## 六、既有交互边界与待定细节
首次打开与重开后的页面记忆、加载和失败提示、道具详情方式、ESC与窗口关闭顺序，均沿用现有交互，本案不新增行为。

待定：锁定作用于单堆还是同种全部物品、拆分合并后的锁继承；收纳法宝具体名称与初始发放对象、同类多件生效方式、法宝本体是否占格及移出后的容量处理；筛选状态下拖放细节。容量取对应收纳法宝的正式配置，原型示例不补成固定格数。
