# P02 修仙属性体系
## 一、权威与有效范围
现行正式源表为`S属性配置表.xlsx`的`attr_config`页签，配置ID连续为1—98，共98项。BASE 84项，MODIFIER 14项；整数47项，万分比50项，固定值1项。

属性名称、编号、role、父子修改器及显示标记以正式源表为准。新增属性定义不等于已经分配角色、怪物、装备或状态的正式数值。

## 二、字段和单位
| 字段 | 类型 | 说明 |
|---|---|---|
| config_id | int | 唯一配置ID，现行1—98 |

| 字段 | 类型 | 说明 |
|---|---|---|
| name | AttrKey | 属性Key；用中文别名填写，与枚举名和值一一对应 |

| 字段 | 类型 | 说明 |
|---|---|---|
| role | AttrRole | BASE直接供各领域规则读取；MODIFIER按父属性关系派生贡献 |

| 字段 | 类型 | 说明 |
|---|---|---|
| parent_attr_modifier | array,AttrModifier | 修改器目标及ADD/MUL关系，支持现有两组父级槽位 |

| 字段 | 类型 | 说明 |
|---|---|---|
| tab | string | 归组或显示标记，不决定属性结算 |

| 字段 | 类型 | 说明 |
|---|---|---|
| desc | string | 属性含义及单位边界 |

| 字段 | 类型 | 说明 |
|---|---|---|
| is_show / is_show_tip | bool | 装备栏/属性Tips显示标记，空与显式FALSE分别保留 |

“整数/万分比/固定值”、父属性辅助列、“属性id”和“备注”保留现有格式；唯一身份使用config_id及AttrKey，辅助“属性id”不得当唯一键。10000万分比等于100%，0是有效数值，不表示缺项。

## 四、属性合成与修改器关系
各来源固定贡献先并入基础值，再统一应用有效百分比贡献；父子修改器按依赖顺序读取上游有效值。仅在对应领域明确了上下限时夹取，不从“BASE/MODIFIER”名称臆造默认上限。

```text
属性有效值 = clamp_value(floor((基础值 + 来源固定合计 + 派生固定合计)
                             × (10000 + clamp_pct(来源比例合计 + 派生比例合计)) / 10000))
```

20—27分别修饰攻击、法力、物防和法防的上下限；29、30分别修饰生命和灵力；47、48同时向攻击与法力上/下限提供ADD贡献；49、50以MUL修饰47、48。83—96是BASE万分比属性，直接供P03完整伤害系别对抗读取，不向攻击、防御或神识登记父级关系，避免重复放大。
