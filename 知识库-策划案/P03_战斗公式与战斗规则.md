# 战斗公式与战斗规则
战斗规则定义命中、伤害修饰与结算边界。属性采用现行定义，旧单值模型停用，完整新公式待统一。

## 万分比解释规则
百分比统一按万分比整数解释：
```text
pct_value = stored_value / 10000
```
同一修饰项不得在属性系统和伤害公式中重复计算。

## 神通倍率与固定值
```text
ability_damage = base_damage × ability_coefficient + ability_fixed
```

## 通用增减伤
```text
modified_damage = ability_damage × max(0, 1 + damage_bonus - damage_reduction)
```

## 暴击与最终值
```text
critical_damage = suppressed_damage × critical_multiplier   // 仅暴击时
final_damage = max(round(critical_damage), 1)
```

## 伤害公式的边界
境界修正的步长与上下界按正式配置，字段及公式尚待统一。PvE 与 PvP 使用不同的境界修正参数，PvP 系数默认更弱。破压制只能修正境界系数，不得直接抹除全部境界差。减伤可实际降低基础伤害，但最终有效命中仍至少造成 1 点伤害，免疫是独立判定。护盾在生命值之前吸收伤害。

## 命中与暴击公式
```text
hit_chance = clamp(base_hit + attacker.hit - defender.dodge, hit_min, hit_max)
crit_chance = clamp(attacker.crit - defender.crit_resist, 0, crit_max)
```

## 命中与暴击的边界
命中、闪避、暴击和免暴均使用万分比。必中、不可暴击、免疫等是显式标签，不通过极端百分比暗示。命中失败不造成伤害；是否返还法力由神通自身配置明确。

## 攻击结算的基本规则
每次有效普攻至少造成 1 点伤害。死亡单位不再接受攻击、移动或交互指令。单次攻击只结算一次，动画事件重复回调不得重复扣血。击杀行为不直接发放修为。

## 死亡、复活与同次攻击只结算一次
死亡单位停止攻击、移动和交互。角色在当前场景指定安全复活点复活，恢复比例、保护时间及状态保留按正式配置。同一次攻击及其同一段、同一跳不因重复反馈再次造成伤害；多段和持续伤害保留各自应有的次数，不合并成重复事件。

## 现行属性对接与待定公式
属性、装备及其数值取值使用现行有效定义，包括攻击、术法攻击、物防和法防上下限，以及天运、天佑规则；不新增表外的atk、def、matk或resist属性键，不把这些上下限宣布为废弃。
新属性如何取值并接入基础伤害、命中、暴击、护盾及境界修正的完整先后顺序尚待统一。保留的增减伤、倍率和暴击表达只说明对应项的局部含义，不单独构成完整伤害公式，不套用旧单值攻减防结果。法力与灵力的配置字段映射尚待统一，不因旧英文符号重命名现行属性。
