# 背包规则
背包规则负责容量、分页、堆叠、拾取、使用和整理的行为边界。物品身份、功能与单格数量上限读取物品配置，丹药效果及丹毒结算由炼丹规则拥有。

## 背包容量与分页
初始背包容量固定为 12 格。界面每页显示 6 格共 2 页，分页不改变真实容量。后续扩容增加真实格数，界面按每页 6 格继续分页。灵石显示在钱包区域，不占背包格。

## 堆叠判定
普通可堆叠物品以物品 ID 和绑定状态判断能否属于同一堆，单格数量不得超过物品配置 `pile_max`。装备、器具和法宝默认不可堆叠；有明确数量配置的物品须结合所属物品规则判断。不可堆叠物品须能逐件区分，不能仅凭显示名称相同合并。

## 放入顺序
物品放入背包时，优先填充相同物品且未满的堆叠，再按格子顺序占用空格。一笔收入必须全部可容纳才提交，空间不足时整笔失败，不允许部分放入。灵石不执行该流程，直接进入钱包事务。

## 拾取成功与失败
背包拾取先检查地面物仍存在、拾取权限和所需空间。拾取成功时，物品进入背包或钱包，并且原地面物消失；任一步失败都恢复到操作前状态。同一次拾取重复处理不得重复发放，不能出现地面与背包各保留一份的结果。

## 手动与自动拾取
普通物品支持点击拾取与自动拾取，两者调用同一拾取事务。灵石自动进入钱包，不需要拾取动作。

## 物品使用
使用前检查拥有数量、冷却、境界要求与当前状态，按 `function_type` 解释 `function_id`。执行实际效果成功后才扣数量；失败不消耗，数量归零时清格。

普通“丹药”按已配置丹效及服药前丹毒检查。没有有效丹效时禁止直接服食，不消耗、不增加杂质；配置错误不可跳过后部分执行。待定丹效保持未配置。

“突破丹”使用后打开突破准备面板，不立即消耗、不增加杂质、不自动投入。正式突破的材料消耗与额外单枚丹药由突破规则处理；背包不绕过突破条件，不将普通丹效是否为空用作突破丹准入依据。

## 穿戴
完整装备六位为冠、法袍、武器、佩、印绶、鞋履。穿戴只改变装备集合，属性系统随后从全部来源重算。替换失败时原装备和背包必须保持不变。法宝不进入固定出战槽，按神识预算和单件御使负荷结算。

## 整理与拆分
背包整理保持物品总数量、绑定状态与每件物品的信息不变。拆分数量必须大于 0 且小于原数量，并有空格可用。丹药的纯度和实际剩余杂质随原丹药保留；整理或拆分不重新计算、不取平均，也不丢弃这些信息。

## 炼丹材料与物品身份
炼丹材料入包、占格和扣除数量使用 W物品表的物品 ID。君、臣、佐、使、丹头的灵植配置 ID 由物品功能关联取得，用于查药力、药性和承药份数等炼丹属性。灵植配置 ID、丹方 ID 和丹效 ID 不能直接代替背包物品 ID。

## 丹药实例与堆叠待定项
携带不同纯度或实际剩余杂质的丹药是否允许合并，以及相同实例信息的丹药按哪些条件合并，尚未确定。当前“普通物品按 ID 与绑定状态堆叠”的规则不覆盖这类丹药；保留各枚原有信息，不把 `pile_max` 当作完整的合并判据。定案会影响入包空间、整理、拆分和服用时选择哪一枚丹药。
