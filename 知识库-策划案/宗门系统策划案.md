# 宗门系统策划案
> 宗门规则包括贡献、自由上交、商品购买、限购与配置有效性；声望字段预留，不参与当前买卖。商品实际数值以配置为准。

## 一 功能范围
玩家在一个宗门主面板内上交闲置物品获得宗门贡献，消耗贡献购买商品。

宗门贡献只有一种，全宗通用，不按品质、堂口或境界拆分。所有购买分类都可访问，不构成玩家职业或流派选择。声望等级和商品最低声望字段预留，当前不启用、不展示、不增加购买门槛。

宗门只包含上交与购买，不包含宗门任务、委托或任务奖励；玩家无需完成任务即可上交或购买。

宗门不包含宗门组织身份晋升、建设、战争、经营、设施租用或自动上交。普通商品只发实际物品或装备，不用备注授予洞府、坐骑、灵兽或其他服务。

步骤1：一条兑换记录只填一个分类，同一境界内的同一商品不重复展示。

步骤2：灵植归丹堂、灵材归器堂。剑类武器属于装备；剑道学习书属于藏经阁，商品分栏不单列剑堂，不改变剑堂在其他玩法中的组织职责。

步骤3：按实际用途区分“能力学习书”和“生产配方/成品”；名称带“符”“阵”等字样不能代替物品类别。

步骤4：每个堂口内，低境界尚有剩余额度的境界限购商品排在其他匹配商品之后；两组内各按 sort_order 升序，同值按条目 ID 升序。排序作用于全部筛选结果，再分页。上交价格与模板准入读取物品/装备售价，不按购买堂口改变回收价格。

步骤5：每个实际投放商品只有一个购买分类归属；跨用途商品仍只展示在一个购买分类中。

贡献和购买额度的归属按配置，展示、结算和保留使用同一口径。切换买卖页、堂口、筛选、关闭重开和退出重进，不改变既有记录。宗门玩法不包含转宗。

## 五 自由上交
步骤1：不接任务也可上交，不设置每日、每周次数、数量或所得贡献上限。

步骤2：**上交价格使用物品表、装备表的 sell_price，不单独配置第二份基础上交价。** 只接受有效的物品或装备；两者上交所得均为宗门贡献，不是金钱。

步骤3：未填写售价或售价为0时不允许上交，不另设上交开关；负数或非法数值按配置错误处理。可上交对象同时具备有效正售价、实际可交库存、正确归属、未穿戴、未锁定、未被占用等条件。

步骤4：普通物品按实际所选件数×sell_price；装备按所选具体实例件数×该装备的sell_price。单价单位为数量1的一件，拆叠合叠、跨格不改变价格。大量物品的贡献合计与实际件数、单价一致，不出现负数、截断或错算。

步骤5：丹药保留已有杂质折价：每件实际贡献=floor(实际成品物品.sell_price×price_factor÷10000)，结果向下取整。按每件丹药的实际杂质分别计价，不能把不同杂质的丹药统一按一个价格计算；基础价、折价系数或实际丹药信息不足以确定价格时，不允许上交。

步骤6：上交只发宗门贡献，不因装备旧售卖货币字段sell_price_id而发灵石。旧回收价rec_price、分解价des_price及对应货币或材料奖励，不与宗门上交叠加。

步骤7：未配置有效售价、正在穿戴、锁定、被占用或无法确定交付与定价规则的对象不显示，不参与搜索、全选或确认。强化、炼化等附加状态不得自行产生额外贡献或返还材料；这类装备只有在上交资格与价格明确后才进入可上交列表。

步骤8：单项默认全部可交数量，可改数量或取消；全选覆盖筛选的所有页。翻页保留选择，改境界、分类、品质、名称或重置筛选清空选择。取消不变更任何资产。

步骤9：确认前展示实际逐项数量、单件贡献及合计。确认时再检查归属、库存、可交付状态、有效售价、实例定价与报价；全部通过才统一扣物品、加贡献，任一失败整笔不成交。

步骤10：同一笔上交无论重复确认、等待结果或断线重进，都只能扣除一次物品、发放一次贡献。结果未确认时，不得把同一笔上交当作新的交易重复结算。同一件物资不能同时用于上交与其他系统消耗。

宗门上交只增加贡献，不自行增加声望。当前物品与装备售价为临时试算值，不作为已完成正式平衡的数值；正式数值同时覆盖上交产出和购买消耗。

## 六 购买与限购
### 6.1 配置与资格
兑换目录配置项：

| 字段 | 配置含义 |
| --- | --- |
| id（兑换条目ID） | 唯一正整数，固定不复用，标识该条商品及其购买记录 |

| 字段 | 配置含义 |
| --- | --- |
| department（所属堂口） | 藏经阁、丹堂、器堂、阵堂、兽堂、庶务堂之一 |

| 字段 | 配置含义 |
| --- | --- |
| name（条目名称） | 玩家看到的商品名称 |

| 字段 | 配置含义 |
| --- | --- |
| item_id（所得物品ID） | 对应实际存在的物品或装备，首位1为物品，首位5为装备 |

| 字段 | 配置含义 |
| --- | --- |
| item_count（每次物品数量） | 正整数，一次购买获得的件数 |

| 字段 | 配置含义 |
| --- | --- |
| contribution_cost（每次贡献价格） | 正整数，一次购买消耗的完整贡献数额 |

| 字段 | 配置含义 |
| --- | --- |
| reputation_level（最低声望等级） | 预留，当前留空，无声望门槛 |

| 字段 | 配置含义 |
| --- | --- |
| limit_period（购买限制） | “不限”或“每周”，表示是否设置周限购 |

| 字段 | 配置含义 |
| --- | --- |
| limit_count（每周购买次数） | 每周限购时为正整数；不限时留空 |

| 字段 | 配置含义 |
| --- | --- |
| open_realm（开放境界） | 必填，商品所属的开放境界 |

| 字段 | 配置含义 |
| --- | --- |
| realm_limit_count（境界限购次数） | 留空表示不设境界限购；正整数表示该兑换条目的累计购买次数上限 |

| 字段 | 配置含义 |
| --- | --- |
| sort_order（显示顺序） | 非负整数，同堂口内各显示组按此值升序，同值按条目ID升序；低境界待补购组始终在后 |

| 字段 | 配置含义 |
| --- | --- |
| enable（是否启用） | TRUE为启用，FALSE为停用；停用条目不参与购买 |

item_id 对应实际存在的物品或装备。每次件数和价格为正整数；购买次数为正整数。所得件数=次数×item_count，消耗贡献=次数×contribution_cost，限购按次数占用。输入次数的单笔上限按配置，贡献余额、剩余境界额度和周额度不改变这个输入上限。玩家可以选择买不起或超过剩余额度的次数；总价与原因照常显示，兑换按钮不可用，输入值不自动缩小或归零。

购买资格包括条目启用、分类合法、开放境界不高于角色境界、物品有效、库存可接收、贡献足够、对应限购的剩余额度足够。余额或额度不足的启用商品仍可查看，显示原因，不能购买；配置本身无效的条目不作为可成交商品开放。

商品最低声望字段留空，声望等级无启用等级；买卖不依赖声望数据。

### 6.2 确认与结算
点击商品只选择和看详情；点击兑换先显示确认弹窗。确认时重新检查全部资格及实际价格，成功才统一扣贡献、发物品、记录购买次数，不部分成交，同一笔只执行一次。

报价变化后显示新价，由玩家重新确认。提交中同一笔确认按钮不可重复提交，取消、关闭、ESC和离开页面始终可用。确认前取消不产生交易；确认后关闭界面不撤销已经提交的交易，也不重复扣费或发货。未得到结果时不显示成功、不自行认定未扣费；结果明确后按实际结果显示成功或失败原因。玩家已离开时不强制重开弹窗，不改变新的页面选择。

购买技能书只取得对应分卷物品，不直接学习；学习仍检查技能系统条件。每门技能只有一套分卷，原有书分别作为第一卷、上卷或筑基篇。浏览当前及以下境界不改变角色境界，也不自动授予学习或使用资格。

### 6.3 限购与记录
宗门商品按境界开放，玩家只能查看和购买当前及更低境界的商品。

周限购与境界限购互斥，同一兑换条目只使用其中一种，也可以均不限购。周限购条目的境界限购次数留空；境界限购条目的购买限制为“不限”、每周购买次数留空。同时配置两种限购属于配置冲突，不开放购买。

境界限购次数留空表示不设境界限购；填写正整数表示累计可购买次数，按购买次数计算。各境界额度独立，突破后仍可使用低境界的剩余额度。低境界有剩余额度的境界限购商品作为“待补购”附加在当前境界结果末尾；分类、品质、名称筛选同样生效。额度用尽后不再附加到当前境界结果，主动选择该低境界或“全部境界”仍可查看。低境界不限购、周限购商品不作为待补购附加。

同一条目 ID 共用一份购买记录；切买卖页、堂口、筛选、关闭重开、退出重进及调整堂口或排序均不刷新额度。周限购按本周已购次数计算，境界限购按累计已购次数计算。每周重置只恢复周额度，不重置境界累计次数。周额度的归属、次数、重置时区和时刻按配置。

### 6.4 价格与买卖差价
上交价是宗门收购物品时给玩家的贡献；购买价是玩家取得商品时消耗的贡献，两者不能混为同一个价格。

价格暂定试算采用：同类、同品质每跨一个大境界，上交基础价×5；凡品至道品的相邻品质倍率依次为×3、×4、×5、×6、×7，累计倍率为1、3、12、60、360、2520。不同类别另有基础价，不能把不同类别的价格直接比较为境界或品质倍率。通用物品的价格不随持有者境界改变。这些倍率属于临时试算，不代表正式平衡数值。

暂定试算的购买参考价为同物品、同品质、同实际状态上交所得贡献的2倍，不采用买卖同价。例如同一件物品上交获得100贡献，购买需200贡献。每次购买发放多件时，购买总价与该次全部物品的上交总价对应。

普通无实例折价物品：`每次购买参考价 = 2 × sell_price × item_count`。丹药按实际品质与杂质折价核对该商品可上交的贡献总额，不能把不同状态的报价混在一起。实际购买价格在兑换目录独立配置；不得因回收价已有数值，就自动把它当购买价或将全部物品上架。

同一商品买入后立即上交按购买参考价为实际同状态上交贡献2倍的暂定口径结算，贡献不会净增加。材料购买、制作消耗和成品回收收益共同构成制作回收的收支，不形成无成本反复获利的循环。

商品配置同时包含常驻消耗项与长期积攒目标，给玩家在用完周限购后继续积攒贡献的用途。

## 七 预留声望配置
声望值、等级和商品最低声望字段预留；当前不显示声望数值、等级、进度、待遇或相关按钮，不提供升级或领取操作，不影响上交与购买。声望等级配置保留 level、name、required_value、treatment_desc、enable 字段；当前无启用等级，商品 reputation_level 留空。贡献的获得和消费不自动形成声望变化。

## 八 配置内容与数据有效性
| 内容 | 需求 |
| --- | --- |
| 物品售价 | 使用物品表sell_price作为基础上交贡献；无价不可上交，丹药保留实际杂质折价 |

| 内容 | 需求 |
| --- | --- |
| 装备售价 | 使用装备表sell_price作为单件基础贡献；旧售卖货币、回收和分解奖励不参与宗门上交 |

| 内容 | 需求 |
| --- | --- |
| 物品持有状态 | 能区分归属、实际可交数量、穿戴、锁定与占用；上交与购买入包遵守背包容量、堆叠和实例规则 |

| 内容 | 需求 |
| --- | --- |
| 兑换目录 | 每条商品明确六类归属、物品、件数、购买价格、开放境界、境界限购、周限购、排序与启用状态；声望门槛字段预留且留空 |

| 内容 | 需求 |
| --- | --- |
| 声望等级 | 页签与字段预留，当前无启用等级，不参与买卖或界面展示 |

宗门配置表只有“兑换目录”和“声望等级”两个页签。上交基础价使用物品表、装备表的sell_price。配置备注仅作填写辅助，不影响商品效果、资格或额度。旧自由上交表及其说明不作为宗门上交价格与资格依据。

购买商品的境界筛选按兑换目录的开放境界；上交物品按自身境界筛选。物品境界取自身境界资料、细分类取实际用途标签、品质取物品品质；装备境界取装备阶级，细分类统一为“装备”。物品的使用等级不等于筛选境界，粗档不等于灵植、丹药等用途细分类；不能根据名称猜测，也不能在资料缺失时自动归为通用。

宗门境界筛选最高为角色当前境界，角色境界变化时可选范围同步更新。购买按商品开放境界、上交按物品自身境界判断可显示范围，选择“全部境界”也不包含更高境界。分类、品质、名称与境界共同取交集。原型的演示分类不作为正式物品资料。

选择某境界时，购买显示开放境界为所选境界的商品；选择角色当前境界时，另附加低境界有剩余额度的境界限购商品并排在最后。上交显示该境界及通用物品；“通用”只显示通用物品，其中购买条目仍受开放境界限制；“全部境界”显示当前及以下境界范围内的全部条目。

未启用的商品、无效物品、缺少必要分类资料或无法确定价格的对象，不开放相应交易，并明确提示原因。正式商品使用完整的件数、价格、资格和限制资料，停用示例、演示数值和备注不作为实际配置。交易按确认时的实际物品状态与购买资格结算。
