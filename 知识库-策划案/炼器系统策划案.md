# 炼器系统策划案

炼器规则负责法宝打造配方、材料准入、消耗与产出；不改变法宝御使、属性与祭炼规则。

## 1. 配方与目标

法宝打造以打造表中的一条有效配方为单位，`fabao_id` 指定目标法宝。同一目标最多对应一条打造配方。

目标法宝由配方确定。主材、辅材和特性材料是该配方的投入条件，不能自行将目标解释为随机法宝，也不能根据材料名称另行生成目标。

## 2. 打造表结构

打造投入按固定材料与分类材料分别配置：

| 字段 | 类型 | 含义 |
|---|---|---|
| `fabao_id` | `int` | 目标法宝ID |
| `core_item_id`、`core_item_count` | `int` | 成宝核心物品ID、数量 |

| 字段 | 类型 | 含义 |
|---|---|---|
| `main_item_id`、`main_item_count` | `int` | 固定主材物品ID、数量 |
| `aux_categories` | `array,string` | 允许选择的辅材分类 |

| 字段 | 类型 | 含义 |
|---|---|---|
| `aux_count` | `int` | 选用辅材的消耗数量 |
| `trait_categories` | `array,string` | 允许选择的特性材料分类 |

| 字段 | 类型 | 含义 |
|---|---|---|
| `trait_count` | `int` | 选用特性材料的消耗数量 |
| `money_id`、`money_count` | `int` | 货币ID、消耗数量 |

| 字段 | 类型 | 含义 |
|---|---|---|
| `realm_req` | `MajorRealm` | 角色打造境界要求 |
| `forge_skill_lv_req` | `int` | 炼器技能等级要求 |

| 字段 | 类型 | 含义 |
|---|---|---|
| `enable` | `bool` | 配方是否开放 |

核心和主材使用指定物品，不因其他物品同类就允许替换。

辅材、特性材料按物品表的分类标签匹配，不能按显示名称包含某个字词来判断。

材料的分类、境界从物品表正式导出的 `tags` 标签读取，品质从 `quality` 读取。物品表中不导出的境界辅助列只供配表核对，不作为运行时筛选依据。

分类数组中配置多个分类时，从允许分类中任选一类，再选择符合条件的具体材料；不是要求把列出的所有分类全部投入。分类为空表示不要求该类材料。

## 3. 材料境界与品质

主材、辅材和特性材料必须与目标法宝同境界、同品质。

- 不允许跨境界混用。
- 不允许跨品质混用。
- 不允许以更高品质等量替代低品质。
- 分类符合不代表可以忽略境界、品质限制。

成宝核心是明确例外：

> 成宝核心境界通用，但品质必须与目标法宝一致。

该例外只适用于配方指定的通用成宝核心，不自动扩展到主材、辅材或特性材料。

角色的 `realm_req`、材料境界和目标法宝境界分别承担不同职责。角色达到打造门槛，不代表材料可以跨境界使用。

## 4. 打造资格与结算

打造前同时检查：

- 配方启用且有效。
- 目标法宝主表有效，并具备有效的初始0层配置。
- 玩家尚未拥有该目标法宝。
- 角色满足打造境界、炼器技能等级及既有公共操作条件。
- 各材料符合指定物品或分类要求。
- 材料境界、品质符合规则。
- 材料总量和货币足够。

同一份库存不能重复满足多个材料栏。不同材料栏使用相同物品时，按总需求检查数量。

全部条件通过后统一消耗。取消或校验失败不消耗，不能发生部分材料已扣、其他条件尚未通过的结算。

打造必定成功，不另设打造成功率、幸运或保底。完成后获得目标法宝，初始为0层、未御使状态。

已有目标法宝时不能重复打造，不扣材料和货币。发生异常时不能显示成功或静默丢失已投入资源。

打造沿用与御使、祭炼等法宝管理操作共用的处理限制，不得通过同时操作重复扣除或重复获得法宝。已经受理的打造不因关闭界面而取消；结果尚未确认时，不能当作失败重新执行并再次扣料。

打造直接获得法宝记录时，以该法宝配置的 `unlock_id` 对应物品ID匹配奇珍录 `unlock_ids`。不能把 `fabao_id` 当作物品收录钥匙；命中任一钥匙即按首次点亮规则处理，已有收录不重复计数。
