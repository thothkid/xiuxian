# 神通系统策划案
配置工作簿：`J技能BUFF表.xlsx`。第一部分定义技能（`skill_config`），第二部分定义状态（`buff_config`）。

## 第一部分：技能（skill_config）
### 一、神通表字段说明
填写位置：`J技能BUFF表.xlsx` → `skill_config`。每行配置一门神通的一个等级。

“配置项”标注列号，“中文名”对应第 4 行表头。

填写口径：布尔值使用 `true / false`；万分比 `10000 = 100%`、`500 = 5%`；逻辑帧 `50 帧 = 1 秒`；距离使用地图距离单位。时间单位以各字段说明为准。

| `id`（B） | 技能ID | 唯一定位神通某一级，供效果调用等引用。保持表内公式完整，按“10000000＋编号表中的编号×10000＋本行等级”生成唯一 ID，如 `10010001` 为对应神通第 1 级。 |

### 六、装载期校验清单
逐行校验，以下情况整行不加载并报错：

1. 选择器填“单体”但 X“施法瞄准类型”不是“单位”。
2. 圆形、扇形 半径 ≤ 0；扇形 张角 ≤ 0 或大于 180；线形 长度或宽度 ≤ 0；环形 外圈半径 ≤ 0、内圈半径 < 0 或 内圈半径 ≥ 外圈半径。主、子选择器同样适用。
3. `channel_time` > 0 但 `channel_interval` < 1。
4. 效果的“作用范围”填“仅子范围内”或“子范围外”，但主选择器不是区域形状，或没有配区域子选择器。
5. 伤害效果、治疗效果 的系数与固定值同时为 0。
6. 调用状态 的状态 ID 为 0 或在 `buff_config` 中不存在（或该状态装载失败）。
7. 调用技能 的等级行 ID 为 0 或不存在（或该行自身校验未通过）。
8. 位移效果 主体、方式、方向均不为“无”时，距离 ≤ 0。
9. 弹道效果 速度 ≤ 0、射程 ≤ 0、命中半径 ≤ 0、总数量 ≤ 0；`sub_skill_id` 为 0 或不存在。
10. 召唤效果 类型与位置均不为“无”时，召唤对象 ID ≤ 0 或单次数量 ≤ 0。

下列情况保留该行，按括号内规则处理并记录告警：`base_power` ≤ 0（按 10000）；效果触发概率 > 10000（按必定触发）；延迟为负（按立即执行）；`falloff_edge_ratio` ≤ 0（按不衰减）或 > 10000（边缘比中心更高）；`max_charges` ≥ 2 但 `charge_recover_time` ≤ 0（按普通冷却）；`channel_interval` > `channel_time`（只跳一次）；位移主体、方式、方向含“无”（本条效果关闭）；直线位移速度 ≤ 0（按 900）；弹道轨迹“无”（本条关闭）；弹射轨迹 `pierce` = 0（不弹射）；命中半径小于每帧移动距离；召唤类型或位置“无”（本条关闭）；单次召唤数量 > 同类上限（自我顶替）；子选择器填“单体”（等同未配）；配了子选择器但主选择器不圈人；单体神通配了边缘衰减（不生效）。

地板类型召唤的参数2不是含光环效果的有效状态 ID；低血量阈值不在 1～10000；调用词条 ID 为 0 或不存在，均整行不加载。

升级相关校验：M 列为 0 时终止升级链；M 列有下一等级时，按当前行 S、T 的组合判断升级条件。T 列为 0 表示本级不积累熟练度。S 列填入的非零道具 ID 必须存在于物品表，引用无效时报告配置错误，并阻止该次升级。

### 七、技能分类、系别转换与加成
#### 1. 三种配置各自负责什么
| 配置位置 | 中文名 | 规则 |
|---|---|---|
| `skill_type`（E） | 技能分类 | 决定天地人面板归属。系别转换后，面板归属保持原配置。 |
| `skill_class`（F） | 技能系别 | 提供神通默认系别，每门神通配置一个值；用于系别加成与按系别触发的熟练度行为匹配。 |
| `skill_effects` → 伤害参数1 | 伤害类型 | 决定物理、法术等攻击取值与防御结算口径，各系别沿用统一伤害公式。 |

#### 2. 先确定本次最终系别
神通默认取 F 列系别。生效的神通效果或词条替换系别后，按新系别匹配，原系别专属加成退出；如改为金行，本次按金行匹配。

F 列保留默认系别；转换仅用于受影响神通的本次结算，其余神通沿用各自系别。

#### 3. 按最终系别匹配加成
| 加成针对的系别 | 可以匹配的神通最终系别 |
|---|---|
| 五行 | 五行、金行、木行、水行、火行、土行 |
| 金行、木行、水行、火行、土行中的单行 | 只匹配该行 |
| 剑道、术法、炼体等其余系别 | 按同名匹配 |

最终系别为金行时，同时适用“五行加成”和“金行加成”。多个有效来源按词条系统的叠加规则汇总。

#### 4. 统一伤害公式，全伤害参与加成
结算顺序为：确定最终系别 → 匹配适用加成 → 按伤害类型执行统一伤害公式 → 对完整伤害施加系别增幅 → 保底及后续护盾、扣血处理。

系别加成后伤害＝统一公式完整伤害×（1＋本次适用的系别伤害增幅）。完整伤害包含系数部分、固定附带伤害、暴击产生的伤害和最后追加的固定伤害；持续伤害每次结算也适用。

例如前段伤害 100、最后追加固定伤害 20，完整伤害为 120；适用 5% 系别伤害增幅后为 126。

本节定义伤害加成。改变范围、人数、速度等参数，按相应词条的修饰内容执行。

#### 5. 调用链沿用最终系别
同次执行的被调用神通、弹道命中、延迟、光环及持续状态，沿用发起神通本次最终系别。被调用行提供自身等级、效果和数值。

共用组件按各次发起神通最终系别分别结算；每段伤害只应用一次系别增幅，调用层数不重复放大。

#### 6. 配置结果示例
| 情况 | 应有结果 |
|---|---|
| 火行神通，没有系别转换 | 享受五行、火行加成。 |
| 火行神通被词条改为金行 | 享受五行、金行加成，不再享受火行专属加成；天地人分类不变。 |
| 金行神通调用没有系别的爆炸组件 | 爆炸伤害沿用该神通的金行归属，享受五行、金行加成。 |
| 同一爆炸组件另被火行神通调用 | 这次爆炸享受五行、火行加成，不混入上一门神通的金行加成。 |
| 金行伤害按统一公式合计为120，适用系别增幅为5% | 完整伤害提高到126；固定伤害部分同样参与。 |

### 八、熟练度与升级
#### 1. 升级条件
M“下一级技能ID”指定升级目标，填 0 表示末级。当前行的 T“熟练度上限”与 S“升级消耗道具”决定升级条件，U“熟练度触发行为”决定熟练度的获取行为：

| T 熟练度上限 | S 升级消耗道具 | 升级方式 |
|---|---|---|
| 正整数 | 0 | 熟练度达到 T 列数值时升级 |
| 正整数 | 道具 ID | 熟练度达到 T 列数值后，还需消耗 1 个该道具才能升级 |
| 0 | 道具 ID | 不积累熟练度，消耗 1 个该道具直接升级 |
| 0 | 0 | 本级不可升级，末级按此填写 |

升级目标须为同识别 ID 的下一等级，且满足目标行 L“前置技能ID”、R“学习技能所需等级”。升级后按新行 S、T 判断下次条件；熟练度扣本级上限，余量带入新等级。

升级固定消耗 1 个道具，不足则不能升级。道具归“功能_技能书”，与学习用同一类道具；背包点击打开神通面板，学习、升级均在该面板完成，具体流程见交互案。

#### 2. 熟练度怎么增长
熟练度累积在已学会且 T 列为正整数的神通上，成长分两类：

**人道战斗神通。** 每次施放本神通判一次，判中加 1～3 点。引导只计一次；前摇中断、未到命中帧不计。独立结算，不要求系统参数存在该神通的“参数_识别ID”条目。

**天道、地道等神通的行为成长。** U 列配一项或多项行为，每次匹配时按本门概率判一次，判中加 1 点。

行为成长概率配在 `X系统参数.xlsx` → `ConfigSystemVar`，参数名 `参数_识别ID<该神通的识别 ID>`，值为万分比。按识别 ID 读取，缺条目则不结算该门的行为成长。

一次行为可让多门神通独立判定、互不影响。如施放剑道人道神通，自身按人道规则增长；已学且关联“使用本系别人道神通”的剑道功法，按各自概率增长。

行为关联示例（含多行为神通）：同一门神通的各项行为使用该神通同一条概率参数。

| 神通识别 ID | 神通名称 | 触发行为 |
|---|---|---|
| 105000 | 灵植术 | 获得灵植、炼丹 |
| 105100 | 灵材术 | 获得灵材、炼器 |
| 107900 | 草木蕴生功 | 获得灵植 |
| 108000 | 万材辨性篇 | 获得灵材 |

例如完成一次炼丹时，已学且关联“炼丹”行为的灵植术、炼丹术、九转合丹经分别判定，各自判中后增加 1 点。

本节熟练度为绝对点数，判中加 1 点或 1～3 点；系统参数“炼丹术每提高 1% 熟练度，除渣力增加万分之几”指进度百分比（本级熟练度 ÷ 本级熟练度上限）。上限为 100 或 1000 时，1% 对应点数不同。

## 第二部分：BUFF（buff_config）
BUFF（状态）是挂在单位身上的持续效果。神通负责选目标、施加状态；状态负责时长、重复施加、属性修正、控制和周期效果。其他玩法同样按具体状态 ID 引用。

填写位置：`J技能BUFF表.xlsx` → `buff_config` 页签。第 1 行是配置项，第 2 行是类型，第 4 行是中文表头，第 5 行起为数据。B—U 为主字段区，U 的 `effects` 是效果数组，占 U—AO 三组效果槽。

填写口径：持续时间、作用间隔均为毫秒，`1000 = 1 秒`；万分比 `10000 = 100%`、`500 = 5%`；布尔值填 `true / false`。状态 ID 与引用 ID 填整数，识别 ID 按字符串保存。取值 0 的含义逐项说明。

| `coefficient` | 效果N参数2／万分比伤害系数 | 填非负整数万分比，`10000` 表示 100% 的基数；0 表示只取固定值。与参数3至少有一项产生正数伤害。 |
| `flat` | 效果N参数3／固定伤害数值 | 填非负整数，加在系数部分之后，再乘层数。此固定值属于本跳的基础伤害，之后仍进入防御、增减伤等结算。 |
| `can_crit` | 效果N参数4／是否允许暴击 | 填 `false`，持续伤害按不暴击结算。 |
| `crit` | 效果N参数5／暴击参数 | 填 0。 |

每跳基础伤害＝`（向下取整〔施加时攻击下限×系数÷10000〕＋固定值）×当前层数`。例如攻击下限 100、系数 2200、固定值 2、1 层，得到本跳基础伤害 24，再进行防御与增减伤结算。

快照固定攻击基数，所有层共用当前生效来源的快照。被拒绝的施加不替换来源或快照。持续伤害不乘调用神通基础威力，不吃穿透、法术威力或法术附带伤害；其他增伤项和目标防御、减伤项仍实时读取。

持续伤害记录施加者和发起神通经转换后的最终系别，享受该系别对应的伤害加成。

#### 4. 状态效果_持续治疗
| 配置项（effects 组内字段） | 中文名（表内位置／参数含义） | 作用与填写说明 |
|---|---|---|
| `heal_type` | 效果N参数1／治疗类型 | “目标血量上限”取携带者每跳时的最大生命；“施法者血量上限”取施加时施加者最大生命快照；物理、魔法分别使用对应攻击属性，按与伤害相同的天运及上下限算法在施加时取值并保存。 |
| `coefficient` | 效果N参数2／治疗万分比系数 | 填非负整数万分比；0 表示只取固定值。与参数3至少有一项产生正数治疗量。 |
| `flat` | 效果N参数3／固定值 | 填非负整数固定治疗量，与系数部分相加后乘当前层数。恢复量受目标最大生命限制。 |
| `can_crit` | 效果N参数4／是否允许暴击 | 填 `false`，持续治疗不暴击。 |
| `crit` | 效果N参数5／暴击参数 | 填 0。 |

每跳治疗量＝`（向下取整〔治疗基数×系数÷10000〕＋固定值）×当前层数`。不乘调用神通的基础威力或角色法术威力；已死亡或生命耗尽的携带者不恢复。

#### 5. 状态效果_光环
| 配置项（effects 组内字段） | 中文名（表内位置／参数含义） | 作用与填写说明 |
|---|---|---|
| `sub_skill_id` | 效果N参数1／光环释放技能ID | 填 `skill_config` 的具体等级行 ID（B 列）。每隔 N“作用间隔”执行一次该行神通效果。参数2～5留空。范围、阵营、人数、数值均在被调用的神通行配置。 |

光环每跳以携带者当前位置为原点、施加者为施法者；伤害归属、阵营按施加者，神通取其实时属性。自挂时两者为同一单位，敌方施加时阵营仍相对敌方施加者判断。

每条光环每跳调用一次，叠层不增加次数。子神通仅执行效果，不扣灵力、不走自身冷却或施法时序；等级由引用 ID 固定，不随外层神通升级换行。

普通光环每跳按“施加者当前位置→携带者当前位置”确定区域方向，重合时取正东。圆形、环形不受朝向影响。地板使用生成时的固定朝向。

光环引用的神通须配置有效区域选择器，以携带者位置为区域原点选取目标。

#### 6. 效果执行顺序
技能触发并成功施加状态后，持续伤害、持续治疗、光环同时计时并首跳，再按配置间隔、次数执行。每跳先按槽位顺序处理持续伤害／治疗，再处理所有光环；三组共享时长、层数和周期。

### 四、重复施加、归属与生命周期
#### 1. 层数与时间分别计算
同一单位上，同识别 ID 的状态按 F 列比较等级，高等级覆盖低等级。首次为 1 层；同等级重复施加时，按配置处理层数与剩余时间；不允许覆盖或叠加时保留原状态。

以持续时间 10000 毫秒、当前还剩 4 秒为例：

| J 时间覆盖类型 | 再次施加后的剩余时间 | K 层数叠加类型的独立作用 |
|---|---|---|
| 无 | 仍剩 4 秒 | 无＝层数不变；有限／无限叠加＝增加 1 层至各自上限。 |
| 覆盖 | 改为 10 秒 | 同上。达到层数上限后仍可刷新时间。 |
| 叠加 | 改为 14 秒 | 同上。达到层数上限后仍可延长时间。 |

永久状态不挂到期计时，重复施加只处理层数和来源等信息。所有层共同到期；属性修正、持续伤害与持续治疗按层数放大，控制标签与光环调用次数不按层数放大。重复施加不重置周期定时器。

同识别 ID 的等级比较统一作用于整条状态，高等级的各组效果按该等级行配置生效。

#### 2. 施加者与来源
同识别 ID 统一比等级，来源不分组。最高等级移除或到期后，仍有效低等级接替；生效状态取对应施加者及快照。卸载仅清理本来源，保留其他有效来源并重算生效等级。

#### 3. 死亡与销毁
| 情况 | 持续伤害／持续治疗 | 光环及其他状态效果 |
|---|---|---|
| 携带者死亡 | 清除其全部状态，停止周期效果。 | 属性修正、控制和持续特效一并清理；复活后重新执行常驻被动。 |
| 携带者实体销毁 | 取消其状态定时器并释放状态数据。 | 清理单位状态及持续特效。 |
| 施加者死亡但实体仍在，携带者存活 | 仍可结算，归属仍为该施加者。 | 普通光环仍可执行。 |
| 施加者实体销毁，携带者存活 | 已保存的基数仍可用于结算，归属退为无主；无法再读取已销毁施加者的其他实时属性。 | 已有属性修正、控制随携带者状态继续计时；光环停止调用并告警。 |

原本没有施加者的光环，使用携带者作为施法者。地板在召唤者死亡时消失。
