# 怪物 AI 规则
怪物的持久状态、状态转换条件、边界基准、各状态行为、可配置参数、受击换目标规则与幂等要求。来源类型不写死行为，具体差异由参数配置。

## 五个持久状态
怪物 AI 使用五个持久状态：`IDLE`（待机）、`CHASE`（追击）、`ATTACK`（攻击）、`RETURN`（返回）、`DEAD`（死亡）。索敌是 `IDLE` 中的周期逻辑，不单独占状态。放弃追击后直接进入 `RETURN`，不建立含义混乱的 `FLEE` 状态。

## 状态转换条件
| 当前状态 | 条件 | 目标状态 |
|---|---|---|
| 任意非 DEAD | `hp <= 0` | DEAD |
| IDLE | 找到最近有效敌对目标 | CHASE |
| CHASE | 目标进入攻击距离 | ATTACK |
| CHASE | 目标失效 | RETURN；若已在出生点则 IDLE |
| CHASE | 超出出生或刷新边界达到配置时长 | RETURN |
| ATTACK | 目标离开攻击距离但仍在脱战边界内 | CHASE |
| ATTACK | 目标失效 | RETURN；若已在出生点则 IDLE |
| RETURN | 到达出生点 | IDLE |
| RETURN | 受到有效攻击 | CHASE 并锁定攻击者 |

## 距离基准
索敌距离相对怪物当前位置计算。脱战距离相对本次出生点或所属刷新区域计算，不相对目标计算。目标越过边界后，怪物不会因继续靠近目标而延长追击。返回状态沿用出生点和刷新区域，避免被无限风筝。

## IDLE 状态行为
怪物原地待机，按 `search_interval` 周期搜索范围内最近的有效敌对单位。无目标时不每帧全图扫描。

## CHASE 状态行为
怪物追向当前目标，每次更新先校验目标、攻击距离和脱战边界。不建立仇恨表，`RETURN` 状态下受击是唯一显式换目标入口。

## ATTACK 状态行为
怪物停止移动并调用统一战斗事件。攻击间隔结束后重新校验目标与距离。目标死亡时立即停止后续攻击事件。

## RETURN 状态行为
怪物清除原目标并返回出生点，到达后恢复由 `return_heal_ratio` 决定的生命比例。返回途中受到有效伤害时，设置攻击者为目标并直接进入 `CHASE`，不经过 `IDLE`；换目标的同时把脱战计时清零。

## DEAD 状态行为
怪物停止全部 AI 计时器和移动。死亡、掉落与销毁事件只触发一次。

## AI 参数
| 参数 | 说明 |
|---|---|
| `search_interval` | 索敌周期 |
| `aggro_range` | 索敌范围 |
| `attack_range` | 攻击范围 |
| `leash_range` | 出生点脱战距离；使用区域边界时可为空 |
| `leash_timeout` | 超界持续多久后返回 |
| `return_speed_multiplier` | 返回速度倍率 |
| `return_arrival_radius` | 到达出生点容差 |
| `return_heal_ratio` | 返回完成恢复比例 |

## AI 参数的来源约束
所有 AI 参数从配置读取。魔化生物不得被全类写成「不恐惧、不休息、必死战」等固定行为。

## AI 性能与幂等要求
距离比较使用平方距离。状态切换时清理旧移动命令、目标和计时器。死亡检测优先于其他状态逻辑。同一死亡事件 ID 不得重复掉落，也不得重复减少刷新存活数。
