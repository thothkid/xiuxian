# 掉落方案表字段
掉落方案表与掉落槽的字段定义、字段边界与校验项。抽取算法使用 32 槽权重池，具体数值以 `D掉落方案` 为准。

## 掉落方案字段
| 字段 | 类型 | 必填 | 说明 |
|---|---|:---:|---|
| `scheme_id` | int 或 string | 是 | 唯一主键 |
| `scheme_name` | string | 是 | 策划识别名 |
| `draw_min` | int | 是 | 最少抽取次数 |
| `draw_max` | int | 是 | 最多抽取次数 |
| `allow_repeat` | bool | 是 | 是否允许同槽重复抽中 |
| `slots` | array | 是 | 最多 32 个有效槽 |

## 掉落槽字段
| 字段 | 类型 | 必填 | 说明 |
|---|---|:---:|---|
| `target_id` | int 或 string | 是 | 物品或装备 ID |
| `target_type` | enum | 是 | `item`、`equipment` 或其他受支持类型 |
| `weight` | int | 是 | 相对权重，必须大于 0 |
| `count_min` | int | 是 | 最少数量 |
| `count_max` | int | 是 | 最多数量 |
| `guaranteed` | bool | 是 | 是否保底 |
| `broadcast_override` | enum 或 null | 否 | 显式覆盖统一品质播报规则 |

## 掉落表字段边界
不使用独立概率字段与权重字段并存。不使用含义不清的等级字段，境界和品质分别读取目标物品数据。最少与最多掉落数决定抽取次数，不对结果二次裁剪。物品品质随目标物品数据，不由掉落表临时改写。怪物来源、品质和首领职能通过选择不同方案体现。

## 掉落表校验项
`draw_min` 不大于 `draw_max`，且两者均不小于 0。保底槽数量不得超过 `draw_max`。所有目标 ID 必须存在，数量范围合法。有效权重总和大于 0。方案主键唯一。
