# 初始角色数据
新角色创建时写入的初始状态语义、派生值与初始真值的区分、初始物品包的引用规则、灵根命格与器物关系的处理方式及校验项。具体数值与物品 ID 以配置表为准。

## 初始状态语义
| 数据 | 语义 |
|---|---|
| 身份 | 青冥宗外门弟子 |
| 境界 | `realm_id` 为 1，`realm_sublevel` 为 1 |
| 生命 | 当前值由最大生命初始化 |
| 法力 | 当前值由最大法力初始化 |
| 背包容量 | 12 格，界面每页 6 格 |
| 灵石 | 钱包资源，不进入背包 |
| 出生位置 | 青冥宗开局区域指定出生点 |

## 派生值不作为初始真值
最大生命、最大法力、攻击、防御和中文境界名都是派生值，创建后由属性系统计算，不作为独立初始真值重复保存。

## 初始物品包
初始物品通过初始包标识引用实际配置，不虚构物品 ID。初始包记录物品种类与数量，描述数量时必须区分「几个单位」与「几种物品」。灵石只写入钱包，禁止同时出现在背包物品列表中。初始包中的消耗品必须使用已存在的正式效果，不使用临时定义的效果。

## 灵根命格与器物关系的处理
灵根、命格和道器显现方式未定稿时，只保留可扩展数据域，不在创角时随机生成固定结果。灵根名称由灵根标识派生，不同时保存标识和中文名。器物关系使用列表或关系对象，不使用只能存一件的单数字段。

## 初始角色校验项
出生点、初始包和所有物品 ID 必须存在。背包物品按堆叠规则计算后不得超过 12 格。当前生命和法力不得超过派生上限。创建事务重复执行时不得重复发放钱包或物品。
