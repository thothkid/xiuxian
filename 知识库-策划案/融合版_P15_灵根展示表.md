# 灵根展示表
灵根的概念边界、展示字段、五行修正的作用边界与创角处的处理方式。具体效果与数值以 `L灵根配置表` 为准。

## 灵根的概念边界
灵根是修士承接与转化天地力量的先天规格。灵根影响修炼与五行亲和，但不等于职业、堂口或功法锁。灵根深层究竟完全属于灵魂，还是位于灵魂与肉身交界，当前不写死。

## 灵根字段
| 字段 | 说明 |
|---|---|
| `linggen_id` | 唯一主键 |
| `linggen_name` | 显示名称 |
| `elements` | 金木水火土中的一个或多个 |
| `color` | 界面显示映射 |
| `icon_id` | 图标资源 |
| `tagline` | 简短风味，不得承诺职业或绝对强弱 |
| `description` | 自足说明 |
| `affinity_modifiers` | 五行与修炼修正项 |

## 五行修正的边界
五行生克只提供可配置修正，不形成绝对命中、免疫或必胜。多灵根、变异灵根、纯度和成长方式在对应系统定稿前不提前扩写。风味文案不得出现「只能修炼某功法」「必须加入某堂口」等职业锁表述。

## 灵根在创角处的处理
灵根方案未定稿前，创角界面不开放相应交互，存档保留可扩展域，不生成伪随机的正式结果。
