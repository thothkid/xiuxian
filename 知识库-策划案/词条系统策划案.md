# 词条系统策划案（按 `affix_config` 修订）


## 一、定位与配置边界

当前 `affix_config` 的对象修正模型中，一条词条选择一个作用对象，对其神通或状态的已有参数、选择器、效果作最多四次修改。一个修改块只做一次修改。词条 ID 由神通系统和状态系统之外的独立来源系统提供；来源的获得与失效由来源系统决定。每次计算先按来源适用范围筛选有效来源，再对本次范围内同时提供的同一 ID 只生效一次。技能表中配置的对象（包括按 `skill_type` 分类的人道·神通、地道·百艺、天道·功法等）、神通效果和状态（Buff）是词条的修正对象，不是词条来源；它们不调用、登记或移除词条。装备、真意、丹药是来源示例，不构成封闭白名单。哪些来源已接入运行时、哪些来源纳入后续范围，仍待核对来源系统与实现后确定；本案不把当前实现情况写成来源设计结论。词条没有等级，每个 ID 是独立词条；技能和状态的等级属于各自基础表，不能把词条 ID 当等级链。

词条只修正已有的技能对象、神通效果和状态（Buff），不改变角色拥有的神通集合：词条不授予角色一门新神通，也不把角色已有的神通 A 顶替为神通 B。角色需要获得新神通时，应配置对应技能，并由独立的技能学习或授予机制决定角色如何获得它。

词条可以修改已有对象的参数与效果，也可以把现有技能或状态模板中的效果追加到已有对象，或修改已有“调用技能”等效果所引用的神通 ID。后两类操作改变的是对象的效果组合或某个效果的调用目标，不会让角色获得、失去或替换一门神通，也不表示技能或状态调用词条。当前 `affix_config` 以一个既有神通或状态为作用对象；第五节“替换”只替换选择器或单个效果模板，不操作角色的技能集合。

技能、状态表提供实际可执行的效果类型、参数和引用。词条可以修改当前参数目录中的项目、替换或追加现有模板的效果；基础表没有的效果类型或词条目录没有的参数，须先接入后才能作为可导出的词条。护盾、反伤、受击回血等旧构想保留为扩展需求，当前技能和状态效果类型中没有可直接填报的对应内容，不得用相似类型代填。

## 二、工作簿、表头与一行结构

正式工作簿为 `C词条表.xlsx`，导出页签为 `affix_config`，每行一条词条。`参数目录与选项`页签只供查阅，不导出。`affix_config` 使用三行 `##var`（字段名、修改序号、修改内子字段名）、一行 `##type`、一行 `##group`、若干行 `##`（首行为中文列名，后续为填表说明）的多行表头。枚举列填中文别名；首列标为 `##` 的示例行不导出。名称、描述属于 `c` 组，只导出给客户端展示；其他字段按表内 `##group` 导出。末列“配置备注”不导出，填写配置意图、构造前提或待接入能力。

| 固定字段 | 中文列名 | 填法 |
|---|---|---|
| `id` | 词条ID | 唯一整数 ID；三表 ID 的跨表约束仍需满足。 |

| 固定字段 | 中文列名 | 填法 |
|---|---|---|
| `name`、`description` | 词条名称、词条描述 | 客户端展示文字，应与最终效果一致。 |

| 固定字段 | 中文列名 | 填法 |
|---|---|---|
| `skill_class` | 作用系别 | 与下面两列三选一；不按系别时填“无”。 |

| 固定字段 | 中文列名 | 填法 |
|---|---|---|
| `skill_identify_id` | 作用神通识别ID | 与另两列三选一；不按神通时填 0。匹配同识别 ID 的全部等级行。 |

| 固定字段 | 中文列名 | 填法 |
|---|---|---|
| `buff_identify_id` | 作用状态识别ID | 与另两列三选一；不按状态时留空。匹配同识别 ID 的状态等级行。 |

| 固定字段 | 中文列名 | 填法 |
|---|---|---|
| `override_priority` | 覆盖优先级 | 仅争用设定、替换、移除时比较；越大越优先，留空按 0。 |

| 固定字段 | 中文列名 | 填法 |
|---|---|---|
| 末列 | 配置备注 | 不导出；记录意图与前置条件。 |

三个作用对象列恰好选一个；全不选属于配置错误，该词条不作用于任何对象并记录错误。`skill_class` 选“五行”时匹配五行、金行、木行、水行、火行、土行六类；神通系别为“无”时不被按系别的词条命中。状态识别 ID 是字符串，状态表要求有效的非 0 数字文本；无效识别 ID 按状态表规则处理，不能当作另一种匹配方式。

修改1～修改4的结构相同，列名均带“修改N·”前缀。修改块按实际填写顺序使用，未使用的整块留空。每块先选 `$type`（增减、设定、替换、追加、移除），填写【公共】定位列，再只填所选操作的专属列段，其他操作列段留空：

| 列段 | 字段及作用 |
|---|---|
| 【公共】 | `slot` 目标位置、`index` 序号、`filter` 效果限定、`via` 沿引用、`via_slot` 引用内位置、`via_index` 引用内序号。 |

| 列段 | 字段及作用 |
|---|---|
| 【增减】 | `adj_param` 修改项目、`adj_add` 固定增减值、`adj_pct` 按比例值。 |

| 列段 | 字段及作用 |
|---|---|
| 【设定】 | `set_param` 修改项目、`set_value` 修改值、`set_text` 文本值；另有 `set_aim`、`set_skill_class`、`set_faction`、`set_priority`、`set_time_override`、`set_pile_type`、`set_attr_key`、`set_control` 八个选项列。 |

| 列段 | 字段及作用 |
|---|---|
| 【替换】 | `replace_id` 模板行ID、`replace_slot` 模板位置、`replace_index` 模板序号。 |

| 列段 | 字段及作用 |
|---|---|
| 【追加】 | `append_id` 模板行ID、`append_slot` 模板位置、`append_index` 模板序号。 |

| 列段 | 字段及作用 |
|---|---|
| 移除 | 没有专属列段，只填【公共】定位列。 |

**非导出示例行**：首列标 `##`；示意 `id=99000001`、`skill_identify_id=123456`，其余作用对象列按未选规则填；修改1填 `$type=增减`、`slot=自身`、`adj_param=冷却时间`、`adj_add=-1000`、`adj_pct=-2000`，其余修改列段留空。若这门神通的原冷却为 10000 毫秒且无其他词条，结果为 `floor((10000-1000)×(10000-2000)/10000)=7200` 毫秒。示意 ID 投放前必须换成实际存在且合法的 ID；此行只展示列段填法。

## 三、对象匹配与系别转换

神通识别 ID 匹配该门神通的全部等级行；状态识别 ID 匹配同族状态等级行。按状态对象的词条对角色施加的该状态在各调用来源生效；从一门神通沿引用进入状态的修改仅作用于该神通的这次调用，其他神通引用同一状态时保持各自结果。引用指向基础表的具体行 ID，识别 ID 负责对象匹配，不作为增减参数。

含 `set_skill_class` 系别转换的按系别词条，按神通默认系别匹配；按神通识别 ID 作用的转换词条也参与决定最终系别。其他按系别词条按转换后的最终系别匹配。火行神通转为金行后，金行词条进入、火行词条退出，“五行”词条在转换前后均可命中。转换优先：按最终系别进入的词条若在争用裁决中压掉或同级互斥掉转换词条，使神通回到该词条已无法匹配的系别，该词条对这门神通整条不生效；不依赖此次转换的词条继续裁决。

## 四、定位、引用与效果身份

`slot`、`via_slot` 和模板位置使用同一位置枚举，但每种操作有自己的合法取值。`slot=自身` 指神通基础参数或状态整体参数；主选择器实际选单位，子选择器划分已选单位；`效果`指基础表原有效果，`效果列表`只供追加，`新增项`只指本词条此前追加的效果。“无”仅用于不需要第二级定位的引用内位置。

| 【公共】填法 | 定位结果 |
|---|---|
| `slot=效果, index=2` | 基础表原效果2，移除效果1后仍叫效果2。 |

| 【公共】填法 | 定位结果 |
|---|---|
| `slot=效果, index=0, filter=持续伤害` | 基础表未移除的全部持续伤害效果，不含任何追加效果；筛不到则本词条对该对象整条不生效。 |

| 【公共】填法 | 定位结果 |
|---|---|
| `slot=效果, index=1, via=引用状态, via_slot=自身` | 效果1引用的状态自身；仅本次调用受局部修改。 |

| 【公共】填法 | 定位结果 |
|---|---|
| `slot=效果, index=1, via=调用神通, via_slot=主选择器` | 调用技能、弹道命中或光环效果引用的神通等级行的主选择器。 |

| 【公共】填法 | 定位结果 |
|---|---|
| `slot=新增项, index=1` | 本词条第一次“追加”生成的效果，供后续修改块调整；不能指向别的词条的新增项。 |

目标位置为“效果”时，正序号从 1 开始，必须在基础表原有效果范围；序号 0 必填 `filter`，只展开原有效果中类型相符且未被移除的项。非 0 序号可以不填 `filter`，填了必须与所指效果的实际类型一致。“新增项”的序号按本词条第几次追加计数，从 1 开始，且只能由后续修改块引用。其他位置序号留空。`via=无` 表示直接修改定位对象；`via=引用状态` 从调用状态效果进入所引状态；`via=调用神通` 从调用技能、弹道命中或光环效果进入所引神通等级行。`via_index` 在引用内位置为“效果”时遵守同一序号规则。引用 ID 被设定到新对象后，引用内定位与项目须按新对象重新检查。

效果限定的现行词表：神通效果为伤害、调用状态、治疗、召唤单位、位移、弹道、调用技能；状态效果为控制、持续伤害、持续治疗、属性修正、光环。没有“调用词条”效果类型。不存在的选择器、越界或已移除的效果、错误的限定，都会使词条对该对象整条失效。

**沿引用合并示例（非导出）**：词条甲选 `buff_identify_id=〔中毒识别ID〕`，修改1填“增减／自身／持续时间／固定增减值 3000”；词条乙选 `skill_identify_id=〔神通甲识别ID〕`，修改1填“增减／效果／序号 1／沿引用 引用状态／引用内位置 自身／持续时间／固定增减值 3000”。在效果1确为调用该中毒状态、原持续时间为 12000 毫秒时，神通甲这次调用的持续时间为 18000 毫秒，其他调用来源为 15000 毫秒。方括号内的识别 ID 须替换为基础表真实值；两条词条均须把项目填在【增减】列段。

## 五、五种修改操作

| 操作 | 合法填法与结果 |
|---|---|
| 增减 | `adj_param` 必填，且须为可增减的数值项目；`adj_add` 按参数单位填整数正负量，`adj_pct` 填整数万分比增量。两列可在同一修改块同时填写，先加全部固定量再按全部比例量缩放。 |

| 操作 | 合法填法与结果 |
|---|---|
| 设定 | 数值、是否类、引用 ID 类填 `set_param` 与整数 `set_value`；文本类填 `set_param` 与**必填的** `set_text`；枚举类用对应选项列，只设选项时 `set_param` 留空。修改项目与八个选项列均空属于配置错误。 |

| 操作 | 合法填法与结果 |
|---|---|
| 替换 | 目标只能是主选择器、子选择器或 `效果` 且序号大于 0。填 `replace_id`、`replace_slot`，模板位置为效果时再填从 1 开始的 `replace_index`。模板行与目标同属神通或状态，模板内容种类与目标相容。 |

| 操作 | 合法填法与结果 |
|---|---|
| 追加 | 目标必须是 `效果列表`；填 `append_id`、`append_slot=效果`、从 1 开始的 `append_index`。把所选模板效果加到列表末尾，后续块可用“新增项”调整。追加后有效效果数允许超过基础表三个效果位。 |

| 操作 | 合法填法与结果 |
|---|---|
| 移除 | 目标只能是 `效果` 且序号大于 0；从有效组合移除该基础表原有效果，其余原有效果序号不重排。 |

替换、追加的模板行 ID：神通内容用技能表具体等级行 `id`，状态内容用状态表行 `id`；不是识别 ID，也不另填“模板对象”。模板位置缺少内容、模板序号越界、模板行不存在或类型不相容时，对该对象整条词条不生效。模板只提供选定的选择器或效果，不复制模板行身份或未选部分。替换后的效果仍以目标原序号定位；其参数必须适用于新效果类型。追加效果只能引用本词条的追加次数。直接改被调用对象用设定引用 ID；不能通过“复制自身”隐式替换整门神通或状态。

文本参数没有“留空即清空或恢复默认”的通用填法；`set_text` 未填属于不合法的设定。需要清空资源时，须先明确该文本列如何表达空串及导出行为，再制定可用填法。

**追加与后续修改示例（非导出）**：某神通词条的修改1填 `$type=追加`、`slot=效果列表`、`append_id=〔有效神通等级行ID〕`、`append_slot=效果`、`append_index=1`；修改2填 `$type=增减`、`slot=新增项`、`index=1`、`adj_param=触发概率`、`adj_add=-1000`。若模板效果1原概率为 10000，且追加内容及参数适用，新增效果的结果为 9000；基础表原效果编号不变。模板行 ID 投放前必须换成包含所需效果的真实等级行 ID。

## 六、参数目录与基础表语义

下表列出新词条目录全部项目；“增减/设定”均使用上述对应列，“仅设定”不得填【增减】。项目不属于定位对象、形状或效果类型时，对该对象整条词条不生效。参数原格留空须先依技能、状态表取得类型默认值或有效值；不得把留空一概解释为可以增减的实数。

## 七、多词条合并、冲突与撤销

对同一对象先结算所有有效的整项替换、追加、移除，形成有效内容，再把设定与增减合并到仍存在的参数。其他词条替换某效果后，针对该位置的数值修改若适用于新类型仍生效；若参数不再适用，相应词条整条失效。移除后的效果不能再用正序号增减或设定；序号 0 展开会跳过已移除的效果。多个追加各自进入列表，不因加入同一列表而争用。

同一处数值参数按全部生效词条统一计算，结果与词条 ID 顺序无关：

```text
基准值 = 有生效设定时的设定值，否则为原值
最终值 = floor((基准值 + Σ固定增减值) × (10000 + Σ按比例值) / 10000)
```

仅在合并后统一向下取整。比例值是万分比增量，多个比例先相加；同一“增减”块允许固定值和比例值同时填。是否类参数仅可设定，按 1/0 落值，结果非 0 为“是”。各参数特殊值、运行校验和边界各自处理，不能凭旧案统一截断为非负。

设定按“实际内容＋修改项目”争用；替换、移除作用整项，按实际内容争用，两种整项操作在同一位置互相冲突。`index=0` 展开后与正序号指到同一原有效果，也算同一处。相同结果共存，不算冲突，同一整项结果只应用一次。增减、追加不参与优先级争用，但所在词条会随其其他修改被整条淘汰。

不同结果争用时，`override_priority` 越高越优先：低优先级词条整条被压制。相同优先级的直接争用方全部不生效，再考虑低一级。每轮先处理高优先级压制，再处理同级互斥，重复裁决到无人出局；已被高优先级压制的词条不得再在另一处牵连其他词条。高优先级词条因配置错误退出时，原来被它压制的低优先级词条重新进入裁决。

**交叉争用例（冷却单位为毫秒，灵力消耗单位为点）**：三条词条作用于同一神通。A 设冷却时间 3000；B 设冷却时间 5000、灵力消耗 8；C 设灵力消耗 6。三条同优先级时 A/B 与 B/C 分别直接冲突，A、B、C 全部退出。A 优先级提高后先压掉 B，C 可生效，结果冷却时间 3000、灵力消耗 6。此例不使用本项目当前固定为 0 的前后摇字段。

一条词条的四块修改对单个被匹配对象是原子的：任一块定位不到内容、效果限定不符、项目或操作不适用、模板无效、文本值缺失、数值不是整数、同条词条自相矛盾，都使该词条对该对象整条失效。按系别匹配多门神通时，一门不适用不影响其他门。所有剩余词条重新裁决与合成。来源撤销或适用范围变化后，按本次范围内仍有效的来源重新裁决与合成；同 ID 在本次范围内尚有任一有效来源时只生效一次。

状态同识别 ID 的不同等级按状态表的同族压制处理；状态各效果施加时独立判概率，周期跳动不重新判。已经开始的冷却不因冷却参数变化而重写剩余时间。其他施放中、状态刷新中与界面预测时点沿技能和状态执行规则核对，不把词条表没有定义的时点行为当作独立填法。

## 八、待裁定或待接入

### 概率结果为 0

技能和状态基础表均写明其原始 `rate` 填 0、负数或不低于 10000 表示必定触发；词条说明却将“触发概率”列为可增减、可设定的 0～10000 参数，没有明确经词条计算得到的 0 是否仍按基础表哨兵值解释。旧案曾主张“修改后的 0 不再当作必定触发”，当前不能据此定稿。投放任何以结果 0 为条件的概率词条前，须明确求有效基准、合并、落值及执行判定是否区分原值 0 和修改后 0。
### 完整伤害增幅

保留“对一次完整伤害（含固定伤害与新增效果）统一增幅”的设计诉求；新 `AffixParam` 没有“完整伤害增幅”，`affix_config` 也没有对应修改列。当前不得按旧案配置或导出此类词条，需先补目录、表列或执行能力，再确认叠加与伤害归属。
### 未开放效果类型

当前效果类型词表无对应项；须先在技能/状态基础表与词条目录明确类型、模板、参数及判定规则，才能制作替换或追加示例。当前“现行可配置”示例不得使用占位模板 ID 冒充可导出行。
### 子选择器公共字段

新词条表允许目标阵营、目标优先级及部分选择器参数定位到子选择器，技能表同时说明子选择器只判断形状、五个公共列不起作用。须确认词条修改在执行时是否同样无效；确认前不把“修改子选择器目标阵营/优先级/人数”写成能改变目标的词条。
### 空文本清除

设定文本参数必须填文本值；当前没有“留空即清除/恢复默认”的合法填法。若确需此能力，须明确专用值或导出规则。
