# 怪物表配置口径
怪物的身份维度、来源类型、核心字段、属性扩展方式与配置校验规则。具体主键与数值以 `G怪物表` 为准。

## 怪物的身份维度
| 维度 | 字段 | 说明 |
|---|---|---|
| 身份 | `monster_id` | 配置唯一主键 |
| 名称 | `monster_name` | 玩家可见名称 |
| 战斗层级 | `realm_id`、`realm_sublevel` | 用于属性基数与境界压制；普通野兽只作为引擎层级，不在文案中称修行境界 |
| 品质 | `quality` | 凡、灵、玄、仙、神、道；高品质同层怪形成精英差异 |
| 特殊职能 | `boss_role` | 是否承担首领机制；不替代品质 |
| 来源 | `origin_type` | 原生、魔化、造物 |
| 行为 | `ai_profile` | 只引用行为参数组，不用来源类型写死全类行为 |
| 掉落 | `drop_scheme_ids` | 引用掉落方案 |

## 品质与战斗层级正交
同层怪可因品质不同形成普通、精英和高品质个体。BOSS 是遭遇职能，不是第七档品质。

## 怪物来源三类
| 枚举 | 中文 | 边界 | 典型 |
|---|---|---|---|
| `native` | 原生 | 自然繁衍或在本地生态中形成 | 小野狼这类普通野兽、具修行层级的妖兽 |
| `corrupted` | 魔化 | 受到魔气、魔物或相关力量改变 | 由魔气改变的原有生灵 |
| `constructed` | 造物 | 被阵法、炼器、术式或其他主体制造 | 石傀儡这类人造守卫 |

## 来源不决定行为
怪物来源只说明来历，不直接决定是否恐惧、休息、逃跑、结群或使用神通。具体行为由 `ai_profile` 引用的 AI 参数配置。

## 怪物核心字段（一）
| 字段 | 类型 | 必填 | 说明 |
|---|---|:---:|---|
| `monster_id` | int 或 string | 是 | 唯一主键；格式以实际配置为准 |
| `monster_name` | string | 是 | 名称 |
| `realm_id` | int | 是 | 0 到 8 的战斗层级 |
| `realm_sublevel` | int | 是 | 小层级；无细分时为 0 |
| `quality` | enum | 是 | 凡、灵、玄、仙、神、道 |
| `boss_role` | bool 或 enum | 是 | 普通遭遇或首领职能 |
| `origin_type` | enum | 是 | `native`、`corrupted`、`constructed` |
| `hp` | int | 是 | 最大生命基础值 |
| `mp` | int | 是 | 法力；不使用神通的怪物可为 0 |

## 怪物核心字段（二）
| 字段 | 类型 | 必填 | 说明 |
|---|---|:---:|---|
| `atk` | int | 是 | 物理攻击单值 |
| `def` | int | 是 | 物理防御单值 |
| `matk` | int | 否 | 术法攻击单值 |
| `resist` | int | 否 | 术法抗性单值 |
| `move_speed` | number | 是 | 移动速度 |
| `attack_range` | number | 是 | 攻击距离 |
| `attack_interval` | number | 是 | 攻击间隔 |
| `aggro_range` | number | 是 | 索敌范围 |
| `leash_range` | number | 是 | 相对出生点或刷新区域的脱战边界 |

## 怪物核心字段（三）
| 字段 | 类型 | 必填 | 说明 |
|---|---|:---:|---|
| `ai_profile` | string | 是 | 行为参数组 |
| `drop_scheme_ids` | array | 是 | 掉落方案列表 |
| `control_ids` | array | 否 | 神通或特殊行为列表 |
| `model_id` | string | 是 | 模型资源标识 |
| `model_scale` | number | 是 | 模型缩放 |
| `description` | string | 否 | 地图或提示文本 |

## 怪物表禁止字段
`G怪物表` 禁止出现击杀经验类字段（`exp_gift`、击杀经验、击杀直接修为），禁止攻击上下限、物防上下限、法防上下限，禁止职业标签和按职业掉落，禁止由文件名或示例数据猜测出的属性键。

## 怪物属性扩展
动态属性修饰项使用键值列表：
```text
modifiers[{attr_key, op, value}]
```

`attr_key` 必须存在于现行属性字典。`op` 只允许固定值加法或万分比乘法。最终属性由属性系统从境界基础值、品质修正和怪物修饰项重算。同一字段不得同时出现在固定列和动态修饰项中。

## 旧项目样例不进现行配置
鸡、鹿、稻草人、多钩猫、钉耙猫等旧项目样例不得进入现行怪物配置。

## 怪物配置校验项
主键唯一，名称非空。`realm_id`、品质、来源和 AI 参数枚举合法。属性值非负，攻击间隔大于 0，索敌范围不大于允许的性能上限。脱战边界必须能映射到出生点或刷新区域。引用的掉落方案、神通和模型必须存在。怪物死亡只触发掉落与事件，不直接增加修为。
