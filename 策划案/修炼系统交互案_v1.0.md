# 修炼界面交互
修炼界面的信息架构、公共视觉与布局规则、修炼页与灵气页的分区与状态、达到突破线的表现、直接突破与材料突破的操作流程、破境准备弹窗的分区、突破判定与结果表现。固定设计分辨率 1344×756。

## 设计结论
1. 修炼系统只有两个一级页签：**修炼**、**灵气**。
2. 修炼页以角色盘坐和修仙氛围为视觉核心，详细灵气统计全部移入灵气页。
3. 角色当前境界、修为进度和是否可突破必须一眼可见。
4. 修为达到突破线后不自动升级，在角色本体上出现可点击的突破光效。
5. `boundary_type` 只有“小 / 大”两类：小显示“突破”，大显示“破境”。两类共用同一套底层流程和准备弹窗结构，只改变名称与表现强度。
6. 是否打开突破准备弹窗由必需材料决定：
   - 未配置必需材料：点击后直接完成，不弹二次确认。
   - 配置了必需材料：打开突破准备弹窗，即使最终成功率为 100% 也要让玩家确认材料消耗。
7. 突破丹药采用 **1 个主突破丹槽 + 2 个辅助丹槽**。必需材料与丹药槽分区展示，不能混为一组。
8. 灵气不影响突破率。最终成功率只读取境界配置、保底和本次投入丹药。
9. 不使用“经验”“周天”“自动突破”等口径。

```text
├─ 修炼页
│  ├─ 当前大境界 / 小境界 / 阶段
│  ├─ 修为进度 / 突破线 / 溢出修为
│  ├─ 角色盘坐与修为飞入表现
│  ├─ 当前状态四项
│  ├─ 右侧属性与效率摘要
│  ├─ 条件状态图标
│  └─ 打坐 / 出关
│
├─ 灵气页
│  ├─ 当前灵气源
│  ├─ 灵气来源贡献明细
│  ├─ 当前储量 / 上限 / 产出
│  ├─ 名额占用
│  ├─ 每时辰吸收
│  ├─ 修为转化率

└─ 二级弹窗

```

## 公共视觉与布局规则·固定画布
- 设计分辨率：1344×756。
- PC 横版，不提供竖版重排。
- 外框、页签、标题玉牌与按钮沿用项目已审核 UI 的统一规格。
- 主材质：玄青深绢、深蓝织锦、旧铜描金、灰青玉、低对比祥云暗纹。
- 不使用现代卡片、玻璃拟态、霓虹发光、亮金大面积装饰。

## 公共视觉与布局规则·公共框架
- 左侧为窄竖向页签，仅显示“修炼”“灵气”。
- 顶部中央使用青玉标题牌，显示当前页名。
- 右上角使用项目统一暗朱红关闭按钮。
- 信息区采用细旧金线分组，不堆叠大量独立卡片。
- 数值文字使用米白色；说明文字使用灰米色；警告使用低饱和暗朱红。

## 公共视觉与布局规则·状态图标
- 虚弱、药效、功法等条件状态使用 42×42 图标。
- 只在状态存在时显示；无状态时不占位。
- 鼠标悬停显示名称、效果和剩余“X时辰X刻”。
- 交付切图时每个图标另出 82×82 高清规格，PNG 透明背景。

## 修炼页·页面目标
玩家打开页面后，第一眼依次看到：
1. 中央正在盘坐的角色。
2. 当前大境界与小境界。
3. 修为进度与是否可突破。
4. 当前打坐状态。
5. 右侧修炼属性摘要。

## 修炼页·页面分区·A. 顶部境界与修为区
- 主标题示例：`筑基 · 三层`。
- 次级阶段：`前期`，小字显示，不抢主标题。
- 修为条显示当前突破段：`12,400 / 20,000`。
- 未满时显示当前百分比。
- 满值后显示“瓶颈”，修为条保持满格；下方显示溢出修为 `溢出 +2,350`。
- 不出现“经验”“经验条”。

## 修炼页·页面分区·B. 中央角色演出区
- 角色处于画面视觉中心，盘坐在蒲团或阵纹之上。
- 有灵气时，使用低饱和青白灵气环绕；灵气强度随实际吸收变化。
- 无灵气、名额已满或灵气干涸时，灵气环绕消失或降至极淡。
- 修为可突破时，在角色胸口至丹田区域出现青玉色呼吸光与细金环纹，鼠标悬停显示：
  - 小突破：`修为已满，点击突破`
  - 大突破：`境界圆满，点击破境`
- 突破入口只在真正可操作时亮起；虚弱期间不显示可点击光效。

## 修炼页·页面分区·C. 修为增长表现
- 每 3～5 秒播放一次表现：灵气从角色丹田向上凝聚，沿弧线飞入修为条。
- 到达修为条时显示本段累计飘字：`修为 +36`。
- 飘字数值为该表现周期内的“基础修为 + 灵气修为”。
- 该表现仅是客户端展示；服务端仍按一刻正式结算并校正。
- 校正时平滑追值，不允许修为条明显回退或连续爆出补偿飘字。

## 修炼页·页面分区·D. 当前状态区
常驻只显示以下四项：
| 项目 | 示例 | 规则 |
|---|---|---|
| 当前场景 | 青冥洞府 | 显示当前实际场景，不等同于灵气源名称 |
| 当前状态 | 打坐中 | 可显示未打坐、打坐中、打坐中·虚弱 |
| 灵气状态 | 充盈 | 取值：充盈、干涸、无灵气、名额已满 |
| 打坐时间 | 3时辰4刻 | 本次连续打坐时长 |

虚弱时间不并入第五个常驻项目。虚弱存在时，在状态区上方额外显示一条暗朱红提示：`虚弱：剩余 2时辰4刻`；无虚弱时整条隐藏。

## 修炼页·页面分区·E. 右侧属性与统计区
右侧只显示修炼结果相关摘要：
- 当前境界：筑基三层。
- 所处阶段：前期。
- 基础修为：12／时辰。
- 灵气修为：18／时辰。
- 合计修为：30／时辰。
- 当前生效效果：仅显示 42×42 图标行，详情悬停查看。
不显示灵气来源、储量、产出、吸收明细和名额详细说明。

## 修炼页·页面分区·F. 操作区
- 固定保留两个按钮位置：`打坐`、`出关`。
- 未打坐：打坐可用，出关置灰。
- 打坐中：打坐置灰，出关可用。
- 点击页面“打坐”：传送回洞府并直接开始打坐。
- 野外“就地打坐”由场景交互提供，不增加修炼页第三个按钮。

## 修炼页·修炼页状态
| 状态 | 角色表现 | 页面反馈 |
|---|---|---|
| 未打坐 | 正常站立或待机 | 效率为 0；打坐按钮亮起 |
| 打坐·充盈 | 盘坐、青白灵气环绕 | 修为条增长；灵气状态为充盈 |
| 打坐·无灵气 | 盘坐、无灵气特效 | 只显示基础修为 |
| 打坐·名额已满 | 盘坐、无灵气特效 | 显示名额已满，仅获得基础修为 |
| 瓶颈 | 人物出现突破呼吸光 | 修为条满格，显示溢出修为 |
| 虚弱 | 角色低头、灰暗、气息紊乱 | 显示虚弱条；不显示可点击突破光效 |

## 灵气页·页面目标
解释“当前灵气从哪里来、积攒了多少、角色能吸多少、最终换成多少修为”。本页承担全部详细灵气信息。

## 灵气页·顶部总览
- 当前灵气源名称：`青冥洞府`。
- 类型：个人灵气源。
- 状态：充盈 / 干涸。
- 储量条：`680 / 1,000`。
- 当前名额：`1 / 1`。

## 灵气页·灵气来源贡献明细
按来源逐项显示，不能只给总数：
| 来源 | 示例贡献 | 展示说明 |
|---|---:|---|
| 洞府基脉 | +8／时辰 | 洞府自身基础产出 |
| 聚灵阵 | +12／时辰 | 阵法或洞府设施 |
| 地底灵脉 | +6／时辰 | 地域、地脉加成 |
| 镇府法宝 | +4／时辰 | 法宝或特殊家具 |
| 其他效果 | +0／时辰 | 临时活动、功法、BUFF 等 |
列表底部显示：`合计产出 30／时辰`。

每行可悬停查看来源对象、是否限时、剩余时间和具体修正方式。没有贡献的来源默认不显示，但“其他效果”有临时效果时自动出现。

## 灵气页·吸收与转化
- 每时辰灵气吸收：18 点／时辰。
- 基础转化值：1 点灵气 → 1 修为。
- 转化增幅与额外转化值合并为可理解结果：`当前转化：1点灵气 → 1.5修为`。
- 实际灵气修为：27／时辰。
- 若灵气不足，额外显示：`当前灵气不足，实际吸收 11／时辰`。
- 若名额已满，显示：`未占用灵气名额，当前仅获得基础修为`。

## 灵气页·灵气页不包含
- 突破率。
- 突破材料或丹药。
- 突破按钮。
- 周天次数或周天上限。

## 达到突破线
1. 服务端在结算结束后标记当前等级可突破。
2. 修为条切换为满格“瓶颈”状态。
3. 角色本体出现突破或破境呼吸光效。
4. 播放一次轻提示音，不弹窗、不打断玩家。
5. 玩家继续打坐时，修为继续进入溢出值，但等级不变。
6. 玩家点击角色光效时，先补算至当前时刻，再检查修为、虚弱、材料和事务状态。

## 直接突破流程·判定
- 当前修为达到突破线。
- 未处于虚弱。
- 当前等级未配置必需材料。
- 基础成功率为 100%。

## 直接突破流程·操作
1. 玩家点击角色身上的突破光效。
2. 客户端立即锁定重复点击。
3. 服务端创建唯一突破事务并完成必定成功判定。
4. 播放短突破特效和新境界名称飘字。
5. 更新等级、属性、修为条和角色表现。
6. 不弹二次确认，不出现材料或成功率界面。

## 直接突破流程·溢出处理
- 成功后保留全部累计修为。
- 若累计修为又达到下一突破线，只重新显示下一次突破入口，不自动连升。

## 材料突破 / 破境准备弹窗·触发
当前等级配置了任意必需材料时，点击角色突破光效后打开弹窗。

## 材料突破 / 破境准备弹窗·弹窗结构
```text
┌──────────────────── 突破 / 破境 ────────────────────┐
│ 当前：筑基三层       →       目标：筑基四层       [关闭] │
├──────────────────────┬──────────────────────────────┤
│                      │ 基础成功率 55%                │
│    角色突破演出区      │                              │
│                      │ 必需材料                      │
│  人物、阵法、丹光      │ [材料 3/5] [材料 8/8] [空]     │
│                      │                              │
│                      │ 突破丹药                      │
│                      │ [主突破丹] [辅助] [辅助]       │
│                      │                              │
│                      │ 最终成功率 82%                │
├──────────────────────┴──────────────────────────────┤
│ 失败后虚弱：12时辰；材料与本次投入丹药不退还             │
│ [暂缓突破]                              [开始突破]       │
└──────────────────────────────────────────────────────┘
```

## 材料突破 / 破境准备弹窗·必需材料区
- 最多展示 3 组固定材料。
- 每组显示 42×42 图标、材料名、需求数与持有数。
- 数量不足使用暗朱红文字并显示来源提示；开始按钮置灰。
- 该区域只读，玩家不能用其他材料替换。

## 材料突破 / 破境准备弹窗·丹药区
- 1 个主突破丹槽，2 个辅助丹槽。
- 点击空槽打开背包式选择浮层，只列出当前境界、当前突破可使用的丹药。
- 列表显示图标、名称、持有数、本次效果。
- 选中后放入槽位并实时重算最终成功率或其他配置效果。
- 再次点击槽位可替换或取下。
- 取消弹窗不消耗丹药。

## 材料突破 / 破境准备弹窗·成功率区
依次展示：
1. 基础成功率。
2. 保底加成，如存在则显示 `连续失败加成 +10%` 或 `本次已触发保底`。
3. 丹药加成。
4. 最终成功率，限制在 0%～100%。
灵气、洞府、打坐时长不得出现在成功率构成中。

## 材料突破 / 破境准备弹窗·失败后果
在确认按钮上方始终明示：
- `失败将进入虚弱 X时辰X刻`。
- `材料与本次投入的丹药不退还`。
- `失败不扣修为、不掉等级`。

## 材料突破 / 破境准备弹窗·按钮
- 暂缓突破：关闭弹窗，保持瓶颈和当前打坐状态，不消耗任何内容。
- 开始突破：材料满足时可用；点击后锁定弹窗并进入事务流程。
- 右上角关闭与“暂缓突破”等价。

## 突破判定与结果·确认后的顺序
1. 再次补算修为。
2. 校验当前等级、突破线、虚弱、材料、丹药与重复请求。
3. 创建唯一突破事务 ID。
4. 预占必需材料和本次丹药。
5. 存档 pending 事务。
6. 读取挑战结果；当前版本无附加挑战时直接进入概率判定。
7. 生成并锁定本次唯一结果。
8. 正常成功或失败均提交材料与丹药消耗。
9. 写入角色结果并播放表现。

## 突破判定与结果·成功
- 进入下一等级。
- 累计修为与溢出修为全部保留。
- 更新等级提供的属性和自动领悟神通。
- 小突破直接成功：轻反馈。
- 材料小突破成功：中反馈。
- 破境成功：全屏重反馈，仅本人可见，不做广播。
- 若溢出修为已达到下一节点，结果结束后重新出现突破光效，仍需再次手动点击。

## 突破判定与结果·失败
- 不扣修为、不掉等级、不退境界。
- 材料与本次丹药正常消耗。
- 增加对应边界的连续失败计数。
- 进入虚弱，突破入口关闭。
- 关闭突破弹窗，返回修炼页显示反噬表现和虚弱倒计时。

## 虚弱流程·推荐冻结规则
- 突破失败后角色保持打坐姿态，不强制出关。
- 角色仍按 10% 效率获得基础修为。
- 立即停止吸收灵气并释放灵气名额。
- `是否打坐` 与 `是否占用灵气名额` 必须分开判定，不能再视为同一个状态。
- 虚弱期间修为可以继续累计，但不能发起突破。

## 虚弱流程·解除
- 时间到后自然解除。
- 可通过丹药缩短剩余时间，具体药效由丹药系统配置。
- 解除时播放一次轻提示，人物恢复正常盘坐表现。
- 如果角色仍在灵气源范围内，解除时即时尝试占用空余名额；当时无空位则只获得基础修为，不进入等待队列。
- 若修为仍达到突破线，重新显示角色突破光效。

## 出关与行为打断
以下操作均按“先结算、再结束打坐、最后执行行为”处理：
- 点击出关。
- 移动。
- 主动攻击。
- 施展神通。
- 受到攻击。
- 传送。
- 离线或掉线。
- 离开场景。

固定顺序：
1. 将 `last_settle_time` 至当前时刻的收益按实际时长结清。
2. 停止打坐。
3. 释放灵气名额。
4. 清理当前在线修炼位置。
5. 执行原行为。
若此前通过修炼页“打坐”传送回洞府，主动出关后传回进入打坐前的合法位置。

## 上线闭关结算弹窗·打开规则
- 每次上线均弹出一次，包括离线时间很短或收益为 0。
- 弹窗覆盖在修炼页之上；背景中的角色已经处于洞府打坐状态。
- 关闭后仍停留在修炼页，不需要再次点击打坐。

## 上线闭关结算弹窗·展示内容
- 标题：`闭关结算`。
- 闭关时长：`12时辰4刻`。
- 达到离线上限时提示：`已达本次闭关收益上限`。
- 获得修为：基础修为、灵气修为、合计修为。
- 灵气收支：洞府产出、实际吸收、剩余储量。
- 当前境界与修为进度。
- 达到突破线时显示主按钮：`前往突破`。
- 未达到时主按钮：`收下`。

## 上线闭关结算弹窗·前往突破
- 点击后先关闭结算内容。
- 页面定位到中央角色。
- 如果是直接突破，立即执行。
- 如果配置了必需材料，打开突破准备弹窗。

## 灵气来源贡献数据
为支持灵气页逐项展示，需要灵气源向前台提供贡献明细。每项至少包含：
| 字段 | 说明 |
|---|---|
| `contribution_id` | 独立贡献实例 ID |
| `provider_type` | 洞府基脉、聚灵阵、地底灵脉、法宝、家具、BUFF 等 |
| `provider_id` | 来源对象 ID |
| `provider_name` | 玩家可见名称 |
| `spirit_rate_delta` | 每时辰产出修正 |
| `spirit_cap_delta` | 储量上限修正 |
| `enabled` | 当前是否生效 |
| `expire_time` | 到期时间，永久来源为 0 |

最终灵气源总值仍由系统统一结算，贡献明细只用于解释和展示，不另建第二套修炼公式。

## 新增运行时与存档需求·打坐计时
- `meditation_start_time`：本次连续打坐开始时间。
- 开始打坐时写入；出关或打断时清空。
- 用于修炼页“打坐时间”，不能用 `last_settle_time` 替代。

## 新增运行时与存档需求·灵气名额
- `is_meditating`：是否正在打坐。
- `occupied_spirit_source_id`：当前实际占用名额的灵气源；为空表示只获得基础修为。
- `cultivation_location`：当前打坐地点或可关联灵气源，不再等同于已经占位。

## 新增运行时与存档需求·突破保底
- `boundary_fail_counts`：按需要记录当前突破节点的连续失败次数。
- 配置需要提供失败递增方式、保底次数或本次固定必成标记。
- 成功后清除当前节点失败记录。
- 首次筑基固定成功可由当前节点配置为最终 100%，但若有必需材料仍须打开准备弹窗。

## 新增运行时与存档需求·丹药槽
丹药配置需要补充：
- 是否为突破可用丹药。
- 槽位类型：主突破 / 辅助。
- 适用境界与适用边界。
- 成功率加成或其他效果。
- 是否允许同名重复投入。
- 单次投入上限。

## 异常与边界处理·重复点击
- 点击“开始突破”后立即禁用按钮。
- 同一事务 ID 的重复请求只返回同一个结果。

## 异常与边界处理·断线或崩服
- 重新上线后发现 pending 突破事务，弹出 `正在恢复本次突破结果`。
- 已产生结果：恢复同一结果并播放简化结果反馈。
- 无法确认结果：回滚预占，不消耗材料和丹药。
- 不允许出现“东西扣了但没有结果”。

## 异常与边界处理·背包数量变化
- 突破弹窗打开后，其他行为导致材料变化时，点击确认必须重新校验。
- 校验失败时不关闭弹窗，刷新持有数并标红不足项。

## 异常与边界处理·虚弱期间到达突破线
- 修为条显示满值和瓶颈。
- 不显示可点击突破光效。
- 虚弱条说明：`虚弱期间无法突破`。
- 虚弱结束后自动刷新入口。

## 异常与边界处理·Lv80
- 达到当前版本终点后不显示普通破境入口。
- 显示版本终点说明；渡劫属于后续独立玩法，不在当前弹窗内预留空按钮。
