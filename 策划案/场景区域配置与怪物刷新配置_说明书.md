# 场景区域配置与怪物刷新配置
场景与区域的字段语义、怪物刷新方案的挂接规则、五时段的作用边界、魔化区域的处理与配置校验项。实际字段与数值以 `C场景区域配置` 和 `G怪物刷新配置` 为准。

## 场景与区域的区别
场景是地图实例与表现资源的容器。区域是场景内承担出生、安全、刷新、传送、采集或事件作用的空间边界。场景 ID 和区域 ID 只表示身份，不编码境界、装备档次或开放顺序。玩家可在规则允许时提前进入高危区，危险由怪物、境界压制和事件承担，不靠 ID 顺序硬锁。

## 场景字段语义
| 语义 | 说明 |
|---|---|
| 场景主键 | 唯一身份 |
| 场景名称 | 玄黄界内正式名称 |
| 地图资源 | 地图块或资源标识 |
| 安全复活点 | 玩家死亡或位置失效时的合法回退点 |
| 推荐境界 | 风险提示，不默认等于准入门槛 |
| 准入条件 | 仅在确有玩法需要时设置 |
| 镜头与地图 | 镜头、小地图和大地图资源 |

## 场景命名范围
场景名称应来自青冥宗、宗门后山、妖兽山脉、古战场、魔化区域等项目内场景。银杏渔村、比奇、沃玛、祖玛、赤月、苍月等外部项目名称全部废弃。

## 区域字段语义
| 语义 | 说明 |
|---|---|
| 区域主键 | 唯一身份 |
| 所属场景 | 必须存在 |
| 区域类型 | `safe`、`spawn`、`loot`、`event`、`teleport`、`boundary` 等 |
| 边界 | 矩形或配置支持的其他形状 |
| 出生与复活标记 | 每场景至少一个合法安全点 |
| 刷新方案 | 可挂接多个怪物刷新方案 |
| 传送目标 | 仅传送区域使用 |

## 全地图边界不参与优先命中
全地图边界属于 `map_bounds`，不作为普通区域参加优先命中查询。

## 怪物刷新挂接规则
一个区域可引用多个刷新方案，一个刷新方案最多包含 10 组怪物。刷新默认在玩家第一次进入刷新区域时激活一次。刷新区域同时提供怪物返回边界，怪物实例另记录本次出生点。刷新方案 ID 不编码 BOSS、场景档次或成长顺序，所有语义使用显式字段。

## 五时段与可作用系统
| 时段 | 世界状态 | 可作用系统 |
|---|---|---|
| 清晨 | 阴阳交替，灵气清明 | 环境、早课、采集条件 |
| 正午 | 日灵气最盛，浊气上升 | 火性炼制、材料与事件条件 |
| 傍晚 | 日灵气回落，药力归根 | 灵植采集、回返事件 |
| 夜间 | 月灵气主导，妖兽与草木活跃 | 特殊刷新、神识相关事件 |
| 深夜 | 魔气更易渗出 | 稀有怪、蓝门、魔化事件 |
时段可以选择刷新集合和事件条件，但不直接乘入修炼倍率。

## 魔化区域的处理
魔化区域描述环境来源，不代表区域内所有单位行为相同。怪物条目仍分别登记原生、魔化、造物来源和 AI 参数。魔化层级可影响怪物配置选择与掉落方案，不临时对同一怪物做无边界倍率叠加。

## 配置与地图边界的关系
配置负责记录地图已经存在的场景、区域和挂接关系，不能代替地图制作与空间验证。坐标必须从实际地图或经过验证的地编数据产生，禁止凭文档猜坐标。区域不得重叠到导致安全区、刷新区和传送区无法确定优先级。地图、配置和运行时查询使用同一坐标单位。

## 场景与区域校验项
场景、区域、刷新和传送引用必须存在。每个可进入场景必须有安全复活点。区域边界必须合法且位于地图边界内。刷新区域不得覆盖安全出生点。时段枚举只使用清晨、正午、傍晚、夜间、深夜五个值。
