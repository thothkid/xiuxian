# 法宝界面交互
法宝界面的执行红线、三栏信息架构、御使页与养炼页与打造页的控件、列表状态与翻页、神识总览与占用展示、祭炼与打造的确认交互、冷却与重复切换、提示与错误文案。固定设计分辨率 1344×756。法宝道具的掉落与拾取属于背包与物品系统的交互，不在本案。

## 执行红线·其一
1. **持有不生效，御使才生效。** 获得法宝后处于祭炼0层、`equipped=false`；只有御使后才应用属性、技能、BUFF、词条与世界用途。
2. **0层不是空白层。** 0层已有完整效果、继承、神识占用和展示信息，只是未御使时不生效。
3. **御使有两道门槛：境界与神识。** 角色当前境界 ≥ 法宝 `realm_id` 才能御使；再校验神识是否够。
4. **主动操作一律拦截，被动变化一律不回收。** 神识上限下降或角色境界回退后，已御使法宝继续生效、不自动收回；但不能再御使新的门槛不足法宝。
5. **表现上限不等于御使上限。** 同屏最多显示 `MaxVisibleIndependent` 件（当前配置 **6**），超出的仍完整生效，只隐藏表现。
6. **祭炼每层是完整快照。** 成功后整体卸载旧层，再应用新层。
7. **描述不参与执行。** 战斗效果、世界用途只作展示，实际逻辑读取配置ID。

## 执行红线·其二
8. **祭炼与打造都校验现有炼器技能等级和角色境界。** 直接读取现有「炼器」技能当前等级，不新建等级；任一门槛不足都不扣材料或货币。
9. **打造本期必成。** 已拥有时禁止打造且绝不扣料；成功获得0层、未御使法宝。
10. **所有改变状态的操作走同步消息和操作锁。** 成功、失败、异常都由唯一 `finally` 释放锁并恢复UI；`equipped`是业务状态，不得代替操作锁。
11. **`加属性`只加给法宝自身。** 即使没有模型和出伤单位，法宝也有逻辑属性容器；影响角色或生产系统的世界用途必须调用带法宝来源的 BUFF / 词条 / 技能。

> ⚠️ **三处境界门槛互相独立**：`法宝.realm_id`（御使门槛）／`祭炼.realm_req`（祭炼门槛）／`打造.realm_req`（打造门槛）。一件法宝完全可能「能打造出来但当前境界还御使不了」，这是允许的，UI 必须分别提示。

## 总体结构·一级页签
顶部一级页签固定为：
```text
御使 / 养炼 / 打造
```
- 页签切换只改变左侧列表数据源和右侧操作区。
- 中央详情始终展示当前选中法宝。
- 跨页切换只使用顶部一级页签，不在右下角重复放“去祭炼”“返回御使”等按钮。
- 御使页右下角只保留“御使 / 收回”；祭炼页只保留“祭炼”；打造页只保留“打造”。

## 总体结构·三栏信息架构
```text
法宝主面板（1344×756）
├─ 顶部：标题「法 宝」+ 御使 / 养炼 / 打造
├─ 左栏
│  ├─ 御使 / 养炼：已拥有法宝列表
│  ├─ 打造：已启用打造配方对应的法宝图录
│  └─ 上一页 / 第 X / Y 页 / 下一页
├─ 中栏：法宝展示、名称、品质、境界、核心数值、效果摘要
└─ 右栏
   ├─ 御使：神识、占用、表现状态、御使 / 收回
   ├─ 养炼：祭炼 / 器灵 / 本命、炼器等级、境界、材料、成功率、结果预览、祭炼
   └─ 打造：炼器等级、境界、配方消耗、拥有状态、打造
```

## 公共视觉与布局
- 主材质沿用现有UI：玄青深底、旧铜描金、灰青玉、低对比祥云暗纹。
- 当前选中、可操作、御使中使用青玉色；品质与标题使用旧金色；材料不足、神识不足、超载使用暗朱红；锁定项使用灰色。
- 不使用现代白色卡片、玻璃拟态、霓虹色和大面积亮金。
- 网页原型允许浏览器缩放，但内容逻辑按1344×756组织。
- 页签、标题玉牌、主按钮沿用现有法宝定妆稿比例。

## 左栏列表与翻页·数据源
| 当前页签 | 左栏数据源 | 是否显示未拥有法宝 |
|---|---|---|
| 御使 | 已拥有法宝记录 | 否 |
| 养炼 | 已拥有法宝记录 | 否 |
| 打造 | `打造`表中 `enable=true` 且主表配置有效的配方目标 | 是 |
- 打造配方 `enable=false`、主表无对应法宝、配方字段无效时不进入玩家列表，并记录配置错误。
- 御使与养炼共用选中项和页码；打造使用独立选中项和页码。切换页签后回到各自上次浏览位置。

## 左栏列表与翻页·分组与排序
- 分组顺序固定：战斗 → 生产 → 辅助。
- 组内按 `sort_order` 升序，再按 `fabao_id` 升序稳定排序。
- 分组标题右侧显示该数据源中该分类的总数，不是当前页条数。
- 分页在完成全量稳定排序后进行，不能每个分类分别从第1页开始。

## 左栏列表与翻页·翻页
- 翻页条固定在左栏底部，显示：`上一页　　第 X / Y 页　　下一页`。
- 每页条数作为UI常量配置；当前原型为4条，用于清楚演示翻页。
- 第1页禁用“上一页”，末页禁用“下一页”；只有1页时两个按钮都禁用，但仍显示 `第 1 / 1 页`。
- 数据增减导致总页数减少时，将当前页夹取到新的末页，不能出现空白页。
- 点击翻页后默认选中该页第一件法宝，使左栏高亮、中栏详情和右栏操作始终对位。

## 左栏列表与翻页·列表项状态
御使 / 养炼页按优先级显示：
1. `配置异常`
2. `运行时重建失败`
3. `御使中 · 表现隐藏`
4. `御使中 · 无独立表现`
5. `御使中 · 场上显示`
6. `境界不足`　　← 未御使且角色境界 < 法宝 `realm_id`
7. `未御使`

> 第 6 条只在**未御使**时显示。已御使的法宝即使角色境界回退也保持第 3~5 条的御使中状态，不显示境界不足（「执行红线」）。

打造页显示：
1. `已拥有`
2. `炼器等级不足`
3. `境界不足`
4. `材料不足`
5. `可打造`

## 左栏列表与翻页·列表操作
| 操作 | 结果 |
|---|---|
| 单击 | 切换选中法宝，中栏与右栏同步刷新 |
| 御使页双击未御使法宝 | 等同点击“御使”；校验失败只提示，不改变状态 |
| 养炼页或打造页双击 | 不执行祭炼或打造，避免误消耗 |

## 中栏法宝详情·公共信息
- 名称、品质、境界、模型和描述读取 `法宝`主表。
- 核心四格固定为：**威能、神识、祭炼减免、实际占用**。
- 「神识」读 `法宝.sense_cost`；实际占用为 `max(sense_cost_min, sense_cost - sense_reduce)`。
- ⚠️ 该字段的玩家可见名统一为「神识」，**不再使用「基础负荷」「御使负荷」「神识负荷」**。
- 副标题的境界读 `法宝.realm_id`，同时是御使门槛。
- 战斗效果显示 `combat_desc`，世界用途显示 `world_desc`；留空显示“无”。
- 效果槽的 `加属性`只进入法宝自身逻辑属性容器，不修改角色属性。角色或生产系统可见的世界效果由被调用的 BUFF / 词条 / 技能决定。
- `combat_desc / world_desc` 不参与任何程序逻辑。

## 中栏法宝详情·打造页预览
- 未拥有目标按祭炼0层展示其完整结果，副标题显示：`打造后祭炼零层 · 品质 · 境界`。
- 已拥有目标显示当前真实祭炼层，并标记“已拥有”。
- 中栏不直接放打造按钮，所有操作仍集中在右栏。

## 御使页·神识总览
- 正常状态显示 `已占用 / 上限`，进度条使用青玉色。
- 被动超载时显示朱红色，并提示：`神识过载；已御使法宝仍继续生效`。
- 被动超载不自动收回；收回按钮始终可用，其他未御使法宝在解除超载前不可继续御使。
- 角色境界回退时同理：已御使的继续生效不回收，未御使且境界不足的不可御使。

## 御使页·选中法宝占用
```text
神识 18 − 祭炼减免 3 ＝ 实际占用 15
最低占用 8
御使境界要求　金丹（当前：金丹）
```
- 境界行在角色境界不足时用朱红色显示，并写明 `需要{门槛}，当前{当前境界}`。

## 御使页·御使 / 收回
- 前台只做即时预检；同步操作到达后台后按顺序执行：数据就绪 → 操作锁 → 重新校验拥有 / 未御使 / 配置与当前层 → **角色境界 ≥ 法宝 `realm_id`** → 神识。任一不过只提示，不改变任何状态。
- 点击后按钮立即置灰并显示处理中；后台完整创建运行时后才提交 `equipped=true`，成功后刷新列表状态、神识和表现资格。
- 创建运行时失败时逆序清理并恢复 `equipped=false`，玩家不能看到半套效果。
- 收回无代价、无CD；收回同样先取得操作锁并在唯一 `finally`释放，后台幂等清理效果句柄、技能、BUFF、词条、事件、timer、表现和代理。
- `配置异常`或`运行时重建失败`时仍允许收回，以便玩家解除神识占用；除此之外的养炼操作全部禁用。
- 每名玩家按 `fabao_id` 升序显示前 `MaxVisibleIndependent` 件有模型法宝（当前配置 6）；其余御使法宝只隐藏表现，不影响逻辑。

## 养炼页：祭炼·二级页签
```text
祭炼 / 器灵 / 本命
```
- 器灵和本命本期锁定，点击只提示“本期暂未开放”，不创建后台请求。

## 养炼页：祭炼·消耗与结果预览
- 顶部先显示目标层的炼器技能等级要求与境界要求，并同时显示玩家当前值。
- 炼器等级直接调用现有技能系统读取「炼器」技能当前等级，不读取新属性，也不建立法宝专属等级。
- 最多3种背包材料，外加1种货币。
- 每项显示名称、需要数和拥有数；不足项使用朱红色，并显示第一个不足原因。
- 成功率读取目标层 `success_rate`，万分比转换为百分比。
- 结果至少展示威能、祭炼减免、实际占用的当前层完整结果与目标层完整结果。
- 达最高层时隐藏材料区，祭炼按钮禁用，并显示“已达当前最高祭炼层”。

## 养炼页：祭炼·点击祭炼
1. 前台检查配置状态、操作锁、现有炼器技能等级、角色境界和材料，仅用于即时反馈；`配置异常`或`运行时重建失败`时禁止发祭炼请求。
2. 发同步操作，后台再次权威读取「炼器」技能等级与境界并校验。
3. 取得锁后按钮显示“祭炼中…”，其他会改变该法宝状态的按钮同时禁用。
4. 炼器等级与境界门槛通过后，才扣材料并使用同步随机源判定；任一门槛不足都不扣料。
5. 成功：层数提升；御使中法宝整体换层并刷新界面。
6. 失败：材料扣除、层数不变，无保底、不掉层、不损坏。
7. 所有返回路径由唯一 `finally` 释放锁并恢复UI。

## 打造页·配置读取
打造页严格读取 `F法宝.xlsx` 的 `打造`页签：
| UI内容 | 配置字段 | 规则 |
|---|---|---|
| 目标法宝 | `fabao_id` | 关联法宝主表，作为配方主键 |
| 背包材料 | `materials` | 最多3组物品ID与数量；UI通过物品表解析名称和图标 |
| 货币 | `money_id / money_count` | 通过资源配置解析名称和图标；与背包材料分开校验 |
| 炼器技能等级 | `forge_skill_lv_req` | 正式启用行必填；直接读取现有「炼器」技能当前等级 |
| 境界门槛 | `realm_req` | 正式启用行必填；读取角色当前大境界ID |
| 是否显示 | `enable` | 仅 `true` 的有效配方进入打造图录 |

本期没有打造成功率字段，统一显示“本期必成”，不得在前台伪造概率、保底或幸运值。

## 打造页·右栏内容
从上到下显示：
1. 成功规则：`本期必成`。
2. 炼器技能等级要求与玩家当前炼器等级。
3. 境界要求与玩家当前境界。
4. 获得状态：`祭炼0层、未御使`。
5. 重复打造规则：`已拥有时禁止且不扣料`。
6. 最多3种背包材料和1种货币的需要数 / 拥有数。
7. 第一条阻塞原因。
8. 单一主按钮“打造”。

## 打造页·当前配置表状态
当前 `打造`页签只有一条带 `#` 的停用示例行：目标为照骨镜，材料ID、货币ID、炼器技能等级要求和境界要求仍为“待填”。因此：
- 这条示例不会导出为正式配方。
- 网页原型中的多条配方仅用于演示已拥有、可打造、炼器等级不足、材料不足、境界不足与打造成功，不代表正式数值。
- 正式程序和最终UI必须读取导出配置，不能把原型示例写死为正式内容。

## 冷却与重复切换
- 收回和御使无CD。
- 法宝技能使用会话级冷却账本，独立于法宝运行时。
- 收回、重新御使、祭炼换层、死亡复活和换角色载体都不重置技能CD。
- UI原型不模拟战斗技能CD。

## 与现有UI图的口径
1. 保留现有玄青、旧铜、青玉视觉和三栏骨架。
2. 保留御使 / 养炼页面，以及器灵 / 本命的锁定氛围状态。
3. 在顶部一级页签新增“打造”；这是现有两张UI图之外的新功能页。
4. 左栏底部新增统一翻页条；打造页左栏切换为打造图录。
5. 打造页继续复用中栏详情，右栏新增炼器等级、境界、材料、货币、已拥有状态和打造按钮。
6. 祭炼页同步增加目标层炼器等级与境界要求，门槛不足时按钮禁用。
6b. 御使页新增御使境界要求行；中栏核心四格第二格文案由「御使负荷」改为「神识」，与配置表和策划案口径一致。
7. 所有页的主操作只放在右栏底部，不增加重复跨页按钮。
