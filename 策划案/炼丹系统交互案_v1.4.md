# 炼丹界面交互
炼丹面板的交互目标、界面结构、公共规则、左中右三栏与底栏的控件与操作流程、实时炼丹状态与预计成丹的展示、炼制数量与保存配方、开始炼丹的确认与结算、结果与丹方发现、丹药详情与服用交互。固定设计分辨率 1344×756。后台规则、公式与事务不在本案。

## 交互目标
玩家在同一个炼丹面板中完成两类操作：
- 丹方炼丹：载入系统默认配方或玩家保存配方，直接自动炼制，可选择批量数量。
- 手动炼丹：选择丹理或自由研制，逐份配置材料并形成真实入炉顺序，只能单枚炼制，可保存有效配方。

面板必须持续回答四件事：当前材料构成什么丹、为什么能或不能成丹、每份材料按什么顺序入炉、正式炼制将消耗多少材料。

## 界面结构
```text
炼丹主面板
├─ 顶部
│  ├─ 境界下拉
│  ├─ 标题：炼丹
│  └─ 丹炉下拉
├─ 左栏
│  ├─ 丹方炼丹 / 手动炼丹
│  ├─ 丹方列表
│  └─ 丹方翻页
├─ 中栏
│  ├─ 君、臣、佐、使、丹头
│  ├─ 丹炉
│  ├─ 实时炼丹状态
│  └─ 炼制数量
├─ 右栏
│  ├─ 材料背包
│  ├─ 手动炼丹筛选与药力排序
│  └─ 材料翻页
└─ 底栏
   ├─ 入炉顺序
   ├─ 保存配方（仅手动炼丹）
   └─ 开始炼丹
```

底栏横跨左栏至“开始炼丹”按钮的全部宽度。入炉顺序使用按钮左侧的全部可用宽度连续排列，不设置翻页。

## 公共规则·境界
- 境界下拉包含：筑基、金丹、元婴、化神、炼虚、合体、大乘。
- 境界筛选控制左侧丹方和右侧材料；丹炉下拉始终显示玩家已拥有的全部丹炉。
- 右侧材料显示所选境界的全部品质。
- 切换境界后清空当前草稿、批量数量复位为 1、丹方和材料翻页位置复位到第一页。

## 公共规则·丹炉
- 丹炉使用下拉选择，不使用左右切换箭头。
- 下拉列出玩家已拥有的全部丹炉；最高可炼境界低于当前所选境界的丹炉保留显示并置灰，悬停提示“最高可炼X，无法炼制Y境丹方”。
- 切换丹炉后立即重新校验丹炉境界、神识门槛、可承受药性、除渣结果、纯度和成丹率。
- 丹方炼丹使用系统默认配方时，切炉后重新搜索安全入炉顺序。
- 使用玩家保存配方时，保留其已保存的入炉顺序并重新校验。

## 公共规则·品质
- 左侧丹方不提供品质选项。
- 系统默认配方使用该基础丹方当前开放的最低品质行。
- 玩家保存配方使用保存时君材确定的品质。
- 手动炼丹的实际成丹品质由君材品质确定。
- 纯度不改变成丹品质。

## 公共规则·配置阶段与正式炼制
- 配置、增减材料、切换丹炉、翻页、保存配方均不扣材料。
- 点“开始炼丹”后先进入确认弹窗。
- 玩家确认后一次性扣除本次全部材料和丹头，随后正式结算。
- 正式炼制失败不退材料。
- 前台预览只提供即时反馈，最终校验和结算以服务器为准。

## 左栏·页签
左栏只有两个页签：
| 页签 | 内容 |
|---|---|
| 丹方炼丹 | 系统丹方及该丹方当前使用的自动配方 |
| 手动炼丹 | 置顶“自由研制”及全部已开放丹理 |
玩家保存配方归入对应丹方，并替换该丹方的系统默认配方。

## 左栏·丹方列表
- 列表按当前境界筛选。
- 每条基础丹方只显示一次，不按品质拆成多条。
- 列表支持左右翻页，翻页按钮位于列表标题右侧。
- 丹药不使用“一阶、二阶、三阶”等称呼。
- 点击丹方同时选中并展开；再次点击可收起详情。

## 左栏·丹方炼丹中的展开内容
```text
丹名
丹理：五行 X，五味 X，药性 X，药力 X
丹效：读取丹方配置的 action / param / value
配方：君材、丹头、臣材、佐材、使材及各自数量
```
- 系统默认配方显示最低开放品质行的丹理和配方。
- `head_id=0` 时配方文本显示“丹头：均可”；载入后由系统选择同境、同品质、容量足够的实际丹头，优先库存最多、同库存按 ID。
- `head_id>0` 时配方文本和实际装入均显示指定丹头。
- 丹效按当前实际使用的丹方品质行读取。
- 丹效尚未配置时，交互原型显示“读取配置表”。
- 玩家已经保存配方时，显示玩家配方并标记“玩家配方”。
- 玩家配方失效时仍原样装入并显示具体失败原因，不自动切回系统配方。
- 玩家可执行“恢复系统配方”；恢复后删除该丹方的玩家配方，重新使用系统默认配方。

## 左栏·点击丹方炼丹中的丹方
点击后执行：
1. 读取系统默认配方或玩家配方；普通系统方按程序策划案选择实际丹头。
2. 按保存的入炉顺序装入正好炼制 1 枚所需的君、臣、佐、使和丹头。
3. 中栏显示单枚材料数量。
4. 底栏显示单枚入炉顺序。
5. 重新计算全部炼丹状态。
6. 右侧背包切为只读材料总览。
若材料不足，仍显示完整配方和缺少的材料，但“开始炼丹”不可用。

## 左栏·手动炼丹中的丹方
- “自由研制”固定置顶。
- 其展开区只显示：`臣药应五行，使药应五味，药性合度，药力既足，则丹可成矣。`
- 自由研制不显示丹效、目标丹名或技术性配置说明。
- 其他丹方展开后显示丹理和丹效，不自动装入材料，也不清空或修改当前草稿。
- “自由研制”与其他丹理的切换都只改变左栏阅读内容，不改动当前草稿。选择某条丹理只用于玩家参考，不锁定最终结果；实际成丹仍按当前材料真实形成的五行、五味、药性、君材品质与丹头定位。

## 右栏材料背包·丹方炼丹
- 显示当前境界全部材位、全部品质的材料和拥有数量。
- 不显示材位筛选、五行筛选、五味筛选、药性筛选、搜索框和药力排序。
- 材料卡不可点击、不可拖动、不可改变当前配方。
- 材料卡支持悬停 TIPS，显示名称、材位、境界、品质、五行或五味、药力、药性、绝对杂质、丹头承药份数和拥有数量中的适用字段。
- 支持左右翻页。

## 右栏材料背包·手动炼丹
第一行材位筛选：`君 / 臣 / 佐 / 使 / 丹头`。
第二、三行根据材位显示：
| 当前材位 | 第二行 | 第三行 |
|---|---|---|
| 君 | 无 | 无 |
| 臣 | 五行：全部、金、木、水、火、土 | 药性：全部、−4 至 +4 |
| 佐 | 无 | 药性：全部、−4 至 +4 |
| 使 | 五味：全部、酸、苦、甘、辛、咸 | 药性：全部、−4 至 +4 |
| 丹头 | 无 | 无 |
- 不提供搜索框。
- 只提供一个药力升降序箭头，不显示“药力排序”文字。
- 筛选、排序和当前境界共同作用。
- 支持左右翻页。

## 右栏材料背包·手动投料
- 单击材料卡：将材料加入对应材位。
- 拖动材料卡至对应材位：结果与单击相同。
- 君材和丹头再次选择时直接替换原材料，数量恒为 1。
- 臣佐使每次单击、拖入或点加号，向 `steps[]` 尾部追加一份该材料。
- 点减号删除该材料最后加入的一份。
- 数量降为 0 后，该材料卡从中栏消失。
- 达到丹头承药上限后，臣佐使不再允许增加，并提示“丹头承药已满”。
- 达到背包拥有数量后不再允许增加，并提示“药材不足”。

## 中栏材料与丹炉·材位
中栏保留君、臣、佐、使和丹头五个材位。
- 君材固定 1 份，不显示加减号。
- 丹头固定 1 个，不显示加减号。
- 臣佐使允许同时存在多种材料。
- 每种材料显示名称和当前填入数量。
- 手动炼丹时，每种臣佐使材料显示独立的减号和加号。
- 当前操作材料置于其材位最前方并高亮，其他同材位材料顺次后排。
- 丹方炼丹时，中栏数量随炼制数量同步放大，但入炉顺序仍只展示单枚模板。

## 中栏材料与丹炉·丹炉表现
- 丹炉位于中栏中央。
- 当前药性偏寒、偏热、越界时可使用不同炉火表现，但表现不参与规则判定。
- 炉火状态只能读取当前预览结果，不自行推断最终结果。

## 实时炼丹状态
状态区位于丹炉上方或与丹炉中央状态板同一视觉区域，不显示“炉内状态”标题。

每项必须单行展示：
| 行 | 显示内容 |
|---|---|
| 丹炉可承受药性 | `−2~+2（寒~热），当前 0（平）` |
| 药力 | `当前 P / 达标 U`；不足时显示还差多少 |
| 当前五行 | 当前臣材形成的五行 |
| 当前五味 | 当前使材形成的五味 |
| 当前杂质 | 剩余杂质 D、纯度 Q、最低纯度 Qmin |
| 成丹率 | 全部成丹条件满足后显示；否则显示“不可成丹：原因” |
| 预计成丹 | 丹名与品质、`？？？？` 或“此配法无法成丹” |
| 炼制数量 | 数量减号、数值、加号及当前批量上限 |

## 实时炼丹状态·状态颜色
- 满足条件：青玉色。
- 不满足条件：对应整行转暗朱红。
- 尚不能计算：灰色，不显示伪造数值。
- 成丹率只有在君材、丹头、五行、五味、最终药性、药力、纯度、丹炉和库存全部满足后显示具体数值。

## 实时炼丹状态·过程反馈与首个失败原因
投料操作先执行即时检查：材位不符时拒绝落位；库存已用尽或丹头容量已满时拒绝继续增加。每次加入材料都重算投药轨迹；出现越界时保留当前草稿，将对应步骤标红；步骤格仍只显示材料自身药性，悬停错误提示显示“偏寒／偏热”。玩家可通过减去某材料最后一份并按新顺序重新加入来修正。

每次预览时，“成丹率”行按以下顺序显示当前首个阻断原因：
1. 缺少君材。
2. 缺少丹头。
3. 缺少臣材。
4. 缺少使材。
5. 丹炉最高可炼境界不足。
6. 神识不足以驱动丹炉。
7. 投药过程药性越出丹炉范围。
8. 臣材五行不唯一。
9. 使材五味不唯一。
10. 无法定位丹方。
11. 指定丹头不符。
12. 丹方炼丹的最终药性未精确命中。
13. 药力不足。
14. 纯度不足。
15. 材料库存不足。

服务端仍校验材料ID、材位、境界、品质、丹头容量和批次数量；这些正常前台不可构造的异常只使用兜底文案，不占用主面板状态行。所有条件的玩家文案见 「错误键与玩家文案」。
“开始炼丹”按钮前不另设一块重复的红色失败原因区。

## 实时炼丹状态·预计成丹
系统根据实际材料定位丹方：
```text
当前境界
+ 臣材五行
+ 使材五味
+ 最终药性
+ 君材品质
+ 丹头
→ 丹方品质行
```
- 已经炼制成功过：显示丹名和成丹品质。
- 从未炼制成功过：显示 `？？？？` 和成丹品质。
- 同一五行、五味、药性和君材品质因指定丹头对应另一丹方时，以实际丹头定位。
- 未命中任何丹方：显示“此配法无法成丹”。
- 命中坐标但指定丹头错误：显示“此配法无法成丹”，成丹率行写“丹头错误”。
- 已定位丹方但纯度不足：预计成丹仍显示已知丹名或 `？？？？`；当前杂质行标红并写“纯度不足”，成丹率不显示数值。

发现记录按丹方 ID 保存布尔值。特殊丹头产生的不同丹方必须分别记录，不能只按五行、五味和药性坐标共用一个记录。

## 底栏入炉顺序·展示
- 入炉顺序只包含臣佐使，君材固定先入炉，丹头不进入投药序列。
- 每个步骤显示：序号、材料名、该材料自身药性。
- 越出丹炉可承受药性的步骤标红；步骤格仍只显示材料自身药性，悬停错误提示显示偏寒或偏热，不显示累计药性数值。
- 不规定固定显示数量，不自动翻页。
- 当前原型将全部步骤压入按钮左侧的可用宽度，尽量一次显示完整入炉顺序。
- 正式界面的单格宽度与最大可见数量由最终 UI 布局确定；若布局需要调整，优先扩大或压缩顺序区，不增加自动翻页。

## 底栏入炉顺序·顺序生成
| 来源 | 顺序 |
|---|---|
| 系统默认配方 | 载入时由系统搜索安全顺序，本次炼制原样使用 |
| 玩家保存配方 | 读取玩家保存的 `steps[]`，原样使用 |
| 手动炼丹 | 按玩家每次加入材料的先后形成 `steps[]` |

同一组材料的顺序只影响能否安全完成，不改变最终药力、杂质、纯度和丹效。界面不提供拖动重排或删除指定步骤；玩家通过减去某材料最后加入的一份，再按新顺序重新加入来调整顺序。

## 炼制数量·手动炼丹
- 数量固定为 1。
- 减号和加号均禁用。
- 提示“手动固定一枚”。

## 炼制数量·丹方炼丹
- 初始数量为 1。
- 点加号时，君材、丹头和全部臣佐使的中栏显示数量同步按模板倍增。
- 入炉顺序仍显示单枚模板，不将多枚顺序拼接为长列表。
- 批量上限取神识上限与材料可炼套数中的较小值。
- 再加一枚会导致任一材料不足时，加号禁用并提示“药材不足”。
- 点减号同步减少一套材料，最低为 1。

## 保存配方
- “保存配方”只在手动炼丹页签显示。
- 当前配法已定位丹方且所有成丹条件满足时按钮可用。
- 保存内容：丹方 ID、君材 ID、丹头 ID、臣佐使 `steps[]`、实际君材品质。
- 每个基础丹方只保存一套玩家配方。
- 新保存配方覆盖该丹方原有玩家配方。
- 保存后，该配方进入“丹方炼丹”并替换系统默认配方。
- 玩家可在丹方展开区恢复系统配方。
- 保存不要求先正式炼制成功。
- 保存不扣材料，不直接触发炼制。

## 开始炼丹与确认·按钮
- “开始炼丹”位于右下角。
- 任一硬条件不满足时按钮禁用。
- 手动炼丹时，“保存配方”位于其左侧。
- 主面板不设置“取消”按钮。

## 开始炼丹与确认·确认弹窗
显示：
- 丹名；未发现丹方显示 `？？？？`。
- 基础品质。
- 炼制方式。
- 炼制数量。
- 单枚及总材料消耗，包含丹头。
- 药力与目标药力。
- 剩余杂质与纯度。
- 成丹率与升品率。
- “确认后立即扣除全部材料，失败不退。”
按钮：`返回 / 确认`。

## 开始炼丹与确认·正式结算
- 确认后服务器再次完整校验库存和配置。
- 校验通过后扣除全部材料。
- 批量 N 枚分别判定成丹与升品，可能得到不同数量、不同品质的成品。
- 同一批只播放一次炼制演出。
- 请求使用唯一 `requestId`；重复提交不得重复扣料。

## 结果与丹方发现
结果页显示：
- 尝试数量、成功数量、失败数量。
- 按最终品质分组的丹药数量。
- 升品结果。
- 每组丹药的实际剩余杂质与纯度。
- 每组丹药的实际售价。

手动炼制成功后，将对应丹方 ID 的发现布尔值写为真。之后相同丹方在自由研制的“预计成丹”和确认弹窗中显示真实丹名。
失败不写入发现记录。

## 丹药详情、服用与五味丹毒·丹药详情页
从背包丹药、炼制结果组或丹毒面板中的相关入口打开。页面分为：
1. 顶部：丹药图标、丹名、最终品质、境界与拥有数量。
2. 丹效：按 `action1..3 / param1..3 / value1..3` 的有效槽顺序展示。加属性显示实际结算值；调用技能、BUFF、词条读取对应系统的展示文字。空槽不显示；三个槽均为空时显示“丹效待配置”，不得用 `function` 参与运行结算。
3. 成色：纯度、剩余杂质、五味归属与实际售价。
4. 服用预览：当前对应毒池占用、服后占用、当前效果倍率和本枚入池量。
5. 底部：`返回 / 服用`。点击服用后按最新角色状态重新请求预览，确认后执行正式服用事务。

## 丹药详情、服用与五味丹毒·服用三态
| 状态 | 条件 | 表现 |
|---|---|---|
| 完整生效 | `T_before < H` | 正常显示效果与“服用” |
| 效果减半 | `H ≤ T_before < 10000` | 橙色提示“当前丹毒较高，本枚药效按50%结算”，确认后方可服用 |
| 禁止服用 | `T_before ≥ 10000` | 红色提示“对应丹毒已满”，服用按钮禁用 |

丹药实例保存实际剩余杂质；服用后按使味进入对应丹毒池。减半倍率及各行为取整读取程序策划案，不由前台自行计算。

## 丹药详情、服用与五味丹毒·五味丹毒面板
面板并列显示酸、苦、甘、辛、咸五个毒池。每池显示当前占用、容量、占用万分比、每日消退量和状态色；达到效果减半线转橙，满池转红。面板提供丹毒规则说明和相关丹药入口，不在炼丹主面板重复铺开五个池子。

服用预览至少返回 `I、Cpool、T_before、effectMultiplier、I_after、T_after`；正式服用完成后，以服务端返回的五池新值刷新详情页与毒池面板。

## 前后台数据合同·正式炼制
正式炼制提交预览确认后的完整配方草稿、批量数量、预览版本和唯一 `requestId`。服务器不得直接信任前台给出的药力、纯度、成丹率和丹名，必须按配置重新计算。

## 异常与反馈·页面级异常
| 场景 | 处理 |
|---|---|
| 当前境界无丹方 | 左栏显示“此境界暂无丹方” |
| 当前筛选无材料 | 右栏显示“当前条件下没有材料” |
| 玩家没有任何丹炉 | 主面板禁用并提示“尚未拥有可用丹炉” |
| 当前境界无可炼丹炉 | 已拥有丹炉保留显示并置灰，开始炼丹禁用 |
| 材料不足 | 对应材料和状态行标红，加号或开始炼丹禁用 |
| 丹头容量已满 | 提示“丹头承药已满（N/Nmax）” |
| 请求处理中 | 相关按钮禁用，防止重复提交 |
| 服务器返回新状态 | 以服务器数据覆盖本地预估 |
