# P04 单位规则

> 版本：v2.0｜2026-08-05｜现行单位基类定义
> 定位：定义玩家、怪物及后续生灵共用的运行时单位模型。

## 一、单位类型

| 类型 | 枚举 | 说明 |
|---|---|---|
| 玩家 | `PLAYER` | 真人控制，耐久数据来自存档 |
| 怪物 | `MONSTER` | AI控制，静态数据来自怪物配置 |
| NPC | `NPC` | 后续启用 |
| 灵兽/召唤物 | `COMPANION` | 后续启用 |

魔化、原生、造物是怪物来源，不新增单位基类。

## 二、运行时字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `unit_id` | uint64/string | 运行时全局唯一，不等于配置主键 |
| `config_id` | int/string | 静态配置主键；玩家可为空 |
| `unit_name` | string | 显示名 |
| `unit_type` | enum | 单位类型 |
| `faction` | enum | 阵营 |
| `hp/max_hp` | int | 生命与上限 |
| `mp/max_mp` | int | 法力与上限 |
| `atk/def` | int | 物理攻防单值 |
| `matk/resist` | int | 术法攻防单值，未启用时为0 |
| `realm_id` | int | 0—8 战斗层级 |
| `realm_sublevel` | int | 小境界层数 |
| `attack_range` | number | 攻击距离 |
| `attack_interval` | number | 攻击间隔 |
| `move_speed` | number | 移动速度 |
| `aggro_range` | number | 索敌范围，仅AI单位 |
| `leash_range` | number | 相对出生点或刷新区域的脱战边界 |
| `spawn_x/spawn_y` | number | 本次实例出生点 |
| `pos_x/pos_y/facing` | number | 当前空间状态 |
| `state` | enum | ALIVE/DEAD 等运行状态 |

运行时 ID 使用服务器分配的单调64位ID或UUID；禁止依靠“玩家1—999、怪物1000+”等固定范围避免冲突。

## 三、阵营与攻击

- V0 玩家与怪物敌对。
- V0 玩家之间、怪物之间不可攻击。
- 攻击者和目标必须存活、可选中、在允许距离内且阵营敌对。
- 来源类型不得自动改写阵营；具体条目显式配置。

## 四、属性边界

- 玩家与怪物都通过统一属性接口读取最终属性。
- 静态配置只提供基础值和修饰来源，最终值由属性系统重算。
- 蓝条中文名固定为法力。
- 攻击、防御是单值；禁止旧上下限与物防/法防双套字段。

## 五、生命周期

玩家：创建或载入角色 → 创建单位 → 绑定耐久数据与派生属性 → 游戏 → 保存耐久数据 → 销毁单位。

怪物：刷新方案激活 → 创建实例 → AI循环 → 死亡事件仅触发一次 → 掉落 → 尸体结束 → 销毁实例 → 重刷计时。

死亡边界：

- 死亡单位立即停止移动、攻击和AI，不能再次成为有效目标。
- 尸体表现时长由系统参数配置，不写死在单位基类。
- 玩家在当前场景指定安全复活点复活；场景没有安全复活点时不得通过配置校验。
- 复活恢复比例、保护时间和死亡惩罚由系统参数决定。

## 六、接口

```text
create_unit(config, runtime_context)
destroy_unit(unit_id)
get_attr(unit_id, attr_key)
recalculate_attrs(unit_id)
is_alive(unit_id)
is_attackable(attacker_id, target_id)
set_state(unit_id, state)
apply_damage(combat_event)
```

任何直接写最终攻击、防御或上限值的接口都必须触发来源重算或被限制为战斗临时状态。

## 七、校验

- `unit_id` 全局唯一。
- 配置主键、单位类型、阵营与来源枚举合法。
- 最大生命大于0，当前生命钳制在0到最大生命。
- 攻击间隔大于0，范围与速度不为负。
- 怪物出生点和脱战边界存在。

> 修订：v2.0 统一法力、数值境界、单值攻防、全局运行时ID和场景安全复活点。
