# P09 掉落表

> 版本：v2.0｜2026-08-05｜现行掉落数据骨架
> 定位：定义掉落方案字段。算法使用32槽权重池，具体数值以配置表为准。

## 一、方案字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|:---:|---|
| `scheme_id` | int/string | 是 | 唯一主键 |
| `scheme_name` | string | 是 | 策划识别名 |
| `draw_min` | int | 是 | 最少抽取次数 |
| `draw_max` | int | 是 | 最多抽取次数 |
| `allow_repeat` | bool | 是 | 是否允许同槽重复抽中 |
| `slots` | array | 是 | 最多32个有效槽 |

槽字段：

| 字段 | 类型 | 必填 | 说明 |
|---|---|:---:|---|
| `target_id` | int/string | 是 | 物品或装备 ID |
| `target_type` | enum | 是 | item/equipment/other_supported |
| `weight` | int | 是 | 相对权重，必须大于0 |
| `count_min` | int | 是 | 最少数量 |
| `count_max` | int | 是 | 最多数量 |
| `guaranteed` | bool | 是 | 是否保底 |
| `broadcast_override` | enum/null | 否 | 显式覆盖统一品质播报规则 |

## 二、边界

- 不使用独立概率字段与权重字段并存。
- 不使用含义不清的 `lv`；境界和品质分别读取目标物品数据。
- 最少/最多掉落数决定抽取次数，不对结果二次裁剪。
- 物品品质随目标物品数据，不由掉落表临时改写。
- 怪物来源、品质和首领职能通过选择不同方案体现。

## 三、校验

- `draw_min <= draw_max`，且均不小于0。
- 保底槽数量不得超过 `draw_max`。
- 所有目标 ID 存在，数量范围合法。
- 有效权重总和大于0。
- 方案主键唯一。

> 修订：v2.0 清除独立概率与权重池双口径，删除模糊等级字段并统一播报边界。
