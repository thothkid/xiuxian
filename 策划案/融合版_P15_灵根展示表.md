# P15 灵根展示表

> 版本：v2.0｜2026-08-05｜灵根展示与边界
> 定位：定义灵根的先天规格、五行展示和说明边界。具体效果与数值以配置表为准。

## 一、概念

- 灵根是修士承接与转化天地力量的先天规格。
- 灵根影响修炼与五行亲和，但不等于职业、堂口或功法锁。
- 灵根深层究竟完全属于灵魂，还是位于灵魂与肉身交界，当前不写死。

## 二、字段

| 字段 | 说明 |
|---|---|
| `linggen_id` | 唯一主键 |
| `linggen_name` | 显示名称 |
| `elements` | 金木水火土中的一个或多个 |
| `color` | UI显示映射 |
| `icon_id` | 图标资源 |
| `tagline` | 简短风味，不得承诺职业或绝对强弱 |
| `description` | 自足说明 |
| `affinity_modifiers` | 五行与修炼修正项 |

## 三、五行边界

- 五行生克只提供可配置修正，不形成绝对命中、免疫或必胜。
- 多灵根、变异灵根、纯度和成长方式在对应系统定稿前不提前扩写。
- 风味文案不得出现“只能修炼某功法”“必须加入某堂口”等职业锁。

## 四、创角边界

- 灵根是否由玩家选择、随机生成或通过后续事件确认仍待定。
- 创角UI只在方案定稿后开放相应交互。
- 未定稿时存档保留可扩展域，不生成伪随机正式结果。

> 修订：v2.0 明确灵根为先天规格、五行只作修正、无职业锁且深层归属暂不写死。
