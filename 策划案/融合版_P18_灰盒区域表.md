# P18 灰盒区域表

> 版本：v2.0｜2026-08-05｜V0灰盒区域语义
> 定位：定义灰盒地图边界、安全区、刷新区和掉落测试区。实际坐标以场景配置为准。

## 一、坐标单位

- “128×128”只表示灰盒地块规模，不直接等于世界坐标范围。
- 地块坐标、WC3世界坐标和UI显示坐标必须分别命名并提供唯一换算。
- 配置表边界统一保存WC3世界坐标。

## 二、区域类型

| 类型 | 用途 |
|---|---|
| `map_bounds` | 全地图合法边界，仅做越界校验 |
| `safe` | 出生、复活和无怪安全区域 |
| `spawn` | 怪物刷新与AI返回边界 |
| `loot_test` | 掉落和拾取测试 |
| `event` | 触发器测试 |

`map_bounds` 不参加普通区域优先命中查询，否则会遮蔽所有内部区域。

## 三、查询优先级

1. 先校验点位是否位于 `map_bounds`。
2. 再按 safe、event、loot_test、spawn 的显式优先级查询。
3. 同优先级区域重叠时配置校验失败，不依赖文件顺序。

## 四、刷新边界

- 刷新方案引用一个spawn区域。
- 怪物出生点必须落在区域内。
- AI脱战判断使用本次出生点或该区域边界。
- 玩家进入区域触发刷新时，激活事件只提交一次。

## 五、安全区

- 出生点和复活点必须位于safe区域。
- spawn区域不得覆盖安全点。
- 位置恢复失败时回到场景指定safe点。

## 六、校验

- 边界满足 `min_x < max_x`、`min_y < max_y`。
- 所有区域位于 `map_bounds` 内。
- 坐标单位一致。
- 同优先级区域无歧义重叠。

> 修订：v2.0 分离地块与世界坐标、独立map_bounds并统一刷新与AI边界。
