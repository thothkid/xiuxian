# P24 提示文案规范

> 版本：v2.0｜2026-08-05｜现行提示字典规则
> 定位：代码只提交文案ID与参数，正文、颜色、位置和时长由配置管理。

## 一、字段
〔出处：融合版_P24_提示文案规范.md · §一、字段 ｜ 定位：代码依据——写代码用〕

```text
message_id
category
text_template
severity
display_area
duration
merge_key
cooldown
parameters
```

单条 `duration` 覆盖HUD默认时长；为空时才使用区域默认值。

## 二、必需错误域
〔出处：融合版_P24_提示文案规范.md · §二、必需错误域 ｜ 定位：代码依据——写代码用〕

| 域 | 必需提示 |
|---|---|
| 创角 | 道号过短、过长、非法、重复、创建中、本地失败、云端待同步 |
| 背包 | 空间不足、物品不存在、数量不足、状态变化、替换失败 |
| 装备 | 装备位不符、境界不足、实例已变化、事务失败 |
| 存档 | 保存失败、版本过高、迁移失败、冲突隔离、待同步 |
| 掉落 | 无归属、已被拾取、背包不足、钱包增加 |
| 修炼 | 法力不足、耐药值高、丹毒、可突破、结算完成 |

## 三、道号提示
〔出处：融合版_P24_提示文案规范.md · §三、道号提示 ｜ 定位：代码依据——写代码用〕

- 汉字每个2单位，英文和数字每个1单位。
- 总长度4—16单位。
- 中文、英文和混合输入共用加权规则，不分别写互相冲突的上限。

## 四、术语
〔出处：融合版_P24_提示文案规范.md · §四、术语 ｜ 定位：代码依据——写代码用〕

| 使用 | 禁止替代 |
|---|---|
| 玄黄界 | 未经确认的其他世界总名 |
| 九重仙劫 | 把渡劫写成第九境界 |
| 神通 | 玩家侧“技能” |
| 法力 | 魔法值、灵力值 |
| 修为 | 经验值 |
| 青冥宗外门弟子 | 预备弟子、穿衣转正 |

## 五、格式
〔出处：融合版_P24_提示文案规范.md · §五、格式 ｜ 定位：代码依据——写代码用〕

- 参数使用命名占位符，不拼接半句。
- 数量、时间、品质和境界使用统一格式化函数。
- 高频重复提示按 `merge_key` 合并。
- 严重存档错误不得被普通拾取提示覆盖。

## 六、代码边界
〔出处：融合版_P24_提示文案规范.md · §六、代码边界 ｜ 定位：代码依据——写代码用〕

- 代码不得硬编码玩家可见正文。
- 未知文案ID在测试环境阻断，在正式环境记录错误并使用安全占位。
- 文案配置缺失必须报告ID、调用系统和参数。

> 修订：v2.0 补齐全系统错误出口、中英混合道号、术语表和展示时长优先级。
