# 装备位设计纲要

> 版本：v2.0｜2026-08-05｜现行装备位设计边界
> 定位：定义外装六位的并发限制、职能与器物关系。数值、解锁节奏和词条由配置决定。

## 一、核心原则

装备位是并发限制规则：规定哪些装备彼此竞争、哪些可以同时生效。物理格数、追逐线数量和有效决策维度不是同一件事。

完整外装固定六位：冠、法袍、武器、佩、印绶、鞋履。

## 二、六位定义

| 枚举 | 名称 | 别名 | 主要职能 |
|---|---|---|---|
| `HEAD` | 冠 | 巾 | 神识、感知、身份外显 |
| `ROBE` | 法袍 | 道袍/法衣 | 生存、外观、宗门表达 |
| `WEAPON` | 武器 | 无 | 攻击方式与构筑核心 |
| `PENDANT` | 佩 | 玉佩/护符 | 机缘、资源与复合词条 |
| `SEAL` | 印绶 | 符印 | 控制、镇压、封禁 |
| `FEET` | 鞋履 | 履/靴 | 身法、闪避、位移 |

别名不形成新枚举。武器示例不得再把“法器”当成武器种类或品质等级。

## 三、境界与品质

- 境界表示装备力量层次与承载门槛。
- 品质使用凡、灵、玄、仙、神、道六档。
- 装备、器具、法宝是结构身份，与品质正交。
- 每个大境界是否整体换装由掉落和数值节奏决定，不在装备位定义中写死。

## 四、启用节奏

- V0只开放武器与法袍两个技术验证位。
- V0子集仅验证代码链路，不等于正式产品解锁顺序。
- 炼气至金丹何时开放其余四位尚未形成独立定稿，必须走配置，不在本文件提前写死。
- 一旦开放，已开放装备位永久保留，除非以后有明确系统裁定。

## 五、法宝

- 法宝不占外装六位。
- 法宝是否有器灵、是否认主、是否形成本命关系分别判断，不是法宝的必备条件。
- 本命法宝是共生关系，不早于金丹形成。
- 同时御使能力由神识预算和单件御使负荷决定，不使用“N个出战位”。
- 法宝可以跨境界成长，但具体成长与淘汰由法宝系统决定。

## 六、道器

- 道器是承载独一规则并介入命途的特殊身份，通常具有道品质，但道品质不等于道器。
- 道器数量、交易、替换、转移、是否占独立位置和轮回关系均未在装备位系统中确定。
- 不设置“每人固定一件”“不可替换”“轮回重抽”等全局硬规则。

## 七、属性与存档

- 装备只保存实例、位置和修饰来源。
- 穿脱后由属性系统重算生命、法力、攻击、防御等派生值。
- 存档保存装备实例与位置，不把最终属性作为唯一真值。

## 八、术语

| 术语 | 定义 |
|---|---|
| 法力 | 施展神通消耗的蓝条资源 |
| 术法攻击 | 术法伤害的攻击属性 |
| 神通 | 玩家主动或触发能力 |
| 肉身承载 | 肉身承担装备、力量与负荷的能力 |

> 修订：v2.0 保留外装六位，删除旧道器一位、法宝固定槽、全法宝器灵认主和旧传奇术语。
