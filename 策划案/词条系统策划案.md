# [Codex] 词条系统策划案 v0.11

> 生成者：[Codex] | 日期：2026-09-08
> 定位：技能与BUFF的通用修饰框架。配套《词条表头_v0.11.xlsx》和《词条表_示例审核稿_v0.11.xlsx》，单页39列。对象范围按本轮已确定需求修订；组合与生效时点仍为本版待审方案。

## 一、框架

每条词条只选择一个神通、一个BUFF或一个系别，针对所选对象配置多项修改。选定神通后可沿其引用修饰BUFF；选定一个系别时，作用于该系别内符合条件的神通。

修饰范围覆盖神通、BUFF及其组成内容中具有玩法或表现含义的可配置参数，包括原来未配置但该能力支持的参数，以及通过新增效果带入的参数。具体改哪项、是否保留原效果，由词条配置决定。

**一条词条＝一个对象选择＋若干修改；一次修改＝目标位置＋操作＋参数值或内容引用。**

| 层次 | 提供什么 |
|---|---|
| 神通、BUFF及其效果 | 提供可用能力、参数、触发条件、目标规则和执行结果。 |
| 词条框架 | 定位这些内容，修改参数，增删或替换效果，处理多条词条组合与来源撤销。 |
| 具体词条 | 选择对象、内容与修改值，组合成一次玩法变化。 |

修改能力实现一次后，具体词条通过配置复用。新增一种底层效果，明确其可修饰位置、参数和对应支持后接入，沿用同一套修改块。

技能、BUFF已定义的能力纳入修饰范围。护盾、反伤、受击回血、召唤等能力的具体开放时间跟随底层系统；当前未完成，不等于从框架中排除，也不把其开发混入词条规则。

## 二、配置表头

正式词条数据只在一个「词条」页签。一行一条词条；前7列填写身份与一个对象选择，后接修改1～修改4，每块8列。四块是展示容量，更多修改延续同样的块，不增加新的字段含义。

表头和示例稿采用相同的两层中文表头，冻结C3。参数目录随底层能力扩展，不以旧版75项为上限；示例稿中的构造对象与模板须补为有效配置后才能投放。

### 1. 固定列

| 列 | 表头 | 配置含义 |
|---|---|---|
| A | 词条ID | 一条词条的唯一编号，供装备、功法、真意等来源引用。 |
| B | 词条名称 | 展示名称。 |
| C | 词条描述 | 说明作用对象和最终变化。 |
| D | 作用对象 | 神通、BUFF、系别，三选一。选择系别时，实际修饰该系别内的神通。 |
| E | 匹配值 | 神通填一个神通识别ID；BUFF填一个BUFF识别ID；系别填一个系别中文名。必填单值，不填多个ID、多个系别或“全部”。 |
| F | 覆盖优先级 | 普通增减留空。争用同一个设定、替换或移除时比较，数值越大越优先；空白按0。 |
| G | 配置备注 | 配置意图、构造前提或上游能力要求。 |

识别ID包含所选神通或BUFF现有及以后新增的各等级。选择“五行”仍是选择一个系别，其包含金木水火土的关系沿用系别规则。各修改块以本行选定对象为起点；来源的获得条件和启用期限由装备、功法等来源系统管理。

### 2. 修改块

修改1为H—O，修改2为P—W，修改3为X—AE，修改4为AF—AM。每块均为以下八项，实际列名加“修改N·”前缀。

| 顺序 | 表头 | 配置含义 |
|---|---|---|
| 1 | 目标位置 | 从本行作用对象定位到自身、选择器、某个效果、效果列表，或沿引用进入另一个神通、BUFF。按中文层级选取。 |
| 2 | 适用限定 | 限定所定位内容的形状或效果类型，使用下列统一中文词表；留空表示不加此项限定。 |
| 3 | 修改操作 | 固定增减、按比例、设定、替换、追加、移除。 |
| 4 | 修改项目 | 参数修改时填参数目录中的中文语义名，如“万分比伤害系数”；不填“效果1参数2”等槽位名。替换、追加、移除时留空，由目标位置确定整项内容。 |
| 5 | 修改值 | 参数的新值或增减量，单位随参数；整项操作留空。 |
| 6 | 模板对象 | 替换、追加时填神通或BUFF；其余操作留空。 |
| 7 | 模板等级ID | 模板的具体等级行ID，确定复制哪个版本的内容。其余操作留空。 |
| 8 | 模板位置 | 模板内的选择器或效果位置；与目标所需内容种类相容。其余操作留空。 |

未用的修改块整块留空。一块只做一项修改。

适用限定按所在位置选择下列名称，按其对应的内容类型判断，不按名称包含关系判断。正式表中的对应名称列在配套核对稿中。

| 所在位置 | 本版统一填写名称 |
|---|---|
| 主选择器、子选择器 | 单体、圆形、扇形、线形、环形。 |
| 神通效果 | 伤害、调用状态、治疗、召唤单位、位移、弹道、调用技能、调用词条。 |
| BUFF效果 | 控制、持续伤害、持续治疗、属性修正、光环。 |

“控制”是本表的统一填写名，不另填“强控”或“状态效果_控制”。类型已有定义不代表每个子功能均已开放。护盾、反伤在结构示例中按其含义定位，待相应类型与修饰支持齐备后加入可用目录；受击回血属性本例归属“属性修正”。

制作配置工具或下拉时，先选位置，再选该位置支持的项目和操作。只剩一种填法时直接确定；不把所有参数放进每个位置的同一份长列表。表头骨架本轮不制作完整的联动下拉。

## 三、对象与位置

### 1. 位置按内容层级选择

| 位置示例 | 定位结果 |
|---|---|
| 自身 | 神通的基础参数或BUFF的整体参数。 |
| 主选择器、子选择器 | 对应的选取或分区配置。 |
| 效果1 | 当前对象的第一个原有效果。 |
| 全部持续伤害效果 | 当前对象原有效果中，属于持续伤害的各项。其他类型同理。 |
| 效果列表 | 当前对象的效果集合，供追加效果。 |
| 效果1 → 引用状态 → 自身 | 神通效果1所调用BUFF的整体参数，例如持续时间、最大叠加层数。 |
| 效果1 → 引用状态 → 效果2 | 所调用BUFF里的效果2，例如其概率、数值或资源。 |
| 效果1 → 命中神通 → 主选择器 | 弹道命中所调用神通的主选择器。 |
| 修改1新增项 | 本条词条修改1追加的内容，供后续修改块继续调整参数。 |

“→”表示逐层选择内容，不规定程序表示法。目标内容应已存在，或由本条词条先行新增；已存在内容中未配置的可选参数，允许按该能力的参数定义补充。原有效果槽位按基础表定位；追加后的有效组合可以超过原表三个槽位。

神通引用BUFF、BUFF引用神通及后续能力的引用关系，均可沿实际引用继续定位。不会因为只定位某门神通，就自动修改它调用链中的所有内容；每个修改块明确指到实际承载参数的位置。

### 2. 直接修饰与沿引用修饰

| 配法 | 生效范围 |
|---|---|
| 作用对象BUFF＋中毒识别ID＋自身持续时间 | 角色施加的该中毒，各调用来源均使用修饰后的时间。 |
| 作用对象神通＋某门神通识别ID＋引用状态的持续时间 | 只修改这门神通本次调用的状态；其他神通引用同一个状态时保持各自结果。 |

基础配置仍为共用定义，修饰属于获得词条的角色及本次作用范围。直接BUFF修饰和指定神通下的局部BUFF修饰落到同一参数时，按同一份有效值合并，各计算一次；局部范围不天然具有更高覆盖优先级。原持续12000毫秒，直接修饰加3000、仅神通甲的局部修饰再加3000，则甲为18000、其他调用神通为15000毫秒。

识别ID负责定位，不按数值增减。调用引用指向具体等级行；直接BUFF词条按识别ID匹配各等级。甲由中毒一级改引二级时，两类词条均可作用于二级；改引另一识别ID的状态时，直接中毒词条不再匹配，局部词条沿新引用检查位置和项目是否适用。需要更换所调用对象，设定引用ID；需要改其内容，沿引用进入后修改。

### 3. 稳定定位与内容引用

原有效果位置保持身份：删除效果1不会把原效果2改称效果1。替换某位置后，对该位置的参数修改作用于替换后的内容，前提是新内容支持该参数；不能把旧类型的参数强塞给新类型。

适用限定检查所定位内容修改前的类型或形状。“全部某类效果”定位原有匹配项，不顺带修改其他词条追加的效果；“修改N新增项”只供本词条后续块定位，限定检查刚从模板带入的内容。引用ID被更换后，沿该引用进入新对象，其内部位置和项目按新对象检查。

模板只提供所选的选择器或效果内容，不复制模板对象的ID、识别ID、等级及其他未选部分。追加进入所选列表；替换覆盖所选效果或选择器；未涉及的内容沿用原配置。审核示例尚无模板时，使用“〔反伤模板等级ID〕”等能区分内容的占位名；实际配置须替换为相容内容的有效等级ID。

整个神通或BUFF不靠“复制自身”隐式替换身份。需要整套更换被调用对象时，设定调用ID；只变效果组合时，替换、追加或移除列表里的效果。

## 四、修改操作与参数分类

### 1. 六种操作

| 操作 | 填写及结果 |
|---|---|
| 固定增减 | 按参数自身单位增加或减少指定数值，可正可负。持续时间加1000毫秒填1000；层数上限减1填-1。 |
| 按比例 | 按指定比例提高或降低参数有效值，填万分比增量。提高20%填2000，降低10%填-1000。 |
| 设定 | 将参数设置为指定数值、中文选项、是/否、引用ID或资源。该能力允许、但原来未配置的可选参数，也用设定补充。 |
| 替换 | 用模板中选定的完整效果或选择器，替换目标内容，参数随新内容带入。例如护盾效果换成受击回血效果。 |
| 追加 | 向目标效果列表加入模板中选定的完整效果及其参数，原有效果保留。例如保留护盾，增加反伤。后续块可调整本次新增项。 |
| 移除 | 将选中的效果移出有效组合，不填数值和模板。未选效果保留，原有效果编号不重排。 |

枚举、布尔、ID、资源使用设定。资源设定为空时按该资源定义清空或恢复默认；其他参数的空白表示未填写，不当作0。时间、层数、系数等数值按各自含义支持增减、比例或设定。比例数值需要区分“相对提高”和“增加百分点”：概率20%相对提高50%是30%；增加50个百分点是70%。

替换和追加引用的是已经配好的内容；只改数值或特效时直接修改参数，不要求另建整套模板。技能效果与BUFF效果分别采用各自底层支持的内容，不能仅因名称相似就跨类型复制。

新增参数按其承载内容处理：

| 原配置情况 | 填写方式与结果 |
|---|---|
| 效果已存在，支持的可选参数尚未填写 | 直接设定该参数。例如伤害效果原无血量限制，补充生效血量阈值3000后，只对生命低于30%的目标生效。 |
| 原来没有所需效果 | 先追加效果，再定位新增项修改参数；需要退出旧效果时使用替换。 |
| 所属能力尚不支持该参数或效果 | 待底层能力及对应修饰支持接入后配置。不能把“原来没填”与“能力不支持”合成同一种情况。 |

未填写参数需要固定或比例增减时，先按其定义取得有效默认值；没有有效基准的，先设定。

### 2. 参数按所属内容分类

| 参数所属内容 | 可修饰内容 | 配置说明重点 |
|---|---|---|
| 神通自身 | 威力、消耗、冷却、充能、施法时序、施法距离、引导、瞄准、生效系别、完整伤害增幅。 | 使用原参数含义；转换系别与完整伤害增幅保持独立项目。 |
| 选择器 | 阵营、是否包含自身、目标优先级、人数、形状与尺寸。 | 主选择器实际选单位；子选择器划分已选单位。人数为整数，尺寸不是人数。 |
| BUFF自身 | 持续时间、作用间隔、时间覆盖方式、层数叠加方式、最大叠加层数、状态表现。 | 修改共享参数时，明确整个BUFF受影响。修改层数上限不等于立即赠送层数。 |
| 神通效果参数 | 伤害、治疗、位移、弹道、调用、召唤等各效果的专属参数。 | 位置先确定效果类型，参数名称与该类型对应，不靠策划记参数序号。 |
| BUFF效果参数 | 属性修正类型与数值、控制类型、持续伤害与治疗系数、固定值、光环引用等。 | 每个效果各有概率和专属参数；概率的判定时机沿用该效果规则。某个效果的值可以为负，应按该参数定义判断。 |
| 效果条件与目标 | 该效果已有的概率、延迟、血量条件、阵营、作用范围等。 | 只改指定效果的条件或目标；不把它们变成整条词条共用的触发条件。 |
| 被动或触发效果 | 所属能力已开放的触发事件、条件、间隔、目标和执行内容。 | 受击回血等行为在底层定义完整后，词条可追加、替换和修饰；不另外创建词条事件系统。 |
| 表现资源 | 动作、模型、附着特效、施法及受击特效、音效等。 | 定位到实际持有资源的神通、BUFF或效果。资源可以独立于数值和效果组合修改。 |

当前BUFF表中，持续时间、作用间隔和层数属于整条状态；概率及效果参数属于各效果。要让减速与眩晕使用不同持续时间，按底层结构分别配置状态，再各自修饰。不能靠词条说明把共享字段变成每效果独立字段。

### 3. 每个参数只保留一份填写说明

参数目录按“所属对象／位置、参数中文名、含义与单位、允许操作、合法边界与特殊值”五项维护。中文名表达参数含义，字段或槽位对应关系放在核对材料中。参数单位逐项核对，不把全部时间项目概括为同一单位。

下表包含配套示例实际使用的参数，并列出距离、概率、整体增幅及召唤时长的本版边界；完整目录按实际接入能力继续维护。

| 所属位置 | 参数 | 含义与单位 | 允许操作 | 边界或特殊规则 |
|---|---|---|---|---|
| BUFF自身 | 持续时间 | 毫秒。 | 固定增减、按比例、设定 | 到期与刷新沿用BUFF规则。 |
| BUFF自身 | 作用间隔 | 毫秒。 | 固定增减、按比例、设定 | 周期效果取正数；非周期效果按其定义。 |
| BUFF自身 | 最大叠加层数 | 状态层数上限，整数。 | 固定增减、按比例、设定 | 与叠层方式配套，不立即赠送层数。 |
| BUFF自身 | 层数叠加类型 | BUFF已有中文选项。 | 设定 | 修改如何接受后续叠层。 |
| BUFF自身 | 状态特效路径 | 对应资源名或路径。 | 设定 | 未选资源与绑定位置保留。 |
| BUFF属性修正效果 | 修正属性值 | 固定值或万分比，由所改属性定义。 | 固定增减、按比例、设定 | 可以有负数；受击回血为基础整数值。 |
| BUFF持续伤害效果 | 万分比伤害系数 | 万分比。 | 固定增减、按比例、设定 | 非负；只改系数，固定伤害不变。 |
| 神通伤害效果 | 本条伤害系数 | 万分比。 | 固定增减、按比例、设定 | 按神通伤害规则，仅本条效果受影响。 |
| 神通效果 | 生效血量阈值 | 目标生命百分比，万分比。 | 固定增减、按比例、设定 | 有效值0～10000；0无条件，正数按严格低于判断。 |
| 神通自身 | 冷却时间 | 秒。 | 固定增减、按比例、设定 | 普通冷却按该神通规则；不改已开始的剩余计时。 |
| 神通自身 | 生效系别 | 一个系别中文名。 | 设定 | 转换后接受最终系别匹配。 |
| 圆形主、子选择器 | 半径 | 地图距离，本版按整数配置。 | 固定增减、按比例、设定 | 正数；主选择器选单位，子选择器划分已选单位。 |
| 具体效果 | 触发概率 | 万分比，10000为100%。 | 固定增减、按比例、设定 | 有效值0～10000；原配置0的默认含义先解析，修饰后的有效0不重新当作必定触发。 |
| 神通自身 | 施法距离 | 地图距离。 | 固定增减、按比例、设定 | 正数；没有0距离或无限距离配置。 |
| 神通自身 | 完整伤害增幅 | 万分比增量，500为增加5个百分点。 | 固定增减 | 有效增幅合计下限0；完整伤害120加5%为126。 |
| 召唤效果 | 存续时间 | 沿用底层时间单位。 | 固定增减、按比例、设定 | 正数；超过统一阈值视为永久。阈值待召唤设计确定。 |

## 五、组合、生效与撤销

本节的组合处理采用本版方案，供框架审核；不把此前建议冒充用户已拍板的结论。

| 情况 | 生效结果 |
|---|---|
| 一条词条包含多项修改 | 针对每个实际匹配的神通或BUFF共同生效。必要内容缺失、参数不受支持或引用无效时，对该对象整条不生效；可选参数原来未填写不算缺失。系别内某门神通不适用，不影响其他神通。 |
| 多条词条修改同一数值 | 先确定设定后的基准，加全部固定增减，再乘以1加全部比例增量之和；最终按参数单位取整和处理边界。 |
| 一条词条替换内容，另一条改其参数 | 替换后仍支持该参数则合并；参数不再适用则对应词条整条不生效。整项移除后，其内部参数修改不再适用。 |
| 多条词条追加效果 | 各自追加，按底层效果执行规则处理；不因追加到同一列表就互相覆盖。新增效果的存在期间跟随所属神通或BUFF。 |
| 多条词条设定、替换或移除同一内容 | 更高覆盖优先级的整条词条优先；低优先级被排除的词条不再影响其他词条。相同结果可以共存，同一内容只覆盖一次。 |
| 同优先级争用不同结果 | 先排除已被更高优先级压住的词条；在剩下的同优先级组中，所有直接参与冲突的词条一起不生效，再考虑更低优先级。不能边删除边放行另一条，从而受比较顺序影响。 |
| 同ID由多个来源提供 | 效果只应用一次；任一来源仍有效就保留。不同ID按各自修改合并。 |
| 来源启用或撤销 | 启用后提供修饰，撤销后按仍有效来源重新得到结果。基础表保持原定义。 |
| 正在执行的技能与BUFF | 本次施放及由此施加的BUFF沿用本次确定的词条修饰；新的施放、施加或允许的刷新采用届时有效修饰。这里只固定词条修饰，其他属性沿用神通、BUFF自身规则。已有冷却与充能保留剩余时间，下一轮使用新值。 |
| 界面展示 | 描述与预计数值采用下一次使用的有效配置；正在计时的冷却、充能显示实际剩余时间。 |

覆盖冲突只比较实际争用的同一位置和项目。替换效果与修改其中仍有效的参数可以兼容；移除效果与保留或替换该效果不能并存。普通固定增减和比例叠加不用比较覆盖优先级。

同优先级交叉冲突示例：A设前摇3；B设前摇5、消耗8；C设消耗6。A与B争前摇，B与C争消耗，三条均直接参与本组冲突，三条均不生效。若A提高优先级，则先排除与A冲突的B，C可生效，结果为前摇3、消耗6。

数字的修改量与结果边界分别判断。允许负修改量，不等于结果必须允许负数；增加30个百分点再减少50个百分点，若该增幅下限为0，最终额外增幅为0。属性修正等本就允许负值的参数保留其负值规则。

数值越界按具体参数合法边界截断；数值截断不把缺少必要内容的组合变成合法组合。原配置0代表默认值时先取得有效值，修饰后的真实0不再被当成默认值。距离、时间、次数各按自己的参数说明处理，不用一条“全部≥0”概括；人数和层数为整数，选择范围尺寸本版按整数配置，合并后统一取整。

状态同识别编号，高等级覆盖低等级；不同编号分别生效；同等级再次施加按BUFF的叠层、刷新配置处理。允许本次施加且效果判定成功后，时间“覆盖”按本次施加来源的有效持续时间重新计满；不另按修饰来源比较时长或伤害大小。

BUFF各效果分别在施加时判自己的概率，周期内不重判；不允许覆盖或叠加时保留原状态，不重判概率。允许施加时，某组判定失败保留该组已有结果，不影响其他组本次成功施加。属性修正也遵守此规则，其施加概率不等于受击回血的每次受击概率。

含系别转换的词条按默认系别定位对象，本条其余修改随同该对象执行；其他系别词条按转换后的最终系别匹配。金行同时匹配五行与金行。完整伤害增幅作用于完整伤害，包括固定伤害及新增效果产生的伤害，同段伤害只计算一次；调用链的伤害归属沿用发起神通最终系别，参数修饰范围仍由目标位置决定。
