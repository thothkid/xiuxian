# 任务2B·上古史与地表·冻结 v1.0


---

## 1. 任务范围、标签与硬边界

任务2B只解决：上古历史如何生成五洲的代表性受创遗痕、局部生态/空间后果，以及每洲可独立发展飞升路径的**历史来源**。

不解决当代势力与城市（任务3）、资源/怪物/灵植/境界路线（任务4）、通行玩法/关卡/地图/数值/美术执行（任务5）。

| 标签 | 含义 |
|---|---|
| 〔底〕 | 世界观底层文档的明确约束 |
| 〔台〕 | 任务1已定的先天地理底盘 |
| 〔共〕 | 经讨论与压测后采用的项目设计前提 |
| 〔推〕 | 从〔底〕/〔台〕/〔共〕自然导出的后果或条件性推演 |
| 〔候〕 | 有价值但未压透的历史碎片/具体版本，不可反写主因果 |
| 〔待〕 | 未决问题，不可据此推导 |

## 2. 共同世界条件与最小共同战争史

### 2.1 底层约束

| 约束 | 对本任务的意义 |
|---|---|
| 〔底〕天界大阵以灵脉网络为物理骨架，节点可依托山川、古阵、**洞天**等落点 | 地理条件可以承载设施、通路和遗构，但设施不是脱离山海凭空出现 |
| 〔底〕上古大战造成飞升通路崩塌、盲区与异常区 | 跨域战争可长期影响多类通路、封存体系和依灵脉而建的设施 |
| 〔底〕原初秩序/混沌、魔气与正常灵气不可混为“安全纯灵” | 盲区或异常外泄必须保留危险性，不能直接写成资源福利 |
| 〔台〕五洲的峰海、冰海、裂谷、火渊、巨木为先天底盘 | 遗痕的受创与保存必须被当地地理塑形 |

### 2.2 最小共同战争史（主脊）

```text
灵脉与大阵提供世界物理骨架；五洲先天底盘各异
                    ↓
天界体系、人间修士及其他上古修行者，
在不同底盘上以直接建造或借用自然地利的方式经营各类设施
                    ↓
上古跨域战争冲击飞升通路、封存体系和依托灵脉环境的设施
                    ↓
五洲各有一处代表性地点受创：崩断 / 冻结镇压 / 破碎 / 焚毁埋没 / 上行断失
                    ↓
高峰、极寒、裂谷沉积、活火涨落、云雾植被决定万年后的不同保存状态
```

> **五洲不是一台机器的五个零件。** 它们是五块可独立形成完整修行域的大陆，各自保留一处长期塑造地理格局的代表性受创遗痕。世界中还存在无名断路、小遗迹与异常区；五洲并非仅有五处战痕。

### 2.3 不进入主脊的强断言

- 五处旧构同属一个完整大阵网，或同一时期/主体/制式建造；
- 五洲受创发生在同一战线、同一日或已有严格先后；
- 人间自建设施等于天界大阵零件；
- 自然大地由战争制造，或整洲地貌均可归因于遗痕。

## 3. 五洲第0行：历史前提摘要

| 洲 | 自然落点〔台〕 | 历史用途〔共〕 | 受创〔共〕 | 保存机制〔推〕 | 最小可见后果〔推〕 |
|---|---|---|---|---|---|
| **岱舆** | 苍岳峰顶、高寒云海、山海高差 | 登临/升阶设施 | 战时崩断并外露 | 高峰高寒令残构不易被沉积吞没 | 峰顶断裂残构、高空旧道残段、局部异常云海/秩序现象 |
| **钟山** | 环冰海内环、长期极寒、环状隔绝 | 封存性质旧设施，非登天设施 | 战后进入冻结镇压、不可自由启闭 | 极寒使设施与周边被厚冰包裹；异常冰层有自然与历史双因 | 内环封闭、局部冰层异常厚、旧构难以直接辨认 |
| **方壶** | 横向裂谷、地热矿脉、风蚀沉积环境 | 人间器修/工艺设施群 | 战争中破碎 | 崩塌、风沙与水流等长期沉积将残构压入地层 | 彩层/断面中可读出非自然夹层与零散工艺残留 |
| **丹穴** | 星火湖及周边火脉岸带、活火火渊 | 人间借地火建设飞火/升阶设施 | 战中焚毁，被熔岩、熔壳和火山沉积覆盖 | 活火脉非定时涨落，使残构反复露出、再掩埋 | 极端低潮或熔壳移位时可见烧熔台基/非自然构件 |
| **玄圃** | 巨木天冠中段枝台、云雾带、稳定树体结构 | 借自然垂直条件设置小型层间连接旧构 | 上行人工连接断失；主干/根海/大面积生态未被改写 | 残构卡在枝台，被附生植被与云雾遮蔽 | 云潮特定时刻显出不通两端的断栈/台基，呈现层间失连 |

| 岱舆 | 钟山 | 方壶 | 丹穴 | 玄圃 |
|---|---|---|---|---|
| 外露 | 冻存 | 夹层 | 涨落露埋 | 云中断链 |

> 五种保存差异由“受创方式 × 先天底盘”产生。

## 4. 代表性受创遗痕与战争关系

本表只写“设施如何与战争发生关系”；不提前锁定政治站队、完整军事过程或严格时序。

| 洲 | 当前可采用的战争关系 | 需保留的边界 |
|---|---|---|
| 岱舆 | 登临遗迹受强烈正面冲击，崩断外露 | 不定最先/最后崩、攻守双方或“天界招兵口” |
| 钟山 | 镇封设施战后进入冻结镇压，后被极寒长期封存 | 不定从未被攻、被放弃、谁施冻或是否仍运转 |
| 方壶 | 〔共〕工艺设施在战争中破坏，后被裂谷沉积覆盖；〔推〕依附灵脉的生产属性使其受创**存在被针对的动机**，与丹穴的被动波及构成对比 | 不定必是兵工厂、主动参战、明确针对者、两边均清除或唯一毁坏机制 |
| 丹穴 | 人间飞火设施遭战争波及、焚毁并受活火反复覆盖 | 不定反天界、政治中立、不依赖正常灵气或必为盲区 |
| 玄圃 | 小型人工连接战争中断失，巨木自然生态大体保留 | 不定天界不修的原因、政治归属纠纷或建木人工造物 |

> 人间自建设施不等同于天界大阵零件，但同样依附于玄黄界共同的灵脉环境。战争对通路与灵脉秩序的冲击，足以让丹穴地火、方壶矿脉及其上设施受到波及；这不要求预设某一方的具体动机。

## 5. 五洲独立飞升：历史接口来源

> 以下来源**由各洲战争脊块的因果自然长出**。历史接口来源不等于终局玩法、具体类别或通行机制。

| 洲 | 历史接口来源〔共〕 | 可继续设计的问题〔待〕 |
|---|---|---|
| 岱舆 | 苍岳峰顶崩断外露的断裂登临遗迹 | 残缺登临路径如何与苍岳历史结合；修复/通行方式 |
| 钟山 | 环冰海内环被封存、难启闭的镇封古阵/旧节点 | 封存结构怎样与飞升历史发生转换；运行状态/钥匙/解封机制 |
| 方壶 | 裂谷深层被夹层掩埋的工艺遗构与旧通路线索 | 工艺遗构如何指向更深处历史出口；出口准确性质 |
| 丹穴 | 星火湖周边随火脉涨落显露的飞火残台及其局部灵气异常区 | 异常区是否构成盲区、异常成因与通行窗口 |
| 玄圃 | 天冠中段的层间断接旧道/连接残构 | 断接结构如何重连或转入高层；是否为完整洞天 |

## 6. 三表扩展边界

| 表 | 可写入 | 不可写入 |
|---|---|---|
| 遗痕卡 | 位置、受创、保存、可见/不可见层次 | 数值、首领、掉落、完整工程说明书 |
| 生态条件变化表 | 遗痕对局部云雾、冰层、沉积、火脉、植被、空间稳定性的影响 | 怪物表、灵植产量、丹药配方 |
| 历史空间关系表 | 自然区与遗痕区的方位、可达性、遮蔽关系；不受遗痕直接解释的自然区 | 当代城镇、宗门势力、传送点、关卡路径 |

每洲必须保留足够大的独立自然区；任何上古遗痕都不能被用来解释整洲生态、所有高阶区或全部地貌。
