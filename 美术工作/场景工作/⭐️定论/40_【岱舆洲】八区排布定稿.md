# 40 · 岱舆洲 · 八区排布定稿

> ## **地理已锁定，不再动。**
> **本件是岱舆洲地理的最终形态。** 秘境与内容场景是**往这套地理里挂点**，**不改地形、不改排布、不改颜色**。

## 一、整体形状

> **整个洲就是一座山，和它脚下的一片湿地。从东南海边上岸，沿一条水一路往西北走，走到雪线以上的峰顶。八区就是这条路上的八段高度。**

```
                              ▲ R08 峰顶（最高）
                             /
                        R07 雪脊
                           /
                    R06 云中残台
                       /
               R05 断裂带（唯一向下）
                  /
 R04 侧坡 ←── R03 汇水盆地（最宽）
（岔出去·可不去）    │
                  R02 峡（第一道门）
                    │
        R01 河口湿地（最低·唯一入口）
                    │
                  ～海～（东南）
```

**一句话记法**：**一条从东南到西北的上山路——中间鼓出一个盆，盆南挂一个可以不去的侧枝，盆北是断口，断口之上一路到顶。**

## 二、八区排布

| 境界 | 区 | 位置 | 地貌一句话 | 主色 | 与上一区的关系 |
|---|---|---|---|---|---|
| 炼气 | **R01** | 东南沿海·最低 | 河口湿地＋苇荡＋岩带露头；**全洲唯一能靠岸的地方** | **暖金嫩绿** | 起点·**唯一入口，只进不出** |
| 筑基 | **R02** | R01 正北·河谷收窄处 | **一条被水切开的窄峡**，两壁夹逼，天空成缝 | **冷灰暗** | **第一道门**·过了看不见苍岳 |
| 金丹 | **R03** | 出峡之后·全洲最宽 | 汇水盆地＋分汊水网＋湿地，**水在这里慢下来** | **碧蓝荷粉** | **豁然开朗**·全洲人烟最盛 |
| 元婴 | **R04** | 盆地**南缘**·岔出去 | 暖赭矿化侧坡，一条短支沟上去又下来 | **偏橙锈赭** | **可以不去的侧枝**·不在主轴 |
| 化神 | **R05** | 盆地**北缘**·主轴 | 断裂带＋一堵截断画面的断墙；**全洲唯一向下** | **冷灰炭黑**（嵌槽近景冷紫灰） | **不可逆**·跨过去回不来 |
| 炼虚 | **R06** | 断裂之上 | **云中残余台地**，**残台先于雾** | **冷白云雾** | 从断口爬上来的第一片平地 |
| 合体 | **R07** | 台地之上 | 雪脊＋冻融碎屑，**季节开窗** | **冰蓝白** | 每年重开一次的地面 |
| 大乘 | **R08** | 峰顶 | 裸岩＋**S01 残损石构** | **金白** | 终点·**苍岳的顶就是这里** |

## 三、颜色走向

> **暖 → 冷 → 暖 → 冷冷冷冷 → 暖**
> **两头暖（R01 河口暖金、R08 峰顶金白），中间一路冷；R04 是唯一插在冷段里的暖，而它在侧枝上。**
> **远看是「暖起、冷透、暖收」。**

**⚠ 色板 hex 是参考值，非最终锁定**〔任务1 表现约束第 7 条〕。**正式色以本表八区分色为准；旧封版底座页三冷色（青灰 `#7B8FA1`／白 `#F0F4F8`／冷蓝 `#4A7C96`）仅作 R02／R05–R07 的参考底色。**

## 四、一锚八相

**苍岳是全洲唯一洲级锚点，八区各能看见它的一个样子：**
R01 天际一线雪顶 → R02 被峡壁挡住 → R03 盆地北缘的完整轮廓 → R04 偏在侧面 → R05 断墙之上 → R06 雾里时隐时现 → R07 已经在它身上 → R08 站在它顶上。

## 五、四条贯穿结构

**受压陆脊 ／ 横切断裂 ／ 残余高台 ／ 单一主出水**

## 六、过渡带因果（相邻区不是色块硬切）

| 过渡 | 因果 |
|---|---|
| 01→02 | 河流下切收窄为水切窄峡 |
| 02→03 | 出峡围合成冲积盆地 |
| 03→04（南支） | 盆地南口横入背风侧坡·**可回** |
| 03→05（北主） | 盆地北口跨断层谷肩·**不可回** |
| 05→06 | 断谷续抬升入云海带 |
| 06→07 | 云台再抬入实体**冻融鞍脊** |
| 07→08 | 雪脊收束至绝顶 |

## 七、共用底座

**青灰岩带贯穿全洲**：R01 藏在土下（岳骨阶＝第一次露头）→ R02 立起来成峡壁 → R05 被切开露断面 → R07 被冻融掰成碎屑 → **R08 它就是地面本身。**
