# 41 · 岱舆洲 · 历史骨架（定稿）

> **给原画、地编、后续策划的唯一一段历史。再长的版本都是它的展开。**

---

万年前神魔大战，岱舆洲不是全洲主战场。但阶梯顶端是一个关键登临节点——所以这里打过，而且打得要紧。

这里的地一直往上顶，水把它切开，大阵埋在灵脉里的节点从来铺不牢：越高，气越近源头。上古修者为此而来。但原初秩序不能直吸，硬吸经脉紊乱，须一级一级改身子——这座山从海到雪线正好是一条从熟到生的梯度。他们沿它布下一路洞府道场：是一架阶梯，不是城，不是宗门。八境界的高度，就是那八次改造的位置。

大战中飞升通道崩塌，阶梯上端接的正是它。争的是那个节点，不是这座山——战痕沿断口一线集中，不漫山遍野。上古修者没有留下来。

此后路断了近万年：低处洞府被水与沉积埋住，高处碎块被剥蚀翻出。近千年劫气渐散，路重新能走。新人从渡口上岸，那是全洲唯一靠岸处，也是上古留下的接引点。他们大多停在低处两段，只是没人知道，这条路是别人修过的。

---

## 一、这段话钉住的四件事

| 问 | 答 |
|---|---|
| **岱舆洲是主战场吗** | **不是全洲主战场。** |
| **那这里打没打过** | ## **打过，而且打得要紧——因为阶梯顶端是一个关键登临节点。** |
| **打成什么样** | **争的是那个节点，不是这座山。战痕沿断口一线集中（R05→R08），不漫山遍野。** |
| **后来的人** | 空了近万年；近千年路通了；新人从渡口上岸，大多停在低处两段。 |

## 二、每一句管住的设计

| 句 | 管什么 |
|---|---|
| 不是主战场，但顶端是关键登临节点 | **山上有真实战痕，但只在断口一线；低三区没有** |
| 地在顶·水在切 | 八区地貌的成因；**八区没有"荒废的遗迹"，只有"还在动的现场"** |
| 大阵铺不牢·越高气越近源头 | **越往北资源越好**；高阶灵植妖兽为什么在高段 |
| 不能直吸·须一级级改·山是梯度 | **八区＝八境界**；为什么不能跳级直接上顶 |
| 布下的是阶梯不是城 | 每区那处遗构规模小、功能单一、一区一处；**不是宫殿** |
| 争的是节点·战痕沿断口一线 | **R05→R08 是古战场带；R01–R03 不是** |
| 空了近万年·低埋高露 | **低段秘境口＝被水泥封着刚露；高段＝崩落堆里的裂口。两种口长得不一样** |
| 渡口是上古接引点 | 全洲唯一入口；跨洲传送的落点 |
| 大多停在低处两段 | 人只住 R01／R03 |
| **没人知道这条路是别人修过的** | **玩家的升仙路＝一万年前断掉的那条路——全洲的钩子** |
