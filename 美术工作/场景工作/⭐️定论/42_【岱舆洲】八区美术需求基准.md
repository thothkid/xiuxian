## 附：全洲三条贯穿线（去文字后仍应读得出）

**① 视野条件梯度**（不是"越高看得越远"的奖励线）
`开阔定向(R01) → 近壁收束(R02) → 水网展开(R03) → 坡折碎视(R04) → 断谷遮蔽(R05) → 窗口可见(R06) → 白化辨脊(R07) → 完整回望(R08)`

**② 一锚八相·苍岳时序**
`方向(R01) → 失去(R02) → 目标与障碍同框(R03) → "你走偏了"(R04) → 被代价挡住(R05) → 间歇的确认(R06) → 身处其中而不自知(R07) → 视点(R08)`
**第二次丢失正好落在不可回那一段——不是巧合：R05 的"被墙截断"与"不可回"本来就是同一件事的两面。**

**③ 垂直关系七种，无一雷同**
低平(R01/R03)｜夹逼(R02)｜斜坡(R04)｜垂直断面(R05)｜水平台(R06)｜脊线(R07)｜锥顶(R08)

> **三条叠起来就是"不平"的可查证明**：颜色管"看着不单调"，材质管"走近了不重复"，垂直关系管"远景剪影不雷同"。**只查颜色不够。**
