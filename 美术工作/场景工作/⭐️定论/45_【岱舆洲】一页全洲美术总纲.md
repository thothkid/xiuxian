## 一 · 一句话

> ## **整个洲就是一座山，和它脚下的一片湿地。从东南海边上岸，沿一条水一路往西北走，走到雪线以上的峰顶。八区就是这条路上的八段高度。**

**而这条路不是天生的**：上古修者借山势布下的**是一架阶梯，不是城，不是宗门**；**八境界的高度就是那八次改造的位置**。今天的人走在上面——**没人知道这条路是别人修过的。**〔`41号`〕

## 三 · 两条链

**一锚八相**（苍岳是全洲唯一洲级锚点）〔`40号`〕：

```
天际一线雪顶 → 被峡壁挡住 → 盆地北缘完整轮廓 → 偏在侧面
→ 断墙之上 → 雾里时隐时现 → 已经在它身上 → 站在它顶上
```

**八词链**（八个剧情格合起来是一条认知线，**不是八个谜题**）〔`46号 §2.3`〕：

```
看见 → 受阻 → 重组 → 岔开 → 断绝 → 暂歇 → 等候 → 回望
```

> ## **八个事名就是一锚八相的命名化**——「岳」出现七次是**有意的**：它让玩家知道自己始终在攀同一座山，**不是八个区各立一座仙山**。
> 「还」两次（**偏岳可还／断墙不还**）是**有意的对句**：R04「可以不去的侧枝」／R05「不可逆·跨过去回不来」。
> **八相的「关系」冻结，「画面」不冻结**——凡属"可能画面"的表述**降为灰盒待验**。

## 四 · 全洲一条物 ＋ 色域

**青灰岩带**：

| R01 | R02 | R05 | R07 | R08 |
|---|---|---|---|---|
| **藏在土下**（岳骨阶＝第一次露头） | **立起来成峡壁** | **被切开露断面** | **被冻融掰成碎屑** | ## **它就是地面本身** |

> ## **玩家在第一个区摸到的石头，就是他最后站在绝顶上的那块。**〔`42号`〕
> **材料血缘一条梯度**：青灰风化岩 → 暖铁 → 崩壁 → 台岩 → 冻融碎屑。## **新增任何异常色带都是在切断它。**
> **四条贯穿结构**〔`40号`〕：受压陆脊／横切断裂／残余高台／单一主出水

**色域**：**暖 → 冷 → 暖 → 冷 冷 冷 冷 → 暖**（两头暖，中间一路冷；**R04 是唯一插在冷段里的暖，而它在侧枝上**）
