## 2. 六栏正文

### R01-N1 · 望岳津 · 〔区级：天际见岳〕

1. **场景功能**：抵达与定向的节点；玩家从可自然靠岸的浅岸进入岱舆，水的走向与苍岳远影同时给出“往内陆走”的第一条读法。〔42号 R01〕
2. **故事与历史**：入境渡口是“能靠岸”的社会条件，不是港口建筑。万宝坊市落在渡口边但不占九格；本格不替它补规模、归属、来客身份或交易机制。〔31号裁定1／46号 §3.1〕
3. **地貌逻辑**：河口开阔的冲积浅岸接单一主出水；细土、砂砾和季节水位先形成可踩近水边，才成立“可靠岸”。〔32b／40号〕
4. **色系光雾**：暖金嫩绿、开阔天光；苍岳雪顶只在天际远处，绝不拉进中景。暖来自水光和植被，青灰岩不染暖。〔42／43号 R01〕
5. **主识别物**〔身份：**节点**〕：可读水向的开阔浅岸与天际雪顶的对应关系；不是码头、栈桥或一座渡口建筑。〔42号〕
6. **碎片＋禁画项**：可有湿土受水线轻微改写、岸生草本随浅水退让。禁完整海港、码头群、固定栈桥、系船柱与绳槽、船队、城墙、宗门、NPC 引导、人工路标。〔32b／42／43号〕

### R01-M1 · 浮沉洲

1. **场景功能**：浅切水网里的短遭遇；让玩家读到水位涨落如何把低浅洲露出又收回，仍保持开阔定向。〔42号 场景分布〕
2. **故事与历史**：不承担旧路事件；当前视觉不立社会设施与人史标记。它只承担入境后“跟水读方向”的自然节奏。〔42／43号〕
3. **地貌逻辑**：浅切支流间的冲积细土和砂砾河阶在季节漫溢中露没，水退时显出低平边缘。〔32b R01〕
4. **色系光雾**：浅水反光和嫩绿岸草形成暖意；不画荷粉、异色水体或自发光植被。〔42／43号〕
5. **主识别物**〔身份：**局部辨识**〕：水线改变后短暂显出的低浅洲边，不成为可远读地标。〔32b〕
6. **碎片＋禁画项**：可有细砾被水冲开、草根边缘被水线压低。禁人工控水痕、人工沉积层、深水、漩涡、污染带和战痕。〔32b／43号〕

### R01-S2 · 水镜滩 · 水退方见

1. **场景功能**：浅切水网中随水退露出的短探秘境口；它让“两态”落在水位，而不是落成机关玩法。〔42号 R01／44号〕
2. **故事与历史**：事名只描述当前“水退才见”的进入条件；低区秘境可由覆盖、误入或短时开放成立，不补建造者、用途、年代或谁曾在此停留。〔46号 §4.3／43号红线〕
3. **地貌逻辑**：浅水与细砾滩在自然涨落下交替覆盖，一处近水面级的低暗口只在水线退开时显出。〔32b R01〕
4. **色系光雾**：水面只反射自然天光；无独立辉光、无异常水色、无荷粉。〔42／43／32b〕
5. **主识别物**〔身份：**局部接口**〕：水退后近读才能发现的一小段低暗边界；不是洞府、拱门或地图目的地。〔42／43号〕
6. **碎片＋禁画项**：可有刚退水的细砾湿痕和浅水反光。禁水下洞穴、深坑、传送门、人工台阶、碑刻、凿痕、固定入口标识。〔32b／43号〕

### R01-M2 · 蔽苇汀

1. **场景功能**：苇湿地遮蔽中的微观遭遇；视线被草本切碎，但水声与水线仍让玩家不失去方向。〔42号〕
2. **故事与历史**：不承担旧路事件；“蔽”仅是湿地遮蔽，不写人躲藏、伏击或遗留营地。〔42／43号〕
3. **地貌逻辑**：浅水边的岸生草本和低坡灌丛在湿土上连成局部苇汀，支流仍从其旁浅切通过。〔32b R01〕
4. **色系光雾**：嫩绿为主，水光穿过苇梢；晨霭若有也低矮、流动、很快散，不可变为 R06 的雾幕。〔42号〕
5. **主识别物**〔身份：**局部辨识**〕：遮住近景、仍留出水线的苇丛豁口。〔42／44号〕
6. **碎片＋禁画项**：可有苇梢统一随风偏向、水面反光沿流向位移。禁成片异色芦苇、人工水道、栈桥、营地、船队、常驻人物和战痕。〔32b／43号〕

### R01-P1 · 异霭浦

1. **场景功能**：遮蔽反转段的灵植微生境；以短暂晨霭和湿地边缘让玩家从“看得远”短暂转为“贴水读方向”。〔42／44号〕
2. **故事与历史**：不承载人物、组织或旧路事件；“异霭”不是异象，只是低地水汽在风与水位间短停。〔42号 R01〕
3. **地貌逻辑**：湿土、浅水与岸生草本交界在自然洪水淤积和植被回占中反复变化，形成局部湿润的灵植生境。〔32b R01〕
4. **色系光雾**：嫩绿、湿金和近水白雾；雾薄、低、流动且很快散，不准常驻成幕，不用异光解释。〔42／43号〕
5. **主识别物**〔身份：**局部辨识**〕：近水草本边缘与一段短停的低霭，不成为独立雾景或地标。〔42／32b〕
6. **碎片＋禁画项**：可有湿干土色差、叶面水珠和被水线推开的细屑。禁发光灵植、草药微光、人工香雾、污染雾带、R06 式永久雾台。〔32b／42／43号〕

### R01-P2 · 砾台

1. **场景功能**：苇湿地边缘的灵植微生境；用砂砾河阶证明湿地并非一片平铺软泥。〔44号／32b〕
2. **故事与历史**：不承担旧路事件；旧登记名“秧浦”仅作审计留痕，不进入画面与事名层。〔44号〕
3. **地貌逻辑**：冲积细土与砂砾河阶在苇湿地边缘抬出一小段较干顶面，岸生草本从湿土过渡到砾面。〔32b R01〕
4. **色系光雾**：砂砾的浅灰与暖金植被并列；暖不染岩底，不画荷粉或人工色带。〔42号〕
5. **主识别物**〔身份：**局部辨识**〕：湿地边缘一小段粗颗粒河阶；“台”只指自然砾面，不指人工台基。〔32b／44号〕
6. **碎片＋禁画项**：可有砾粒大小变化、湿土退到砾面下缘。禁人工沉积层、石砌台基、码头、田埂、农具、采集牌和战痕。〔32b／43号〕

### R01-D1 · 蚀苇沼 · 末流所积

1. **场景功能**：滞水角落的短时风险遭遇；只承担 R01 的魔界格配额，不给低地另造裂隙、主线或魔界入口。〔46号 §4.4〕
2. **故事与历史**：事名“末流所积”保留一源八落：R05／R07 两处裂隙的渗漏沿既有水文下移，在本区水末端短时收集。本格不写输送路线、源头或战事。〔46号 §4.4／43号〕
3. **地貌逻辑**：既有低洼湿地、滞水角、细粒沉积和稀苇先存在；异常不改造地貌，也不形成连续带。〔32b／46号〕
4. **色系光雾**：湿土深绿、细泥暗值与正常水面反光；不得用魔气、紫黑裂纹、污染带、异常水色或异光作可视解释。〔32b／43／46号〕
5. **主识别物**〔身份：**局部辨识**〕：苇根旁一段水流变慢、细屑更易停住的滞水边，不发展成入口。〔44／46号〕
6. **碎片＋禁画项**：可有细屑在苇根外侧停留、清浊水面在小范围贴边。禁污染带、成片枯苇、能量场、粒子、魔界门、跨区输送轨迹、战痕。〔32b／43／46号〕

### R01-M3 · 岳骨阶

1. **场景功能**：风化岩露头旁的遭遇；让玩家第一次摸到贯穿全洲的青灰岩带，为进入 R02 的竖直峡壁作低平预告。〔40／42号〕
2. **故事与历史**：不承担旧路或修者遗构事件；“阶”是地貌名的一部分，不授权人工台阶、凿刻或道场解释。〔40／43号〕
3. **地貌逻辑**：湿土与砾石间的风化青灰岩在河口低地第一次自然露头，仍是水平、低矮的岩面，不提前长成峡壁。〔40／32b／42号〕
4. **色系光雾**：岩面保持青灰；暖金来自周围植被和水光，不把暖色涂到岩底。〔42号〕
5. **主识别物**〔身份：**局部辨识**〕：一段从湿土中露出的低矮青灰岩面；不是地标、祭坛或登高点。〔40／44号〕
6. **碎片＋禁画项**：可有风化边缘、湿土贴岩和细砾积在岩脚。禁人工台阶、凿痕、矿脉、祭坛、碑、瞭望台、坐痕与刻字。〔32b／43号〕

### R01-S1 · 垂练岩 · 覆而偶开

1. **场景功能**：入峡前框景段的短探秘境口；它把低区“覆盖后偶尔露出”的规律放在风化岩露头旁，不变成固定门槛。〔42／44／46号〕
2. **故事与历史**：事名描述当前覆盖与偶开，不讲独立人史；低区秘境可由生活层覆盖、误入或短时开放成立，不补道痕、建造者、用途、年代。〔46号 §4.3／43号〕
3. **地貌逻辑**：风化岩露头、湿土和近水边界在季节水位与覆盖物变化中形成一处短探的浅层例外。〔32b R01／42号场景分布〕
4. **色系光雾**：框景只利用开阔湿地的自然天光和岩面阴影；无洞内辉光、无异色雾、无荷粉。〔42／43号〕
