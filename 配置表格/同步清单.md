## 排除规则（这些文件即使出现在①区也不同步，且不入库）

| 模式 | 说明 |
|------|------|
| `luban.conf` | Luban 导表配置——**2026-08-01 撤出，只留③区** |
| `post-process.mjs` | 导表后处理脚本——**2026-08-01 撤出，只留③区** |
| `一键导表.bat` | 导表批处理——**2026-08-01 撤出，只留③区** |
| `aot-split.mjs` | AOT 分层对账脚本——只留③区 |
| `inject-rect-coords.mjs` | 区域坐标注入脚本——只留③区 |
| `*.mjs` `*.bat` `*.conf` `*.exe` `*.dll` `*.pdb` `*.zip` | 代码与二进制一律不同步、不入库 |
| 图片（`*.png` `*.jpg` `*.svg` 等） | 不入库 |
| `._*` | macOS 资源分支文件（泄漏产物） |
| `~$*` | Office 临时锁定文件 |
| `_dump.txt` | 临时导出 |
| `export_json/` | Luban 导出目录（本地调试用） |
| `备份/` | 本地备份目录 |
| 名单外的任何文件 | 默认不同步 |

---

> **入库文件类型总原则**（2026-08-01 thoth 定）：只提交 `.md` / `.txt` / `.doc(x)` / `.xls(x)`；
> 图片、代码、可执行文件、压缩包等一律不提交，除非 thoth 明确指定。
