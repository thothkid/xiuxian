# 一、物质法则的总原则

人间界不是一个天然纯净的修仙世界，而是一片由三种力量共同塑造出的废墟：

- **大轮回的自然呼吸**：原初秩序凝聚，原初混沌解散。
- **天界大阵的格式化工程**：原初秩序被整理成修士能够吸收、功法能够调用、境界能够承接的灵气。
- **魔气的怨化侵蚀**：原初混沌被封印、压缩、怨恨浸染后，变成破坏人间秩序结构的魔气。

所以，物质层的第一条原则是：

**万物不是被灵气"凭空创造"的，而是已有物质被灵气重新组织；也不是被魔气"凭空毁灭"的，而是已有结构被魔气扰乱、侵蚀、改写。**

灵气与魔气都不是单纯能量。它们都是"能量 + 信息"。

区别在于：

- 灵气携带的是被天界大阵整理后的秩序信息，修士可以读懂、吸收、压缩、调用。
- 魔气携带的是被封印怨化后的混乱信息，修士无法正常读懂，只能感到侵蚀、压迫、错乱。

这里要特别说明：**不可理解不等于完全无秩序。** 魔气内部也有某种结构，只是那种结构不适合人族修士、不适合正常妖修、不适合天界大阵设定的修炼体系。对人间界来说，它表现为污染、异化、狂乱和破坏。

# 二、境界与品质：物品的两条轴

**v6.0 起，"品阶"一词作废。** 它过去同时指五套互不相通的体系（灵石四档、材料品质四档、丹药九品、妖兽阶位、器物层级），是全项目最大的术语混淆源。现拆分为两条**正交轴**，任何物品同时挂在这两条轴上，缺一不可。**（例外：货币、能源类物品——如灵石——只挂品质轴，不挂境界轴，见 §七。）**

## 两条轴

| 轴 | 档数 | 回答的问题 | 字段 |
|---|---|---|---|
| **境界** | 9 | 这东西**给谁用**、掉在哪一层、什么修为能用 | `realm_id` |
| **品质** | 6 | 这东西**多好**、数值多高、能不能上坊市 | `quality` |

两轴**互不换算、互不覆盖**。同一个境界下有全部六种品质，同一种品质散布在全部九个境界。

## 轴一 · 境界（9 档）

| `realm_id` | 境界 | 说明 |
|---|---|---|
| 0 | **凡** | 凡人。无灵根者、普通野兽、未被灵气改造的物质 |
| 1 | 炼气 | 玩家起点 |
| 2 | 筑基 | |
| 3 | 金丹 | |
| 4 | 元婴 | |
| 5 | 化神 | |
| 6 | 炼虚 | |
| 7 | 合体 | |
| 8 | 大乘 | 人间界顶点 |

**凡（0）是一个真实的存在状态，不是"还没开始"。** 没有灵根的凡人不是修为为零的修士——灵气经过他的身体像风吹过石头，不会被留下。所以凡阶物品不是"最低级的修士装备"，而是**根本不为修士设计的东西**：凡铁、凡木、凡草。它们对玩家的意义是炼制原料的输入端，不是可穿戴物。

**渡劫不是境界。** 渡劫是大乘圆满之后引动九重仙劫的特殊阶段，是一个事件不是一个台阶。飞升亦然。人间界的境界到大乘为止。

**妖兽阶位与境界的对应**——妖兽沿用传统的"一阶到九阶"读法，注意它比 `realm_id` 大 1：

## 轴二 · 品质（6 档）

品质轴衡量**一件存在能够稳定承载并显现多深的原初力量与规则**。秩序侧越高越接近原初秩序，魔侧越高越接近原初混沌；同一品质只表示所达深度相近，不表示性质相同或能够互相替换。结构自洽程度、力量承载、信息复杂度、规则深度，是判断品质的四个观察角度，不是四条数值轴。这不是拍脑袋的强度标签，是从第一因推出来的。（2026-08-04 更新：原表述"距离源头的远近"扩写为可容纳秩序、混沌两侧的总定义，全物品统一适用——高阶魔族器物可能更接近原初混沌，却依然有极高的结构层次与规则深度。）

| `quality` | 品质 | 色 | 内在含义 |
|---|---|---|---|
| 1 | **凡品** | 白 | 未被灵气改造，或改造极浅 |
| 2 | **灵品** | 绿 | 被格式化灵气充分梳理，正式进入修真体系 |
| 3 | **玄品** | 蓝 | 灵气结构复杂到超出常规功法理解 |
| 4 | **仙品** | 紫 | 接近飞升者层级的秩序密度 |
| 5 | **神品** | 橙 | 神魔大战级别的遗留，人间已不可再造 |
| 6 | **道品** | 红 | 触及原初秩序本身，唯一、不可复制 |

**"稀有度"这条轴已删除。** 原先的"普通/稀有/史诗/传说"与品质是同一个概念的两种说法，全项目统一称**品质**，不再出现"稀有度"字样，也不再使用"史诗""传说"这类词。

**"下品/中品/上品/极品"作废**，灵石改挂上表六品质。

## 命名格式

**「境界 · 品质 · 名称」**，口语可省境界或品质：

- `筑基 · 玄品 · 聚气丹`，口语"玄品筑基丹"
- `金丹 · 仙品 · 青冥剑`
- `凡 · 道品 · 三月草`

## 两轴各管什么

| | 境界轴管 | 品质轴管 |
|---|---|---|
| **丹药** | 服务哪个境界（筑基丹=筑基阶）| 药效强度 + **丹毒量**（凡品丹毒最高，道品几乎无毒）|
| **灵植** | 药效对应境界 | **年份**（详见 §八）|
| **妖兽** | 阶位 | **精英/词缀等级**——高品质＝同阶中的异种 |
| **装备/器物** | 境界淘汰位 | 六档品质（凡·灵·玄·仙·神·道）。**注：2026-08-04 起"凡器/法器/灵器/法宝/本命法宝/道器"六级梯子废除——品质与"装备/器具/法宝/道器"等身份分开，详见文末《器物·装备·器具·法宝》章** |
| **灵石** | 无境界轴 | 灵气压缩密度＝瞬时功率 |
| **魔化材料** | 9 档 | 6 档（"魔化"是来源标签，不占轴）|
| **器纹/词条** | 跟随所附着的物品 | 6 档，**独立于物品本身的品质**——神品装备也可能只出灵品词条 |

## 由双轴推出的三条设定结论

**一、捡漏机制有了物质法则层面的成因。** 两轴正交意味着可以存在「**凡阶 · 道品**」——一株只有一年份的凡草，因为长在仙路断裂处吸过原初秩序，它是道品。摊主看它是凡阶，两块灵品灵石挂出去；识货的人捡漏。万宝坊市"摊主走眼"的核心玩法不再靠随机数硬凑。

**二、词缀怪不是独立机制。** 精英怪就是"高品质的同阶妖兽"，掉落自动跟着品质走。一套规则覆盖怪物与掉落两个系统。

**三、词条与物品各自挂品质。** 器纹是材料淬炼时环境微差的自然外显（见 §十二），因此同一件装备上每条器纹的品质可以各不相同，也与装备整体品质无关。一件神品装备可能只 roll 出灵品词条，一件玄品装备也可能撞出一条道品词条——这是刷宝深度的来源。

**四、认主有了物理门槛。** 只有神品（橙）以上的胚子才撑得住真元共振，因此才能祭炼成本命法宝——低品法宝在物理上无法绑定。（2026-08-04 更新：祭炼、绑定、择主、本命共生的口径已细分，见 §十二 与文末《器物·装备·器具·法宝》章；此处"无法绑定"特指本命共生级的跨境界绑定。）

# 三、四种气

所有物质法则都必须先区分四种气。

| 气 | 来源 | 性质 | 修士关系 | 当前存在位置 |
|---|---|---|---|---|
| **原初秩序** | 大轮回吸气时自然凝聚 | 庞大、无方向、携带源头完整信息。未经任何处理 | 极难承载——修士丹田经脉是为天界格式化后的灵气设计的，原初秩序没有"经脉路径"这个概念，强行吸收会经脉紊乱。但一旦建立起新的承载结构，可开辟天界功法之外的全新修炼路径 | 天界大阵盲区、古战场深处、仙路断裂处、封禁洞府、部分蓝门秘境 |
| **原初混沌** | 大轮回呼气时自然解散 | 中性、流动、负责解构与回收。它不是邪暗属性，而是自然回收力 | 与修士秩序结构冲突。它不攻击秩序，但它流过秩序结构时会叫秩序回归自然循环——对修士等同"被解散" | 魔界极深处、未完全怨化区域、天界控制盲区 |
| **灵气** | 原初秩序被天界大阵格式化 | 有方向、有节奏、易吸收、稳定。格式化屏蔽了源头信息——修士吸收时不接收大轮回信号 | 修士日常修炼版本。稳定、可控、可预测。但上限被天界预设路径锁定 | 天界大阵覆盖区域 |
| **魔气** | 原初混沌被封印、压缩、怨恨浸染后的变质形态 | 高能量但紊乱、侵蚀、异化、怨化 | 正常修士直接吸收会严重损毁经脉。极少数魔修以特殊功法在体内建立隔离结构微量利用，每次都是风险 | 魔界裂隙、魔化区域、古战场污染层 |

这个区分不能混：

- 原初秩序不是灵气。灵气是它被天界大阵处理后的版本。
- 原初混沌不是魔气。魔气是它被封印怨化后的污染版本。
- 灵气不是绝对自然。它是稳定、好用、可修炼，但已经被编辑过。
- 魔气不是"邪恶灵气"。它是怨化混沌在人间界的泄漏形态。

# 四、日月、阴阳与浊气

人间界的修炼节律来自灵气在不同时间、不同环境下的流态变化。

**日灵气**是白昼中更偏向生长、外放、升腾的灵气流。它不是太阳凭空创造的另一种能量，而是天界大阵与天地节律共同作用下，灵气呈现出的白昼形态。它适合灵植生长、血肉活化、火性功法、外放法术。

**月灵气**是夜晚中更偏向凝聚、内敛、沉降的灵气流。月夜并不低级，也不是"不纯"。它适合妖类吐纳、草木凝药、神识沉淀、内修打坐。很多灵植在夜间药力回流，很多妖兽在夜晚更活跃，都是因为月灵气更适合它们的内部循环。

**浊气**不是魔气。浊气是白日过盛、地热上升、尘土、焦燥、杂乱灵流混在一起形成的燥烈之气。它带有混乱倾向，但还没有变成魔气。普通修士不喜欢浊气，因为它会让灵气不顺、心绪躁动、修炼效率下降。

魔族和魔化生物更喜欢浊气环境。原因不是"浊气等于魔气"，而是浊气更容易被魔界裂隙中的魔气引动、扭曲、转化。浊气像干柴，魔气像火星。没有裂隙时，它只是燥乱；有裂隙时，它会加速魔化。

因此，人间界一天的节律可以这样理解：

| 时段 | 灵气状态 | 适合行为 |
|---|---|---|
| 清晨 | 阴阳交替，灵气清明，日灵气初生而月灵气未散 | 打坐、吐纳、采集叶花类灵植 |
| 正午 | 日灵气最盛，但浊气上升 | 外出办事、火性炼制、部分阳性材料处理 |
| 傍晚 | 日灵气回落，灵植药力开始归根 | 采集果实、整理材料、回洞府 |
| 夜间 | 月灵气主导，灵气内敛，妖兽与草木更活跃 | 妖兽刷新、特殊灵植开花、神识修炼 |
| 深夜 | 魔气更容易从裂隙边缘渗出，风险收益升高 | 稀有怪、蓝门秘境、魔化事件 |

这解释了为什么修士清晨修炼、白天刷怪办事、夜里风险更高但产出更好。

# 五、五行与物质结构

五行不是五种化学元素。五行是灵气被梳理后呈现出的五种运动形态。

| 五行 | 灵气形态 | 物质表现 |
|---|---|---|
| **金** | 锐利、收束、切割、集中 | 矿脉、金铁、爪牙、锋锐器物 |
| **木** | 生长、舒展、延伸、复苏 | 古林、藤蔓、灵植、草木精怪 |
| **水** | 流动、渗透、沉降、润化 | 寒潭、泉水、血液、解毒清心类材料 |
| **火** | 爆发、交换、升腾、破膜 | 丹火、器火、火山、火候药引 |
| **土** | 承载、凝聚、稳定、厚重 | 山体、灵脉、根茎、骨骼、防御材料 |

五行生克，是这些灵气形态之间的相互转化和相互妨碍。生克不是绝对胜负——境界、灵气密度、功法理解、材料品质都能压过五行关系。五行只解释"同层级下为什么更顺或更冲"。

**灵根**决定修士更容易读懂哪一种五行灵气。单灵根适配度高，读一种秩序极快；多灵根适配面广，但每一种都慢。异灵根可以理解为对某种复合流态特别敏感——风、雷、冰这类不是基础五行，而是五行在特定节律下的复合形态。

# 六、修士身体观

修士的身体不是普通肉身加一条蓝条。它是一套用来接收、压缩、理解、调用灵气的秩序结构。

## 灵根

灵根决定修士能更顺利地解开哪一种五行灵气的"锁"。**〔灵根归属·待确认〕** 建议口径（两段式）：灵魂携带先天的**倾向**，肉身提供**土壤**，两者在灵魂依附肉身时于交界处**定型为灵根**——转世换体后灵根会依新土壤重新定型，但常带前世倾向的影子（这也解释了道痕残留）；夺舍默认得新体之灵根；元神极强者能携旧规格重塑新体，是高阶特例而非默认。（原表述"灵魂中自带的天然秩序框架"与概念归位处"灵魂与肉身交界处的规格"不完全一致，二者的统一待 thoth 拍板。）

没有灵根的凡人不是完全没有灵气，而是无法识别灵气的结构。灵气经过身体，也只是像风吹过石头，不会被留下。

## 经脉

经脉是灵气在体内流动的能量通道，不是血管，也不是神经。

小境界突破时，经脉会扩宽、加固、分支增多。单位时间内能通过的灵气越多，修士法力恢复越快，施法承载越强。这就是"经脉拓宽，法力如河"的物质来源。

## 丹田

丹田是灵气压缩仓。

天地灵气是天界大阵格式化后的稀薄气体形态，不能直接拿来施法。丹田把它压缩成液态灵气（灵液），再压缩成固态（金丹），让能量密度提高到足以外放的程度。丹田的容量决定了法力池——它是境界基数的物理载体。

## 淬体

淬体不是"加血条"——它是物质载体的秩序密度。

身体和灵脉同源。灵脉是大地被灵气长期冲刷形成的天然通道；经脉、丹田、血肉则是人体被灵气长期梳理形成的微观通道。淬体的本质，是提高这套物质结构的秩序密度与承载上限。

虎骨藤、铁线草、龙血苔一类淬体药材不凭空添加力量——它们提供外来的秩序模板，让身体按更致密的模式重组。

承载力决定一个修士能容纳多高密度的灵气。承载不足而强行拔高境界，经脉无法容纳跃升的灵气密度，结构崩解——这是"爆体"的物理含义。不是数值惩罚，是物理必然。

淬体药材与补气药材、凝神药材并列，构成修炼三大物质支柱：补气填灵力、淬体扩承载力、凝神提精度。（"淬体"一词两义、沿用不改：作名词，指肉身承载基础及其淬炼程度；作动词，指强化这一基础的过程。）

## 神识

神识是灵魂向外的读写接口。它不是"我"——它是"我"用来感知和操控灵气的手和眼。

若灵气是能量与信息的合流，神识就是读写这段信息的器官。它的来源不神秘：意识本是秩序与混沌涌现的结果，神识是这一自然意识经修炼强化后的形态。

**读**——感知灵气中的信息。妖兽移动会扰动周围灵气；秘境入口会让空间灵气出现不自然流向；天界大阵盲区中的原初秩序，会让高阶修士感到"这里不对"。

**写**——引导灵气流向并使其精细成形。运转功法、控制丹火、编织阵法，都是神识在"写"。灵气的操作分两级：粗放级靠身体与火候，借灵气自身的秩序/混沌特性来引导（如河道、堤坝顺水性导水）；精细级靠神识，主动操控灵气结构。

化神以后，修士开始感到某些灵气流"不自然"。

# 七、灵气如何孕育物质

灵气不创造新物质。灵气重排已有物质。就像一个编辑按照固定的模板把一篇文章重新排版——不是改变元素种类，是改变排列方式。

## 灵脉

灵脉是地层中稳定流动的灵气通道。它既是自然地理，也是天界大阵的物质骨架之一。

一条灵脉经过山体，山中矿石会变成灵矿；经过林地，草木会变成灵植；经过兽巢，野兽会长期受灵气改造，逐渐变成妖兽。

## 灵石

灵石是灵气在地层中长期凝结后的晶体。它不是普通石头里"塞了能量"，而是整块石头被灵气格式化成特殊晶体结构——类似于空气中的水蒸气遇到冷面变成水。

灵石只挂品质轴，不挂境界轴——它是货币与能源，不服务于某个特定境界。品质越高，灵气压缩程度越高，而压缩度决定两件事：**总量**（面额）与**瞬时功率**（单位时间能释放多少灵气）。

第二条才是关键：高阶阵法、高阶丹炉需要的不是"更多灵气"，而是"单位时间输入更多灵气"。低品灵石堆再多，释放速率上不去——一万节干电池推不动电磁炮。**这是数量无法替代品质的物理原因，也是高阶内容对灵石设品质门槛而非数量门槛的依据。**

| 品质 | 物质表现 |
|---|---|
| 凡品 | 结构松散，杂质多，凡人也能拿在手里，修士视作零钱 |
| 灵品 | 结构成型，适合日常消耗 |
| 玄品 | 内部出现稳定纹路，适合阵法与炼制 |
| 仙品 | 内部灵气流转清晰，适合高阶修炼与高阶阵法 |
| 神品 | 接近固态灵气核心，可作稀有炼制材料，坊市硬通货 |
| 道品 | **结晶化的原初秩序**——未被天界大阵格式化过。价值最高，但常规修士的经脉是为格式化灵气设计的，直接吸收会经脉紊乱。它只对接触原初秩序的上古路线有意义 |

道品灵石是一个刻意设置的悖论物：全世界最值钱、同时对绝大多数修士毫无用处。它是原初秩序修炼路线的入口物品。

# 八、灵植体系

灵植不是"草药加灵气"。灵植是一套活的灵气循环系统。

一株普通草木如果长期生长在灵脉附近，体内会逐渐形成类似经脉的灵气回路。根负责吸收地气和水气，茎负责输送，叶吸收日灵气，花果在月灵气中凝聚药力。同样的遗传密码，灵气充足时表现为灵植，灵气不足时表现为普通植物——灵气把植物基因的潜在表达方向重新编排了。

|---|---|---|
| 子时 | 药力向根部沉积，土气与水气最重 | 适合采根、采茎，偏固本培元 |

| 酉时 | 药力回流至果实与根部 | 适合采果、种子、凝聚类药材 |
| 月夜 | 月灵气沉静，花与果凝药 | 适合凝神、神识、阴性灵植 |

采集就是打破这个循环。卯时采叶——叶子里的灵气正在处理白日信号，药性偏向发散。子时采根——根部灵气正在吸收土的凝聚信息，药性偏向沉积。采集时断根须——不是断一个物理连接，是断了一条灵气通路。就像人类经脉断裂——灵气从断口流失，整个循环失衡，药力流失。这就是采参必须保根须的本质——不是玄学，是灵植内部灵气循环的物理机制。

# 九、妖兽、精怪与气灵

妖兽不是天生怪物。妖兽是动物长期受灵气改造后的结果。

一个普通山狐、黑熊、蛇蟒，如果世代生活在灵脉附近，血肉、骨骼、神经都会被灵气重排。一只野狼在灵气泄漏点旁生活了几年，灵气浸入肌肉纤维、骨骼、神经系统——肌肉更密更强、骨骼轻而刚、神经传导更快。久而久之，身体更强，寿命更长，灵气在体内沉淀成妖丹。妖丹不是狼刻意修炼出来的——是灵气被它的体温、心跳、猎杀、进食这些生命活动自然加工后沉淀在体内，年深日久形成了凝结物。

| **兽魂** | 高阶妖兽意识残留 | 肉体死亡后短暂保留的神识结构——不是灵魂，是意识在肉体死亡后短暂的残留 | 法宝祭炼、器灵前身、灵兽培养 |
| **灵髓** | 骨髓深处 | 妖兽体内灵气密度最高部位之一 | 洗髓、突破、高阶炼制 |

## 妖兽阶位

妖兽阶位可以与修士境界对应，但不是完全同一条路。**一阶是普通野兽，不是妖兽**——妖丹从二阶才开始出现，这条分界线正好卡在"凡兽→妖兽"上。

| 妖兽阶位 | `realm_id` | 对应修士境界 | 特征 |

| 三阶 | 2 | 筑基 | 初成妖丹，灵气护体 |
| 四阶 | 3 | 金丹 | 完整妖丹，肉身坚固 |
| 五阶 | 4 | 元婴 | 妖丹含魂，可用本命神通 |
| 六阶 | 5 | 化神 | 灵智成熟，可通人言 |

这意味着"词缀怪"不是一套独立机制，而是品质轴在怪物身上的表现。

# 十、魔化生物与魔核

魔化不是"妖兽变坏"。魔化是魔气侵入已有生命结构后，对其秩序进行扭曲。

魔化生物分两类：

| 类型 | 说明 |
|---|---|
| **魔化生物** | 原本人间界生物，被魔气污染后异变 |
| **魔界原生生物** | 从魔界裂隙中进入人间界的生物，结构本就不适合人间秩序 |

魔化妖兽不再按原本生物本能行动。它们更少恐惧，更少休息，更容易被魔气区域吸引。不是因为它们"邪恶"，而是原本生命结构中维持平衡的部分被魔气打乱。

**魔核不是妖丹染黑。** 魔核是魔气在生物体内形成或重构出的混乱核心。它能量高，但信息难以读懂。正常修士不能直接炼化。炼器师、魔修、屠魔录奖励体系可以利用它的高能量，但风险很高。

魔化灵植也是同理：原本灵气循环被魔气打断后自行重组，形成能量高、药性怪、炼丹失败率高但效果特殊的材料。

# 十一、炼丹：秩序的重组

炼丹不是化学反应。炼丹是把不同材料中已经整理好的灵气结构拆开、调和、重组。

火候不是单纯加热。火候是用火性灵气的高频交换打破材料外层灵气膜，让君药、臣药、佐药、使药之间重新配对。火候本身是由火属性灵气在炉内的高频流动产生的——火的灵气是五种方向中边界最模糊的一种，它不是烧，是高频的能量交换。

## 君臣佐使

项目中可称"君臣佐辅"，但底层角色按"君臣佐使"理解。

| 角色 | 作用 | 说明 |
|---|---|---|
| **君药** | 决定核心作用方向 | 君药的灵气结构是整颗丹的"主旋律"。修为丹用补气类，突破丹用破境主药 |
| **臣药** | 放大君药效果 | 与君药药性互补，不可强冲 |
| **佐药** | 抑制副作用、吸收混乱残留 | 丹毒防线——佐药的灵气循环像海绵一样吸收混乱碎片 |
| **使药** | 引导药力入对应经脉 | 酸苦甘辛咸决定药力先入哪条五行经脉 |

没有使药的配方也能炼——只是药力进体后没有引导方向，被经脉自然分流，损失约两成药力。

## 丹药分类

| 类型 | 主材料 | 作用 |
|---|---|---|
| **修为丹** | 补气类 | 直接增加修为 |
| **突破丹** | 破境主药 + 辅材 + 灵石 | 辅助大境界突破 |
| **属性丹** | 淬体、凝神类 | 永久增加某类属性 |
| **战斗丹** | 混合配方 | 临时爆发、抗性、续航 |
| **解毒丹** | 解毒清心类 | 清丹毒、抗魔气污染 |
| **洗髓丹** | 洗髓类 | 改善资质、辅助灵根方向 |
| **疗伤丹** | 补气、淬体、清心混合 | 快速恢复战斗损伤 |

## 丹毒

丹毒分三层理解。

第一层，是药渣、杂质、火候不均导致的残留。低阶炼丹师常见。

第二层，也是更深层——炼丹时，四性五味的灵气结构被火候强行撮合的过程中，总有一部分灵气结构在打破外膜之后找不到合适的"配对"，变成了无方向的小碎片。这些小碎片本质上是被火的高频能量打成混沌的状态。它们在药液中被使药引导入经脉后，因为没有方向，便附着在经脉壁上——金丹以下修士的丹田压缩能力不足以把它们压出去，它们一直在那，慢慢堆、慢慢堵着灵气通道。

这就是为什么高阶修士也无法完全避免丹毒。原因不是炼丹技术永远不够，而是火候本身就处在秩序与混乱的边界。火太弱，结构不破；火太强，结构碎散。只要用火重组灵气，就一定会有边缘碎片——打散的速度和重新配对的速度不可能完全同步，总有边缘的那部分被打成了混沌碎片。

**第三层——神识精度决定源头**。火候打破材料外膜后，碎片需重新秩序化配对。神识精度不足→秩序化不彻底→残留未被秩序化的混沌碎片=丹毒。这意味着：同一份材料、同一个丹方，神识更强的修士炼出的丹毒更低。这解释了"为何高阶修士丹毒少"——不是因为火候技术更好（那只能改善第一层），而是因为神识精度足够在碎片配对阶段就减少混沌残留。

三道工序各归其位：**神识**管源头（产生多少混沌碎片）、**佐药**管中段吸收（海绵吸水）、**丹田**管末端排出（压缩力）。三者协同决定一颗丹的最终丹毒量。

丹毒会随时间缓慢排出——修士的经脉自身有缓慢清理的能力。但吃丹速度远大于排出速度——这就是每日丹药上限的物质法则解释：不是暴雪暴血，是循序渐进的堵塞累积。

## 丹药的两条轴

丹药同样挂双轴。**境界轴决定这颗丹给谁吃**（筑基丹给筑基修士），**品质轴决定它多好、丹毒多重**。

| 品质 | 丹毒量 | 炼制难度 | 定位 |
|---|---|---|---|
| 凡品 | 最高 | 入门 | 自动炼丹产出——日常修为丹 |
| 灵品 | 高 | 容易 | 日常消耗 |
| 玄品 | 中等 | 中等 | **坊市流通起点** |
| 仙品 | 较低 | 高 | **拍卖行级别** |
| 神品 | 很低 | 极高 | **全服播报**——年产量不过个位数 |
| 道品 | 极低，但不等于绝对无 | 极限 | 传说级——需接触过原初秩序的材料或环境 |

> 倍率示意，具体以数值表为准。品质是纵向飞跃点：凡品到灵品是日常消耗；玄品进入坊市；仙品上拍卖行；神品全服播报——传闻神品筑基丹能让筑基修士瞬间体质跃迁，但整个岱舆洲百年也出不了几颗。

丹毒随品质递减的原因见上文丹毒三层模型：**神识精度管源头**（产生多少混沌碎片）、**佐药管中段**（吸收）、**丹田管末端**（排出）。品质高的丹药，是这三道工序都做到位的结果，不是单纯"火候好"。

# 十二、炼器、法宝与道器

> **【2026-08-04 更新】** 本章原文描述的炼制物理（凡器→法器→灵器怎么炼、器纹如何自然外显、器灵如何涌现）仍然有效，予以保留。但"六级＝装备品质梯子"这一框架已废除，改为**器物·装备·器具·法宝**的身份体系——品质（凡灵玄仙神道六档）与身份（装备／器具／法宝／有灵法宝／本命法宝／道器）分开。完整新口径见**文末《器物·装备·器具·法宝》章**；本章下文冲突处已就地标注。

区别在于：
- 炼丹重组的是药力结构，最后进入身体。
- 炼器重组的是物质结构，最后成为外物。

**凡器**——把普通材料（玄铁、灵木）放进炼器炉，用已经格式化好的灵气驱动炉中火气，让灵气渗透入材料的晶体结构。灵气不是给材料"充能"——是在重新排列材料的内部原子。玄铁→灵铁：同样的铁元素，不同的排列方式，更密的晶体，更硬的刃。

**法器**——用更高密度的格式化灵气把材料晶体结构推到更紧密的状态。金丹期修士驱动炉火时，炉内灵气密度是普通丹炉的数十倍。

**灵器**——最紧实状态。材料的晶体排列被压缩到几乎无法再压缩的极限——这时材料表面会出现纹路。不是工匠刻的，是材料本身在极致的灵气淬炼下，内部晶体排列的自然外显。这些纹路就是"器纹"或"灵纹"——普通装备的词条来源。

**法宝**——不是炼出来的，是养出来的。炼器师打造一个"胚子"——一枚接近最紧实状态但没有完全压死的灵器。然后修士用自己的灵力、精血、甚至一丝真元来祭炼它。祭炼的过程不是"加属性"，是**修士自己的灵气开始和胚子内部的灵气共振**。共振久了，胚子内部形成了和修士经脉同步的微型灵气循环。这件法宝在别人手里只是一块死铁——因为别人没有同一个频率的灵气来驱动。这就是认主的物理本质：材料内部的灵气循环结构和主人的经脉灵气形成了同步共振。

**本命法宝**——极少数法宝在主人突破时会被主人的境界跃迁带动。主人丹田扩大、经脉加宽、灵气密度跃升，这股跃迁的能量顺着血脉冲击法宝。如果法宝的材料结构承受住了——它就跟着升级了。不是自己升级，是被主人的跃迁推着升。这就是本命法宝跨境界成长的物理机制。单角色限制1-2件——因为和法宝保持共振需要消耗真元，大多数修士的真元撑不住同时维持两个以上的共振。

**道器 / 道器碎片**——不按普通炼器逻辑复制。道器更接近上古特殊秩序残留：上古法宝、阵法核心、古修道痕、上古秩序结构碎片、神魔大战残留结构，在特殊条件下被保留下来，成为独一无二的生涯级奇物。道器之所以不可交易、不可复制，是因为它不是单纯物质，而是一段特定秩序信息与持有者灵魂结构产生的共振。

## 器纹与词条

灵器表面的纹路不是工匠随手刻上去的装饰，而是材料内部被灵气重排到极致后，自然外显出的结构差异。

每块材料接受灵气淬炼时的温度、湿度、灵气浓度、五行偏向、炉火节奏都有微差。这些微差会变成不同器纹——也就是装备词条、小极品、特殊属性的世界观来源。不是工匠赋予的，是灵气淬炼的过程中自然的差异。

## 器灵

当法宝内部灵气循环复杂到临界点，意识会涌现。

这和生灵、精怪的诞生逻辑一致：秩序结构复杂到一定程度，便可能"知道自己在"。器灵不是被塞进去的魂魄——是器物秩序自己活了。

最古老的器灵是某个上古修士的本命法宝。主人陨落后，法宝没有碎（材料够强），继续在炉子旁吸收炉灰中残余的灵气。千年后它醒了——自己会选下一任主人了。这就是器灵：是精怪（草木玉石修行成灵）的金属版本——都是在足够复杂的灵气结构里涌现出的意识。

兽魂可以作为器灵前身，因为兽魂本身就是高阶妖兽死后短暂保留的神识结构。把它炼入法宝，相当于给器物意识提供一个种子，但最终能不能长成器灵，仍取决于法宝自身结构。

# 十三、符箓与阵法

符箓和阵法的底层是同一件事：**把灵气结构固定在载体上。**

区别在于：
- 符箓把结构固定在纸、兽皮、玉片等小载体上。
- 阵法把结构固定在空间里。

## 符箓

正常施法需要修士临时调用法力、构建灵气结构、释放效果。符箓把"构建灵气结构"这一步提前完成——使用时只需要输入少量法力触发，符纸上的结构就一次性释放。

符纸用灵木压制——灵木的优势在于它作为活过的植物，材料内部曾经有过灵气循环的"轨迹"，类似刻录机中预格式化的光盘，比普通纸更适合承载灵气结构。符墨用妖血+灵墨——妖血携带妖兽体内的灵气"解读成果"（和妖丹一样），比人类血液更适合穿透符纸的纤维结构。画符需要集中神识——在描的同时把神识中已经构建好的法术结构"投射"到纸上。

符箓是一次性消耗品——你能连丢三张，但每一张需要独立的绘制、独立的材料、独立的时间。释放时载体上的灵气结构被完整解放，符纸自身也被破坏。

## 阵法

阵法是空间化的符箓。阵旗是锚点，阵盘是中枢，灵石是持续供能。阵法把一片空间中的灵气强制定型，使其形成固定功能。

| 阵法 | 物质机制 | 用途 |
|---|---|---|
| **聚灵阵** | 把周围灵气排列成向中心汇聚的漏斗结构——漏斗口朝外，底朝内，灵气自然向低密度区流动 | 洞府修炼、灵植种植 |
| **护府阵** | 在边界形成灵气膜，外物进入时触发扰动 | 洞府警戒、防御 |
| **困阵** | 提高局部灵气密度，让目标体内灵气与外界互斥——不是物理屏障，是灵气密度高到人体穿过时自身灵气和外界严重对立导致僵直 | 定身、减速、控怪 |
| **陷阱阵** | 预存灵气结构，目标触发后一次性释放 | 偷渡、高级区猎杀 |
| **迷阵** | 制造细微灵气错位，干扰神识与方向感 | 降低仇恨、隐藏路线 |
| **古传送阵** | 以特定灵气波动解锁空间结构——本质是禁制的解码器 | 秘境、蓝门、古洞府 |
| **禁制阵法** | 将空间、门、宝箱、洞府入口进行灵气加锁 | 遗迹机关 |

符箓可以理解成微型阵法，阵法可以理解成展开在空间里的符箓。

## 天然阵势与拓印（2026-08-04 补）

前文的阵法都是修士**布设**的——阵旗为锚点、阵盘为中枢、灵石供能。但也存在**无人布设而自行定型**的灵气结构，人间修士称之为**天然阵势**。

它的真实成因有两种：一是灵脉走向、地势与灵气流动长期作用后自然凝成；二是上古工程、古阵或大战结构的残留，因来历被岁月磨去而被现代修士误认成"天然"。所以"天然"是人间的认识分类，未必是终极意义上的无人设计——这与器灵"器物秩序自己活了"是同一种句式。

天然阵势的本体存在于特定地点，**不能直接携走**。修士以神识读取、以特殊材料**拓印**，将其中一段稳定结构凝入阵印、阵图等小型载体。拓印不是搬走或完整复制原阵，而是截取并保存其中一部分规则——拓印物可随身生效，原阵仍留原地。

# 十四、魔化材料与风险利用

> **【2026-08-04 补】** 与"魔"相关之物分三类，不得混称（总规则见《第一因》§六·补）：**魔化之物**——原有结构被魔气侵入扭曲重组（含魔化生灵、魔化灵植、魔化矿物、魔化材料）；**魔界原生之物**——在魔界环境中自然生成、结构从一开始就适应魔气，不经历"被魔化"；**魔道造物**——以魔气和魔道方法主动培育、炼制、构筑者，再分魔族造物与人间魔修造物。下文的魔核、魔晶、魔骨、魔化灵植按此三分各自归位（如魔核出自魔界原生之兽，则属魔界原生之物而非魔化之物）。

魔化材料不是废料。它是高能、混乱、难以控制的材料。

**"魔化"是来源标签，不占轴。** 魔化材料同样挂完整的九境界 × 六品质——存在凡阶凡品的魔化材料，也存在大乘阶道品的魔化材料。它与正常材料的区别不在等级高低，而在于灵气结构的方向：正常材料越往上越接近原初秩序，魔化材料越往上越接近**原初混沌**。两者在品质轴上并行，不互相换算。

# 十八、器物·装备·器具·法宝（2026-08-04 补）

> 本章取代原 §十二"器物六层＝装备品质梯"的框架。§十二 的炼制物理仍有效，此处只重立身份体系。

**总纲**：器物是总称；**装备借人而运，器具借外而用，法宝自成其法**。法宝可以具有装备形制，但只有接入神识后才开启法宝能力；能否装备看形制与肉身接口，是不是法宝看它有没有独立运行结构。

**器物**——一切经过炼制或自然形成、具有稳定结构与用途之物。边界：以稳定存续、可反复使用为要；以自身耗散换取效果者（丹药、一次性符箓）不入器物，可反复使用的阵旗、阵盘、丹炉归器具。炼器是生产和改造一切器物的学问，产出统称炼器造物。

**三种身份**：
- **装备**：穿戴或持用、以肉身经脉灵力为运行核心之物，是身体的延伸。可有极高品质、道纹、词条与装备神通（主要在修士体内完成，由装备增幅、转化、释放）；有神通不能用来判定它是法宝。
- **器具**：借使用者操作、外部供能或材料本性发挥作用之物——丹炉、普通阵盘、储物器、测灵器、生产工具。
- **法宝**：自身形成完整独立运行结构之物——有自己的灵气循环与神通结构，修士以神识连接、唤醒、控制。不要求必有器灵，不要求会飞。
- **形制不决定身份**：只有被纳入既定装备部位、并以肉身为运行核心的器物才具装备身份；仅被拿着、挂着、戴着不自动成为装备——储物戒戴在手上仍是器具。

**装备与法宝的关系**：法宝是器物本身的结构身份，装备是当前接入肉身的使用方式。故有普通装备、不可装备法宝（印钟镜壶塔等无对应装备部位者）、可装备法宝（剑冠法袍鞋履佩饰等）三种。可装备法宝：未建神识连接时只作装备（发挥材质、品质、道纹、词条，不占神识，法宝神通不启动），建立连接后法宝神通唤醒、占神识、若仍穿戴则装备作用保留——**穿戴效果是否生效，看它当下是否仍接入肉身**；同一件不得在装备与法宝两边重复计算。

**两种神通的判据**：看神通在哪里完成。装备神通借穿戴者肉身完成、脱离即不能独立施展；法宝神通主要在法宝自身结构中运行，修士以神识唤醒、维持控制。

**品质与身份分开**：品质仍是凡·灵·玄·仙·神·道六档（总定义见 §二）；身份是装备／器具／法宝／有灵法宝／本命法宝／道器。正式表达如"玄品装备""仙品法宝""仙品有灵法宝""神品本命法宝""道品道器"。**"凡器/法器/灵器"三词退役**，"法宝"只保留身份义。法宝不设绝对最低品质——结构门槛、品质软底：自持循环对结构有最低要求，品质越低越难成、成了也不稳、易崩散，成熟稳定的法宝通常见于仙品以上。

**有灵法宝 / 本命法宝 / 道器**：
- 有灵法宝——已孕育器灵的法宝（"有灵"专指器灵已成；只有亲疏反应、祭炼反馈的称"具有灵性"）。
- 本命法宝——与主人建立本命共生后的关系身份，不是天然品质；通常需足够高的品质与承载。
- 道器——承载成段独一规则、并能以此介入持有者命途或成长路径的特殊身份；通常达道品，但道品不自动等于道器；可有灵可无灵、可有装备形制可不可装备。道器的核心规则不完全来自天界格式化后的修行体系，因此不能被天界既有道路完全解释和约束，可绕过、抵抗或扰动天界体系，但不等于对天界绝对免疫。

**灵性·意识·器灵**：灵性（对力量与使用者有稳定适配差异，无自我）→意识（感知外界、知道自己存在）→器灵（意识获连续性、自举成独立的"我"）。器灵真正成"我"即属生灵、有灵魂：有灵法宝是双重身份——**器物为身，器灵为生灵**，故不仅可祭炼与拥有，也可以收服、交流、相处。器灵自主护主、拒绝或擅自行动，是它自己的行为，耗法宝自身力量，不要求主人持续以神识操控。

**祭炼·绑定·择主·本命共生**：祭炼是过程（灵力精血长期浸润）；绑定是结构专属共振（无意识之物也可绑定）；择主是有意识、有器灵之物的主动认可；本命共生是与真元、道基相连、随主跨境界成长的关系——结契以真元为引，共振扎根于道基，日常维系不以真元为燃料，最早始于金丹以后。"法宝是养出来的"正解：器身可炼、法宝结构可祭炼，灵性、器灵和本命关系是养出来的。

**神识与法宝**：普通装备不占持续神识；凡由修士唤醒御使的法宝神通须分神识连接照管——每唤醒一件承担一份持续压力，神识越强能同时唤醒御使的越多。"神识增强可御使更多"与"每件被唤醒的都占神识"是同一事实的两个方向。

**来源不改身份品质**：天地自生、人工炼制、魔界原生、魔道造物、遭受魔化是来源或状态，均按品质总定义衡量；魔化装备不自动成为法宝，只有形成独立运行结构后才是法宝；人族连接魔气法宝须隔离或转化。**重新炼制与重新归类**（无"蜕变"机制）：装备或器具经重新炼制、最终形成能自持运行并施展独立神通的内部循环，自完成那一刻起按现状重新认定为法宝——只是跨过定义边界后的重新归类，不保证发生、不预设词条如何继承。**道器与轮回**：本体永续，持有关系一世（身死或轮回即断，须重逢、重识、重建共振）。**名号**：拥有独特来历、独立神通、器灵或重大经历的高阶法宝以专名行世；无器灵而举世唯一的法宝或道器同样可有名号。

# 十九、三才之学（2026-08-04 补 · 文明侧）

> 前十八章讲"世界的物质怎么运行"。以下讲人间修真文明**怎么认识和运用**这套运行——仍是底层设定，不含具体系统。

**世界的三个层面**：世界本体分为天、地、生灵三个层面：天是支配万象的抽象规律；地是规律在物质、环境与万物形质中的显现和承载；生灵是能够感知、抉择并主动作为的存在。（与《第一因》§二"三是天、地、生灵"同一件事。）人间修真文明据此建立**天地人三才之学**，并从自身立场把生灵一层称为"人"——世界本体第三层是生灵，人间研究生灵如何认识、抉择、作为的学问称为**人道**。

**三道之学**：天道之学——参究规律，并循规律修行自身、递进境界；地道之学——格察万物，认识万物之性、加工万物之材；人道之学——研究并实践有意识者如何运用自身与万物（修行实践、抉择、组织、驾驭、创造；个人修行中最直接的表现是神通与技法）。三者**按主要研究的问题区分，不按执行者区分**（人炼丹仍属地道；炼丹者如何抉择、临场操控，则有人道的一面）；**同一主题具有天地人三面，是正常结构**——以剑为例：剑理属天、炼剑养剑属地、剑招御剑属人。

**三类产物**：**功法**——修士把规律整理成可理解、可修习、可反复运用之路；功法属天道之来源，但作用可落在任何领域，其中大部分路是天界一脉走出来铺下的，不是天道自己生出功法。**修真百艺**（简称百艺）——地道认识与改变万物的诸般技艺，泛称不锁门类。**神通**——能够被主动施展或触发的具体能力，可由修士习得、妖兽天生拥有、法宝承载。

**地道七域**正式名：**灵植、灵材、炼丹、炼器、符箓、阵法、御兽**（"丹理""器理"等只作解释原理时的普通表述，不作正式分类名）。

**与三层真相**（宇宙本体／天界工程／人间修真文明）：那是"真相有几层、谁知道多少"，三才是"世界有哪三个层面、文明怎么按它建学问"，两套交叉、不一一对应——人间所见的现象与力量真实存在，但对"天道"的理解与绝大多数可修习的道路已被天界整理、铺设、遮蔽，真实规律并未消失，只是所见并非全貌。**与操作三元**（灵力／淬体／神识，§六）：三元是"人这台机体自身有什么"（结构），三才是"文明怎么把这些认识、加工、运用成能力"（学问），层级不同，不是互斥分类。

# 二十、奇珍与天材地宝（2026-08-04 补 · 文明侧）

**奇珍是什么**：不是装备、器具、法宝那样的结构身份，而是**评价与收录身份**，回答"此物是否罕见、其中是否有道、是否值得收入奇珍录"。两者正交——一件奇珍可以同时是装备、器具、法宝、材料、灵植或传承古物。收录与携带是两件事：收入奇珍录不等于当前正在生效。

- **人间定义**：天地孕育、机缘之下带有一丝道、随身便有奇效的罕见之物。
- **底层真相**：在罕见条件下形成并被稳定保存下来的一段特殊秩序或混沌信息结构，可寄托于物质、传承、痕迹或场域；经对应载体携带在身时持续产生奇效。它可能由天地自然凝成，也可能来自天界工程、古修或当代修士造物、魔族文明、魔化重组以及生命自组织，极少数直通原初。人间无法辨清大多数奇珍的真实成因，故常统称"天地孕育"——现代修士口中的"天生"，很多时候只是"不知道是谁设计和留下的"。

**收录标准（两条）**：**罕见**（当代难以稳定复制或批量取得，不要求绝对唯一）＋**有道**（内部存在能稳定持续、产生特殊作用的秩序或混沌结构）。罕见、有道与品质高低彼此独立——凡品奇珍可以很弱但极特殊，高品质制式物品也可能因能量产而不属于奇珍。

**八类奇珍、八个携带位**（每类一位、每位一件，放入携带位方才生效）：

| 类别 | 对应 | 收录内容 |

| 灵植 | 地道·灵植 | 奇花异草及特殊灵植 |
| 灵材 | 地道·灵材 | 灵矿、灵木、妖丹、精血、兽骨、鳞甲等 |
| 炼丹 | 地道·炼丹 | 奇丹、古丹、天然丹胎、承载特殊丹方的玉简古物 |
| 炼器 | 地道·炼器 | 特殊装备、器具、法宝、古修器物及有灵法宝 |
| 符箓 | 地道·符箓 | 特殊灵符、祖符、符骨、符种等 |
| 阵法 | 地道·阵法 | 阵图、阵心、阵枢、阵印及特殊阵势拓印 |
| 传承〔类名待确认〕 | 天道（功法）与人道（神通） | 功法与神通的玉简、古碑、残页及其他传承古物；普通秘籍不算奇珍，须满足罕见、有道且能携带生效 |
| 道痕 | 天道为主 | 被收取、封存或拓印到载体上的特殊规则痕迹 |

> **〔待确认〕** 第七类名字：thoth 先后有"改名为**传承**、兼收功法与神通传承古物"与"**功法**名称保留"两种指示，此处暂用"传承"，待定。地道御兽域对应**独立的灵兽系统**（收服、培养、驾驭活着的特殊生灵，附属图鉴记录特殊怪物），不设奇珍位。

**携带与标签**：统一用"携带"一词；一切生效奇珍须有可随身的实体载体（传承凭玉简碑片残页；道痕须收取、封存或拓印入道印碎片；阵势须先成阵图、阵心、阵印）；**场域只以本体入录，真正携带的是拓印载体**；灵兽不能被携带。**同一物既是装备又是奇珍**：可同时作装备与奇珍使用，独立效果共存，但同一效果不得重复计算。**标签三组**：形态（物质／传承／痕迹／场域，玩家可见）、来源（玩家可见但为人间说法、不保证正确）、真实成因（仅策划可见）。魔之三物不另设标准，满足罕见、有道即入对应类别。**双轴**：奇珍同挂境界与品质两轴，奇珍身份、罕见程度与品质高低互不替代。

**天材地宝**：与奇珍大体**同物两称**——市井称天材地宝，重罕见、贵重和用途；修士以奇珍录收录，重奇异性质与其中有道。因人间无法辨清真实来源，即使实际来自天界工程、古修造物或失传炼制，也可能被误称为天材地宝。

# 二十一、宗门与堂口（2026-08-04 补 · 文明侧）

**宗门与堂口**：宗门是修士把传承、资源、庇护与争胜组织起来的形态，是人道之学"组织"一面的主要产物。**学问按主要研究的问题分域；宗门按需要长期承担的事务设立堂口。** 地道七域是学问分类，堂口是组织——一个堂可同时调用几个学问域，一个学问域也可由几个堂共同承担。**堂口是能力与学问在宗门组织中的投影；投影可以合并、缺省或分拆，建制因宗而异，不构成天下统一规则。**

**本宗五堂（示例建制）**：

| 堂口 | 主要学问与传承 | 宗门管理职能 |
|---|---|---|
| 丹堂 | 炼丹、灵植 | 药圃、药材培育、丹炉与丹药供给，疗伤、修炼、突破所需丹药 |
| 器堂 | 炼器、灵材，兼符箓制作一侧 | 矿材器材，炼制维护装备器具，制作符纸、符墨及符箓载体 |
| 阵堂 | 阵法，兼符箓结构一侧 | 护宗大阵、禁制、传送阵、洞府阵法，研究符文结构、负责空间防护 |
| 兽堂 | 御兽 | 收服、驯养、培育灵兽，管理兽苑、坐骑、侦察灵兽及危险妖兽 |
| 剑堂 | 人道战修，以剑修传承为核心 | 战备、护卫、巡查、对外征战与战斗训练，本宗主要武力组织 |

五堂只是本宗主要专业组织，不等于宗门全部机构——弟子身份、门规、藏经、传功、财货与总务由掌门、长老会及公共机构统摄。**法修、体修、神通不另设堂**（神通是主动能力统称、不是一门学问；法修体修通用传承由藏经、传功、长老指点承担，可进剑堂承担战事；剑堂成堂靠本宗以剑传家的门风与战斗职能，不是"每个战斗方向都要一堂"）。其他宗门若以法修、体修、符箓立宗，可设法堂、体堂、符堂——建制因宗而异。**符箓**有域无堂：制作归器堂、结构归阵堂。**操作三元**（灵力、淬体、神识）是所有修士必备基础，不设堂，应用散入五堂。

**三个概念分开**：**修士境界**（整体修行层次）、**学问造诣**（某领域学得多深，如炼丹造诣；高阶传承以对应造诣为门槛）、**堂内身份与声望**（组织对其信任、贡献与地位）——三者互不替代（丹堂声望高不代表炼丹造诣高，炼丹造诣深也不必然是丹堂长老）。**无职业之锁**：修士可学多方向、在不同堂口学习办事；灵根只影响学习是否顺畅，不限制能否学习；高阶内容由学问造诣控制，不由出身、灵根或堂口名称锁死。

**类比与真相**：理解性类比（非世界内部正式称谓）——宗门如国，堂口如行当，学问造诣如技艺深浅，堂内身份如组织地位，灵根如天赋之倾。宗门是天界修行道路在人间的重要传播网络，但宗门中的庇护、传承与同门关系都是真实的，被整理和遮蔽的是道路与解释。魔族文明存在自己的组织形态，本轮只立原则，不逐项命名。
