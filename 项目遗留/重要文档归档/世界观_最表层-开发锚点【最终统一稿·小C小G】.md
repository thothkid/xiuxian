## 零、卷首总述

### 【一句话】

这是一个由天界大阵格式化灵气、魔界裂隙泄漏怨化魔气、神魔大战废墟散布其间的修真世界。玩家是边荒小宗门青冥宗的一名外门弟子——刚刚引气入体的那一刻。

### 【玩家第一刻】

你睁开眼，经脉里第一次涌动着灵气的暖流。眼前的世界不一样了——你能"看见"空气中的灵气在流动。师兄递给你一本入门功法，管事登记了你的灵根，给了你一处简陋洞府的钥匙。白天出门斩妖，傍晚回洞府炼丹，夜里山外魔气起伏，偶尔有蓝色秘境裂隙在远处闪烁。第二天上线，闭关的修为涨了一截——但真正改变命运的，还是昨晚冒险带回来的主药和法宝。

百年后你可能青冥宗的金丹长老，千年后你或许是化神老怪，万年后九重雷劫之下飞升而去——或者轮回重来。

### 【三才与修真文明】

世界本体分为天、地、生灵三个层面；人间修真文明据此建立天地人三才之学。天道参究规律并循规律修行进境，地道格察万物而成灵植、灵材、炼丹、炼器、符箓、阵法、御兽七域，人道是有意识者的修行实践、选择、组织、驾驭、创造与争胜。学问按主要研究的问题区分，不按执行者区分。

功法是把规律整理成可理解、可修习、可反复运用的具体修炼路径；修真百艺是地道诸艺；神通是能够被主动施展或触发的具体能力，可以由修士习得、由法宝承载，也可以由妖兽等生灵天生具有。人间所学大多是天界一脉整理并铺下的路；修行所依据的现象与力量并非虚假，但修士实际接触的灵气、信息与道路已经过大阵格式化。识破天界的解释，不等于解除这种物质改造。

### 【不做什么】

❌ 不做天命救世主 ❌ 不做强制主线一本道 ❌ 不做纯挂机成仙 ❌ 不做一局速通 ❌ 不做剧情压过刷怪 ❌ 不做宗门绑死成长 ❌ 不做必须组队推进的核心进度

## 一、世界结构

### 【世界叙述】

世界目前主要呈现为三界。**玄黄界（人间界）**——玩家所在的物质世界，天界大阵覆盖其上，格式化灵气流转于灵脉网络。**天界**——最早一批拒绝大轮回解散的秩序生命建立的存在机器，飞升通道是它回收人间天才的管道。**魔界**——天界为封印原初混沌及混沌侧生灵构筑的封闭空间；漫长岁月中形成魔气循环、原生万物与魔族文明，长成事实上的一界。它不是与天地同时自然生成的混沌位面。

### 【开发锚点】

| 位面 | 系统对应 |
|---|---|
| 人间界 | 玩家全部日常活动舞台 |
| 天界（大阵+飞升+轮回） | N突破/A基础架构/M境界/AR终局轮回 |
| 魔界侵蚀 | E怪物词缀/Z魔化层级/AH屠魔录 |

## 二、时代背景

### 【世界叙述】

万年前神魔大战撕裂了天地。飞升通道崩塌，天界大阵出现大量盲区。此后万年，原初秩序和原初混沌开始在某些地方渗回人间界。近千年劫气渐散，被封禁的上古洞府开始松动，蓝光传送门偶尔在山崖上裂开。修士在古战场挖出不属于任何炼器流派的碎片——没人知道它们来自哪一方，但它们携带的能量至今没有完全消散。

### 【开发锚点】

| 世界观元素 | 系统对应 |
|---|---|
| 仙路断裂+大阵盲区 | 上古功法残页(P)、高阶机缘(AG)、原初秩序接触点 |
| 洞府封禁松动 | AG机缘秘境——蓝门触发 |
| 古战场残留 | Z高级区、AH屠魔录入口 |
| 劫气渐散=新秀辈出 | 散修/小宗门玩家也能出头 |

## 三、四种气

### 【世界叙述】

修士日常感知的"灵气"其实是四种气的其中之一。真正流过这个世界的气有四类：

**原初秩序**——大轮回吸气的自然产物。庞大、无方向、携带宇宙源头完整记忆。未经天界大阵处理。修士经脉和丹田是为格式化后的灵气设计的，强行吸收原初秩序会经脉紊乱。但一旦建立起新的承载结构，可开辟天界功法之外的全新路径。仅存于大阵盲区——古战场深处、仙路断裂处、封禁洞府。

**原初混沌**——大轮回呼气的自然产物。中性、流动、负责解构与回收。它不是邪暗属性，而是自然回收力。与修士秩序结构冲突——它流过秩序时会叫秩序回归自然循环。仅存于魔界极深处和天界控制盲区。

**灵气**——原初秩序被天界大阵格式化后的产物。有方向、有节奏、易吸收、稳定。但被屏蔽了源头信息——修士吸收时不接收大轮回信号。修士日常修炼的版本，上限被天界预设路径锁定。天界大阵覆盖区域的全部灵脉都流淌着这种灵气。

**魔气**——原初混沌被封印百万年后，在压力、隔绝与怨恨中变质的污染形态。高能量但紊乱，携带被封者的怨恨信号。正常修士直接吸收会严重损毁经脉。极少数魔修以特殊功法在体内建立隔离结构微量利用。从魔界裂隙泄漏，污染魔化区域和古战场。

### 【开发锚点】

| 设定项 | 游戏机制 |
|---|---|
| 四种气的区分 | 所有物质系统的底层逻辑——不同区域产出不同气态对应不同资源 |
| 灵气=格式化后的原初秩序 | L修炼——修炼路径被锁定在标准体系内 |
| 魔气=囚禁怨化后的原初混沌 | Z魔化区域特殊规则、魔抗属性需求 |
| 大阵盲区中的原初秩序 | AG机缘秘境——高阶玩家的"不自然"感知 |

## 四、日月、阴阳与浊气

### 【世界叙述】

**日灵气**——白昼形态的灵气，偏向生长、外放、升腾。适合灵植生长、血肉活化、火性功法。**月灵气**——夜晚形态的灵气，偏向凝聚、内敛、沉降。适合妖类吐纳、草木凝药、神识沉淀。

**浊气**不是魔气。浊气是白日过盛、地热上升、尘土、杂乱灵流混合成的燥烈之气。它带有混乱倾向但还没变成魔气。魔族和魔化生物更喜欢浊气环境——浊气像干柴，魔气像火星。没有裂隙时只是燥乱，有裂隙时加速魔化。

一天节律：清晨灵气清明（打坐）、正午日灵气盛但浊气升（办事）、傍晚灵气回落（整理）、夜间月灵气主导（妖兽活跃）、深夜魔气渗出（风险收益双高）。

### 【开发锚点】

| 设定项 | 游戏机制 |
|---|---|
| 清晨灵气最纯 | Y时间系统——清晨打坐加成 |
| 浊气≠魔气，但易被引动 | Z魔化区域——浊气浓度影响魔化刷新 |
| 夜间月灵气→妖兽活跃 | D怪物刷新——夜间特殊刷新 |
| 深夜魔气渗出→稀有怪 | AG蓝门秘境触发、E词缀怪概率 |

## 五、五行与物质结构

### 【世界叙述】

五行不是五种化学元素，是灵气被梳理后呈现出的五种运动形态——金（锐利收束）、木（生长舒展）、水（流动渗透）、火（爆发交换）、土（承载凝聚）。生克不是绝对胜负——境界、灵气密度、功法理解都能压过五行关系。

灵根决定修士更容易读懂哪一种五行灵气。单灵根读得快但单一，多灵根适应性广但慢。异灵根（风雷冰）是五行在特定节律下的复合形态。

### 【开发锚点】

| 设定项 | 游戏机制 |
|---|---|
| 五行=灵气运动形态 | 所有材料/怪物/地图挂五行标签 |
| 生克关系 | C战斗伤害修正、S炼丹成功率修正 |
| 灵根=魂身交界处的先天规格，深层归属待定 | O灵根系统——修炼效率的区域差异 |

## 六、修士身体观

### 【世界叙述】

**灵根**——表现为灵魂与肉身交界处的先天规格，不属操作三元；它首先属于灵魂，还是魂身相接后共同形成，当前仍不说死。**操作三元**——灵力提供可调用力量，肉身决定修士的承载上限，神识负责感知与精细操控。**灵力**是天地灵气入体后被留存、调用的形态；**法力**是施展能力时由灵力压缩、组织而成并被消耗的力量；**修为**是长期修炼造成的总体积累，是度量而非一种气；**真元**自金丹起凝成，与道基相连，不作日常消耗。**道基**是修士筑基后形成、用于承接后续修炼的稳定根基。**神识**不是灵魂本身，而是灵魂读写灵气信息的手眼。**寿元**是体内秩序结构的自然维持周期。**道心**是灵魂对自身道路的稳定认同。

### 【开发锚点】

| 设定项 | 游戏机制 |
|---|---|
| 经脉宽度=灵力运行能力 | M境界—小境界→灵力流速、恢复与法力调用能力提升 |
| 丹田=灵力储存、压缩与调度中心 | M境界基数→灵力储量与法力调用基础 |
| 神识=灵气信息读写 | 小地图范围、隐藏探测、Q法宝出战位 |
| 灵根=灵气吸收通行证 | O灵根系统 |
| 真元=本源灵气 | Q本命共生、N渡劫等根本事件的世界观依据；具体是否消耗留待设计 |
| 道心=秩序认同 | N心魔劫抗性 |
| 冠/巾=境界身份外显 | H装备位——低构筑·高填充位 |
| 法袍/道袍=身披道法 | H装备位——生存+外观，题材包装位 |
| 武器=手持战力 | H装备位——攻击方式选择，高构筑位 |
| 佩/护符=腰载权能 | H装备位——流派词条位 |

## 八、妖兽、精怪与气灵

### 【世界叙述】

妖兽是动物长期受灵气改造的结果。一个普通山狐世代生活在灵脉附近，血肉骨骼被灵气重排——更壮更快更硬。妖丹不是它刻意修炼的，是灵气被体温、心跳、猎杀这些生命活动自然加工后沉淀在体内的结晶。修士炼化妖丹，本质上是借用了妖兽数十年数百年对灵气的理解成果。

**妖修分三类**：妖兽（肉身路线）、精怪（草木玉石灵气结构复杂到涌现意识——和器灵诞生逻辑一致）、气灵（高浓度灵气临时聚成的短暂意识）。

妖兽阶位 1-9 阶对应凡到大乘（`realm_id` = 阶位 − 1）。**一阶是普通野兽，无妖丹**——妖丹从二阶开始。五阶以上有兽魂——肉体死亡后短暂保留的神识结构。六阶可通人言，七阶可化形。

妖兽同样挂品质轴：同一阶有六档品质，玄品以上开始出现词缀。**词缀怪不是独立机制，就是高品质的同阶妖兽**，掉落品质自动跟着走。

### 【开发锚点】

| 设定项 | 游戏机制 |
|---|---|
| 妖兽1-9阶（realm_id=阶位−1）+产出全表 | D怪物刷新/F掉落表 |
| 妖兽品质=精英/词缀等级 | E怪物词缀——与品质轴合并，不再是独立机制 |
| 妖丹=生命解读成果 | S炼丹主材/N突破主药 |
| 精怪=草木成灵 | AA NPC（稀有交互）/AK灵兽 |
| 气灵=临时意识 | AG机缘中的特殊事件 |
| 兽魂 | Q法宝祭炼/AK灵兽培养 |
| 妖兽可驯化为灵兽 | AK伙伴系统 |

## 九、魔族、魔修、魔化与魔界原生

### 【世界叙述】

魔族是共同身份，魔修是持续采用魔气的修行道路，魔化是原有结构遭魔气侵入后的变化状态，魔界原生说明出生与生成环境。魔气相关之物分为魔化之物、魔界原生之物、魔道造物；魔道造物再分魔族造物与人间魔修造物。四个基本词与三类产物不得混用。

**魔核不是妖丹染黑。** 魔核可以由魔气在原有生灵体内重构，也可以在魔界原生生灵体内自然形成；前者属于魔化之物，后者属于魔界原生之物。两者都能量高、信息难读，正常修士不能直接炼化。

### 【开发锚点】

| 设定项 | 游戏机制 |
|---|---|
| 魔化生物 vs 魔界原生生物 | D怪物分类——词缀怪 vs BOSS |
| 魔化生物不恐惧不休息 | D怪物AI |
| 魔核≠妖丹 | F掉落——两套掉落体系 |
| 魔核高能不可直接炼化 | T炼器特殊材料/AH屠魔录奖励 |

## 十、灵植体系

### 【世界叙述】

灵植不是"草药加灵气"。灵植是一套活的灵气循环系统——根吸收地气水气→茎输送→叶吸收日灵气→花果在月灵气中凝聚药力。同样的遗传密码，灵气充足时表现为灵植，灵气不足时表现为普通植物。

采集就是打破这个循环——卯时采叶（药性发散），子时采根（药性沉积）。断根须不是少了一点重量，是断了一条灵气通路，整个循环失衡。

**四性**——寒热温凉是灵植体内灵气的主流流动方向。**五味**——酸苦甘辛咸是灵植灵气与人体五行回路的天然亲和，决定药力先入哪条经脉。**药效八类**——补气/凝神/淬体/洗髓/破境主药/解毒清心/火候药引/魔化灵植。**年份＝灵植的品质轴**——一年凡品/十年灵品/百年玄品/千年仙品/万年神品；**道品不看年份看产地**，长在大阵盲区、吸收过原初秩序的灵植即为道品。灵植的境界轴另算，由药效服务于哪个境界决定。

### 【开发锚点】

| 设定项 | 游戏机制 |
|---|---|

## 十一、炼丹

### 【世界叙述】

炼丹不是化学反应。炼丹是把不同材料中已整理好的灵气结构拆开、调和、重组。火候是用火性灵气的高频交换打破材料外层灵气膜，让君臣佐使之间重新配对。

**丹毒**——炼丹时四性五味的灵气结构被火候强行撮合，总有一部分被打散后找不到配对，变成无方向的小碎片附着在经脉壁上。打散速度和重新配对速度不可能完全同步——这是热力学问题，不是技术问题。丹毒缓慢排出，但吃丹速度远超排出速度——这就是每日上限的物质法则解释。

**丹药双轴**：境界轴决定这颗丹给谁吃（筑基丹给筑基修士），品质轴决定效果与丹毒。六档品质效果递增、丹毒递减，倍率示意以数值表为准。品质是纵向飞跃点——**玄品进入坊市、仙品拍卖行级别、神品全服播报**。

## 十二、炼器、器物、装备、法宝与道器

### 【世界叙述】

炼器产出的可反复使用外物统称器物。器物再按运行结构分为三类：**装备借人而运**，穿戴或手持并以修士肉身为运行核心；**器具借外而用**，依靠使用者操作、外部供能或材料本性；**法宝自成其法**，内部具有独立自持循环与自己的神通结构，能被祭炼或由神识建立联系，不要求必有器灵。

外形不决定身份。法宝之剑既可手持作装备，也可由神识御使；是否生效装备作用，看当下是否接入肉身，是否生效法宝神通，看是否与法宝结构建立联系。同一作用不重复计算。

品质与身份分开。凡品、灵品、玄品、仙品、神品、道品衡量承载原初力量与规则的深度；装备、器具、法宝、本命法宝、道器说明运行结构或关系。旧称凡器、法器、灵器退出正式口径。法宝没有硬性最低品质，成熟稳定者常见于仙品以上。

**有灵法宝**专指器灵已经形成的法宝；具有灵性不等于器灵已成。**本命法宝**是法宝与主人道基建立本命共生后的关系身份，不是品质，最早始于金丹以后。**道器**是承载一段独一规则、能够介入持有者命途或成长道路的特殊身份，通常达到道品，但道品不等于道器。

祭炼是长期浸润并建立亲和；主人可以与法宝建立稳定调用关系，此处不另立专名；认主是器灵主动认可主人；本命共生是法宝与道基深度相连。器灵能够自主行动；主人主动御使法宝时仍需持续分出神识。

### 【开发锚点】

| 设定项 | 游戏机制 |
|---|---|
| 装备/器具/法宝三分 | H装备/Q法宝/T炼器器具按运行结构归类 |
| 法宝可穿戴、手持或脱手御使 | 同一器物按肉身接入与神识连接决定当前生效部分 |
| 品质与器物身份正交 | 六品质不再对应旧器物六级 |
| 有灵法宝=器灵已成 | Q法宝高阶养成/AK灵兽同类逻辑 |
| 本命法宝=道基共生关系 | Q本命法宝，最早金丹后 |
| 道器=独一规则介入命途 | R道器系统 |
| 器纹/灵纹=装备词条 | J词条系统/I小极品 |

## 十三、符箓与阵法

### 【世界叙述】

符箓和阵法的底层是同一件事——把灵气结构固定在载体上。符箓固定在纸/兽皮/玉片上，阵法固定在空间里。

**符箓**——神通结构的临时缓存。正常施法需要临时构建灵气结构，符箓把这一步提前做好了，使用时只需输入少量法力触发。符纸用灵木压制——灵木曾经有过灵气循环轨迹，类似预格式化的光盘。符墨用妖血——妖血携带妖兽对灵气的解读成果，比人血更适合穿透符纸纤维。

**阵法**——空间化的符箓。阵旗是锚点，阵盘是中枢，灵石是持续供能。天然阵势是人间对无人布设而长期定型的灵气结构的称呼，真实成因既可能是灵脉地势自然凝成，也可能是失去来历的上古工程与古阵残留。阵势本体不能携走，只能把其中一段结构拓入阵图、阵心、阵印等小型载体。

现行阵法按主要用途分为七类：聚灵阵、护府阵、困阵、陷阱阵、迷阵、古传送阵、禁制阵法。天然阵势说的是形成来源和存在状态，不取代这七种用途分类。

### 【开发锚点】

| 设定项 | 游戏机制 |
|---|---|
| 符箓=提前缓存神通结构 | T符箓制作——偷渡/战斗消耗品 |
| 符纸/符墨/符笔 | U通用合成——材料→符箓 |
| 阵法七类（聚灵、护府、困、陷阱、迷、古传送、禁制） | V阵法系统——阵旗阵盘+灵石 |

## 十四、灵石与矿产

### 【世界叙述】

灵石是灵气在地层中长期凝结后的晶体——整块石头被灵气格式化成特殊晶体结构，品质越高压缩程度越高。**灵石只挂品质轴，不挂境界轴。** 凡品（零钱）、灵品（日常消耗）、玄品（辅助修炼+阵法）、仙品（高级阵法+高阶丹炉）、神品（接近固态灵气核心，坊市硬通货）、道品（结晶化的原初秩序，常规修士无法吸收）。

压缩度决定的不只是面额，更是**瞬时功率**——高阶阵法与丹炉要的是"单位时间输入多少灵气"，低品灵石堆再多也顶不上。这是高阶内容对灵石设**品质门槛而非数量门槛**的依据。

矿产的本质是物质晶体被灵气长期重排——玄铁（金气重排铁矿）、精金（极限致密）、陨铁（天外材料+灵气重构）、灵木（内部形成稳定灵气回路）、玉髓（灵石变体，适合承载灵气信息）、五行精华（单一五行灵气极致压缩）。

| 灵石多用途 | L修炼/S炼丹/V阵法/N突破消耗 |
| 矿产=灵气重排物质晶体 | T炼器材料/H装备制作 |

## 二十三、上古大战的物质后果

### 【世界叙述】

大战后飞升通道崩塌，天界大阵出现盲区。原初秩序和原初混沌在某些地方渗回人间。**古战场**——天界封印、魔界铭刻、古修道痕混杂，出古修残器和道器碎片。**仙路断裂处**——大阵不完整，原初秩序偶尔泄露，出高阶机缘。**封禁洞府**——上古修者留下的独立环境，灵气规则可能不同。**蓝门秘境**——大阵薄弱处或空间临时错位，随机资源。**妖兽山脉深处**——古修遗骸或高阶灵脉影响，出精怪和高阶材料。

### 【开发锚点】

| 设定项 | 游戏机制 |
|---|---|
| 古战场→残器+道器碎片 | Z高级区/R道器材料 |
| 仙路断裂处→大阵盲区 | AG高阶机缘/P功法残页 |
| 封禁洞府→独立灵气规则 | AG秘境/X灵植/Q法宝胚子 |
| 高阶玩家"不自然"感 | AM提示——神识感知异常→大阵盲区提示 |

## 二十四、奇珍录

### 【世界叙述】

奇珍是评价与收录身份，不是器物结构身份。共同标准只有两条：当代难以稳定复制或批量取得的**罕见**，以及内部有能持续产生特殊作用之结构的**有道**。人间常说奇珍为天地孕育；底层真实来源还可能是天界工程、古修遗留、当代造物、魔界原生、魔道造物、魔化重组或生命自组织。

奇珍分八类：灵植、灵材、炼丹、炼器、符箓、阵法、功法、道痕。前六类对应地道六域；御兽另归灵兽体系；功法与道痕偏天道。每类设一个携带位，只有放入对应位置的奇珍才持续生效。活着的妖兽与精怪不归奇珍；阵势、功法与道痕必须先依托可随身载体。

天材地宝与奇珍大体同物两称：市井重其罕见、贵重与用途，修士重其奇异性质与其中有道。

### 【开发锚点】

| 设定项 | 游戏机制 |
|---|---|
| 奇珍八类、每类一携带位 | AJ奇珍录与八类携带 |
| 灵兽不入奇珍 | AK灵兽独立体系 |
| 天然阵势以拓印载体携带 | 阵图/阵心/阵印类奇珍 |
| 奇珍身份与装备/器具/法宝正交 | 同物可以兼具多种身份；同时占位与效果并存方式留待具体设计 |

## 二十五、术语与命名规范

### 【核心术语】

| 术语 | 精确定义 |
|---|---|
| 灵力 | 天地灵气进入身体后被留存、调用的形态 |
| 修为 | 长期积累的修炼进度，不可消耗（=经验条） |
| 法力 | 施展神通时由灵力压缩、组织而成并被消耗的力量 |
| 神识 | 灵魂读写灵气信息的器官，负责感知与精细操控 |
| 真元 | 金丹以上凝成、与道基相连的本源灵气，不作日常消耗 |
| 道基 | 修士筑基后形成、用于承接后续修炼的稳定根基 |
| 功法 | 把规律整理成可理解、可修习、可反复运用的具体修炼路径 |
| 神通 | 能够被主动施展或触发的具体能力 |
| 法宝 | 内部自成循环、具有独立神通并可由祭炼或神识建立联系的特殊器物身份 |
| 寿元 | 体内秩序结构自然维持周期（=氛围数值） |
| 道心 | 对自身秩序路径的稳定认同（=心魔抗性） |

### 【品质与色系】

**品质六档**：凡品(白) / 灵品(绿) / 玄品(蓝) / 仙品(紫) / 神品(橙) / 道品(红)。品质衡量一件存在能够稳定承载并显现多深的原初力量与规则；秩序侧越高越接近原初秩序，魔侧越高越接近原初混沌。

**"稀有度"这条轴已删除**——它与品质是同一个概念的两种说法。全项目统一称"品质"，不再出现"稀有度""史诗""传说"作为档位名。

**"品阶"一词作废**，拆分为「境界」（9档，realm_id 0-8）与「品质」（6档）两条正交轴，详见 `世界观_中间层-物质法则.md` §二 双轴总表。

境界色系语义递进：低境界质朴→中境界富贵→高境界沉稳→终局超脱。具体色值交视觉规范。

### 【命名规则】

物品统一按 **「境界 · 品质 · 名称」**，口语可省其一：

- 丹药："筑基 · 玄品 · 聚气丹"，口语"玄品筑基丹"；带属性时"寒 · 筑基 · 玄品 · 聚气丹"
- 装备："金丹 · 仙品 · 青冥剑"；仙品是品质，不等于法宝身份
- 功法按"意境+类型"如"青冥剑诀"。独特法宝可有自己的名号，本命法宝是关系身份，不是命名类别。
