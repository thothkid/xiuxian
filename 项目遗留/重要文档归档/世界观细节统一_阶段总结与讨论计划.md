# 一、文档用途

本轮工作是在项目世界观形成一段时间后，回头补全并统一重要细节。新设定与旧文档出现差异是正常现象，因为旧文档可能写得较早、较浅或尚未展开。

本文保存四类内容：

1. 已经讨论收口、目前可以作为依据使用的现行口径。
2. 正在讨论但尚未收口的方案与分歧。
3. 尚未开始的后续步骤，以及每一步准备解决的问题。
4. 已发现但暂时不应打断当前步骤的待归位事项。

“收口”表示当前讨论已经形成统一认识，不表示永远不可修改。以后若发现其自身不能成立，或与更深层已经拍板的设定矛盾，可以重新打开讨论；浅层文档、旧策划和实现方式不能成为推翻深层世界观的理由。

# 二、本轮讨论规矩

## 1. 当前只做世界观

本轮只讨论概念、定义、因果、边界和相互关系。不讨论数值、界面、配置、编号、存档、版本排期、快捷键等实现问题。

## 2. 世界观正文使用中文

世界观讨论和基础文档不使用无必要的英文词语。将来进入表格、配置和程序工作时，若必须使用英文名称，必须同时给出清楚的中文含义。

## 3. 新旧不一致不自动算冲突

新设定与旧文档不一致时，默认视为旧文档等待更新。只有两种情况需要立即提出：新设定自身前后不能成立；或新设定与更深层已经拍板的世界规律矛盾。

“以前没写过”不等于“现在不能有”；“旧文档已经这样写”也不等于不能修改。

## 4. 深层决定浅层

第一因和已经确认的物质规律负责裁定世界能否成立。具体策划、文档结构与实现方式只能向它们靠拢，不能反过来限制世界观。

## 5. 先辨别观察角度，再判断是否冲突

同一个事物可以同时拥有本体、来源、状态、用途、承载方式、人间称呼等多种属性。不同分类发生交叉是正常现象，不应强迫每件东西只能进入一个格子。

## 6. 每一步的讨论方法

1. 先找它在第一因和物质法则中的根。
2. 区分世界客观真相、人间或其他文明的认识、具体运用三层说法。
3. 给出讨论草案。
4. 找出草案自身的含混、过度推断和遗漏。
5. 经托特裁定后形成现行口径。
6. 相关问题全部谈清后统一写回世界观，不边谈边让旧文档反过来限制讨论。

# 四、第一项现行口径：三才本体

## 1. 世界本体与人间命名

世界本体分为天、地、生灵三个层面：

- **天**是支配万象的抽象规律。
- **地**是规律在物质、环境与万物形质中的显现和承载。
- **生灵**是能够感知、抉择并主动作为的存在。

第一因所写的“三是天、地、生灵”，讲的是世界本身怎样分层。人间修真文明依据这三个层面建立天地人三才之学，并从自身立场把生灵这一层称为“人”。因此，世界本体的第三层叫生灵；人间建立的第三门学问叫人道。人不等于全部生灵，“人道”是人间文明站在自身位置上的命名。

## 2. 三才之学

- **天道之学**参究规律。
- **地道之学**格察万物。
- **人道之学**研究并实践有意识者如何运用自身与万物，包括修行实践、抉择、组织、驾驭、创造与争胜。

三才按照“主要研究和解决什么问题”分类，不按照“是谁在做”分类。同一主题同时具有天地人三面，是正常结构，不是分类冲突。

## 3. 功法、修真百艺与神通

- **功法**是修士把规律整理成可理解、可修习、可反复运用的路径。功法不是天道自己生出的东西，而是修士对规律的理解和整理；人间现有的大部分道路，是天界一脉曾经走出、铺设并传下来的。
- **修真百艺**是地道认识、加工和改变万物所形成的诸般技艺，简称百艺。“百”是泛称，不表示恰好一百种，也不提前锁死具体门类。
- **神通**是能够被主动施展或触发的具体能力。修士可以习得神通，妖兽可以天生拥有神通，法宝可以承载神通。在个人修行中，人道最直接的表现是神通与技法，但人道并不只有战斗。

剑可以作为三才交叉的说明：剑的作用背后有规律；剑的材料、锻造和养护落在万物承载；剑招、御剑、临敌选择和流派创造落在有意识者的运用。

## 4. 三才与三层真相

“宇宙本体、天界工程、人间修真文明”讲的是真相有几层、谁知道多少；“天、地、生灵”讲的是世界由哪三个层面构成。两套结构彼此交叉，但不一一对应。

人间修士接触到的现象和力量真实存在，真实规律始终在底层起作用。被天界整理、铺设、筛选乃至遮蔽的，主要是人间对规律的解释、命名和能够走的修行道路。因此，人间所敬畏和参悟的“天道”不是纯粹骗局，却远远不是宇宙规律的全貌。

“天道”一词继续保留。现代人间修士把天界铺设后的道路当作唯一天道，正是本世界认知深度和后续揭示的重要部分。

# 五、第二项现行口径：操作三元

## 1. 总起与判据

操作三元是修士运行的三项基础：灵力提供可调用的力量，淬体决定肉身的承载，神识负责感知与精细操控。

它们共同回答“修士凭什么接收、承载并运用灵气”，不是三个材质相同的身体零件。三元不是学问分类，不与三才并列：三才按照主要研究的问题分类，三元是生灵一层的具体构造。

“精气神”只可作为传统文化类比，不能与本项目三元直接画等号，尤其传统意义的“神”远比本项目的神识更宽。

## 2. 灵力及其相关概念

天地灵气进入身体并被留存、调用，形成灵力。灵力一元统摄灵气的吸收、储存与调用。

- **法力**：实际施展能力时消耗的压缩灵气。
- **真元**：金丹以后凝成、与修士根本结构绑定的本源灵气，不作日常消耗。
- **修为**：长期修炼造成的总体积累，是度量，不是一种气，更不是灵力沉淀出的物质。

真元目前只有概念解释作用：它区分日常消耗与伤及根本的本源力量，并暂时关联金丹、元婴、本命法宝祭炼和渡劫等根本事件。它目前没有形成独立运转体系，也不属于操作三元。具体作用等相关内容展开时再定。

## 3. 淬体

淬体所对应的是承载灵力和神识运行的物质结构，包括经脉、丹田与血肉。

人体不是简单装灵气的容器。灵脉是大地被灵气长期冲刷形成的天然通道；经脉、丹田和血肉，是人体被灵气长期梳理形成的微观通道，两者同源。

淬体这一维的高低，表现为物质结构的秩序密度与承载上限。承载不足而强行拔高境界，经脉无法容纳突然跃升的灵气密度，身体结构便会崩解。爆体是物理必然，不是外加惩罚。

“淬体”一词保留两种用法：作为名词，指肉身承载基础及其淬炼程度；作为动词，指强化这一基础的过程。

## 4. 神识

神识是灵魂向外读写灵气信息的接口。灵气既是能量也是信息，神识负责读取其中的信息，并引导灵气流向、使其精细成形。

意识是秩序与混沌在临界处涌现的结果；神识是自然意识经过修炼强化后，能够作用于灵气的形态。

- **读**：感知灵气中的信息与异常。
- **写**：引导灵气流动，精细调整其结构。

神识不是舵手。灵魂这个“我”才是舵手；神识是舵手的眼睛、手、舵与闸门。

## 5. 粗放操作与精细操作

凡人具有意识，却尚未形成能够直接读写灵气的可用神识。初入修行者的神识也十分微弱，往往需要依靠肉身、经脉、器具、火候和材料本性，间接而粗放地引导灵气。

随着神识增强，修士才逐渐能够直接感知并精细调整灵气结构。这是逐渐增强的过程，不是突然出现的绝对开关。

## 6. 三元与灵魂

灵魂不等于肉身，也不等于神识。肉身毁坏后，灵魂仍可能短暂相续，但未修成稳定形态的灵魂会消散、回归自然轮回或被天界轮回机制截取。只有修炼到足够层次，才能以元神等形态稳定脱离肉身。

神识即使受损或失去，“我”仍然是“我”，只是失去了感知和操控灵气的手眼。

道心属于灵魂本身。灵根不属于操作三元；它究竟是灵魂自带的结构，还是灵魂与肉身交界处的先天规格，留到概念归位时单独决定。

## 7. 当前边界

- 神识用途保持开放。
- 神识如何御使法宝，留到第四项器物体系讨论。
- 神识与丹毒保留现有世界观因果，不提前规定具体怎样生效。
- 三元以人族修士为标准形态；妖、魔等生灵大体存在相应结构，但具体形态留给对应步骤展开。

# 六、第三项现行口径：魔族、魔修、魔化与魔界原生

## 1. 四个基本概念

魔族是共同身份，魔修是修行道路，魔化是变化状态，魔界原生是出生与生成环境。四者分别回答“属于谁”“走什么路”“变成了什么”“生在哪里”，不得混用。

- **魔族**：封印催生出的生灵共同身份及其文明。混沌侧生灵在封印中相续、自举，于共同怨恨中长成“我们”。魔族是来源、灵魂变化与共同身份结合而成的新身份，不是单纯的出生族属。
- **魔修**：主动把魔气持续纳入自身修行方式的非魔族修行者。偶尔使用一次魔化材料、魔核或魔气，不足以成为魔修，关键在是否把魔气变成持续的修行方式。“魔修”是人间视角的用词；魔族内部如何称呼自己的修行者，暂不命名。
- **魔化生灵**：原有生命结构被魔气侵入、扭曲后的状态。魔化是变化过程，不是族属或产地。
- **魔界原生**：出生或生成于魔界环境，从形成之初便适应魔气循环，不经历由正常状态转为魔化状态的过程。

## 2. 入魔不等于成为魔族

使用魔气修行，是魔修；身体或意识被魔气扭曲，是魔化生灵；只有灵魂与身份被纳入魔族那个共同的“我们”，才可能真正成为魔族。

一个人可以是魔修，也可以严重魔化，但仍然保持自己原有的族属与自我。是否存在彻底加入魔族共同意识的转化，保留可能性，等写到魔族内部时再展开。

## 3. 魔气与代价

魔气是原初混沌被囚禁、压缩并受怨恨浸染后的变质形态，同样具有能量与信息两面。

魔气首先侵蚀经脉、丹田与血肉，淬体是第一道承压层；侵蚀长期积累后，还可能继续污染神识、扰乱意识，并沿道心裂缝伤及灵魂主轴。

隔离功法解决的是不让魔气直接撞上正常灵力结构，不是彻底消除代价。

## 4. 正法与魔功

人间正统把灵气法门称为正法，把魔气法门称为魔功；这是人间文明的命名，不代表灵气天然正义、魔气天然邪恶。

三才每一道之下都可能出现围绕魔气形成的变体。“两气皆可行的通用法门”暂不立名目：灵气与魔气结构相冲，若真能兼行，必须依靠隔离、转化或两套循环。目前只保留这种可能性。

## 5. 魔之三物

- **魔化之物**：原有结构被魔气侵入并扭曲重组，包括魔化生灵、魔化灵植、魔化矿物、魔化器物与其他魔化材料。
- **魔界原生之物**：在魔界环境及魔气循环中自然生成、繁衍或凝结的生灵、植被与矿产，其结构从一开始便适应魔气，不得称作魔化。
- **魔族造物**：魔族文明利用魔界原生之物或魔气主动培育、炼制、构筑出来的丹、器、阵、兽与其他产物。

现有魔化材料以后应按这三类重新归位。例如魔核如果出自魔化生灵，属于魔化之物；如果出自魔界原生兽类，则属于魔界原生之物，不能只因名称相同便认定来源相同。

第四项继续讨论魔族器物与魔化器物如何进入器物体系；第五项讨论三类东西中哪些够资格列为奇珍。

## 6. 平行体系与伦理

魔族文明依据同样的天、地、生灵三个世界层面，拥有自己的认识、技艺与施为体系。它与人间修真文明在骨架上可以大体映照，具体形态因魔气和魔界环境而改变，并不要求逐项一一对应。本轮只立原则，不给魔族内部各门类强行命名。

魔气本身是囚禁的产物，魔族连所凭之气、所处之境都受到上古天界工程塑造。“魔与仙是同一件事在不同土壤里的两种长法”，说明双方都不是本质邪恶。

双方的真实罪责来自各自行为：天界实施封印，魔族把无辜人间卷入复仇。共同的灵魂根源负责消解脸谱化，具体选择和造成的伤害才负责建立真实罪责。

# 七、已形成方向、但必须在后续步骤复议的事项

## 1. 功法、神通、词条与铭文

- 功法可以作用于修炼、战斗、炼丹、炼器、凝神等不同领域，不是单一技能入口。
- 神通是能够主动施展或触发的具体能力；世界观表达统一使用“神通”。
- 词条和铭文不是谁取代谁。二者背后都是对原有对象或效果进行改变的单元；挂在装备上称词条，挂在神通上称铭文或符文。具体规则以后另补。

## 2. 修行方向、灵根与组织

- 当前不设排他的职业。修士可以学习多个方向，高阶传承可以要求某个方向达到相应层次。
- 灵根是天赋倾向，不是职业，也不锁死人生道路。
- 宗门更像共同体，堂口更像其中的行当与组织。组织分类可以与能力分类重合，但是否必须重合尚未确定。
- 法修、体修、神识相关方向是否需要专门堂口，留到第六步讨论。

## 3. 奇珍方向

- 奇珍录不是普通装备图鉴，而是对罕见、高价值、具有特殊性质或规则意义之存在的收录。
- 有意识与无意识之物都可能成为奇珍；是否有灵不能作为排除标准。
- 奇珍与法宝、异兽、丹方、阵法痕迹等身份可以交叉，收录与佩戴、携带、收服、同行互不排斥。
- “天生还是人造”不能简单决定它是不是奇珍。人间所谓天然之物，可能实际上是古修或天界工程遗留。
- “天材地宝”目前理解为人间对罕见、高价值、蕴含特殊性质之物的泛称，不严格等于纯天然物。
- 怪物相关收录只记录特殊存在，不建立普通怪物大全。
- 现有奇珍录提出九类，但分类是否合理、是否应与地道诸领域对应，必须在第五步重新讨论。

## 4. 器物方向

- 六级旧称暂为：凡器、法器、灵器、法宝、本命法宝、道器。
- 目前只确认旧称齐全，各级本质尚未收口。
- “法宝”既被用作其中一级，又被用作整个御使器物体系的泛称，必须在第四步解决。
- 器物品质、是否有灵、与主人关系、是否触及原初规则可能是不同维度，不能未经讨论便绑成同一条梯子。
- 器灵、祭炼、认主、共生与跨境界成长不是同一件事，必须分别定义。
- 法宝可以天地自生，也可以经修士炼制、祭炼或培养；自然形成与人工形成不能单独决定它是不是法宝或奇珍。
- 法宝如何占用神识、道器是否拥有独立位置、奇珍怎样携带，目前都属于待定内容。

# 八、待归位清单

1. **灵根归属**：现有文档一处写“灵魂中自带的天然秩序框架”，另一处更接近“灵魂与肉身交界处的先天规格”，概念归位时必须统一。
2. **道基定义**：当前用它解释真元与修士根本结构的绑定，但世界观正文尚无正式定义。
3. **真元作用**：目前保留本源力量的解释，不建立独立体系；到本命法宝、渡劫、金丹元婴或元神相关内容时再判断是否展开。
4. **神识与丹毒**：保留“神识精度影响炼制时的秩序化程度”这一世界观因果，不提前规定具体怎样生效。
5. **由灵魂定义推出的三条推论**：天界之悲、魔族之镜、飞升之疑是否写入第一因，等统一落盘时决定。
6. **天然阵法**：区分真正由自然规律自发形成的稳定结构，以及天界、古修留下而被现代修士误认为天然的阵势。
7. **魔界内部生态**：魔界原生兽类、植被、矿物与魔族培育造物的具体形态，先定来源边界，具体门类随第三、第四、第五步逐层展开。

# 九、后续各步如何确定

## 第四步的讨论方法

先不讨论能带几件、放在哪里，而是逐项回答：

1. 六品质究竟只衡量材料与结构，还是同时决定器物是否有灵。
2. 灵性、意识、灵魂与器灵分别是什么，能否由品质直接推出。
3. 祭炼、归属、认主、本命共生与跨境界成长之间是什么关系。
4. “法宝”是品质名、器物类别、御使方式，还是人间泛称。
5. 道器由什么定义，是否必然无灵，是否能够被御使，其本体与持有关系怎样跨越轮回。
6. 魔界原生器物、魔化器物和魔族造物如何进入共同尺度。

以上本体问题收口后，再讨论神识御使法宝的关系。

## 第五步的讨论方法

先给奇珍建立两层定义：人间修士如何称呼，底层世界实际上为何形成。随后确定统一收录判据，再检验九类草案，而不是先保住九这个数字。

分类尽量与地道认识万物的各领域相互照应，同时允许用来源、是否有灵、是否为传承、是否可随身等附加描述表达交叉性质。主分类与附加性质不能混为一套。

## 第六步的讨论方法

先区分“世界中有哪些修行学问”和“宗门为了传承、生产、管理怎样设立组织”。两者可以重叠，但没有必须一一对应。确定组织需要解决的职责后，再判断法修、体修、神识和符箓是否需要独立堂口。

## 第七步的落盘方法

1. 先更新最底层第一因，只写真正属于宇宙根源、灵魂与文明真相的内容。
2. 再更新中间层物质法则，写三元、魔气生态、器物、奇珍形成等具体规律。
3. 最后更新最表层世界观，使其服从前两层；具体开发文档在此之后另行统一。
4. 每个概念只保留一处正式定义，其他位置只引用或简述，避免多份副本漂移。
5. 不再需要的旧稿归档，不进入日常项目索引。
6. 重要文件正文只保留当前版本；若确需追溯，将修订记录集中到单独文件。
