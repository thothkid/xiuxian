# 炼丹系统 · 第六版数值与配置工作框架 v1.6

**整理**：小G  
**日期**：2026-08-14  
**性质**：炼丹系统后续数值、配置、纸推、交互与经济工作的执行顺序。

## 一、文档职责

《炼丹系统·第六版设计定稿》保存全部正式规则、数值原则、配置归属和待定参数。

本文件只保存：

- 完成第六版所需的工作步骤；
- 各步骤的输入、工作内容和通过条件；
- 候选值、反推结果与正式配置值的施工状态；
- 参数变更后的回归范围；
- 最终交付清单。

规则、公式、数值原则或配置归属发生变化时，修改《炼丹系统·第六版设计定稿》；工作顺序、施工范围或通过条件发生变化时，修改本文件；同时影响两者的改动在同一次工作中同步更新内容、标题版本和文件名。

## 二、数值状态

| 状态 | 用途 |
|---|---|
| 第一版候选值 | 由第四步数值生成器生成，写入工作配置表供全量填表与纸推使用 |
| 反推候选值 | 由切片和组合分布回调生成，等待联合验证 |
| 正式配置值 | 数学、玩法与经济验证通过后写入正式配置 |

候选值必须保留版本，不得在验证通过前标记为正式值。

## 三、工作顺序

### 第一步（贯穿全程）：维护正式设计文档

输入：讨论中已经确认的系统裁定。

工作：

- 将正式规则、公式、配置归属和待定参数写入《炼丹系统·第六版设计定稿》；
- 正式规则只记录已经确定的输入、条件、流程和结果；
- 删除公式可以直接推出的解释和重复内容；
- 检查每项规则是否只有一个完整出处。

通过条件：《炼丹系统·第六版设计定稿》能够独立说明系统如何运行，其他文档不补充规则。后续步骤形成新裁定时，同步回写该文档。

### 第二步：冻结公式、边界与数据职责

输入：《炼丹系统·第六版设计定稿》中的系统规则。

工作：

- 确定境界、品质、药力、药性、杂质、丹头、炉膛、除渣、纯度、成丹率、升品和丹毒之间的输入输出关系；
- 固定单位、取整、上下限和数据归属；
- 将尚无数据依据的常数列入待定参数。

通过条件：每个数值只有一个职责和一个保存位置，全部公式可组成完整结算链。本步不决定各模块的具体量级和比例。

#### 第二步输出：数学验收指标

本步建立后续切片、批量纸推和回调共用的指标名称，不提前填写目标区间：

- 配方指标：药力达成比`P/U`、丹头占用比`N/Nmax`、技能除渣比`A/Zf`、纯度余量`Q−Qmin`、剩余杂质占池比`D/Cpool`；
- 解空间指标：死方率、有效解数量、代表路线数量、最低杂质触底率、丹头和炉型覆盖率；
- 产出指标：成丹与升品后的期望产量、单枚期望成本、参考售价与利润；
- 稳定性指标：关键候选参数变动后，死方、全过、路线消失、大面积触底和跨境收益的变化。

各指标的目标区间由第四步数值生成器提出，在第九至第十一步验证和回调。

### 第三步：建立配置骨架

输入：《炼丹系统·第六版设计定稿》中的配置数据归属。

工作：

- 建立灵植表、丹方表、丹炉表、除渣力、丹毒池、成丹率描述、系统参数和属性配置接口；
- 君、臣、佐、使和丹头统一保存在灵植表；
- 每个基础丹方的每个开放品质使用一条完整丹方品质行，成丹条件、丹效、升品率和参考售价保存在同一行；
- 确定主键、引用、字段类型、合法范围、唯一性约束和运行页签；
- 使用中文显示名，同时保留稳定技术表ID和字段ID；
- 建立同方相邻启用品质、特殊丹头、默认材料、除渣来源、丹毒属性和系统参数的引用校验；
- 批次数量由神识与材料公式计算，不新增批次数量配置字段。

产出方式：字段结构和约束逐项人工确认；机械字段与基础行由脚本生成后人工校订。

通过条件：全部数据可沿引用关系导表，同一数据不存在重复保存，配置骨架与《配置表字段与程序使用说明》一致。

### 第四步：建立跨表数值生成器并落地第一版候选值

输入：《炼丹系统·第六版设计定稿》中的数值设计原则与第三步配置骨架。

本步产出由锚点、派生规则和校验判据组成的数值生成器。一次生成按“锚点→派生值”执行；校验不通过时调整锚点或派生规则后重新生成，不直接修改单个派生结果掩盖问题。

第四步按4.1～4.9依次施工。每个小步完成后提交对应验收材料，由用户确认；未经确认不进入下一小步。

#### 4.1 清点字段归属与数值分层

输入：第三步已经确认的全部运行页签、字段和系统接口。

工作：

- 逐字段清点灵植表、丹方表、丹炉表、除渣力、丹毒池、成丹率描述、系统参数和属性配置；
- 建立字段矩阵，至少记录“工作簿、页签、字段、数值语义、分类、唯一保存位置、上游锚点、派生规则、初值阶段、最终反推阶段、人工覆盖、校验用途”；
- 将ID、境界、品质、材位、五行、五味和成丹性值列为结构坐标，不计入数值层；
- 将其余字段划分为锚点、派生值和校验指标；人工例外作为派生值的覆盖标记，不单独构成一层；
- 明确君材自身药力与君材目标药力、丹方神识要求与丹炉神识门槛、价格输入与参考售价输出等不同语义；
- 明确丹炉、炼丹术和灵植术均保存在除渣力页签，分别使用独立的来源ID、基准境界和境界差；
- 列出不进入第六版生成器的旧页签、旧字段和旧参数；
- 确定锚点、派生公式、试算结果和校验结果使用的工作载体。

产出：《第四步字段归属与数值分层矩阵》、跨表关系图、旧数据隔离清单和计算载体方案。

验收机制：逐表检查字段无遗漏、唯一归属无冲突、数值分层和生命周期明确、旧数据已隔离。提交用户确认后进入4.2。

不通过时：返回第三步修正字段或引用；仅属分类、归属和载体问题时留在4.1修正。

#### 4.2 确定玩法与经济锚点的定义

输入：通过验收的4.1成果与设计定稿中的玩法目标。

工作：

- 定义高药力省位、低药力洁净、易调性和低成本路线分别依靠哪些数值形成；
- 定义普通丹头、大丹头、基础炉、宽炉、偏性炉和净炉的适用场景；
- 定义各境界、各五味期望连续服丹数量、效果减半位置和自然消退节奏；
- 定义同境炼制、高一境回炼和更高境回炼低境丹的收益边界；
- 区分材料、君材、丹头和丹炉价格锚，与丹药参考售价的成本、药效价值、稀缺性三部分；
- 定义六品质的自用、出售、稀缺和升品关系。

产出：《玩法与经济锚点定义表》，只写可计算的目标和比较关系，不填写具体量级。

验收机制：逐项确认每个玩法目标都有对应数值抓手，不存在两个互相冲突的目标。提交用户确认后进入4.3。

不通过时：玩法目标问题返回第一步；数据抓手缺失返回第三步；其余留在4.2修正。

#### 4.3 确定境界与品质的基准值和比例

输入：通过验收的4.2锚点定义。

工作：

- 确定八个角色境界的总体量级，其中筑基至大乘为七个可炼境界；
- 确定七个可炼境界的药力、绝对杂质、除渣力、毒池、药效和价格基准；
- 确定六品质系数及每方三个开放品质之间的档差；
- 确定目标药力、材料药力、材料绝对杂质、丹头容量和炉膛宽度的基础比例；
- 确定成丹、升品、毒池节奏、跨境衰减和价格使用的基准单位、取整位置与候选区间；
- 明确哪些基准值固定为锚点，哪些只能在第十一步根据分布反推。

产出：《境界与品质基准表》及全部候选比例、区间和取整规则。

验收机制：检查境界、品质和各模块使用同一量级体系，所有比例均能追溯到4.2目标。提交用户确认后进入4.4。

不通过时：目标定义问题返回4.2；量级和比例问题留在4.3修正。

#### 4.4 建立材料、容量、炉型与除渣派生规则

输入：通过验收的4.3基准值和比例。

工作：

- 由境界、品质、材位、路线定位和药性生成普通灵植的药力、绝对杂质与价格；
- 由境界和君材品质生成君材目标药力、君材自身药力、药性、绝对杂质与价格；
- 由境界、品质和定位生成丹头容量、稀有度与价格；
- 由最高可炼境界、品质和炉型生成丹炉炉膛、神识门槛与价格；
- 由来源ID、基准境界、品质、熟练度和境界差分别生成丹炉过滤率、炼丹术除渣力和灵植术除渣力；
- 明确各派生字段的上下限、离散档位、取整顺序和人工覆盖条件。

产出：《材料与能力派生规则表》，每个输出字段均列出上游锚点和计算方法。

验收机制：抽取各境界、品质和路线样例，逐项复算派生结果，确认三种除渣来源独立结算。提交用户确认后进入4.5。

不通过时：基准量级问题返回4.3；派生公式问题留在4.4修正。

#### 4.5 建立纯度、产出、丹毒、药效与价格派生规则

输入：通过验收的4.4派生规则和设计定稿中的结算公式。

工作：

- 建立材料组合到总药力、炉后杂质、剩余杂质和纯度的计算链；
- 建立材料分布到最低纯度、最低杂质和神识要求候选值的生成方法；
- 建立基础成丹率、纯度增益、成丹率上限、固定升品率与各品质期望产量的关系；
- 建立单枚剩余杂质、毒池容量、效果减半和每日消退之间的关系；
- 建立丹效数值、持续时间、固定效果和药效价值的关系；
- 建立路线期望成本、药效价值、稀缺性与参考售价的关系；
- 明确第四步生成初值与第十一步根据分布反推最终候选值的字段生命周期。

产出：《结算与经济派生规则表》及逐公式取整、边界和生命周期说明。

验收机制：从输入到参考售价逐项手算一组完整链路，确认每个中间值只有一个来源。提交用户确认后进入4.6。

不通过时：输入派生值问题返回4.4；基准量级问题返回4.3；结算规则问题返回第一、二步；其余留在4.5修正。

#### 4.6 确定校验判据与回调对象

输入：通过验收的4.2～4.5成果及第二步数学验收指标。

工作：

- 为`P/U`、`N/Nmax`、`A/Zf`、`Q−Qmin`、最低杂质触底率和`D/Cpool`设定目标区间；
- 为死方率、有效解数量、代表路线数量、支配材料数量、丹头覆盖和炉型覆盖设定判据；
- 为七个可炼境界纵向增长、高境回炼低境丹、成丹、升品、期望成本、参考售价和利润设定判据；
- 设定“刷低品质赌升品不得替代直接炼高品质”的比较判据；
- 为省位、洁净、易调性和低成本路线设定成立条件；
- 为每项判据指定失败时需要调整的锚点或派生规则。

产出：《数值校验与回调矩阵》。

验收机制：逐项检查判据可计算、目标清晰、回调对象唯一或有明确优先级。提交用户确认后进入4.7。

不通过时：判据无法计算则返回4.1；判据与目标不一致则返回4.2；区间不合理则返回4.3；其余留在4.6修正。

#### 4.7 最小候选数据试算

输入：通过验收的4.1～4.6成果。

工作：

- 使用最少量的境界、品质、材料类型、君材、丹头、丹炉、技能和丹方候选值贯通全部生成关系；
- 至少构造省位、洁净、易调性和低成本路线；
- 分别计算丹炉、炼丹术和灵植术的境界差；
- 检查剩余杂质能生成毒池候选容量，路线期望成本能生成参考售价；
- 将每个输入、中间值、取整位置和输出保存为标准手算案例；
- 按4.6判据记录框架不能闭合或取舍消失的位置。

产出：《最小框架试算表》与标准手算案例。

验收机制：提交完整输入、计算过程、结果和问题清单，由用户判断数值关系与玩法取舍是否符合预期。用户确认后进入4.8。

不通过时：按4.6回调矩阵返回4.2～4.5对应环节，修改后重跑4.7。

#### 4.8 生成并填写第一版基准候选值

输入：通过验收的4.7试算结果。

工作：

- 生成七个可炼境界、六品质、材料类型、君材、丹头、炉型、除渣、毒池、药效与经济所需的第一版基准候选值；
- 将已有唯一归属的跨表参数写入对应工作配置；
- 输出第五至第八步批量铺设全量配置所需的区间、档位、生成参数和人工覆盖规则；
- 标记需要在第十一步根据全量组合分布反推的字段；
- 标记特殊丹药、特殊丹头、特殊炉型和经济例外。

产出：第一版基准候选值、配置写入清单和第五至第八步生成输入。本步不代替第五至第八步铺设1050行材料与2625条丹方品质行。

验收机制：按模块提交候选值及其上游依据，确认每项均可由已验收规则生成。提交用户确认后进入4.9。

不通过时：数值量级返回4.3；派生结果返回4.4或4.5；目标不成立返回4.2。

#### 4.9 汇总跨表一致性并形成全量施工输入

输入：通过验收的4.1～4.8全部成果。

工作：

- 检查每个需要填值的字段均有唯一归属、上游锚点、派生规则、数值状态和后续反推阶段；
- 检查设计定稿、配置骨架、字段说明和第四步生成器的字段名称、单位、取整和引用一致；
- 检查第五至第八步的脚本生成项、人工配置项和特殊覆盖项已经分开；
- 汇总第五至第八步所需的正式施工清单、生成顺序和回归范围；
- 将第四步形成的数值原则、比例、区间和待定参数同步回写设计定稿的新版本。

产出：《第四步跨表数值框架与第一版候选值汇总》、第五至第八步施工输入，以及同步更新的设计定稿。

验收机制：逐表核对无重复保存、无缺失输入、无旧数据混入；用户确认第四步整体成果后，第四步完成并进入第五步。

不通过时：按问题来源返回4.1～4.8对应小步，修改后重做受影响的后续小步。

第四步产出方式：锚点、派生规则和校验判据人工审定；机械计算由可读的计算表或脚本执行。计算工具只服务数值设计，不属于游戏功能实现。

### 第五步：全量配置普通灵植

输入：第四步生成器确定的材料类型、候选区间、境界倍率和品质比例。

工作：

- 配置臣材的五行及固有数值；
- 配置使材的五味及固有数值；
- 配置佐材的药力、药性与绝对杂质；
- 按高药力、低杂质、易调性和低成本等类型生成候选材料；
- 检查各行、各味与正负药性覆盖；
- 填写第一版候选价格；
- 先按材料池规则脚本铺行，再逐池人工校订名称、分布和取舍。

通过条件：全量普通灵植完成第一版候选配置；同池材料的定位可区分，不存在生成规则造成的直接全面支配。

### 第六步：配置君材与丹头

输入：第四步目标药力、君材固有值和丹头容量规则，以及第五步材料药力带。

工作：

- 配置各境界、各基础品质君材的目标药力与固有数值；
- 配置丹头容量、稀有度、定位和第一版候选价格；
- 建立特殊丹头的丹方引用关系；
- 按境界与品质脚本建立基础行，再人工配置定位和特殊引用。

通过条件：君材与丹头全量候选配置完成；基础容量、大容量和特殊丹头具有不同的预期用途。

### 第七步：配置丹炉、除渣与丹毒候选值

输入：第四步炉膛、除渣、剩余杂质和毒池派生规则。

工作：

- 配置丹炉最高可炼境界、炉膛、神识门槛、价格、启用状态和定位；
- 在除渣力表配置炼丹术、灵植术和丹炉的同境六品质基础值；
- 三种除渣来源分别按自身基准境界计算境界差；
- 在丹毒池配置各境界五味容量与每日消退率；
- 配置成丹率描述、炼丹系统参数和炼丹相关属性接口；
- 填写第一版候选过滤率、技能除渣力、毒池容量、消退率和价格。

通过条件：各数据只有一个保存位置；炉膛形成基础炉、宽炉、偏性炉、净炉等定位；全部候选值符合第四步生成规则。

### 第八步：配置丹方品质行

输入：第四步丹方、品质、药效和经济派生规则，以及第五至第七步全量候选配置。

工作：

- 脚本生成875个基础坐标及每方三个开放品质行，共用`recipe_id`；
- 每行完整配置境界、品质、君材品质、臣行、使味、成丹性值、启用状态和指定丹头；
- 人工配置正式丹名、规则小名、作用说明、丹效行为、参数、数值和持续时间；
- 填写第一版候选跳档率、最低纯度、最低杂质、神识要求、基础成丹率、成丹率上限和参考售价；
- 默认投料在第十二步生成，不保存默认投药顺序。

通过条件：875个基础坐标与2625个丹方品质行结构完整；机械字段可重建，人工内容已校订，第一版候选数值已填写。

### 第九步：七个可炼境界纵向切片与跨境横向切片

输入：第五至第八步全量候选配置。

方法：

- 每个可炼境界选择覆盖五行、五味、正负药性、开放品质和炉型的代表丹方品质行；
- 对同一代表丹方定向寻找最少份数、低剩余杂质、易配平和低成本等不同路线；
- 比较同境炼制、高一境回炼、更高境回炼低境丹时的丹炉与技能除渣、纯度、成丹率、剩余杂质和成本；
- 分别计算丹炉、炼丹术和灵植术的境界差；
- 对每个境界记录`P/U`、`N/Nmax`、`A/Zf`、最低杂质触底、`Q−Qmin`、`D/Cpool`、期望产量、期望成本和参考售价；
- 检查跨境增长是否改善结果但不使低境材料选择、丹头、炉型、毒池和价格失去意义；
- 形成可供后续批量脚本对照的标准计算案例。

本步只验证数值设计，不测试游戏功能代码、界面或存档状态递推。

通过条件：筑基至大乘七个可炼境界均有可计算的代表路线；同一代表丹方存在符合其定位的多种方案；纵向成长和跨境回炼符合第四步目标区间；没有发现需要推翻数值生成器结构的问题。

### 第十步：第一轮全量组合纸推

输入：全量候选配置与第九步标准计算案例。

方法：

- 建立读取正式表结构的批量结算与代表解搜索脚本，并用第九步标准案例逐项对照；
- 对全部启用丹方品质行执行约束求解，同时统计875个基础坐标的结构覆盖；
- 每行寻找最少份数、低剩余杂质、易配平和低成本代表解；
- 用分层抽样观察解分布；
- 用剪枝状态搜索判定代表解的安全投药顺序；
- 不生成、保存或统计每行的全部配法。

份数指标：

- `N_struct`：不读取最低纯度，满足药力、药性与安全顺序的最少份数；
- `N_clean`：低剩余杂质代表路线的份数。

正式运行前确定求解变量边界、代表解目标函数、抽样规模和停止条件。

检查：

- 启用丹方品质行死方为0，每个代表解至少有一条安全顺序；
- 875个基础坐标均有启用品质行和合理炉型；
- 同池材料不存在全面支配；
- 高药力省位、低药力洁净、易调性和低成本路线按预期出现；
- 普通丹头、大丹头和各类炉型均有独立场景；
- 基础炉与高境炉覆盖符合设计定稿；
- 三种除渣来源的境界差结算正确，来源低境时贡献为0；
- 统计第四步确定的全部配方、解空间、产出和稳定性指标；
- 不存在单一选材、份数或炉型策略通吃；
- 关键候选参数变化不造成大面积死方、全过、路线消失或普遍触底。

通过条件：全部启用丹方品质行数学可行；脚本与第九步标准案例一致；输出代表解、覆盖率、分布指标、边界问题和敏感性结果。

### 第十一步：反推并回调判定类数值

输入：第九步切片结果与第十步全量组合分布。

工作：

- 反推各丹方品质行的最低纯度、最低杂质和神识要求；
- 反推炼丹术与灵植术的基础除渣力及熟练参数；
- 反推丹炉各品质过滤率与低境界炼丹倍率；
- 反推各丹方品质行的基础成丹率、成丹率上限与固定升品率；
- 根据各境界、五味和路线的剩余杂质分布及目标服丹节奏，反推毒池容量、每日消退率和取整规则；
- 计算`N_pass`：最低纯度确定后，满足全部硬条件的最少份数；
- 校验每行至少存在一套在最低杂质生效后仍达到最低纯度的合法配方；
- 校验普通丹门槛可弥补性：低一档炉＋该境满熟练技能＋同境最优材料配法的可达纯度不低于该行门槛；
- 用回调值重跑第九、十步，复查路线、跨境增长、最低杂质触底率、`A/Zf`和`D/Cpool`。

若单项参数回调无法同时满足目标区间，退回第四步修改锚点、派生规则或校验判据，不用局部补丁掩盖数值框架问题。

通过条件：各境界、品质和路线进入第四步目标区间；全部启用丹方品质行仍有合法解；纵向成长、跨境回炼、毒池节奏和产出关系成立。

### 第十二步：生成默认方并验证安全顺序

输入：通过第十一步回调的候选配置。

工作：

- 为每个启用丹方品质行选择教学可读、材料可得的默认投料；
- 搜索一条安全投药顺序，只把材料ID和数量写入丹方表；
- 将安全顺序与全链路验算结果保存到验证报告，不写入丹方表；
- 按最终药力、药性、炉膛、纯度、最低杂质和丹头条件复核；
- 验证当前“一种臣材＋一种佐材＋一种使材”的默认字段是否足够；不足时退回第三步扩展表结构并重跑第四至第十二步。

通过条件：全部默认方存在安全顺序并满足全部数值条件；丹方表只保存默认材料与数量。

### 第十三步：第二轮玩法纸推与交互流程设计

输入：默认方、自由配方、代表路线和正式候选结算链。

工作：

- 设计逐份投药、实时炉相、配置检查、确认扣料、正式失败、升品、批次选择、保存配方和自动炼制流程；
- 纸推普通玩家使用默认方的成功体验；
- 纸推熟手能否通过选材、设备和顺序改善结果；
- 检查玩家能否根据规则与数值理解配置失败和炼制结果；
- 检查是否存在简单操作或数值策略通吃。

失败归因与回退：

- 规则或公式问题退回第一、二步；
- 字段或引用结构问题退回第三步；
- 数值生成器、锚点或派生规则问题退回第四步；
- 材料、君材、丹头、丹炉或丹方分布问题退回第五至第八步；
- 判定类数值问题退回第十一步；
- 默认方问题退回第十二步；
- 交互流程问题留在本步修改。

通过条件：默认玩法与进阶玩法均成立；发现的问题已按来源回退，不用参数调整掩盖规则、结构或数值生成器问题。

### 第十四步：第三轮经济与资源纸推

输入：通过玩法纸推的配置与产量分布。

工作：

- 核算灵植、君材、丹头、丹炉和代表配方成本；
- 核算默认方、洁净方、省位方、低成本方和高风险方的收益；
- 将成丹失败率、升品率和剩余杂质折价纳入产值；
- 将神识与材料决定的批次上限纳入产量核算；
- 比较低品质炼制后升品与直接炼制高品质的期望产量、成本和利润；
- 确定灵植、君材、丹头、丹炉和各丹方品质行的正式价格；
- 验证六品自用、出售和稀缺定位；
- 验证稀有资源对高品产量的控制；
- 验证高境角色炼低境丹对低境经济的影响。

产出方式：成本、概率和产量由设计验算脚本计算；路线定位、稀缺度和价格由人工审定。

通过条件：主要路线均有经济定位，不出现单一路线垄断、低境经济失效或未经设计的升品套利。

### 第十五步：联合压力测试与回调

输入：数学、玩法和经济三轮结果。

工作：按第四部分回归矩阵重跑所有受影响环节，直到设计定稿、配置表、验证结果和交互案一致。

通过条件：不存在死方、失效默认方、无脑材料、统治炉型、异常产量或利润漏洞。

### 第十六步：正式交互案与最终审定

输入：通过联合回调的全部成果。

工作：

- 形成正式《炼丹系统交互案》；
- 回写经联合回调确认的正式配置值；
- 完成纸推与数值验证报告；
- 回查设计定稿、配置、交互与程序接口的一致性；
- 将仍未决定的内容保留在设计定稿“待定参数”。

通过条件：正式成果齐全，全部现行结论均能在设计定稿中找到唯一出处。

## 四、回归矩阵

| 改动 | 必须重跑 |
|---|---|
| 公式、数据职责或数值生成方向 | 从第二步重新核对，并重跑全部下游步骤 |
| 配置字段、引用或默认材料容量 | 从第三步重建骨架，并重跑全部受影响的生成与验证 |
| 锚点、派生规则或校验判据 | 从第四步重生成候选值，并重跑最小试算、全量配置、切片和纸推 |
| 普通灵植 | 组方、代表解、安全顺序、支配检查、成本与价格 |
| 君材目标药力 | 份数、路线、品质成功率、升品产量、成本与价格 |
| 丹头容量 | 高药力、低杂质、易调性和低成本路线 |
| 炉膛 | 安全顺序、丹炉覆盖和跨境回炼 |
| 过滤率、技能除渣或境界差倍率 | 剩余杂质、纯度、成丹率、毒池和跨境回炼 |
| 最低杂质 | 纯度、成丹率、毒池、售价 |
| 丹方神识要求 | 批次产量、成本与利润 |
| 最低纯度 | 死方、默认方、成丹率 |
| 成丹率 | 品质产量、成本与利润 |
| 升品率或每方开放品质 | 品质产量、售价、稀缺度与利润 |
| 毒池容量、消退率或取整 | 自用节奏与每日消退 |
| 丹效行为或数值 | 价格、自用与出售定位 |
| 价格 | 路线选择、成本、利润和高低境经济 |
| 交互流程 | 第二轮玩法纸推与正式交互案 |
