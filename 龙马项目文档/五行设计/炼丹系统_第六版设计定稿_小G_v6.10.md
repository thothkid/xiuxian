# 第一部分 · 系统规则

## 一、炼丹闭环

每次炼丹依次完成：

1. **组方**：在丹头容量内配置君、臣、佐、使，满足丹方的五行、五味、药力、最终药性和最低纯度。
2. **投药**：逐份安排臣、佐、使的顺序，使累计药性始终处于丹炉炉膛范围。
3. **成丹**：配置通过后扣除材料，判定成丹率；成功后判定升品并生成丹药。
4. **服用**：丹药的剩余杂质按五味进入人物丹毒池。

## 二、材料职责

每炉固定投入一份君材、一个丹头，以及若干份臣材、佐材和使材。

| 类别 | 数量与属性 | 职责 |
|---|---|---|
| 君材 | 每炉一份；具有境界、品质、目标药力、药力、药性、绝对杂质 | 确定本炉境界、基础品质和药力门槛；其药性构成开炉初值 |
| 丹头 | 每炉一个；不占臣佐使份数 | 给出臣佐使最大承药份数；可作为特殊丹方凭证 |
| 臣材 | 至少一份；每份具有一个五行及药力、药性、绝对杂质 | 决定丹药作用 |
| 使材 | 至少一份；每份具有一个五味及药力、药性、绝对杂质 | 决定丹药作用部位 |
| 佐材 | 可选；具有药力、药性、绝对杂质 | 补充药力、调整药性 |

君材按“境界×品质”配置，同境同品质的丹方通用。

五行职责：

| 五行 | 作用 |
|---|---|
| 金 | 离：分离、清除、守界 |
| 木 | 生：生长、修复、连接 |
| 水 | 行：输送、渗透、恢复 |
| 火 | 化：激发、催化、破旧 |
| 土 | 载：承载、积累、稳固 |

五味职责：

| 五味 | 部位与作用域 |
|---|---|
| 甘 | 丹田：修为与境界结构 |
| 辛 | 气脉：灵力运行与战斗回路 |
| 咸 | 骨底：肉身根基、寿元与灵根 |
| 苦 | 心神：神识及泄浊 |
| 酸 | 血肉：筋骨、气血与肉身损伤 |

## 三、丹方、品质与丹效

丹方表一行表示一个基础丹方坐标的一个基础成丹品质。同一基础丹方的三个开放品质行共用丹方ID，每行完整保存本品质的君材品质、成丹条件、默认投料、成丹率、升品率、丹效和参考售价；行间不继承空值。默认投料不保存投药顺序。

丹方品质行的硬条件：

1. 丹方品质行与丹炉均已启用，丹炉最高可炼境界不低于丹方境界，玩家神识达到丹炉驱动门槛；
2. 君、臣、佐、使和丹头均属于丹方境界；君材与丹头品质均等于本行君材品质；
3. 全部臣材符合本行臣五行，全部使材符合本行使五味；
4. 总药力达到君材目标药力；
5. 最终药性精确等于本行成丹性值；
6. 逐份投药全程处于炉膛范围；
7. 纯度达到本行最低纯度；
8. 臣佐使份数不超过丹头容量；
9. 指定丹头条件满足。

当前世界观有八个大境界，炼气暂不开炼丹：

```text
7个可炼境界 × 5种五行 × 5种五味 × 5档最终药性 = 875个基础丹方坐标
```

全局品质为凡、灵、玄、仙、神、道六品。每张基础丹方开放其中三品：

```text
875个基础坐标 × 每方3品 = 2625个丹方品质行
```

同一基础丹方的三个开放品质分别配置最低纯度、最低杂质、神识要求、基础成丹率和成丹率上限。多五行、多五味及其他特殊丹方使用独立扩展配置。

未指定丹头ID时，同丹方境界且品质等于本行君材品质的丹头均可使用；指定丹头ID时，只接受该丹头。

本行君材品质决定所需君材，所用君材的品质决定本炉基础成丹品质。正式炼制成功后，按当前行的固定升品率（万分比）执行一次跳档判定：命中则读取同一丹方相邻更高的启用品质行生成成品；未命中则读取当前行。最高启用品质行的升品率为0。

## 四、药力、药性与炉膛

### 1. 药力

```text
总药力 P = Σ（君、臣、佐、使材料份数 × 单份药力）
药力条件：P ≥ 君材目标药力 U
```

### 2. 药性

```text
最终药性 = Σ（君、臣、佐、使材料份数 × 单份药性）
```

单份药性为−4～+4的整数，丹方最终药性为−2～+2。

### 3. 炉膛

```text
炉膛范围 = [承寒下限，承热上限]
```

君材入炉后形成初始累计药性并检查炉膛；臣、佐、使每投入一份，先把该份药性加入累计值，再检查炉膛。任一步累计值低于承寒下限或高于承热上限，该顺序不通过。全部投药结束时，累计药性必须等于本行成丹性值。

丹炉的最高可炼境界不低于丹方境界时可以使用。炉膛读取丹炉表；丹炉基础过滤率按丹炉ID读取除渣力表，并按第六节的境界差规则换算。

神识达到丹炉驱动门槛后取得该炉使用资格。

## 五、配置、扣料与结果

新组合先进入自由炼制的配置阶段：

1. 放入君材和丹头；
2. 配置臣、佐、使的材料、份数和顺序；
3. 系统逐项检查全部硬条件，每投入一份材料检查一次炉膛；
4. 配置未通过时显示具体原因，材料保持未消耗状态；
5. 配置通过后，玩家可以确认正式炼制。

确认正式炼制时，一次性扣除本炉全部材料并执行一次成丹率判定：

- 判定成功：按当前丹方品质行判定升品并产出丹药；
- 判定失败：产丹为零，材料不退。

同一材料集合的总药力、总杂质、最终药性、纯度、剩余杂质和基础丹效固定。投药顺序的结算结果是该集合能否通过炉膛检查。

## 六、杂质、纯度、成丹率与升品

### 1. 除渣境界换算

炼丹术、灵植术和丹炉分别按自身基准境界计算：

```text
境界差 Δ = 除渣来源基准境界序号 − 丹方境界序号

Δ＜0：该来源贡献为0
Δ＝0：境界倍率 M＝1
Δ＞0：境界倍率 M＝K^Δ

K = 系统参数“参数_低境界炼丹”
```

技能熟练度以0～100的整数百分数`p`表示，熟练参数`S`分别读取“参数_炼丹术熟练”和“参数_灵植术熟练”：

```text
技能实际除渣力
= 向下取整[本品质基础除渣力 ×（10000＋p×S）÷10000 × M]

丹炉有效过滤率 Fe
= clamp[0，向下取整（本品质基础过滤率 × M），10000]
```

基础除渣力和基础过滤率按本次炼制的丹方品质行读取对应品质列。成丹后的跳档不回改本炉除渣结算。

### 2. 杂质

```text
总杂质 Z = Σ（君、臣、佐、使材料份数 × 单份绝对杂质）
炉后杂质 Zf = 向上取整[Z ×（10000 − Fe）÷10000]
技能剔杂 A = 炼丹术实际除渣力 + 灵植术实际除渣力
剩余杂质 D = max（本行最低杂质 L，Zf − A）
```

丹炉基础过滤率使用万分比；炼丹术与灵植术使用绝对剔杂点数。本行最低杂质`L ≥ 1`。

### 3. 纯度

```text
纯度 Q（万分比）
= clamp[0，10000 − 向上取整（D × 10000 ÷ P），10000]
```

纯度达到本行最低纯度后取得正式炼制资格；超出的纯度余量进入成丹率公式。

### 4. 成丹率

读取当前丹方品质行的最低纯度`Qmin`、基础成丹率`B`和成丹率上限`C`：

```text
成丹率 R
= min[C，B＋向下取整（(C−B) × (Q−Qmin) ÷ (10000−Qmin)）]
```

成丹率使用万分比整数；实际纯度等于最低纯度时，成丹率等于`B`。

### 5. 升品

每次成丹成功后读取当前行`jump_tier_prob`执行一次升品判定。命中时读取同一丹方相邻更高的启用品质行；未命中时读取当前行。最终丹名、品质、丹效和参考售价读取最终品质行。本炉实际纯度和剩余杂质`D`写入成品。

### 6. 批次炼丹

```text
神识批次上限 = 向下取整（玩家当前神识 ÷ 本行神识要求）
实际批次数 ≤ min（神识批次上限，材料可完整复制的配方套数）
```

每批完整复制单丹配方，每枚消耗一套材料，并分别判定成丹与跳档。同一配方产出的同品质丹药具有相同纯度和剩余杂质。

## 七、服用与五味丹毒池

丹药保存剩余杂质，人物保存五味绝对杂质。服用时：

```text
入池点数 = 该枚丹药的剩余杂质
该味丹毒 T = clamp[0，向下取整（该味绝对杂质 I × 10000 ÷ 当前境界该味池容量），10000]
```

角色境界变化时保留绝对杂质`I`，读取新境界容量重算丹毒。

五味使用独立毒池。服用前读取该味丹毒`T_before`和系统参数“参数_效果减半丹毒”`H`：

- `T_before ≥ 10000`：禁止服用；
- `H ≤ T_before ＜ 10000`：本枚丹药效果减半；
- `T_before ＜ H`：本枚丹药效果完整生效。

允许服用时，先按服用前丹毒执行本枚丹效，再把本枚剩余杂质加入对应绝对杂质池，并以池容量封顶；新增占用从下一枚丹药开始参与判定。

```text
服用后绝对杂质 I' = min（该味池容量，I + D）
每日消退点数 = 该味池容量 × 该味每日消退率 ÷ 10000
```

每日消退率按境界、五味配置，单位为万分比；每日消退点数的整数取整方式待定。一个游戏日对应一现实小时。

## 八、炼制方式

| 方式 | 规则 |
|---|---|
| 自由炼制 | 玩家自行投料，系统按君材境界与品质、臣五行、使五味和最终药性定位丹方品质行 |
| 自动炼丹 | 系统默认方读取材料和数量并在运行时搜索安全顺序；玩家保存方原样重放自由炼制成功时保存的逐份投药顺序 |

自动炼丹开放给系统默认方，以及玩家自由炼制成功并主动保存的个人配方，可批次炼丹。两种方式共用同一套硬条件、扣料、成丹、升品和批次规则。

# 第二部分 · 数值设计原则

本部分规定正式数值的生成关系、取整方式、约束和验证目标。

## 一、数值轴与取整

设境界倍率为`R[r]`，当前候选：

```text
R[r+1] ≈ 3 × R[r]
```

炼气为第一境，筑基为首个配置境界。目标药力、单份药力、单份杂质、最低杂质、技能绝对剔杂值和毒池容量使用对应境界的绝对量级。

药性、丹头份数、炉膛、纯度万分比、成丹率和升品率保持跨境同量级。

```text
君材目标药力 U[r,q]
= 筑基凡品基准药力 × R[r] × 品质系数 Q[q]
```

`Q[q]`随品质递增，增幅小于境界倍率，并使基础丹头能够承载高品目标。

| 品质 | 定位 |
|---|---|
| 凡 | 教学保底 |
| 灵 | 普通玩家稳定自用 |
| 玄 | 熟手主力自用与稳定获利 |
| 仙 | 高成本、高风险，偏出售 |
| 神 | 满配约三成，赌博品质 |
| 道 | 极稀少顶点成果，不进入普通量产经济 |

取整规则：

- 筑基凡品目标药力建议不低于1000；
- 药力、杂质、剔杂、剩余杂质和毒池容量使用整数；
- 百分比使用万分比整数；
- 炉后杂质和纯度损失向上取整；
- 技能实际除渣力、丹炉有效过滤率和成丹率加成向下取整；
- 纯度不足一万分之一按不足处理；
- 最终值夹在合法上下限内。

## 二、材料数值

### 药力

- 同境材料使用同一基础药力带，总跨度约3～5倍；
- 同品质同时配置高、低药力材料；
- 保留补尾数、调药性和铺投药路线的小面额；
- 材料品质等比缩放药力与绝对杂质：高品质灵植药力更高、绝对杂质同比更高，杂质密度跨品质不变；高品的洁净收益由丹炉过滤能力与技能除渣承担，不来自材料自身更净；
- 常见组方目标为约5～7份臣佐使，具体值由组合验证确定。

### 药性

- 单份取−4～+4，丹方目标取−2～+2；
- 同境、同品、同材位、同行或同味覆盖不同药性与药力粒度；
- 每种五味均配置寒、热使材；
- 佐材覆盖九档药性。

### 杂质

```text
杂质密度 = 单份杂质 ÷ 单份药力
```

同境、同品质的直接竞争材料须形成以下取舍：

- 高药力路线节省份数，配置较高杂质密度或较难使用的药性；
- 低药力路线占用更多份数，配置较低杂质密度；
- 易调性材料不得同时取得最高药力和最低杂质；
- 同一竞争池不存在药力、药性易用度和杂质三项全面领先者；
- 各行、各味及正负药性两侧分布均衡。

## 三、君材、丹头、丹炉与技能

君材目标药力是对应品质的药力门槛。品质越高，目标药力越高。

丹头以整数配置臣佐使总份数上限。普通丹头覆盖多数基础丹方；大丹头为更多材料位和特殊丹药提供配置空间。具体档位由全坐标组合结果确定。

丹炉的炼丹数值为炉膛与过滤率，神识门槛是使用条件。同档丹炉在炉膛和过滤率之间形成宽炉、偏性炉、净炉等定位，不设置同时全面领先的炉型。

炼丹术、灵植术和丹炉共用境界差倍率。来源境界低于丹方境界时贡献为0；同境使用基础值；高于丹方境界时按逐境倍率增长。两项技能分别配置同境基础除渣力和熟练参数。常规配法不得因除渣力过高而普遍触及最低杂质；具体比例由组合验证反推。

## 四、纯度、成丹率、升品与丹毒参数

每个丹方品质行的最低纯度从合法组合分布确定：

- 同境同品基础坐标初配使用统一门槛；
- 突破、永久强化、洗灵根等高价值丹可以单独提高；
- 门槛低于该坐标最干净可达值；
- 设备门槛丹的最低纯度位于低档炉最优值与目标炉合理值之间。

各丹方品质行的基础成丹率、成丹率上限和纯度增幅根据合法组合的纯度分布确定，并符合六品定位。

固定升品率与材料成本、成丹率、丹效和参考售价联合反推；经济纸推同时比较低品炼制后升品与直接炼制高品的预期产出和收益。

各境界、各五味毒池根据典型单枚剩余杂质、使用频率和期望可服枚数配置。

## 五、材料混用与养成定位

君、臣、佐、使使用目标丹方境界的材料；同境内允许不同品质臣佐使混用。

材料为每炉消耗，炼丹术与灵植术为长期成长，丹炉为长期装备。辅材品质通过绝对杂质影响纯度、成丹率和服用负担；炉型通过炉膛改变可用投药路径。

## 六、待定参数

- 筑基基础药力单位、境界倍率最终值、六品目标药力系数；
- 每张基础丹方开放的三个品质及道品启用安排；
- 材料药力、药性与绝对杂质分布；
- 君材目标药力、丹头容量、炉膛、过滤率和丹炉神识门槛；
- 各丹方品质行的最低杂质、最低纯度、神识要求、基础成丹率和成丹率上限；
- 两项技能的基础除渣力、熟练参数和低境界炼丹倍率；
- 各丹方品质行的固定升品率；
- 五味毒池容量与自然消退率；
- 每日消退点数的整数取整方式；
- 默认投料；同一材位是否需要多种默认材料由纸推结果确定。
