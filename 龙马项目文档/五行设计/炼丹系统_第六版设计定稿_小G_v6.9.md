# 第一部分 · 系统规则

## 一、炼丹闭环

每次炼丹依次完成：

1. **组方**：在丹头容量内配置君、臣、佐、使，满足丹方的五行、五味、药力、最终药性和最低纯度。
2. **投药**：逐份安排臣、佐、使的顺序，使累计药性始终处于丹炉炉膛范围。
3. **成丹**：配置通过后扣除材料，判定成丹率；成功后判定升品并生成丹药。
4. **服用**：丹药的剩余杂质按五味进入人物丹毒池。

## 二、材料职责

每炉固定投入一份君材、一个丹头，以及若干份臣材、佐材和使材。

| 类别 | 数量与属性 | 职责 |
|---|---|---|
| 君材 | 每炉一份；具有境界、基础成丹品质、目标药力、药力、药性、绝对杂质 | 确定本炉境界、基础品质和药力门槛；其药性构成开炉初值 |
| 丹头 | 每炉一个；不占臣佐使份数 | 给出臣佐使最大承药份数；可作为特殊丹方凭证 |
| 臣材 | 至少一份；每份具有一个五行及药力、药性、绝对杂质 | 决定丹药作用 |
| 使材 | 至少一份；每份具有一个五味及药力、药性、绝对杂质 | 决定丹药作用部位 |
| 佐材 | 可选；具有药力、药性、绝对杂质 | 补充药力、调整药性 |

君材按“境界×基础品质”配置，同境同基础品质的丹方通用。

五行职责：

| 五行 | 作用 |
|---|---|
| 金 | 离：分离、清除、守界 |
| 木 | 生：生长、修复、连接 |
| 水 | 行：输送、渗透、恢复 |
| 火 | 化：激发、催化、破旧 |
| 土 | 载：承载、积累、稳固 |

五味职责：

| 五味 | 部位与作用域 |
|---|---|
| 甘 | 丹田：修为与境界结构 |
| 辛 | 气脉：灵力运行与战斗回路 |
| 咸 | 骨底：肉身根基、寿元与灵根 |
| 苦 | 心神：神识及泄浊 |
| 酸 | 血肉：筋骨、气血与肉身损伤 |

## 三、丹方、品质与丹效

基础丹方保存境界、臣五行、使五味、最终药性、最低纯度、最低杂质、神识要求、指定丹头引用、默认投料、古意描述和白话说明。

基础丹方的硬条件：

1. 全部臣材符合指定五行；
2. 全部使材符合指定五味；
3. 总药力达到君材目标药力；
4. 最终药性精确等于丹方值；
5. 逐份投药全程处于炉膛范围；
6. 纯度达到最低纯度；
7. 臣佐使份数不超过丹头容量；
8. 指定丹头条件满足。

当前世界观有八个大境界，炼气暂不开炼丹：

```text
7个可炼境界 × 5种五行 × 5种五味 × 5档最终药性 = 875个基础丹方坐标
```

全局品质为凡、灵、玄、仙、神、道六品。每张基础丹方开放其中三品，每品对应一条逻辑丹效：

```text
875个基础坐标 × 每方3品 = 2625条逻辑丹效
```

每张丹方保存一条最低纯度，三个开放品质共用。多五行、多五味及其他特殊丹方使用独立扩展配置。

指定丹头ID为空时，同君材境界品质丹头均可通过；填写指定丹头ID时，只接受该丹头。

君材确定基础成丹品质。正式炼制成功后，按当前丹效配置的固定升品率（万分比）执行跳档判定：命中则按同一丹方相邻更高品质的丹效记录生成；未命中按当前丹效记录生成。每方开放品质中的最高一档不配置跳档（升品率为0）。

## 四、药力、药性与炉膛

### 1. 药力

```text
总药力 P = Σ（材料份数 × 单份药力）
药力条件：P ≥ 君材目标药力 U
```

`P`是本炉全部君、臣、佐、使的实际药力总和，并作为纯度公式的药力输入。

### 2. 药性1.03

```text
最终药性 = Σ（材料份数 × 单份药性）
```

单份药性为−4～+4的整数，丹方最终药性为−2～+2。

### 3. 炉膛

```text
炉膛范围 = [承寒下限，承热上限]  
```

君材入炉后形成初始累计药性；臣、佐、使每投入一份，即把该份药性加入累计值。任一步累计值低于承寒下限或高于承热上限（在丹炉表配置），该顺序不通过。

丹炉境界表示最高可炼丹方境界。高境炉可以炼制低境丹方。君、臣、佐、使使用目标丹方境界的材料。

```text
境界差 Δr = 丹炉境界 − 丹方境界
有效过滤率 Fe = min（10000，向下取整[丹炉基础过滤率 F × 1.03^Δr]）
```
注意，这里的1.03直接读系统参数，同时不光是丹炉，还有技能也如此生效，都用同一个系统参数表内容。
炉膛读取当前丹炉配置；过滤按有效过滤率结算。

神识达到丹炉驱动门槛后取得该炉使用资格。

## 五、配置、扣料与结果

新组合先进入手动配置：

1. 放入君材和丹头；
2. 配置臣、佐、使的材料、份数和顺序；
3. 系统逐项检查全部硬条件（每次手动操作投入一个材料检查一次）；
4. 配置未通过时显示具体原因，材料保持未消耗状态；
5. 配置通过后，玩家可以确认正式炼制。

确认正式炼制时，一次性扣除本炉全部材料并执行一次成丹率判定：

- 判定成功：产出丹药（读丹效表有几率跳档升1个品质）；
- 判定失败：产丹为零。

同一材料集合的总药力、总杂质、最终药性、纯度、剩余杂质和基础丹效固定。投药顺序的结算结果是该集合能否通过炉膛检查。

## 六、杂质、纯度、成丹率与升品

### 1. 杂质

```text
总杂质 Z = Σ（材料份数 × 单份绝对杂质）
炉后杂质 Zf = 向上取整[Z ×（10000 − 有效过滤率 Fe）÷ 10000]
技能剔杂 A = 炼丹术剔杂值 + 灵植术剔杂值
剩余杂质 D = max（丹方最低杂质 L，Zf − A）
```

丹炉基础过滤率使用万分比；炼丹术与灵植术使用绝对剔杂点数。丹方最低杂质 `L ≥ 1`。

### 2. 纯度

```text
纯度（万分比）
= clamp[0，10000 − 向上取整（D × 10000 ÷ P），10000]
```

纯度达到丹方最低纯度后取得正式炼制资格；超出的纯度余量进入成丹率公式。

### 3. 成丹率

凡品通过全部硬条件后，成丹率为100%。灵品至道品读取品质基础成丹率 `B[q]`、上限 `C[q]` 与纯度余量：

```text
纯度余量 E =（实际纯度 − 最低纯度）÷（10000 − 最低纯度）
成丹率 = B[q] + E ×（C[q] − B[q]）
```

结果使用万分比整数并向下取整。

### 4. 升品

每次成丹成功后执行一次升品判定：读丹效表固定配置。
读取相邻更高品质的丹效记录；判定未中时读取当前丹效记录。本炉剩余杂质 `D`按实际炼制结果记录在成品上。

### 5. 批次炼丹

```text
神识批次上限 = 向下取整（玩家当前神识 ÷ 丹方神识要求）
实际批次数 ≤ min（神识批次上限，材料可完整复制的配方套数）
```

每批完整复制单丹配方，每枚消耗一套材料，并分别判定成丹与跳档。同一配方产出的同品质丹药具有相同剩余杂质。


## 七、服用与五味丹毒池

丹药保存剩余杂质，人物保存五味丹毒池。服用时：

```text
入池点数 = 该枚丹药的剩余杂质
该味丹毒百分比 = 该味累计点数 ÷ 服用者当前境界该味池容量
```

毒池规则：

- 达到80%：该味丹药效果减半；
- 达到100%：禁止继续服用该味丹药；
- 五味使用独立毒池；
- 丹毒按游戏日自然减少。

服用前达到100%时不能服用。其余情况先按服用前的毒池占用结算本枚药效，再将本枚剩余杂质加入毒池；新增占用从下一枚丹药开始生效。

```text
毒池容量 C[r,t] = 该境界该味典型单枚剩余杂质 × 期望正常可服枚数
每日衰减点数 = 向上取整（C[r,t] ÷ 30）
```

目标周期为一整池约30游戏日、约30现实小时清除。当前七个可炼境界配置35个实际容量，炼气预留。

| 自由炼制 | 玩家自行投料，系统按君材境界与基础品质、臣五行、使五味和最终药性定位丹方 |
| 自动炼丹 | 系统默认方读取材料和数量并搜索安全顺序；玩家保存方原样重放已保存的投药顺序。 |

# 第二部分 · 数值设计原则
本部分只定数值设计思路，不定规则
## 一、数值轴与取整

设境界倍率为 `R[r]`，当前候选：

```text
R[r+1] ≈ 3 × R[r]
```

炼气为第一境，筑基为首个配置境界。目标药力、单份药力、单份杂质、技能绝对剔杂值、毒池容量和每日衰减点数随 `R[r]`缩放。

药性、丹头份数、炉膛、纯度万分比、成丹率和升品率保持跨境同量级。

```text
君材目标药力 U[r,q]
= 筑基凡品基准药力 × R[r] × 品质系数 Q[q]
```

`Q[q]`随品质递增，增幅小于境界倍率，并使基础丹头能够承载高品目标。

| 品质 | 定位 |
|---|---|
| 凡 | 教学保底 |
| 灵 | 普通玩家稳定自用 |
| 玄 | 熟手主力自用与稳定获利 |
| 仙 | 高成本、高风险，偏出售 |
| 神 | 满配约三成，赌博品质 |
| 道 | 极稀少顶点成果，不进入普通量产经济 |

取整规则：

- 筑基凡品目标药力建议不低于1000；
- 药力、杂质、剔杂、剩余杂质和毒池容量使用整数；
- 百分比使用万分比整数；
- 剩余杂质向上取整；
- 剔杂收益、成丹率加成向下取整；
- 纯度不足一万分之一按不足处理；
- 最终值夹在合法上下限内。

## 二、材料数值

### 药力

- 同境材料使用同一基础药力带，总跨度约3～5倍；
- 同品质同时配置高、低药力材料；
- 保留补尾数、调药性和铺投药路线的小面额；
- 材料品质等比缩放药力与绝对杂质：高品质灵植药力更高、绝对杂质同比更高，杂质密度跨品质不变；高品的洁净收益由丹炉过滤能力与技能剔杂承担，不来自材料自身更净。
- 常见组方目标为约5～7份臣佐使，具体值由组合验证确定。

### 药性

- 单份取−4～+4，丹方目标取−2～+2；
- 同境、同品、同材位、同行或同味覆盖不同药性与药力粒度；
- 每种五味均配置寒、热使材；
- 佐材覆盖九档药性。

### 杂质

```text
杂质密度 = 单份杂质 ÷ 单份药力
```

同境、同品质的直接竞争材料须形成以下取舍：

- 高药力路线节省份数，配置较高杂质密度或较难使用的药性；
- 低药力路线占用更多份数，配置较低杂质密度；
- 易调性材料不得同时取得最高药力和最低杂质；
- 同一竞争池不存在药力、药性易用度和杂质三项全面领先者；
- 各行、各味及正负药性两侧分布均衡。

## 三、君材、丹头、丹炉与技能

君材目标药力是基础品质的药力门槛。品质越高，目标药力越高。

丹头以整数配置臣佐使总份数上限。普通丹头覆盖多数基础丹方；大丹头为更多材料位和特殊丹药提供配置空间。具体档位由全坐标组合结果确定。

丹炉的炼丹数值为炉膛与过滤率，神识门槛是使用条件。同档丹炉在炉膛和过滤率之间形成宽炉、偏性炉、净炉等定位，不设置同时全面领先的炉型。

炼丹术与灵植术共用境界差修正结构，分别配置成长幅度和剔杂占比：低于丹方境界时衰减，高于丹方境界时递减增长，剩余杂质以丹方最低杂质为下限。同境满熟练配合同档炉后，应保留本境高品丹的典型剩余杂质。

## 四、纯度、成丹率、升品与丹毒参数

每张丹方的最低纯度从合法组合分布确定：

- 同境基础坐标初配使用统一门槛；
- 突破、永久强化、洗灵根等高价值丹可以单独提高；
- 门槛低于该坐标最干净可达值；
- 设备门槛丹的最低纯度位于低档炉最优值与目标炉合理值之间；

品质基础成丹率、上限和纯度增幅根据合法组合的纯度分布确定，并符合六品定位。

跳档
品质由君材基础品质确定。成丹成功后，按当前丹效配置的固定升品率（万分比）执行一次跳档判定：
命中 → 成品按同一丹方相邻更高品质的丹效记录生成；
未命中 → 成品按当前丹效记录生成。

各境界、各五味毒池根据典型单枚剩余杂质、使用频率和期望可服枚数配置。

## 五、材料混用与养成定位

君、臣、佐、使使用目标丹方境界的材料；同境内允许不同品质臣佐使混用。

材料为每炉消耗，炼丹术与灵植术为长期成长，丹炉为长期装备。辅材品质通过绝对杂质影响纯度、成丹率和服用负担；炉型通过炉膛改变可用投药路径。

## 六、待定参数

- 筑基基础药力单位、境界倍率最终值、六品目标药力系数；
