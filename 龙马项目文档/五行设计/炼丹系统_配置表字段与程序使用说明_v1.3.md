# [小G] 炼丹系统·配置表字段与程序使用说明 v1.3

> 生成者：[小G] | 日期：2026-08-14

## 文档状态

本文规定炼丹配置的字段职责、跨表引用、运行时索引、校验顺序和结算公式。现行规则与公式以《炼丹系统·第六版设计定稿》v6.10为准；本文只说明程序如何读取和执行。

当前进入数值设计第四步。工作簿内尚未通过纸推和回调的药力、杂质、份数、容量、概率、倍率、门槛、价格、持续时间和效果数值均为示例或占位值。程序不得把当前数值写成代码常量；正式数值按工作框架逐阶段回填。

当前第四步只处理炼丹本体数值。以下字段保留既定结构和运行语义，但本轮不配置候选值、不参与反推：丹方`spirit_requirement`、丹炉`spirit_requirement`、丹方`duration`、`action1..3`、`param1..3`、`value1..3`、`reference_price`。神识数值在玩法与批次阶段处理；丹效和成品参考售价在后续产出与经济阶段处理。`jump_tier_prob`继续参加当前炼丹本体数值设计。

其他说明、计算、编号和数值施工页签不进入运行时。

## 二、表头与通用加载规则

### 2.1 Luban表头

| 行标记 | 含义 |
|---|---|
| `##var` | 稳定技术字段名 |
| `##type` | 导出类型 |
| `##group` | 导出分组 |
| `##` | 中文显示名 |
| 第5行起 | 数据行 |

程序使用导表生成的数据类型，不按中文表头或Excel列位置取值。`X系统参数.xlsx`和`S属性配置表.xlsx`沿用项目现有导表合同，不用新表的`c`分组规则反推其导出范围。

### 2.2 通用规则

- `seq`只用于策划排序。
- 实体引用使用整数ID，名称只用于显示和检查。
- 可选整数引用由配置表显式填写`0`表示未配置；程序不把空单元格自行归一为`0`。
- 每个丹方品质行独立完整，不从相邻行继承空值。
- 程序加载配置后建立只读索引，不排序或回写配置对象。

## 四、丹方表

### 4.1 行模型

一行表示一个基础丹方的一个基础成丹品质。同一基础丹方的开放品质行共用`recipe_id`，每行保存本品质的全部条件、概率、丹效和价格。

### 4.2 识别与品质字段

| 技术字段 | 类型 | 中文表头 | 程序含义 |
|---|---|---|---|
| `id` | `int` | ID | 当前品质行唯一ID |
| `recipe_id` | `int` | 丹方ID | 同一基础丹方的组ID |
| `pill_name` | `string` | 正式丹名 | 本品质成品显示名 |
| `rule_name` | `string` | 规则小名 | 策划识别名 |
| `function` | `string` | 作用说明 | 白话药效说明 |
| `realm` | `string` | 境界 | 丹方境界 |
| `quality` | `ItemQuality` | 品质 | 本行直接产出的基础品质 |
| `jun_quality` | `ItemQuality` | 君材品质 | 本行要求的君材品质 |
| `jump_tier_prob` | `int` | 跳档几率（万分比） | 成丹成功后的升一品概率 |
| `enabled` | `bool` | 是否启用 | 当前品质行是否进入运行时 |

### 4.3 成丹条件与默认方案字段

| 技术字段 | 类型 | 中文表头 | 程序含义 |

| `nval` | `int` | 成丹性值 | 投药结束时必须精确命中的药性 |
| `head_id` | `int` | 丹头ID | `0`为普通丹头；非`0`时指定唯一丹头 |
| `jun_id` | `int` | 默认君材ID | 系统默认方案的君材 |
| `jun_num` | `int` | 君材数量 | 系统默认方案固定为`1` |
| `min_id` | `int` | 默认臣材ID | 默认方案的臣材 |
| `min_num` | `int` | 臣材数量 | 默认臣材份数 |
| `ast_id` | `int` | 默认佐材ID | 默认方案的佐材；`0`表示不投入 |

| `min_purity` | `int` | 最低纯度 | 本品质行的最低纯度，万分比 |

默认方案只保存教学和快捷投料，不限制自由炼制使用其他合法材料。

### 4.4 丹效与价格字段

| 技术字段 | 类型 | 中文表头 | 程序含义 |
|---|---|---|---|
| `duration` | `int` | 持续秒数 | `0`由行为类型解释为瞬时或永久；后续丹效阶段配置 |
| `action1..3` | `string` | 行为1..3 | 依次执行的丹效行为；后续丹效阶段配置 |

| `value1..3` | `int` | 数值1/ID..3/ID | 行为读取的数值或目标ID；后续丹效阶段配置 |

## 六、除渣力表

### 6.1 来源字段

| 技术字段 | 类型 | 中文表头 | 程序含义 |
|---|---|---|---|
| `seq` | `int` | 序号 | 策划排序 |
| `source_id` | `int` | 来源ID | 技能等级ID或丹炉ID |
| `name` | `string` | 名称 | 显示和检查用 |
| `base_realm` | `string` | 基准境界 | 本行基础值对应的境界 |
| `source_type` | `string` | 来源 | `技能`或`丹炉` |

技能行填写`remove1..6`，丹炉行填写`filter1..6`。

### 6.2 品质列

| 后缀 | 品质 | 技能字段 | 丹炉字段 |
|---:|---|---|---|
| 1 | 凡品 | `remove1` | `filter1` |
| 2 | 灵品 | `remove2` | `filter2` |
| 3 | 玄品 | `remove3` | `filter3` |
| 4 | 仙品 | `remove4` | `filter4` |
| 5 | 神品 | `remove5` | `filter5` |
| 6 | 道品 | `remove6` | `filter6` |

`remove`为绝对除渣点数，`filter`为过滤率万分比。品质列按本次炼制的基础丹方品质行读取；跳档在成丹成功后执行，不回改本炉除渣结算。

程序分别从技能系统取得玩家当前炼丹术技能ID和灵植术技能ID，再以各自的技能ID查询`source_id`：

```text
当前炼丹术技能ID → 除渣力行 → 炼丹术熟练度 → 参数_炼丹术熟练
当前灵植术技能ID → 除渣力行 → 灵植术熟练度 → 参数_灵植术熟练
```

`source_type=技能`只区分技能与丹炉。技能类型由查询入口确定。丹炉`source_id`关联`furnace_config.id`。

## 十一、运行时索引与配置校验

### 11.1 索引

程序加载后建立：

- `herbById[id]`
- `recipeRowById[id]`
- `recipeRowsByRecipeId[recipe_id]`，按`ItemQuality`顺序排列
- `recipeRowByCoordinate[realm, jun_quality, element, taste, nval]`
- `furnaceById[id]`
- `drossBySource[source_type, source_id]`
- `poisonPoolByRealm[base_realm]`
- 成丹率描述区间表
- 系统参数`ParamID`索引

### 11.2 加载校验

1. 所有运行主键唯一，所有引用ID存在。
2. 同一自由炼制坐标只匹配一条启用品质行。
3. 丹方行`quality = jun_quality`。
4. `0 ≤ jump_tier_prob、base_rate、max_rate ≤ 10000`，且`base_rate ≤ max_rate`。
5. `0 ≤ min_purity ≤ 9999`，`min_impurity ≥ 1`，`spirit_requirement ≥ 1`。
6. `cold_min ≤ heat_max`，容量为正整数，消退率在`0..10000`。
7. `remove1..6 ≥ 0`，`filter1..6`在`0..10000`。
8. `jump_tier_prob > 0`时，同一`recipe_id`存在相邻更高的启用品质行；最高开放品质的跳档率为`0`。
9. 成丹率描述区间不重叠，并覆盖运行时需要显示的正成丹率。
10. 丹炉在除渣力表中存在唯一`source_type=丹炉`记录，且`base_realm = max_realm`。
11. 默认君材和丹头的材位、境界、品质符合当前丹方行；默认臣、佐、使的材位与境界正确，臣材五行和使材五味符合当前丹方行。同境臣、佐、使允许混用品质。

任一加载校验失败时，输出工作簿、页签、行ID、字段和值。

## 十二、自由炼制与自动炼丹

### 12.1 自由炼制

玩家选择丹炉、君材、丹头及逐份投入的臣、佐、使。程序按以下坐标查询启用丹方行：

```text
丹方境界 = 君材.realm
君材品质 = 君材.quality
臣行 = 投入臣材的element
使味 = 投入使材的taste
成丹性值 = 投药结束时的current_nval
```

全部臣材使用同一五行，全部使材使用同一五味。坐标无对应启用行时，配置不通过。

自由炼制正式成功后，玩家可以保存本次完整方案。保存方案至少包含丹方品质行ID、君材ID、丹头ID、臣佐使的逐份材料ID与投药顺序。

### 12.2 自动炼丹

自动炼丹只读取两类方案：

1. 系统默认方案；
2. 玩家自由炼制正式成功后保存的方案。

系统默认方案从丹方表读取材料ID和数量，运行时根据当前丹炉炉膛搜索安全投药顺序；找到后用于本次自动炼丹，找不到则配置不通过。

玩家保存方案从玩家存档读取自由炼制成功时保存的逐份材料ID和投药顺序，自动炼丹时原样重放。

两类方案均重新执行本说明的全部配置校验。校验未通过时不扣材料。

## 十三、配置阶段结算

### 13.1 准入与引用

```text
丹方.enabled = true
丹炉.enabled = true
丹方.realm ≤ 丹炉.max_realm
玩家当前神识 ≥ 丹炉.spirit_requirement
君材.realm = 丹方.realm
君材.quality = 丹方.jun_quality
臣、佐、使.realm = 丹方.realm
丹头.realm = 丹方.realm
丹头.quality = 丹方.jun_quality
```

`head_id > 0`时，所用丹头ID必须等于`head_id`；`head_id = 0`时，使用任一满足本行境界与君材品质条件的丹头。

### 13.2 份数、药力与杂质

设本炉君、臣、佐、使材料集合为`i`，每种数量为`count[i]`：

```text
臣佐使份数 N = Σ臣佐使count[i]
N ≤ 丹头.max_material_count

总药力 P = Σ君臣佐使(count[i] × power[i])
P ≥ 君材.target_power

原始总杂质 Z = Σ君臣佐使(count[i] × dross[i])
```

### 13.3 药性与炉膛

君材形成开炉初值并立即检查：

```text
current_nval = 君材.nval
丹炉.cold_min ≤ current_nval ≤ 丹炉.heat_max
```

臣、佐、使按实际投药顺序逐份执行：

```text
current_nval = current_nval + 本份材料.nval
丹炉.cold_min ≤ current_nval ≤ 丹炉.heat_max
```

全部投药结束：

```text
current_nval = 丹方.nval
```

### 13.4 除渣境界换算

境界序号读取项目统一境界顺序：

```text
Δ = 来源.base_realm序号 − 丹方.realm序号
```

`Δ < 0`时，该来源贡献为`0`。`Δ = 0`时使用同境基础值。`Δ > 0`时：

```text
K = 系统参数[参数_低境界炼丹]
境界倍率 M = K^Δ
```

技能熟练度以`0..100`的整数百分数记为`p`，对应熟练参数记为`S`：

```text
技能实际除渣力 A_skill
= floor(本品质remove × (10000 + p × S) ÷ 10000 × M)
```

分别计算炼丹术`A_alchemy`和灵植术`A_plant`。

丹炉实际过滤率：

```text
F = clamp(0, floor(本品质filter × M), 10000)
```

### 13.5 剩余杂质与纯度

```text
炉后杂质 Zf = ceil(Z × (10000 − F) ÷ 10000)

剩余杂质 D
= max(丹方.min_impurity, Zf − A_alchemy − A_plant)

纯度 Q
= clamp(0, 10000 − ceil(D × 10000 ÷ P), 10000)
```

配置通过条件：

```text
Q ≥ 丹方.min_purity
```

### 13.6 成丹率

设`Qmin = min_purity`、`B = base_rate`、`C = max_rate`：

```text
成丹率 R
= min(C,
      B + floor((C − B) × (Q − Qmin) ÷ (10000 − Qmin)))
```

`Q = Qmin`时`R = B`。

### 13.7 批次数量

```text
神识批次上限
= floor(玩家当前神识 ÷ 丹方.spirit_requirement)

实际批次数
≤ min(神识批次上限, 库存可提供的完整方案套数)
```

## 十四、确认、成丹与跳档

配置阶段任一条件不通过时，返回具体原因，不扣材料，不产生结果。

玩家确认正式炼制后：

1. 一次性扣除本次批量所需的全部材料；
2. 每枚分别生成`1..10000`随机数，随机数不大于`R`时成丹成功；
3. 成丹失败时，该枚材料不退；
4. 成丹成功后，按当前行`jump_tier_prob`分别执行升品判定；
5. 升品命中时读取同一`recipe_id`的相邻更高启用品质行；未命中时使用当前行；
6. 最终丹名、品质、丹效和参考售价读取最终品质行；
7. 本炉实际纯度`Q`和剩余杂质`D`写入成品数据。

批量炼制的每枚丹分别判定成丹与跳档，因此成功数量和最终品质可以不同。

## 十五、服丹与丹毒

### 15.1 丹毒计算

按丹方`taste`选择对应杂质池。设当前绝对杂质为`I`，当前境界池容量为`Cpool`：

```text
丹毒 T = clamp(0, floor(I × 10000 ÷ Cpool), 10000)
```

角色境界变化时保留`I`，读取新境界容量重算`T`。

### 15.2 服用顺序

服用前读取对应池丹毒`T_before`和系统参数`H = 参数_效果减半丹毒`：

| 条件 | 本枚结果 |
|---|---|
| `T_before ≥ 10000` | 禁止服用 |
| `H ≤ T_before < 10000` | 可以服用，丹效倍率为`5000` |
| `T_before < H` | 可以服用，丹效倍率为`10000` |

允许服用时：

1. 将本枚丹效倍率作为`effect_multiplier`传入`action1..3`的执行器；
2. 各丹效行为对效果量应用该倍率，具体字段和取整由统一丹效行为接口规定；
3. 将本枚剩余杂质加入对应绝对杂质池：`I = min(Cpool, I + D)`；
4. 重算丹毒；新丹毒从下一枚丹药开始参与服用判定。

### 15.3 每日消退

每个游戏日读取当前境界、对应池容量和该池`daily_decay`：

```text
每日消退点数 = 取整(Cpool × daily_decay ÷ 10000)
I = max(0, I − 每日消退点数)
```

每日消退点数的整数取整方式尚未裁定。随后重算丹毒。一个游戏日对应一现实小时。

## 十六、运行时与存档数据

### 16.1 丹药实例

每枚成品至少保存：

- 最终丹方品质行ID；
- `recipe_id`；
- 实际纯度`Q`；
- 实际剩余杂质`D`。

### 16.2 玩家自动方案

玩家保存方案至少保存：

- 丹方品质行ID；
- 君材ID与数量；
- 丹头ID；
- 臣、佐、使的逐份材料ID与投药顺序。

### 16.3 角色数据

角色保存五种绝对杂质。五种丹毒由当前绝对杂质和当前境界容量计算。

## 十七、取整与边界

| 项目 | 规则 |
|---|---|
| 份数与批次数 | 向下取整 |
| 熟练与跨境后的技能除渣力 | 全部倍率计算后向下取整 |
| 跨境后的丹炉过滤率 | 向下取整并限制在`0..10000` |
| 炉后杂质 | 向上取整 |
| 纯度扣减 | 向上取整 |
| 成丹率纯度增量 | 向下取整 |
| 丹毒 | 向下取整并限制在`0..10000` |
| 每日消退点数 | 待定；统一裁定后回写 |
| 概率与比例 | 万分比整数`0..10000` |
| 药力、杂质、除渣、容量 | 非负整数；容量为正整数 |
| 最低杂质 | 正整数 |
| 神识要求与神识门槛 | 正整数 |
