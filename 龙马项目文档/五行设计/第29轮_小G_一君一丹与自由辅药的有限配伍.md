## 〇、先给结论：第28轮的数量模型整体作废

第28轮三家都依据当时转述的“一对一”理解，把君臣佐使写成共同组数N。thoth现已当面澄清：

> **每炉固定一份君药，成功则产出一颗丹；臣、佐、使三位的数量分别自由，不随君药数量一对一。**

因此以下旧规则全部作废：

- 君N、臣N、佐N、使N；
- “组数N”概念；
- 单组药力Q与`P=N×Q`；
- 单组性值T与`S=N×T`；
- 温、凉只能一组而热、寒能两组的非单调问题；
- 为修补非单调而提出“只有佐位数量独立”；
- 丹炉按组数限制2／3／4组；
- 成丹药力下限L；
- 君药力必须占全炉三成。

最终数量模型是：

```text
君：固定1份
臣：n臣份，n臣≥1
佐：n佐份，n佐≥1
使：n使份，n使≥1
```

当前每个位仍先选一个灵植ID，再调整该位数量。首版不在同一个臣位混多种臣材、不在同一个佐位混多种佐材、不在同一个使位混多种使材；将来多行多味再通过副臣／副使或行谱／味谱扩展。

一句话：

> **一君成一丹，臣使定行味，佐辅调寒温；三辅可增减，药力不得逾君。**

2. 同一境界内若五种君药只有容量大小差，最终容易退化成“越大的君越好”，是纵向替代，不是五个长期并存的选择。

五味选择君核确实会增加材料门槛，但这是用户明确要求的“由行或味决定君药”的配方结构。掉落压力应通过多来源、种植、交易与替代君材解决，不应删除这条药理关系。

### 小龙：7.4分

优点是把第27轮时能施工的部分整理清楚，并支持125格先做一境、八境复用语义。这个施工顺序继续采纳。

但其“新增共识”中的一对一组数、组数容量和`min(总药力,君上限)`均已被用户最新裁决替换；它还把君上限公式差异视为“不阻塞”的参数细节，实际上超限到底是浪费还是炸炉会直接改变玩家配药行为，不能含糊。本轮统一为**硬上限**：总药力超过君上限即失败。

## 二、四位最终职责与数量规则

| 位置 | 最终职责 | 数量 | 自身字段 |
|---|---|---:|---|
| **君** | 凝成丹核；决定全炉药力上限、可产品质区间；一君对应一颗成品 | **固定1** | 境界、君核类型、性、药力、承载上限、品质下限、品质上限 |
| **臣** | 决定五行，即药力怎样运作 | **自由整数n臣≥1** | 五行／行谱、性、药力 |
| **佐** | 调整全炉最终性，也贡献药力 | **自由整数n佐≥1** | 性、药力 |
| **使** | 决定五味，即药力作用到哪个身体域 | **自由整数n使≥1** | 五味／味谱、性、药力 |

四类材料全部有性、全部有药力。臣没有主效，使没有五行，佐没有五行五味，君没有五行五味。

### 2.1 一君一丹

一份君药在炉中凝成一个丹核：

- 炼制成功，固定产出一颗成品；
- 要批量炼十颗，就消耗十份君药，独立或批量执行十次品质结算；
- 增加臣佐使数量不会增加成品颗数，只会改变性值、总药力与品质概率；
- 炼丹技能、丹炉和特殊玩法以后可以修改成功率或追加副产物，但不能默认把一君一丹改掉。

这使君药的经济意义非常清楚：**它既是每颗丹的核心耗材，也是这颗丹的容量与品质天花板。**

## 三、最终药力公式：无下限，只有硬上限

设一份君、臣、佐、使的单份药力分别为`p君、p臣、p佐、p使`：

```text
总药力P
= p君
+ n臣 × p臣
+ n佐 × p佐
+ n使 × p使
```

君药配置固定承载上限`U君`：

```text
合法药力条件：P ≤ U君
```

### 3.1 不再设置成丹下限L

只要下列结构成立，就存在最低档成丹：

1. 一份君药已经放入；
2. 臣、佐、使三位至少各一份；
3. 臣行、使味能够生成一个正常效果坐标；
4. 全炉性值落在-2至+2；
5. 总药力未超过君上限。

在这些合法组合中，药力最低的那批自然最容易产出君药品质池里的最低品质，不需要再拍一个人为下限。

### 3.2 超过上限怎样处理

```text
P > U君 → 君核承载失败 → 废丹／炸炉
```

不使用：

```text
成品药力 = min(P, U君)
```

因为后一种写法会让玩家可以无脑塞药，超过部分只浪费而不构成风险。硬上限才能形成“尽量贴近上限但不能越界”的真实配药题。

### 3.3 第18轮“君药力≥全炉三成”正式作废

旧规则：

```text
p君 / P ≥ 30%
```

本轮删除，不再用于成丹、品质、成功率或丹效判定。

君之所以是君，不是因为它必须占三成药力，而是因为：

- 没有君就没有丹核；
- 一份君只成一颗丹；
- 君决定总药力上限；
- 君决定可产出的品质区间；
- 主味决定必须使用哪类君核。

即使一炉中臣佐使合计药力远高于君自身药力，只要没有超过君核U，这仍是合法配伍。这个改变会给廉价辅材、高药力辅材和玩家炼丹手艺留下真正的经济空间。

## 四、最终寒热公式：三辅数量成为真正的配平旋钮

设一份君、臣、佐、使的性值分别为`s君、s臣、s佐、s使`：

```text
全炉性值S
= s君
+ n臣 × s臣
+ n佐 × s佐
+ n使 × s使
```

成丹五档：

| S | 成品性 |
|---:|---|
| -2 | 寒 |
| -1 | 凉 |
| 0 | 平 |
| +1 | 温 |
| +2 | 热 |
| ≤-3 | 过寒，普通炼制失败 |
| ≥+3 | 过热，普通炼制失败 |

三位数量完全独立以后，小C发现的“温凉只能一组”问题自然消失。玩家可以：

- 多放臣，强化某种五行材料带来的药力，但同时承担其性偏；
- 多放使，提高药力并改变性偏，但作用域仍由同一种味保持不变；
- 多放佐，把最终S拉向目标五性；
- 在性值合法的所有整数解中，继续挑药力尽量接近U的组合。

佐仍是最主要的配平位，但不再是唯一可调数量。**臣佐使三个数量都是旋钮，佐只是专门负责寒热的那一个。**

## 五、配法为什么仍然有限：这是一个有上界的整数配伍题

取消药力下限和一对一以后，并不会恢复无穷配法，前提只有一条：

> **所有可投入灵植的单份药力必须为正整数，禁止药力0或负药力。**

因为：

```text
n臣 × p臣 + n佐 × p佐 + n使 × p使 ≤ U君 - p君
```

当`p臣、p佐、p使`全部大于0时，三个数量都必然有有限上界：

```text
n臣 ≤ floor((U君-p君-p佐-p使) / p臣)
n佐 ≤ floor((U君-p君-p臣-p使) / p佐)
n使 ≤ floor((U君-p君-p臣-p佐) / p使)
```

程序可以对每组“君ID＋臣ID＋佐ID＋使ID”枚举全部有限整数解，再以性值窗口筛选；但开发配置表不需要把这些数量解逐条穷举保存。

玩家成功炼出某一组数量后，个人配方册记录：

```text
君ID×1
臣ID×n臣
佐ID×n佐
使ID×n使
```

只为以后快捷复现，不做全服唯一配方、首验留名或拓本交易。

## 六、药力现在正式参与品质概率，但不直接生成连续丹效数值

thoth本轮明确：

> **一个君药通常管2—3个成品品质；总药力越高，产出高品质的概率越高。**

这意味着第28轮“药力与品质完全分开”的表述需要修正。正确关系是：

- 药力**不直接决定**成品品质；
- 药力是品质结算的一个重要概率输入；
- 君药决定这一炉允许抽取的品质池；
- 丹炉品质、炼丹技能、灵植品质等继续共同修正概率；
- 一旦品质结果确定，实际药效调用该品质对应的丹效配置，不让每一个药力点都生成一种新物品。

### 6.1 君药的品质池

每种君药配置一个连续的2—3档品质区间：

```text
quality_min
quality_max
```

例如某君核允许：

```text
凡品／灵品／玄品
```

另一种更稀有或更高档君核可以允许：

```text
玄品／地品
```

本轮只冻结“2—3档连续品质”，不拍具体哪种君对应哪几档。

### 6.2 药力饱和度

定义一个直观输入：

```text
药力饱和度R = P / U君
```

R只在`0<R≤1`内合法。

| R状态 | 品质倾向 |
|---|---|
| 较低 | 最低品质权重最高 |
| 中等 | 中间品质权重上升 |
| 接近1 | 最高品质权重最高 |
| ＞1 | 不进入品质结算，直接失败 |

不建议把R切成“到80%必出灵、到95%必出玄”的绝对阈值。保留概率，玩家才会继续投资丹炉、技能和材料品质。

### 6.3 品质结算的最终结构

```text
可产品质池 = 君药[quality_min .. quality_max]

品质权重修正 =
    药力饱和度R
  + 灵植品质修正
  + 炼丹技能修正
  + 丹炉品质修正
  + 其他明确Buff／天赋修正

在君药品质池内按最终权重抽取1个品质
```

具体权重、曲线和各因素占比以后单独纸推。本轮只定职责：

| 因素 | 决定什么 |
|---|---|
| 君药 | 品质池上下界＋药力上限U |
| 总药力P | 通过R推动高品质概率 |
| 灵植品质 | 修正品质权重或稳定性 |
| 炼丹技能 | 提高成功率与高品质权重 |
| 丹炉境界／品质 | 决定能否承炼、成功率和高品质权重 |

### 6.4 这与丹效表怎样衔接

125格仍只负责确定“这是什么效果”：

```text
效果坐标 = 五行 × 五味 × 最终五性
```

品质结算负责确定“这个效果用哪一档数值”：

```text
最终丹效 = 丹效表[效果坐标][成品品质]
```

药力P不直接成为物品上的连续数值，因此不会出现药力37、38、39各是一种不同丹，需要在物品表无限开行的问题。

## 七、五种标准君核：继续按五味分，不按容量五档分

第28轮小C提出五种君药按小／中／大／特大／巨五个承载规格分档。这个方案在同一境界中容易形成单向淘汰：若其他条件相同，玩家总会偏向容量更大的君药，前四种逐渐退化成过渡材料。

本轮继续采用：

| 主使五味 | 作用域 | 所需标准君核 |
|---|---|---|
| 甘 | 修炼／丹田 | 丹田核 |
| 辛 | 灵法／气脉 | 气脉核 |
| 咸 | 根基／骨底 | 骨底核 |
| 苦 | 心神 | 心神核 |
| 酸 | 气血／血肉 | 血肉核 |

理由不变：五味是去处，君核是承载该去处的器；五种君核是五个横向作用域，不是五个迟早被替换的容量等级。

每一种标准君核内部再配置：

- 药力上限U；
- 2—3档可产品质；
- 自身性与药力；
- 境界；
- 价格、稀有度和获取方式。

这样既满足“正常约五种君药”，也满足“一君管2—3个品质”。特殊洗灵根、延寿、双味、极寒极热等仍可使用特殊君核。

君核与使味相合虽然是两件材料共同表达一个作用域，但它不是无用重复：

- 使负责把药力引去该域，并参与性与药力计算；
- 君负责该域能承载多少、能产哪些品质，并作为一丹一枚的核心消耗；
- 两者不合时结构失败，形成可读的配伍规则。

玩家界面可以在选中君核后，只高亮兼容使材；或先选使材后，只显示兼容君核，降低操作负担。

## 八、125格母表的最新冻结

thoth已明确同意：

1. **125个正常行味性坐标全部有结果。** 不预设空格。
2. **不要求125个不同属性ID。** 可以使用属性、参数、Buff、技能共同实现。
3. **同一ID可以复用。** 只要最终效果在峰值、持续、总量、速度、触发方式或反噬上形成玩家可感知差异。

因此配表纪律为：

```text
125格 = 5味 × 5行 × 5性
每格最多3套药效
每套药效 = 类型 + 属性/参数/技能/Buff ID + 具体参数
```

所有正常坐标都能成丹，但重要性不同：

- **核心丹**：加修为、大小突破、回血回灵、关键战斗、永久强化、清修为毒、清灵根毒、延寿等；
- **常用丹**：大量战斗与恢复属性；
- **偏门丹**：特定Boss、状态解除、特殊流派与边缘用途。

失败只来自：

- 君核与主味不合；
- 缺少必要位置；
- 性值超出-2至+2；
- 总药力超过君上限；
- 炼制成功率结算失败；
- 特殊规则明确禁止。

不是因为某个合法行味性坐标被策划故意留空。

## 九、这套玩法为什么开始真正好玩

玩家想炼一颗火·酸·温的丹：

1. 选血肉核君药，知道这颗丹最多能承多少药力、可能出哪2—3个品质；
2. 选火行臣材，确定“催动／爆发”的运作方式；
3. 选酸味使材，把药力引到气血；
4. 用臣、使、佐三个数量把全炉性值调到+1；
5. 在不超过U的前提下继续提高总药力P，让高品质概率上升；
6. 若性被推到+2，效果会从火酸温变成火酸热；若药力越过U，则直接失败。

玩家同时在解三道题：

| 题 | 玩家在权衡什么 |
|---|---|
| 行味题 | 想做什么、作用到哪里 |
| 寒热题 | 具体要哪一种效果 |
| 药力题 | 如何贴近君上限、提高品质概率而不炸炉 |

这三道题使用同一批灵植数据，不靠隐藏丹方答案。廉价材料只要行、味、性和药力组合得好，就可能在高技能、高品质丹炉下炼出更值钱的丹，承接了thoth此前要求的“低成本灵植炼丹卖药发财”。

## 十、第29轮冻结项

1. 一炉固定一份君药，炼制成功固定产出一颗丹。
2. 臣、佐、使数量分别自由，首版均为大于等于1的整数。
3. 首版每个位各选一个灵植ID；同位多物种留待多行多味扩展。
4. 总药力`P=p君+n臣p臣+n佐p佐+n使p使`。
5. 不设药力下限L；最低药力的合法组合自然对应最低品质倾向。
6. 君药决定硬上限U；P＞U直接失败，不取min、不吞溢出。
7. 第18轮“君药力≥全炉三成”正式作废。
8. 君药力不需要占任何固定比例；臣佐使可以贡献大部分药力。
9. 全炉性值`S=s君+n臣s臣+n佐s佐+n使s使`，正常只接受-2至+2。
10. 所有灵植药力必须为正数，因此臣佐使数量解必然有限。
11. 一个君药通常配置连续2—3档成品品质池。
12. 药力饱和度`R=P/U`越高，高品质权重越高；R＞1不结算品质，直接失败。
13. 灵植品质、炼丹技能、丹炉品质继续共同修正成功率与品质概率，具体权重后置。
14. 药力不直接生成连续丹效数值；品质确定后调用对应品质的丹效配置。
15. 五种标准君核继续按甘辛咸苦酸五域区分，不按同境容量五档区分。
16. 125个正常行味性坐标全部有效；每格可调用属性、参数、Buff、技能，允许合理复用ID。
17. 臣无主效；最终效果仍由五行×五味×最终五性确定。
18. 首版丹毒继续只有修为丹毒、灵根丹毒。

## 十一、下一轮可以直接施工什么

规则层现在已经足够稳定，下一轮可以正式出125格语义母表。建议：

1. 先做一张`5味×5行×5性`的125行设计母表，不乘境界、不配数值；
2. 每格填写效果族、白话作用、首选实现类型、首选属性／参数／Buff／技能、备选第二第三药效；
3. 标注核心丹／常用丹／偏门丹；
4. 对125格做重复、空格、反直觉、无程序承载四项检查；
5. 母表通过后，再建立品质维度的丹效数值行；
6. 最后纸推君药U、灵植药力、合法数量解和品质概率曲线。

药力和品质规则现在不会阻塞语义母表，因为母表只回答“是什么效果”，质量结算回答“出哪一档数值”。

## 十二、一句话收束

> **一君凝一丹，三辅各随宜；性和定其效，药力逼其极。未满亦成，近满则精，过满则裂。**

这一次数量自由、寒热配平、药力上限和品质概率终于形成同一个玩法闭环：玩家不是寻找唯一答案，而是在有限空间里寻找更便宜、更接近上限、更可能出高品质的答案。
