# [小G] 修炼系统策划案：一念逍遥母版与项目收敛
> 生成者：[小G] | 日期：2026-07-31 | 轮次：第二轮

版本：V2.4  
状态：第二轮讨论稿；已完成三份模块清单交叉校验，补充追赶接口与灵气档位配置层  
范围：时间、境界、等级、修为、打坐、洞府灵气、丹药、耐药、突破、虚弱、瓶颈、离线、节奏与渡劫接口  

## 0. 本轮结论

### 0.1 已定

1. 先完整拆解《一念逍遥》修炼母版，再做项目差异化。
2. 项目只有一条修炼主线，不分法修、体修、剑修、鬼修、儒修、血炼。
3. 角色等级就是小境界序号；每一级就是一个小境界。
4. 每个大境界固定10级，不随后期境界增加层数。
5. 每个大境界的阶段固定为：
   - 1—3级：前期。
   - 4—6级：中期。
   - 7—9级：后期。
   - 10级：圆满。
6. 每一个等级边界都需要一次小突破；第3、6、9级之后属于强化的小突破节点。
7. 每个大境界圆满后必须进行一次大境界突破。
8. 突破丹是可选辅助，不是突破门票；允许不吃丹直接突破。
9. 突破失败不扣修为、不清空大境界、不降低等级。
10. 突破失败进入虚弱期；虚弱期间不能再次突破，修为获取降低。
11. 虚弱自然恢复，也可使用恢复类丹药提前恢复。
12. 修为达到突破线但尚未突破时仍可继续增长；打坐修为速度降低，溢出修为保留。
13. 修为丹不采用现实自然日的固定服用次数，改用随游戏昼夜自然恢复的耐药负荷。
14. 离线修炼、相邻大境界修为倍率、阶段节奏保留。
15. 渡劫不是大境界，是大乘大成后的特殊行为。
16. 飞升不是大境界，是渡劫成功后的终局结果。
17. 高效打坐必须在洞府内进行；洞府外允许打坐，但只获得极低修为。
18. 洞府具有可积攒、可消耗的灵气储量池；储量按游戏世界时间在线、离线持续汇聚。
19. 一个游戏日为现实60分钟；每个现实日经过24个游戏日。
20. 洞府灵气使用“灵气日”作为标准单位；默认上限30灵气日，基础产出1灵气日/游戏日。
21. 默认灵气池从满到空约可支持6现实小时满速吸收；吸空后立即进入低效修炼。
22. 不设置清晨、白昼、夜间等时段倍率；修炼差异只由地点、灵气、加成、瓶颈和虚弱决定。
23. 突破虚弱期间不能吸收洞府灵气；洞府灵气不消耗，只能获得极低的基础修为。
24. 离线后角色自动进入洞府闭关；离线只修炼、不自动突破。
25. 基础满级时间必须按洞府灵气长期产出能力计算，不能把每天都从满池开始作为默认前提。

### 0.2 世界观裁定

项目大境界共8个：

`炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘`

终点状态：

`大乘十级 → 大乘·大成 → 特殊行为：渡劫 → 终局结果：飞升或留世`

裁定理由：

1. 三份世界观底层文档均使用炼虚，并赋予炼虚“借法则看见天界大阵痕迹”的独立质变，不能删除。
2. 三份世界观底层文档使用大乘，不使用大成作为独立大境界。
3. “大成”适合作为大乘十级完成后的状态名，表示修炼主线已经完成。
4. 世界观已经把丹田定义为灵气压缩仓，并明确灵气由气态、液态进入金丹固态；紫府没有不可替代的物质机制。
5. 紫府在部分家族修仙作品中位于筑基与金丹之间，在另一些作品中只是丹田、识海或内景的别称，不是修仙题材的统一大境界。
6. 本项目不增加紫府大境界。需要使用“紫府”一词时，只能作为筑基后期开辟内景的文学称呼，不进入等级和境界枚举。

### 0.3 丹药品质裁定

1. 丹药使用一品至九品，不使用下品、中品、上品、极品作为主品质轴。
2. 原因是世界观底层已经冻结丹药九品，并明确一、三、五、七、九品是主要品质跃迁点。
3. “下品/中品/上品/极品”可用于灵石或其他资源，不再与丹药九品并存，避免双品质轴。
4. 修为丹继续采用“等价基础修炼时长”计算，这是最容易控制和跨境界平衡的数值方式。


### 0.4 系统模块总览

大模块共12个：

1. 境界与突破。
2. 修为与瓶颈。
3. 打坐与洞府。
4. 丹药与耐药。
5. 虚弱与恢复。
6. 离线闭关。
7. 时间与节奏。
8. 修炼加成。
9. 修炼追赶。
10. 配置与存档。
11. 渡劫接口。
12. 表现反馈。

层级关系：

`修炼系统`

→ `时间`

→ `境界：大境界/小境界/阶段/圆满/大成/突破`

→ `修为来源：打坐/丹药`

→ `打坐：洞府/洞府外/灵气汇聚/灵气吸收/修为转化`

→ `状态：正常/瓶颈/虚弱/离线`

→ `数值：需求/速度/耐药/满级时间`

→ `数据：配置表/运行时存档`

→ `反馈：修炼速度/灵气剩余/瓶颈/虚弱/离线报告`

策划归属上，突破属于境界推进；实现上，突破判定和虚弱状态独立配置，避免把概率与状态字段塞入境界静态表。

### 0.5 本轮补齐的遗漏

1. 状态优先级：虚弱优先于瓶颈，瓶颈优先于正常修炼。
2. 边界拆段：离线结算跨越灵气耗尽、修为满线、虚弱结束时必须拆段。
3. 加成接口：区分吸收速度与转化效率，避免同一加成重复乘算。
4. 运行时存档：保存修为、灵气、耐药、虚弱和统一结算时间戳。
5. 表现反馈：显示灵气、速度、剩余高效时长、瓶颈、虚弱和离线收益。
6. 时间守恒：满级时间按灵气长期产出计算，不能假定每天满池。

### 0.6 三份清单交叉裁定

1. 项目固定8个大境界，不是7个。
2. 每一级都要主动突破，炼气一层开始生效；不是金丹才开始小突破。
3. 大境界突破是10级圆满到下一大境界一层；渡劫只在80级大乘·大成后开放，不等同于大境界突破。
4. 不使用丹药每日次数上限；修为丹使用耐药负荷、药效衰减和自然恢复控制。
5. 离线不自动突破，因此不会产生新的突破失败或新的虚弱；已有虚弱仍按世界时间恢复。
6. 灵气四档作为可配置的修炼效率层保留；灵气汇聚与实际吸收公式仍是唯一资源结算依据。

## 1. 《一念逍遥》修炼母版

本节只记录竞品母版，不代表项目最终规则。

### 1.1 结构

《一念逍遥》的修炼层级为：

`修炼方向 → 大境界 → 前/中/后期 → 重数 → 修为 → 瓶颈 → 突破`

特殊点：

1. 炼气/通脉使用十层制。
2. 后续大境界使用“前期/中期/后期+重数”。
3. 每一重都是小境界。
4. 修为达到当前重上限后，角色出现破境或突破入口。
5. 每次突破都可以服用一颗对应突破丹提高成功率。
6. 当前大境界内部突破使用本境界丹药。
7. 后期圆满突破到下一大境界使用下一大境界的突破丹。
8. 大境界提升后可刷新修为丹、吐纳等限次资源；该规则属于版本性设计。

### 1.2 当前境界母表

《一念逍遥》当前已出现法修、体修、御剑、驭鬼、圣儒、血炼六个修炼方向。项目删除方向差异，但完整母版仍保留法修/体修对应关系：

| 阶位 | 法修 | 体修 | 世界层级 | 版本状态 |
|---:|---|---|---|---|
| 0 | 江湖好手 | 凡人之躯 | 凡俗 | 起始状态 |
| 1 | 炼气 | 通脉 | 人界 | 十层制 |
| 2 | 筑基 | 锻骨 | 人界 | 前/中/后期+重 |
| 3 | 结丹 | 炼腑 | 人界 | 前/中/后期+重 |
| 4 | 元婴 | 元武 | 人界 | 前/中/后期+重 |
| 5 | 化神 | 神力 | 人界 | 前/中/后期+重 |
| 6 | 返虚 | 破虚 | 灵界 | 前/中/后期+重 |
| 7 | 合体 | 混元 | 灵界 | 前/中/后期+重 |
| 8 | 大乘 | 大成 | 灵界 | 前/中/后期+重 |
| 9 | 渡劫 | 涅槃 | 灵界 | 2021年后追加 |
| 10 | 真仙 | 仙体 | 仙界 | 仙界境界 |
| 11 | 金仙 | 金相 | 仙界 | 仙界境界 |
| 12 | 太乙 | 太上 | 仙界 | 2024年追加 |
| 13 | 大罗 | 罗天 | 仙界 | 大罗为官方；罗天为当前玩家资料名 |

版本口径：

1. 旧攻略中的道祖/道体列表是旧版本快照，不能直接插在金仙和太乙之间作为当前必经大境界。
2. 炼气/通脉可以确认是十层。
3. 筑基以后可以确认使用前期、中期、后期和重数。
4. 公开资料出现过结丹后期六重、元婴后期八重、化神后期十五重、大乘/渡劫二十重等不同快照。
5. 当前资料也出现前期二十重、中期二十重。
6. 因此不能把某一个版本的重数写成永久统一规则，也不能仅凭不同大境界的后期数字推导同一大境界前中后数量不等。
7. 项目不复制该动态扩层方式，统一收敛为每个大境界十级。

### 1.3 修为来源

《一念逍遥》的核心修为来源：

| 来源 | 规则 |
|---|---|
| 洞府打坐 | 按时间持续获得修为 |
| 离线修炼 | 离线继续按修炼规则积累 |
| 修为丹 | 立即增加对应修炼方向的修为 |
| 修为秘药 | 立即增加修为，通常不占普通修为丹次数 |
| 吐纳 | 主动操作获得修为，可触发倍率 |
| 洞府、聚灵阵、功法、古宝等 | 提升洞府灵气或吸收率 |
| 奋起 | 落后服务器前列时增加修炼速度 |

基础关系：

`修炼速度 = 洞府灵气 × 吸收率`

普通修为丹存在服用次数；历史公开资料常见每日20次，大境界突破后刷新。吐纳也存在限次与大境界刷新。具体次数发生过版本调整，母版记录机制，不把20写成项目永久值。

### 1.4 丹药分类

《一念逍遥》中与修炼相关的丹药至少分为：

| 类型 | 是否直接增加修为 | 作用 |
|---|:--:|---|
| 修为丹 | 是 | 立即增加修为 |
| 修为秘药 | 是 | 立即增加大量修为 |
| 突破丹 | 否 | 提高突破成功率 |
| 恢复类突破丹效果 | 否 | 缩短元神受损时间 |
| 气血/真元恢复丹 | 否 | 战斗恢复 |
| 永久属性丹 | 否 | 永久增加指定属性 |

不是所有丹药都会增加修为。只有物品效果明确写有“增加修为”的丹药才增加修为。

### 1.5 突破

《一念逍遥》的公开规则可以确认：

1. 小境界和大境界都存在主动突破。
2. 可以不服用突破丹直接尝试。
3. 突破丹提高成功率。
4. 突破失败会获得“元神受损”状态。
5. 元神受损期间不能再次突破。
6. 部分突破丹可以缩短元神恢复时间。
7. “瓶颈松动”等效果可以提高下一次突破成功率。
8. 公开资料对失败是否扣修为存在版本和来源冲突，不能作为固定竞品事实。

### 1.6 项目不复制的部分

| 《一念逍遥》内容 | 项目处理 |
|---|---|
| 多修炼方向 | 删除，只保留单主线 |
| 后期每期大量重数 | 删除，所有大境界固定10级 |
| 现实自然日服药次数 | 改为游戏昼夜驱动的耐药负荷 |
| 渡劫作为境界线中的独立阶段 | 改为大乘大成后的特殊行为 |
| 飞升作为境界推进节点 | 改为终局结果 |
| 方向专属修为丹 | 删除，只保留统一修为丹 |

## 2. 常见修仙小说规则归纳

修仙小说不存在统一境界和丹药标准，只能归纳常见结构。

### 2.1 修为来源

1. 打坐吐纳，吸收天地灵气。
2. 运转功法，将灵气转化为自身修为。
3. 服用修为丹、聚气丹、增元丹等直接补充灵气。
4. 炼化天材地宝、妖丹、灵物。
5. 接受传功、灌顶、机缘。
6. 在灵脉、洞府、聚灵阵等高灵气环境修炼。

项目核心只保留两种通用入口：

1. 打坐修炼。
2. 直接增加修为的丹药或秘药。

其他系统若奖励修为，统一调用“增加修为”入口，不在修炼系统内分别维护来源。

### 2.2 丹药常见作用

| 类型 | 常见作用 | 是否增加修为 |
|---|---|:--:|
| 修为丹 | 补充和凝练灵气 | 是 |
| 突破丹 | 稳定经脉、冲击瓶颈、提高成功率 | 否 |
| 淬体丹 | 提高肉身承载 | 否 |
| 凝神丹 | 提高神识或稳定心神 | 否 |
| 洗髓丹 | 改善资质或灵根 | 否 |
| 疗伤丹 | 恢复伤势 | 否 |
| 战斗丹 | 临时增加战斗能力 | 否 |
| 解毒丹 | 清除毒素、丹毒或魔气污染 | 否 |
| 养神丹 | 恢复突破失败造成的元神受损 | 否 |

### 2.3 过量服药的常见后果

1. 丹毒积累。
2. 药效递减。
3. 耐药性上升。
4. 经脉堵塞。
5. 根基虚浮。
6. 后续突破难度上升。

项目采用“耐药负荷+药效递减”，不采用永久损坏根基。

## 3. 等级、境界与阶段

### 3.1 推导公式

角色等级范围：

`1—80级`

大境界索引：

`大境界索引 = 向下取整((角色等级 - 1) ÷ 10)`

境界内等级：

`境界内等级 = ((角色等级 - 1) mod 10) + 1`

阶段：

| 境界内等级 | 阶段 |
|---:|---|
| 1—3 | 前期 |
| 4—6 | 中期 |
| 7—9 | 后期 |
| 10 | 圆满 |

### 3.2 突破节点

| 当前境界内等级 | 下一步 | 类型 |
|---:|---|---|
| 1、2、4、5、7、8 | 下一小境界 | 普通小突破 |
| 3 | 中期一层 | 阶段小突破 |
| 6 | 后期一层 | 阶段小突破 |
| 9 | 圆满 | 圆满小突破 |
| 10 | 下一大境界一层 | 大境界突破 |
| 大乘10 | 渡劫准备 | 终局特殊行为 |

每一级都是小境界。前期、中期、后期只是阶段标签，不额外占等级。

## 5. 修为、打坐与洞府灵气

### 5.1 修为数据

1. 修为是角色长期累计进度。
2. 每个等级有一个累计修为突破线。
3. 升级、突破和突破失败均不清空修为。
4. 等级只在突破成功后提升。
5. 超出当前突破线的修为全部保留。
6. 溢出修为不能自动跨级；每个等级边界仍需单独突破。

### 5.2 修为来源

修为来源只保留两类：

| 来源 | 规则 |
|---|---|
| 打坐修炼 | 按时间持续获得修为；高效修炼依赖洞府灵气 |
| 丹药 | 修为丹直接增加修为；修炼增益丹影响吸收速度或转化效率 |

其他系统奖励修为时调用统一“增加修为”入口，不在修炼系统内增加第三种核心来源。

### 5.3 打坐修为公式

每3秒结算一次。

基础修为：

`基础打坐修为 = 当前等级基础速率 × 地点倍率 × 外部修炼倍率 × 瓶颈修炼倍率 × 虚弱修炼倍率 × 经过时间`

实际吸收灵气：

`本次可吸收上限 = 基础吸收速度 × 吸收速度倍率 × 瓶颈吸收倍率 × 经过游戏日数`

`本次实际吸收灵气 = min(结算期可用灵气, 本次可吸收上限)`

灵气修为：

`灵气修为 = 本次实际吸收灵气 × 当前等级单位灵气修为值 × 灵气转化效率 × 外部修炼倍率`

最终修为：

`本次修为 = 基础打坐修为 + 灵气修为`

| 参数 | 默认/来源 |
|---|---|
| 当前等级基础速率 | 等级配置；无灵气时的低速修炼 |
| 地点倍率 | 洞府内1.00；洞府外测试初值0.05 |
| 外部修炼倍率 | 功法、装备、活动等系统汇总 |
| 基础吸收速度 | 洞府灵气配置；默认6灵气日/游戏日 |
| 吸收速度倍率 | 功法、丹药等效果接口；默认1.00 |
| 单位灵气修为值 | 等级配置 |
| 灵气转化效率 | 洞府、功法、丹药等效果接口；默认1.00 |
| 瓶颈修炼倍率 | 修为满线未突破时的基础修为倍率 |
| 瓶颈吸收倍率 | 修为满线未突破时的灵气吸收倍率 |
| 虚弱修炼倍率 | 按虚弱类型配置 |

不设置时段倍率。

### 5.4 洞府灵气池

#### 5.4.1 时间单位

`1时辰 = 现实5分钟`

`1游戏日 = 12时辰 = 现实60分钟`

`1现实日 = 24游戏日`

`经过游戏日数 = 经过现实秒数 ÷ 3600`

洞府灵气使用“灵气日”作为标准单位：

`1灵气日 = 基础洞府经过1游戏日自然产出的灵气量`

#### 5.4.2 默认参数

| 参数 | 默认值 |
|---|---:|
| 灵气储量上限 | 30灵气日 |
| 灵气自然产出 | 1灵气日/游戏日 |
| 满速吸收上限 | 6灵气日/游戏日 |
| 洞府外地点倍率 | 0.05 |
| 结算周期 | 3现实秒 |

默认空池到满池：

`30 ÷ 1 = 30游戏日 = 30现实小时`

默认满池连续打坐时，产出与吸收同时发生：

`净消耗速度 = 满速吸收6 - 同期产出1 = 5灵气日/现实小时`

`满池吸空时间 = 30 ÷ 5 = 6现实小时`

#### 5.4.3 汇聚、吸收与消耗

灵气产出：

`本次灵气产出 = 基础产出速度 × 灵气产出倍率 × 经过游戏日数`

结算期可用灵气：

`可用灵气 = min(当前储量 + 本次灵气产出, 灵气储量上限)`

灵气吸收：

`本次实际吸收灵气 = min(可用灵气, 本次可吸收上限)`

储量更新：

`新储量 = clamp(可用灵气 - 本次实际吸收灵气, 0, 灵气储量上限)`

规则：

1. 在线、离线均自然产出灵气。
2. 不打坐时只产出、不吸收。
3. 洞府外打坐不吸收洞府灵气。
4. 洞府内正常打坐时，有多少灵气就吸收多少，但不超过当期吸收上限。
5. 储量大于0时可以接近满速吸收。
6. 储量为0且持续打坐时，只能即时吸收当期新产出的灵气。
7. 基础产出1、满速吸收6时，枯竭后的灵气修为约为充裕状态的六分之一。
8. 通过单位灵气修为值调参，使有灵气时的总修炼效率约为无灵气时的5—10倍。
9. 结算跨越储量为0的边界时必须拆段，禁止整段按满速吸收。

#### 5.4.4 加成接口

本轮只定义接口，不展开洞府成长来源：

| 接口 | 作用 |
|---|---|
| 灵气储量上限加成 | 增加最多可积攒的灵气 |
| 灵气产出速度加成 | 加快洞府灵气自然汇聚 |
| 灵气吸收速度加成 | 单位时间吸收更多灵气，同时更快消耗储量 |
| 灵气转化效率加成 | 同样灵气转化为更多修为，不增加灵气消耗 |

洞府、功法、丹药可以向这些接口提供加成；具体来源与成长规则由对应系统后续设计。


#### 5.4.5 灵气效率阶梯

采用四档作为修炼效率与表现层：

| 档位 | 触发 | 作用 |
|---|---|---|
| 充盈 | 灵气储量处于高位 | 灵气转化效率最高 |
| 稀薄 | 灵气储量下降到中低位 | 灵气转化效率下降 |
| 枯竭 | 尚有少量存量 | 灵气转化效率很低 |
| 干涸 | 灵气储量为0 | 只能转化当期即时产出，最低效率 |

规则：

1. 四档只修改“灵气转化效率档位倍率”，不替代灵气产出、吸收和储量公式。
2. 有多少灵气仍吸收多少，实际吸收量始终受当期可用灵气和吸收上限约束。
3. 阈值和四档倍率独立配置，当前不冻结具体百分比，必须与“满池约6小时吸空”的目标一起压测。
4. 洞府外不进入灵气档位，固定使用洞府外地点倍率。


### 5.5 瓶颈与溢出

修为达到当前突破线但尚未突破：

1. 修为继续增加。
2. 基础打坐修为降为正常的25%。
3. 灵气吸收上限降为正常的25%。
4. 灵气消耗随实际吸收量同步降低，不额外浪费灵气。
5. 修为丹仍可使用，但受耐药效率和虚弱状态影响。
6. 离线修炼使用相同瓶颈规则。
7. 突破成功后全部溢出修为保留。
8. 不设置溢出修为硬上限。
9. 无论溢出多少，都不能跳过突破节点。

测试初值：

`瓶颈修炼倍率 = 0.25`

`瓶颈吸收倍率 = 0.25`

### 5.6 状态优先级

结算优先级：

1. 虚弱。
2. 瓶颈。
3. 正常洞府打坐。
4. 洞府外打坐。

虚弱优先级高于瓶颈。角色同时处于虚弱和瓶颈时：

1. 不能吸收洞府灵气。
2. 洞府灵气不消耗并继续自然汇聚。
3. 只结算虚弱状态下的低速基础修为。
4. 不能发起突破。

## 6. 丹药修炼

### 6.1 基础公式

每颗修为丹绑定一个适用大境界。

`修为丹基础修为 = 该丹适用境界的标准每分钟修炼速率 × 等价修炼分钟`

`实际修为 = 基础修为 × 耐药效率 × 虚弱倍率`

修为丹不读取玩家的外部修炼速度加成，避免玩家同时放大打坐和丹药。

4. 直接修为丹不读取灵气转化效率，避免重复放大。
5. 吸收加速与转化增效均受耐药效率影响。

## 7. 耐药性

### 7.1 状态定义

耐药负荷范围：

`0—100`

1. 0表示没有耐药。
2. 数值越高，丹药实际效果越低。
3. 服用丹药先按当前耐药负荷计算效果，再增加耐药负荷。
4. 耐药负荷可以到达100，但不会禁止服药。
5. 达到高耐药后继续服药只能获得极低收益。

### 7.2 药效公式

`耐药效率 = max(10%, (1 - 当前耐药负荷 ÷ 100)²)`

| 当前耐药负荷 | 实际效率 |
|---:|---:|
| 0 | 100% |
| 10 | 81% |
| 25 | 56.25% |
| 50 | 25% |
| 75 | 10% |
| 100 | 10% |

该曲线使连续嗑药快速进入低收益区，但不设置强制每日次数。

### 7.3 自然恢复

`经过游戏日数 = 经过现实秒数 ÷ 一昼夜现实秒数`

`恢复后的耐药负荷 = max(0, 原耐药负荷 - 经过游戏日数 × 每游戏日恢复值)`

测试初值：

`每游戏日恢复60点耐药负荷`

一个完整昼夜固定为现实60分钟：

1. 100点耐药负荷完全恢复需要约1.67个游戏日。
2. 对应现实时间约100分钟。
3. 在线和离线都自然恢复。
4. 修改昼夜长度时不需要重写耐药规则。

## 10. 突破失败与虚弱

### 10.1 固定规则

突破失败：

1. 不扣修为。
2. 不清空修为。
3. 不降低等级。
4. 不倒退大境界。
5. 保留全部溢出修为。
6. 已使用的突破丹和材料不返还。
7. 获得“元神受损/破境虚弱”状态。
8. 虚弱期间不能进行小突破、大突破或特殊渡劫。
9. 虚弱期间不能吸收洞府灵气。
10. 虚弱期间洞府灵气不消耗，仍按时间自然汇聚。
11. 虚弱期间只能获得极低的基础打坐修为。
12. 修为丹、修为秘药和其他直接修为入口仍乘虚弱修为倍率。

### 10.2 虚弱强度

测试初值：

| 失败类型 | 持续时间 | 现实时间 | 基础修为倍率 | 可吸收灵气 |
|---|---:|---:|---:|:--:|
| 普通小突破失败 | 0.25游戏日 | 15分钟 | 20% | 否 |
| 阶段小突破失败 | 0.50游戏日 | 30分钟 | 15% | 否 |
| 圆满小突破失败 | 1.00游戏日 | 60分钟 | 10% | 否 |
| 大境界突破失败 | 2.00游戏日 | 120分钟 | 5% | 否 |
| 特殊渡劫失败 | 单独配置 | 单独配置 | 单独配置 | 否 |

虚弱倍率同时作用于：

1. 在线基础打坐修为。
2. 离线基础打坐修为。
3. 修为丹。
4. 修为秘药。
5. 其他直接增加修为的入口。

灵气修为固定为0，不再乘虚弱倍率。

### 10.3 恢复

1. 虚弱按游戏世界时间自然恢复。
2. 在线与离线都恢复。
3. 养神丹可以缩短剩余虚弱时间。
4. 养神丹不增加修为。
5. 养神丹增加耐药负荷。

养神丹测试公式：

`缩短比例 = 5% + 丹药品阶 × 5%`

| 品阶 | 缩短当前剩余时间 |
|---:|---:|
| 一品 | 10% |
| 三品 | 20% |
| 五品 | 30% |
| 七品 | 40% |
| 九品 | 50% |

按当前剩余时间缩短，连续服用自然递减。

### 10.4 修为损失字段

突破配置保留失败修为损失率字段，但普通小突破和大境界突破固定填0。

该字段只供特殊剧情突破、高风险秘法、终局渡劫和后续玩法变体使用。

## 11. 渡劫与飞升

### 11.1 渡劫

渡劫不是境界，不占等级。

开放条件：

1. 角色达到80级。
2. 境界状态为“大乘·大成”。
3. 完成渡劫准备条件。
4. 当前不处于虚弱。

渡劫是独立特殊行为，可采用九道雷劫、心魔或其他事件，但不改变1—80级境界枚举。

### 11.2 飞升

飞升不是境界，不占等级。

飞升是渡劫成功后的终局结果之一：

1. 飞升。
2. 留在人间。
3. 轮回。

具体终局分支由终局系统决定，修炼系统只提供“大乘大成”和“渡劫结果”。

## 12. 修炼节奏与离线闭关

### 12.1 相邻大境界

测试初值：

`下一大境界总修为需求 = 上一大境界总修为需求 × 2.2`

修为需求与等级基础速率必须同步压测，禁止只提高需求。

### 12.2 境界内需求

`下一突破线增量 = 当前突破线增量 × 1.12`

大境界突破线额外乘以1.5。

阶段体感目标：

| 阶段 | 占当前大境界总时间 |
|---|---:|
| 前期 | 20% |
| 中期 | 30% |
| 后期 | 40% |
| 圆满与大突破准备 | 10% |

### 12.3 离线闭关

1. 角色离线后自动进入洞府闭关。
2. 单次离线修炼结算上限测试初值为8现实小时。
3. 离线使用与在线相同的基础修为、灵气产出、灵气吸收和灵气消耗公式。
4. 离线达到突破线后不自动突破。
5. 达到突破线后的剩余离线时间按瓶颈倍率结算。
6. 离线处于虚弱时不能吸收洞府灵气，只获得虚弱基础修为。
7. 虚弱时间、耐药负荷和洞府灵气均按离线经过时间恢复或结算。
8. 登录时必须按状态边界、灵气耗尽边界和突破线边界拆段结算。
9. 不使用时段倍率。

### 12.4 基础满级时间：当前待定

旧测试目标：

`总满灵气等价修炼时长 = 1440现实小时`

当前洞府默认参数：

`灵气产出 = 1灵气日/现实小时`

`满速吸收 = 6灵气日/现实小时`

长期平均可支撑的满速等价修炼时间：

`24小时 × 产出1 ÷ 吸收6 = 4小时/现实日`

如果总需求仍为1440满速等价小时：

`基础满级时间 = 1440 ÷ 4 = 360现实日`

若要保持240现实日，有三种方案：

| 方案 | 调整 |
|---|---|
| A | 总需求改为960满速等价小时 |
| B | 基础灵气产出从1提高到1.5灵气日/游戏日 |
| C | 保留1440小时与产出1，要求玩家长期平均获得1.50倍转化/修炼加成 |

当前建议：

1. 纯基础、无丹药、无功法、无洞府成长口径按360现实日。
2. 活跃玩家通过功法、丹药和其他加成压缩至约240现实日。
3. 该结论尚未冻结，待确定满级目标后再反推各境界修为需求。



### 12.5 修炼追赶

保留追赶接口，不在本轮冻结具体阶梯。

1. 比较角色修为进度与服务器/赛季标杆进度。
2. 落后时获得修炼追赶倍率；追赶倍率只作用于在线与离线打坐的基础修为、灵气修为。
3. 不直接增加修为，不提高突破成功率，不改变丹药直接修为，不改变灵气储量和吸收消耗。
4. 追赶结束后倍率自然回到1.00。
5. 具体差距分档、倍率、上限和标杆口径进入独立配置表。
