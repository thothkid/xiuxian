## §0 结论摘要

1. **大境界**：凡人 → 炼气 → 筑基 → 金丹 → 元婴 → 化神 → 合体 → 大乘。7 个可修炼大境界。**渡劫是大乘圆满后的特殊事件，飞升是终点，二者不占大境界位。**
2. **小境界**：每个大境界固定 10 层。1-3 层=前期、4-6 层=中期、7-9 层=后期、10 层=圆满。等级 1-10=炼气，11-20=筑基，…，61-70=大乘。
3. **命名**：`炼气七层·后期`、`元婴·圆满`。前期不用初期，圆满是独立状态节点，巅峰是排名称号不用作小境界名。
4. **修炼获取**：打坐挂机（主渠道）+ 丹药（每日限量+耐药性）+ 吐纳（手动暴击）+ 秘药（稀缺不占次数）。
5. **突破**：炼气/筑基全层自动过；金丹起小境界需丹药+概率突破；大境界突破需渡劫事件。失败=虚弱期（不扣修为、不掉境界），丹药可缩短。
6. **洞府灵气汇聚**：灵气按游戏内天数自动汇聚（每 1 游戏天 = 现实 60 分钟恢复 1 份）。默认容量 30 天份，可用道具扩充。灵气池余量决定修炼效率阶梯（充盈 100%→稀薄 60%→枯竭 30%→干涸 10%）。洞府外修炼固定 5%。此机制迫使玩家每天修炼几小时后必须出门历练。
7. **丹药品阶**：依世界观九品制（一品至九品），不另创。
8. **耐药性**：每日丹药超过阈值的部分按耐药性公式衰减；耐药性按游戏内昼夜自然恢复。
8. **无修炼方向分化**：不做法修/体修/剑修等分支，单一路径。
9. **炼虚**：世界观文档含炼虚（在化神和合体之间），本稿暂不入枚举，列待裁定。
10. **总计**：7 大境界 × 10 层 = 70 个可修炼小境界。凡人和飞升不计入。

# 第一部分 · 竞品事实层（一念逍遥）

## 1.1 总架构

一念逍遥的修炼体系是四层正交结构：

```
界域（三段）    人界 → 灵界 → 仙界        单向门，飞升不可逆
修炼方向（6条） 法修/体修/剑修/鬼修/儒修/血修   每方向独立境界名表
大境界（14阶）  炼气 … 大罗              各方向同阶对应，只换名不换骨架
小境界          期(前/中/后) × 重(N)      N 随大境界递增，不统一
```

- 各方向严格同阶对称〔实〕——只换名字，不换数值骨架。
- 官方用「对应境界」措辞暗示共用同一阶位表〔实〕。

## 1.4 小境界命名规则

- 仅最低 1 阶（炼气/通脉）用「N 层」〔实〕
- 其余全部用「大境界 + 期 + N 重」〔实〕，期 ∈ {前期, 中期, 后期}
- 不用「初期」，全来源统一用「前期」〔实〕
- 「圆满」是独立状态节点——决定是否触发破境丹〔实〕
- 「巅峰」不是小境界名，是玩家称号/排名档位〔实〕

## 1.5 修炼速度公式

```
修炼速度（修为/周天）= 洞府灵气 × 吸收率              〔实·官方原文·4源重合〕
洞府灵气 = 基础灵气 130 × (1 + Σ各项加成%)              〔实·全加区·数值自洽验证〕
```

玩家实测反推验证：269.36 × 0.45 = 121.21 ✓ 精确吻合。

吸收率只由境界决定，任何系统不得加成它〔实〕——这是最核心的数值闸门。

## 1.7 突破规则

| 项 | 小境界（升层/升重） | 大境界 |
|---|---|---|
| 触发 | 手动点击突破按钮 | 同，可自主选择渡劫时机 |
| 丹药 | 本境界丹药（如结丹用金元丹） | 下一境界丹药（如结丹→元婴用元婴丹） |
| 圆满额外 | 需破境丹 | — |
| 成功率 | 有，随境界递减 | 有，随境界递减 |
| 渡劫 | 无 | 筑基起每大境界需渡劫 |

后期大境界有强制前置任务链（如合体需炼化心魔、大乘需过荧惑守心）〔实〕。

竞品实测成功率：结丹 35% → 元婴 15% → 返虚各阶段 5%〔实〕。失败冷却：结丹 ~45min → 元婴 ~9h → 返虚 ~33h〔实〕。

失败惩罚以【元神受损】debuff（冷却期内无法突破）为主，是否掉修为：〔冲〕三说并存。

竞品**没有**「失败 N 次必成」的硬保底。类保底机制：「瓶颈松动」奇遇（触发后+下次成功率）〔实〕。

## 1.8 渡劫

- 形式：9 段雷劫，非战斗，纯数值承伤
- 倍率：1 / 1.2 / 1.5 / 2 / 3 / 4 / 5 / 7 / 10（Σ=34.7）〔单·自洽验证通过〕
- 辅助：劫盾（橙）减伤 60%、灵盾（紫）减伤 30%〔实〕
- 前期难度极低：「突破到筑基的天劫很弱，不要浪费机缘买灵盾」〔实〕

## §3 修为获取规则

### 3.1 基础公式

```
每 3 秒获得修为 = 境界基础速率(3秒) × (1 + ΣA类加成) × (1 + ΣB类加成) + Σ固定值
即时修为（丹药等）：修为 += effect_value（当场查当前境界列直接累加，不过速率公式）
```

- A 类加成：灵根、先天道器——极少数来源，独立乘区
- B 类加成：功法、装备、丹药 buff、洞府灵气、宗门、法阵——常规来源，汇总乘区
- 固定值：吐纳、部分装备词条——直接累加

**关键约束**：`base_cult_speed`（境界基础速率）只由境界决定。任何丹药/功法/装备/阵法/洞府/付费项目一律不得直接加成或替换 base_cult_speed，只能走 A/B/flat 三池。依据：一念逍遥吸收率只由境界决定〔实〕——这是最核心的数值闸门。

### 3.2 修为获取渠道

| 渠道 | 类型 | 规则 |
|---|---|---|
| **打坐修炼** | 持续 | 主渠道。在线/离线均生效。 |
| **修为丹** | 即时 | 每日限 N 次（具体数值待定），受耐药性影响（见 §4）。大境界突破时刷新次数。 |
| **秘药** | 即时 | 不占每日次数，来源稀缺（天机阁/古修商店/特权卡等）。 |
| **吐纳** | 即时 + 手动 | 每日限次数。点击节奏判定倍率（普通 ×1 / 顺畅 ×2 / 完美 ×5）。吐纳读取境界标准值，不读取修炼速度加成，防止倍率重复放大。 |
| **聚灵丹** | 持续 buff | 一定时间内提高 B 类加成。不占修为丹次数。 |

| 二品 | 高 | 容易 | 日常消耗 |
| 三品 | 中等 | 中等 | 标准丹药 |
| 四品 | 中等 | 中等 | 标准丹药 |
| 五品 | 较低 | 较高 | 高品质——坊市流通 |
| 六品 | 较低 | 高 | 坊市高级货 |

| 二品 | 10 分钟 |
| 三品 | 20 分钟 |
| 四品 | 30 分钟 |

## §4 耐药性系统

### 4.1 设计理由

一念逍遥用「每日次数 + 大境界刷新」控制丹药节奏。每日重置这种方式在 WAR3 ORPG 的昼夜循环（游戏内时间流动）里不自然——更适合用「耐药性」替代，和世界观丹毒机制对齐。

### 4.2 耐药性计算

```
实际丹药效果 = 基础效果 × 耐药性系数

耐药性系数 = max(0.1, 1.0 - 耐药性累积值 / 耐药性阈值)
```

| 项 | 规则 |
|---|---|
| 耐药性累积 | 每服用一颗修为丹，耐药性 +该丹品的耐药值。品级越高，耐药值越高。 |
| 耐药性阈值 | 基准值待定。达到阈值后丹药效果衰减至最低 10%。 |
| 耐药性恢复 | 按游戏内**自然天数**恢复。约 1-2 个游戏昼夜（现实约 30-60 分钟）恢复至零。 |
| 恢复速度 | 均匀恢复，和丹毒排出机制同源——经脉自身的缓慢清理能力（世界观中间层 §十）。 |
| 其他丹药 | 突破丹、聚灵丹等非修为丹药不受耐药性影响（或不共用同一耐药性池）。 |

### 4.3 和每日次数的关系

保留每日次数作为**辅助限制**（防止极端嗑药），耐药性作为**主限制**（控制长期节奏）。两者叠加：

- 每日次数：硬上限，到了不能再吃
- 耐药性：软衰减，吃越多效果越差

## §5 突破规则

### 5.1 三档分级

| 档 | 适用范围 | 流程 | 消耗 |
|:--:|---|---|---|
| **档0 自动过** | 炼气全层、筑基全层 | 修为满即自动升层，无判定、无消耗、无中断 | 无 |
| **档1 判定突破** | 金丹起，每大境界的 1→9 层 | 修为满 → 出现【突破】按钮 → 消耗丹药+灵石 → 概率判定 | 本境界突破丹 + 灵石 |
| **档2 渡劫** | 所有大境界的圆满 → 下一大境界（含大乘圆满→渡劫事件） | 修为满 + 材料齐 → 渡劫台 → 渡劫事件 | 下一境界突破丹 + 破境丹 + 材料 |

### 5.2 突破成功率

| 大境界 | 档1 升层基础成功率 | 档2 渡劫基础成功率 |
|---|:--:|:--:|
| 炼气 / 筑基 | —（档0） | 90% |
| 金丹 | 85% | 70% |
| 元婴 | 80% | 60% |
| 化神 | 75% | 50% |
| 合体 | 70% | 40% |
| 大乘 | 65% | 35% |

丹药加成：突破丹提供固定百分比，加法叠加。上限 95%（保留不确定性）。累积概率：每失败 1 次，下次成功率 +10%（成功后清零）。

> 不照抄一念逍遥的 35%/15%/5%——那是放置手游，失败冷却 8.89h 对它是正常节奏。WAR3 ORPG 是实时在线，基础成功率必须更高，惩罚必须更轻。

### 5.3 失败惩罚：虚弱期

| 档 | 失败惩罚 |
|:--:|---|
| **档1** | 进入【虚弱期】。期间无法再次突破，修炼速度降低 50%。冷却 3 分钟。**不掉修为、不掉层。** |
| **档2** | 进入【虚弱期】。期间无法再次突破，修炼速度降低 70%。冷却 30 分钟。**不掉修为、不掉大境界。** |

缩短虚弱期：
- 定神丹：缩短档1 虚弱期（数值待定）
- 高品质丹药：缩短档2 虚弱期

**不做境界倒退**。ORPG 里境界倒退是极高流失风险动作。

保底：档1 连败 3 次必成，档2 连败 3 次必成。与累积概率双层兜底。

### 5.4 渡劫事件设计

渡劫是大乘圆满→飞升之间的特殊事件，不是可修炼的大境界。

| 项 | 规则 |
|---|---|
| 触发 | 大乘圆满 + 修为满 + 材料齐 → 渡劫台（安全区内固定点）→ 主动开启 |
| 形式 | 9 道雷劫，实时战斗事件。每道间隔 3 秒，玩家可走位/吃药/开盾。 |
| 伤害倍率 | 1 / 1.2 / 1.5 / 2 / 3 / 4 / 5 / 7 / 10（Σ=34.7）——直接借用一念逍遥 5 年线上验证的曲线 |
| 抗性 | 生命值 + 灵力值共同承伤。辅助：劫盾（橙）减伤 60%、灵盾（紫）减伤 30%。 |
| 失败 | 生命值归零 = 渡劫失败。按档2 惩罚（虚弱期 30min），不死亡、不掉装备。 |
| 成功 | 飞升。进入终局/周目内容。全服公告。 |

> 一念逍遥渡劫是纯数值承伤，WAR3 改为实时战斗事件——利用即时战斗引擎的仪式感优势。

## §6 修炼节奏

### 6.1 单个大境界耗时分配

| 阶段 | 占本大境界总修炼时长 |
|:--|:--:|
| 前期（1-3 层） | 15% |
| 中期（4-6 层） | 25% |
| 后期（7-9 层） | 45% |
| 圆满准备与突破 | 15% |

同样是 3 层，后期单层耗时约为前期的 3 倍。后期延长通过阈值与突破压力完成，不增加层数。

### 6.2 修为溢出

| 场景 | 处理 |
|---|---|
| 档0（炼气/筑基自动过） | 溢出修为结转到下一层，不浪费 |
| 档1（金丹起判定突破） | 修为满后可继续打坐，获得修为但速度降到正常值的 20% |
| 档2 圆满→渡劫 | 修为满后可继续打坐，获得修为但速度降到正常值的 10%。提示「可渡劫」 |

### 6.3 离线修炼

- 上限 8 小时
- 离线期间使用与在线相同的常驻公式
- 限时增益按真实剩余时间生效并消耗
- 离线修为可以填满当前层
- 离线期间不自动执行有失败率的突破
- 档0 的自动层允许离线连续通过
- 离线结算不跨越阶段突破或大境界突破

### 6.4 追赶

追赶只加快修为获取，不提高突破成功率，不免除材料与承载条件。

| 与服务器/存档标杆差距（统一序号） | 修炼速度加成（进 B 类） |
|:--|:--:|
| 0-5 | 0% |
| 6-15 | +25% |
| 16-30 | +50% |
| 31-50 | +80% |
| 51+ | +120% |

标杆取活跃玩家境界统一序号前 10 名的中位数。

## §7 状态机

| 状态 | 进入条件 | 可进行操作 | 退出条件 |
|---|---|---|---|
| 修炼中 | 当前修为未满 | 打坐、丹药、吐纳、离线积累 | 修为达到上限 |
| 待精进 | 档0 层修为已满 | 自动精进 | 进入下一层 |
| 待小突破 | 档1 层修为已满 | 放置材料、吃突破丹、点突破 | 成功 / 进入虚弱期 |
| 圆满 | 后期 3 层完成 | 准备大境界突破 | 修为满 + 材料齐 → 待渡劫 |
| 待渡劫 | 圆满 + 修为满 + 材料齐 | 前往渡劫台、吃辅助丹、开盾 | 成功 / 进入虚弱期 |
| 虚弱期 | 突破失败 | 等待、吃定神丹缩短 | 冷却时间结束 |
| 已飞升 | 大乘渡劫成功 | 终局/周目内容 | 按终局规则 |
