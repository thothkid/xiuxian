## §0 结论摘要





1. **大境界**：凡人 → 炼气 → 筑基 → 金丹 → 元婴 → 化神 → 合体 → 大乘。7 个可修炼大境界。渡劫是大乘圆满后的特殊事件，飞升是终点，二者不占大境界位。


2. **小境界**：每个大境界固定 10 层。1-3 层=前期、4-6 层=中期、7-9 层=后期、10 层=圆满。等级 Lv1-10=炼气，Lv11-20=筑基，…，Lv61-70=大乘。


3. **命名**：`炼气七层·后期`、`元婴·圆满`。前期不用初期，圆满是独立状态节点，巅峰是排名称号不用作小境界名。


4. **修炼获取**：洞府打坐（主渠道）+ 丹药 + 吐纳 + 秘药。洞府外修炼效率极低（5%）。


5. **洞府灵气汇聚**（核心节律机制）：灵气按游戏内天数自动汇聚——每 1 游戏天（现实 60 分钟）恢复 1 天份灵气。默认容量 30 天份（可用道具扩充至 48 天份上限）。汇聚/产出速度均可用道具提升。灵气池余量决定修炼效率阶梯（充盈 100%→稀薄 60%→枯竭 30%→干涸 10%）。此机制迫使玩家每天修炼数小时后必须出门历练。


6. **突破**：炼气/筑基全层自动过。金丹起小境界需丹药+概率突破。大境界突破=渡劫事件。失败=虚弱期（不扣修为、不掉境界）。


7. **丹药品阶**：依世界观九品制（一品至九品）。


8. **耐药性**：按游戏内昼夜自然恢复。丹药累积超过阈值后衰减。


9. **无修炼方向分化**：单一修炼路径。


10. **炼虚**：世界观含炼虚（化神和合体之间），本稿暂不入枚举，列待裁定。


11. **时间系统**：1 时辰=5 分钟现实，1 游戏天=60 分钟现实，24 游戏天=1 现实天。


12. **满级时间**：活跃玩家约 6-12 个月（70 小境界，基于充盈档每日修炼数小时估算）。


13. **总计**：7 大境界 × 10 层 = 70 个可修炼小境界。凡人和飞升不计入。

# 第一部分 · 竞品事实层（一念逍遥）





## 1.1 总架构





一念逍遥的修炼体系是四层正交结构：





```


界域（三段）    人界 → 灵界 → 仙界        单向门，飞升不可逆


修炼方向（6条） 法修/体修/剑修/鬼修/儒修/血修   每方向独立境界名表


大境界（14阶）  炼气 … 大罗              各方向同阶对应，只换名不换骨架


小境界          期(前/中/后) × 重(N)      N 随大境界递增，不统一


```





- 各方向严格同阶对称〔实〕——只换名字，不换数值骨架。


- 官方用「对应境界」措辞暗示共用同一阶位表〔实〕。

## 1.4 小境界命名规则





- 仅最低 1 阶（炼气/通脉）用「N 层」〔实〕


- 其余全部用「大境界 + 期 + N 重」〔实〕，期 ∈ {前期, 中期, 后期}


- 不用「初期」，全来源统一用「前期」〔实〕


- 「圆满」是独立状态节点——决定是否触发破境丹〔实〕


- 「巅峰」不是小境界名，是玩家称号/排名档位〔实〕





## 1.5 修炼速度公式





```


修炼速度（修为/周天）= 洞府灵气 × 吸收率              〔实·官方原文·4源重合〕


洞府灵气 = 基础灵气 130 × (1 + Σ各项加成%)              〔实·全加区·数值自洽验证〕


```





玩家实测反推验证：269.36 × 0.45 = 121.21 ✓ 精确吻合。





吸收率只由境界决定，任何系统不得加成它〔实〕——这是最核心的数值闸门。

## §3 修为获取规则





### 3.1 基础公式





```


每 3 秒获得修为 = 境界基础速率 × 洞府灵气系数 × (1 + ΣA类加成) × (1 + ΣB类加成) + Σ固定值


即时修为（丹药等）：修为 += effect_value（当场查当前境界列直接累加，不过速率公式）


```





- `境界基础速率`：只由境界决定。任何丹药/功法/装备/阵法/付费项目一律不得直接加成或替换。


- `洞府灵气系数`：玩家当前所在位置的灵气浓度系数。见 §3.4 洞府灵气汇聚系统。


- A 类加成：灵根、先天道器——极少数来源，独立乘区


- B 类加成：功法、装备、丹药 buff、宗门、法阵——常规来源，汇总乘区


- 固定值：吐纳、部分装备词条——直接累加





### 3.2 修为获取渠道





| 渠道 | 类型 | 规则 |


|---|---|---|


| **洞府打坐** | 持续 | 主渠道。在线/离线均生效。受洞府灵气系数影响。 |


| **修为丹** | 即时 | 每日限 N 次（具体数值待定），受耐药性影响（见 §5）。大境界突破时刷新次数。 |


| **秘药** | 即时 | 不占每日次数，来源稀缺（天机阁/古修商店/特权卡等）。 |


| **吐纳** | 即时 + 手动 | 每日限次数。点击节奏判定倍率（普通 ×1 / 顺畅 ×2 / 完美 ×5）。读取境界标准值，不读取修炼速度加成。 |


| **聚灵丹** | 持续 buff | 一定时间内提高 B 类加成，不占修为丹次数。 |

#### 丹药获取修为





丹药主要有两类，一念逍遥设计沿用：





**① 修为丹（日常涨修为）**：每日限次。每个大境界有对应的主力修为丹，数值按境界递增。品质越高数值越大。





**② 突破丹（大境界突破时专用，一颗）**：炼气→筑基用筑基丹 / 筑基→金丹用金元丹 / 金丹→元婴用元婴丹 / …以此类推。突破丹只在大境界突破时使用，日常修为获取不吃突破丹。





修为丹 =/= 突破丹，两条线互不替代。

## §4 洞府灵气汇聚与消耗（核心节律机制）



### 4.1 设计目的



防止玩家无限挂机打坐。制造「每天有几小时高效修炼→其余时间必须出门历练」的天然节律。



### 4.2 三条核心公式



洞府灵气系统由三个独立公式构成：



#### 汇聚公式



```

灵气池存量(t) = min(容量上限, 灵气池存量(t₀) + 汇聚速率 × Δ游戏天数)



汇聚速率 = 1 天份/游戏天（基础值，可被聚灵阵/功法/道具提升）

容量上限 = 30 天份（基础值，可用道具扩充至 48 天份）

```



玩家不在洞府打坐的每一游戏天（现实 60 分钟），灵气池恢复 1 天份。到上限后停止汇聚。



#### 消耗公式



```

灵气消耗速度 = 当前修炼速度 × 档位消耗倍率



档位消耗倍率：

  充盈档（池余量 100%→20%）：1.0 倍

  稀薄档（池余量 20%→5%）：0.6 倍

  枯竭档（池余量 5%→0%）：0.3 倍

  干涸档（池余量 0%）：0.1 倍

```



修炼越快、池越满，消耗越快。约 5-6 现实小时可将 30 天份的满池耗至稀薄档。



#### 吸收转化公式



```

实际获得修为 = 消耗掉的灵气量 × 转化效率



转化效率 = 1.0（基础值，可被特定丹药提升）

```



注意：转化效率 ≠ 修炼速度。修炼速度由 §3.1 公式决定（境界基础速率 × 灵气系数 × A/B 加成）。转化效率是额外一层——某些丹药的效果是「吸收 1 点灵气获得 1.2 点修为」，直接提升灵气到修为的转化比。



| 项 | 数值 | 说明 |

|---|---|---|

| 汇聚速率 | 1 天份 / 1 游戏天 | 每现实 60 分钟恢复 1 天份。可用道具/功法/阵法提升。 |

| 默认容量 | 30 天份 | 约 30 现实小时从空回满 |

| 扩充上限 | 48 天份 | 可通过道具提升 |

| 基础转化效率 | 1.0 | 可被特定丹药提升（如「吸收 1 灵气→1.2 修为」） |



**满池所需时间**：

- 空→满（30天份）：30 游戏天 = 30 现实小时 ≈ 1.25 现实天

- 空→满（48天份扩充后）：48 游戏天 = 48 现实小时 = 2 现实天




### 4.3 修炼效率阶梯（按灵气池余量）





| 档 | 灵气池余量 | 洞府灵气系数 | 体感 |


|:--:|:--|:--:|------|


| **充盈** | 100% → 20% | **1.0** | 效率最高。玩家应在这个档内修炼。 |


| **稀薄** | 20% → 5% | **0.6** | 效率下降，玩家开始考虑是否出门。 |


| **枯竭** | 5% → 0% | **0.3** | 继续打坐性价比低。 |


| **干涸** | 0% | **0.1** | 保底速率。吸引力极低但不禁止。 |





### 4.4 消耗速率





玩家在洞府中打坐时，灵气池持续消耗。消耗速度与修炼效率成正比——灵气池越满，修炼越快，消耗也越快。





| 档 | 灵气池消耗速度 |


|:--|:--|


| 充盈 | 将 30 天份的灵气池从满耗至 20%，约需持续打坐 **5-6 现实小时** |


| 稀薄 | 消耗速度减慢（效率只有 60%，消耗也同比例减慢） |





> 数值目的：30 天份灵气池 ≈ 每天约 5-6 小时的高效修炼窗口。玩家在此窗口内修炼性价比最高。窗口用完后灵气池需要约 30 现实小时（1.25 现实天）回满。





### 4.5 洞府之外





任何非洞府地点（野外、宗门广场、坊市等）修炼系数固定为 **0.05**。这意味着：


- 没人在野外打坐——这不是 bug，这是设计


- 玩家上线必然回洞府


- 洞府作为「家」的归属感被修炼效率这条硬利益锚定





### 4.6 每日节律设计





```


卯时（清晨）   → 回洞府开打坐。灵气池有余量 → 充盈档


辰时-午时      → 持续打坐。效率最高。→ 充盈档


未时-申时      → 灵气池进入稀薄档（60%）。效率下降。


酉时           → 出门历练。妖兽刷新、坊市扫货、任务。


戌时-子时      → 深夜。魔气溢出、稀有怪概率翻倍。


丑时-寅时      → 独有 BOSS 窗口、蓝门触发最高。


次日卯时       → 灵气池经一天自然汇聚后恢复。回洞府。→ 充盈档


```





这个节律让「上线→回洞府打坐几小时→出门冒险→下线」成为自然行为，不需要弹窗。





### 4.7 可扩展性





| 扩展点 | 机制 | 配置表 |


|---|---|---|


| 扩充灵气池容量 | 道具/灵石购买，增加池上限（30→48 天份） | `cave_qi_config` |


| 提升汇聚速率 | 聚灵阵等级、功法、特殊道具 | `cave_qi_config` |


| 降低消耗速率 | 道具/丹药 buff | B 类加成池 |


| 提升干涸档保底 | 高级洞府/道器 | `cave_qi_config` |





### 4.8 对升级时间估算的影响





之前给出的「6-12 个月满级」估算，隐含假设是玩家**每天利用充盈档（前 5-6 小时）修炼**。如果玩家每天只打坐 2 小时（也在充盈档内），每日修炼量等比例减少，但体感效率不变——这是公平的。满级时间等比例拉长。

## §5 耐药性系统





### 5.1 设计理由





一念逍遥用「每日次数 + 大境界刷新」控制丹药节奏。本项目改用「耐药性」，和世界观丹毒机制对齐（中间层 §十）。





### 5.2 耐药性计算





```


实际丹药效果 = 基础效果 × 耐药性系数





耐药性系数 = max(0.1, 1.0 - 耐药性累积值 / 耐药性阈值)


```





| 项 | 规则 |


|---|---|


| 耐药性累积 | 每服用一颗修为丹，耐药性 +该丹品的耐药值。品级越高，耐药值越高。 |


| 耐药性阈值 | 基准值待定（压测后填入）。达到阈值后丹药效果衰减至最低 10%。 |


| 耐药性恢复 | 按游戏内自然天数恢复。约 1-2 个游戏昼夜（现实 1-2 小时）恢复至零。 |


| 恢复速度 | 均匀恢复，和丹毒排出机制同源——经脉自身的缓慢清理能力。 |


| 其他丹药 | 突破丹、聚灵丹等非修为丹药不受耐药性影响。 |





### 5.3 和每日次数的关系





保留每日次数作为**辅助限制**（防极端嗑药），耐药性作为**主限制**。每日次数=硬上限，耐药性=软衰减。

## §6 突破规则





### 6.1 三档分级





| 档 | 适用范围 | 流程 | 消耗 |


|:--:|---|---|---|


| **档0 自动过** | 炼气全层、筑基全层 | 修为满即自动升层。无判定、无消耗、无中断。 | 无 |


| **档1 判定突破** | 金丹起，每大境界的 1→9 层 | 修为满→【突破】按钮→消耗丹药+灵石→概率判定 | 本境界突破丹 + 灵石 |


| **档2 渡劫** | 所有大境界的圆满→下一大境界（含大乘→渡劫事件） | 修为满+材料齐→渡劫台→渡劫事件 | 下一境界突破丹 + 破境丹 + 材料 |





### 6.2 突破成功率





| 大境界 | 档1 升层基础成功率 | 档2 渡劫基础成功率 |


|---|:--:|:--:|


| 炼气 / 筑基 | —（档0） | 90% |


| 金丹 | 85% | 70% |


| 元婴 | 80% | 60% |


| 化神 | 75% | 50% |


| 合体 | 70% | 40% |


| 大乘 | 65% | 35% |





丹药加成：突破丹提供固定百分比，加法叠加。上限 95%。每失败 1 次，下次成功率 +10%。





> 不照抄一念逍遥的 35%/15%/5%——那是放置手游，失败冷却 8.89h 正常。WAR3 ORPG 基础成功率须更高、惩罚须更轻。





### 6.3 失败惩罚：虚弱期

突破失败后进入【虚弱期】，灵气吸收通道被突破失败的反噬暂时封堵。

| 档 | 失败惩罚 |
|:--:|---|
| **档1** | 进入【虚弱期】。**无法吸收灵气**（洞府打坐修为近乎归零），丹药仍可服用但不享受灵气加成。冷却 3 分钟。不掉修为、不掉层。 |
| **档2** | 进入【虚弱期】。**无法吸收灵气**，丹药仍可服用但不享受灵气加成。冷却 30 分钟。不掉修为、不掉大境界。 |

虚弱期内：
- 洞府打坐灵气系数强制为 0（不可修炼灵气，等同于修炼停滞）
- A/B 类加成和固定值（丹药/吐纳）仍可生效，但失去了灵气底数后收益极低
- 定神丹可缩短档1 虚弱期；高品质丹药可缩短档2 虚弱期

不做境界倒退。保底：档1 连败 3 次必成 / 档2 连败 3 次必成。



#### 虚弱期配置表 weakness_config

| 字段 | 类型 | 说明 |
|---|---|---|
| weakness_id | int | 对应 breakthrough_config.fail_weaken_id |
| duration_seconds | int | 持续时间（秒） |
| can_absorb_qi | bool | 能否吸收灵气（false=灵气系数强制0） |
| can_breakthrough | bool | 能否再次突破（false） |
| cult_speed_pct | float | 修炼速度系数（A/B/flat打折比例） |
| direct_cult_pct | float | 直接修为系数（丹药/吐纳打折比例） |

### 6.4 渡劫事件设计





渡劫是大乘圆满→飞升之间的特殊事件，不是可修炼的大境界。





| 项 | 规则 |


|---|---|


| 触发 | 大乘圆满 + 修为满 + 材料齐 → 渡劫台 → 主动开启 |


| 形式 | 9 道雷劫，实时战斗事件。每道间隔 3 秒，玩家可走位/吃药/开盾。 |


| 伤害倍率 | 1 / 1.2 / 1.5 / 2 / 3 / 4 / 5 / 7 / 10（Σ=34.7）——借用一念逍遥 5 年线上验证曲线 |


| 辅助 | 劫盾（橙）减伤 60%、灵盾（紫）减伤 30% |


| 失败 | 生命值归零 = 渡劫失败。按档2 惩罚，不死亡、不掉装备。 |


| 成功 | 飞升。全服公告。进入终局/周目内容。 |

### 7.2 满级时间估算





基于「玩家每天利用充盈档（5-6h）修炼」假设：





| 大境界 | 预计现实时间 |


|---|:--|


| 炼气 Lv1-10 | 第 1 天（~1-2h） |


| 筑基 Lv11-20 | 3-5 天 |

| 合体 Lv51-60 | 2-4 月 |


| 大乘 Lv61-70 | 3-6 月 |


| **总计** | **约 6-12 个月**（休闲玩家 12-24 个月） |

### 7.3 修为溢出





| 场景 | 处理 |


|---|---|


| 档0（炼气/筑基自动过） | 溢出修为结转到下一层，不浪费 |


| 档1（金丹起判定突破） | 修为满后可继续打坐，速度降至 20% |


| 档2 圆满→渡劫 | 修为满后可继续打坐，速度降至 10%。提示「可渡劫」 |





### 7.4 离线修炼





上限 8h。使用与在线相同的常驻公式。限时增益按真实时间消耗。档0 自动层允许离线连续通过。不自动执行有失败率的突破。





### 7.5 追赶





只加快修为获取，不提高突破成功率。





| 与标杆差距（统一序号） | 修炼速度加成（进 B 类） |


|:--|:--:|


| 0-5 | 0% |


| 6-15 | +25% |


| 16-30 | +50% |


| 31-50 | +80% |


| 51+ | +120% |





标杆取活跃玩家境界统一序号前 10 名的中位数。
