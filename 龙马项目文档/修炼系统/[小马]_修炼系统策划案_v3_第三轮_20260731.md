## §0 已定清单（thoth 指令逐条收敛）

1. 大境界序列：凡人 → 炼气 → 筑基 → 金丹 → 元婴 → 化神 → 合体 → 大乘。7 个可修炼大境界。
2. 渡劫 = 大乘圆满后的特殊行为，不是大境界。飞升 = 终局结果。
3. ▲ **待裁定**：世界观三层文档均含「炼虚」（化神→炼虚→合体），本稿暂按 7 境界（1-70 级）出表，炼虚作为可插入位保留。
4. 每个大境界固定 10 级。1-3 级=前期，4-6 级=中期，7-9 级=后期，10 级=圆满。
5. 角色等级 = 小境界序号。Lv1-10=炼气，Lv11-20=筑基，…，Lv61-70=大乘。
6. 突破分三档：档0 炼气/筑基全层自动过；档1 金丹起每层需丹药+概率突破；档2 圆满→下一大境界渡劫。
7. 突破丹 = 可选辅助，不是门票。允许不吃丹直接突破，丹药提高成功率。
8. 突破失败不扣修为、不降等级、不清空大境界。
9. 突破失败 → 虚弱期。虚弱期内无法吸收洞府灵气，修炼效率骤降。虚弱自然恢复，可用丹药缩短。
10. 修为满未突破时可继续打坐，速度降至正常 20%（档1）/ 10%（档2）。溢出修为保留但不自动跨级。
11. 修为丹不采用现实日固定次数，改用游戏昼夜驱动的耐药负荷。
12. 离线后角色自动进入洞府闭关。只修炼，不自动突破，不产生新虚弱。
13. 高效打坐必须在洞府内。洞府外允许打坐但只获极低修为（5%）。
14. 洞府有可积攒/消耗的灵气池。1 游戏天（现实 60 分钟）汇聚 1 天份灵气，默认容量 30 天份，可扩充至 48 天份。
15. 不设清晨/白昼/夜间时段倍率。修炼差异只由地点、灵气池档位、加成、瓶颈和虚弱决定。
16. 丹药品阶：一品至九品（世界观 §十一），不用下/中/上/极品。
17. 修为丹采用「等价基础修炼时长」计算，不读取修炼速度加成。
18. 无修炼方向分化，单一修炼路径。
19. 无紫府大境界。
20. 修为是累计进度，升级和突破失败不清空修为。
21. 丹药分修为丹和突破丹两条线，互不替代。
22. 满级时间按灵气池长期产出计算，不以每天满池为前提。

## 二、竞品母版（一念逍遥）

### 2.1 结构

```
修炼方向 → 大境界 → 前/中/后期 → 重数 → 修为 → 瓶颈 → 突破
```

- 炼气/通脉：十层制，不分前中后

## 四、修为获取

### 4.1 核心公式

每 3 秒结算一次。修为由两部分组成：

```
基础修为 = 当前等级基础速率 × 地点倍率 × 瓶颈倍率 × 虚弱倍率

灵气修为 = min(结算期可用灵气, 吸收上限) × 单位灵气修为值 × 转化效率 × 外部倍率

本次修为 = (基础修为 + 灵气修为) × (1 + ΣA类加成) × (1 + ΣB类加成) + Σ固定值
```

| 参数 | 说明 |
|---|---|
| 当前等级基础速率 | 由 realm_config 决定，无灵气时的保底修炼速度 |
| 地点倍率 | 洞府=1.0，洞府外/野外=0.05 |
| 瓶颈倍率 | 修为满未突破时 0.2（档1）/ 0.1（档2） |
| 虚弱倍率 | 正常=1.0，虚弱期=0.05 |
| 可用灵气 | 洞府灵气池当前存量 |
| 吸收上限 | 基础吸收速度 × 吸收倍率（丹药可提升） |
| 单位灵气修为值 | 每 1 点灵气→修为的基础转化量 |
| 转化效率 | 基础=1.0，丹药/功法可提升（如吸收 1 灵气→1.2 修为） |
| A 类加成 | 灵根、先天道器——极少数来源，独立乘区 |
| B 类加成 | 功法、装备、丹药 buff、聚灵阵、宗门——汇总乘区 |
| 固定值 | 吐纳、部分装备词条——直接累加 |

硬约束：`当前等级基础速率` 和 `单位灵气修为值` 只由境界决定。任何系统不得直接加成或替换。

### 4.2 加成接口

A/B/flat 三类加成池为**外部接口**。具体哪个系统（灵根/功法/装备/丹药/阵法/宗门）挂什么值，由各系统自行配置，修炼系统只负责在结算时读取并代入公式。修炼系统内部闭包的参数：境界基础速率、单位灵气修为值、地点倍率、瓶颈倍率、虚弱倍率。

### 4.3 修为来源渠道

| 渠道 | 类型 | 规则 |
|---|---|---|
| 洞府打坐 | 持续 | 主渠道。在线/离线均生效。受洞府灵气池影响。 |
| 修为丹 | 即时 | 增加修为。每日限次（辅助限制），受耐药性影响。大境界突破时刷新次数。 |
| 秘药 | 即时 | 不占每日次数，来源稀缺。 |
| 吐纳 | 即时+手动 | 每日限次数。点击判定倍率（×1/×2/×5）。读取境界标准值，不读修炼速度加成。 |
| 聚灵丹 | 持续 buff | 一定时间内提高 B 类加成。不占修为丹次数。 |

### 4.4 丹药类型

| 类型 | 增加修为 | 作用 |
|:--|:--:|---|
| 修为丹 | 是 | 立即加修为，采用「等价基础修炼时长」计算 |
| 秘药 | 是 | 不占每日次数的大额修为 |
| 聚灵丹 | 否 | 提高 B 类修炼速度加成 |
| 转化丹 | 否 | 提高灵气→修为转化效率（如 1.0→1.2） |
| 突破丹 | 否 | 提高突破成功率 |
| 护脉丹 | 否 | 降低突破失败修为损失 |
| 定神丹 | 否 | 缩短虚弱期 |

## 六、洞府灵气汇聚与消耗

### 6.1 三条核心公式

#### 汇聚公式

```
灵气池存量(t) = min(容量上限, 灵气池存量(t₀) + 汇聚速率 × Δ游戏天数)

汇聚速率 = 1 天份/游戏天（可被聚灵阵/功法/道具提升）
容量上限 = 30 天份（可用道具扩充至 48 天份）
```

玩家不在洞府打坐的每一游戏天（现实 60 分钟），灵气池恢复 1 天份。到上限停止。

#### 消耗公式

```
灵气消耗速度 = 当前修炼速度 × 档位消耗倍率

充盈档：1.0 倍  稀薄档：0.6 倍  枯竭档：0.3 倍  干涸档：0.1 倍
```

修炼越快、池越满，消耗越快。30 天份满池约需 5-6 现实小时耗至稀薄档。

#### 吸收转化公式

```
实际获得修为 = 消耗掉的灵气量 × 转化效率
转化效率 = 1.0（基础值，可被丹药/功法提升）
```

### 6.2 修炼效率阶梯

| 档 | 灵气池余量 | 洞府灵气系数 |
|:--:|:--|:--:|
| 充盈 | 100%→20% | 1.0 |
| 稀薄 | 20%→5% | 0.6 |
| 枯竭 | 5%→0% | 0.3 |
| 干涸 | 0% | 0.1 |

洞府外修炼系数固定 0.05。满池所需时间：30 游戏天 ≈ 30 现实小时 ≈ 1.25 现实天。

## 七、耐药性

```
实际丹药效果 = 基础效果 × max(0.1, 1.0 − 耐药累积值 / 耐药阈值)
```

| 项 | 规则 |
|---|---|
| 耐药累积 | 每服一颗修为丹，耐药值 + 该丹品耐药负荷。品级越高，负荷越高。 |
| 耐药恢复 | 按游戏自然天数恢复。约 1-2 游戏昼夜（现实 1-2 小时）恢复至零。 |
| 辅助限制 | 保留每日次数作为硬上限，耐药性为主限制。 |

## 八、突破

### 8.1 三档分级

| 档 | 适用范围 | 流程 |
|:--:|---|---|
| 档0 自动过 | 炼气全层、筑基全层 | 修为满即自动升层。无判定、无消耗。 |
| 档1 判定突破 | 金丹起，每大境界 1→9 层 | 修为满→突破按钮→消耗丹药+灵石→概率判定。允许不吃丹直接突破。 |
| 档2 渡劫 | 所有大境界圆满→下一大境界（含大乘→渡劫事件） | 修为满+材料齐→渡劫台→渡劫事件 |

### 8.2 成功率

### 8.3 虚弱期

突破失败后灵气吸收通道被反噬封堵。

| 档 | 惩罚 |
|:--:|---|
| 档1 | 虚弱期。无法吸收灵气（洞府打坐修为归零），修炼效率 ×0.05。冷却 3 分钟。不掉修为不掉层。 |
| 档2 | 虚弱期。无法吸收灵气，修炼效率 ×0.05。冷却 30 分钟。不掉修为不掉大境界。 |

虚弱期内：洞府灵气系数强制为 0，A/B 加成和固定值仍可生效但失去灵气底数后收益极低。定神丹缩短档1，高品质丹药缩短档2。不做境界倒退。保底：连败 3 次必成。

| 51+ | +120% |

标杆 = 活跃玩家统一序号前 10 名中位数。

## 十、状态机

状态优先级：**虚弱 > 瓶颈 > 正常**。

| 状态 | 进入条件 | 可操作 | 退出条件 |
|---|---|---|---|
| 修炼中 | 修为未满 | 打坐/丹药/吐纳/离线 | 修为达上限 |
| 待突破 | 修为满（档0/档1/档2） | 自动/手动突破 | 成功/虚弱期 |
| 瓶颈 | 修为满未突破 | 继续打坐（效率×0.2/0.1） | 突破或离线 |
| 虚弱期 | 突破失败 | 等待/定神丹缩短 | 冷却结束 |
| 已飞升 | 大乘渡劫成功 | 终局/周目 | 按终局规则 |
