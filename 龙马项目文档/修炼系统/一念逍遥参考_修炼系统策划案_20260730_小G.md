# [小G] 修炼系统策划案：一念逍遥母版与项目收敛
> 生成者：[小G] | 日期：2026-07-31 | 轮次：第二轮

版本：V2.0  
状态：第二轮产出；用户已定项直接执行，测试数值仍待压测  
范围：境界、等级、修为、打坐、修为丹、耐药性、小突破、大突破、虚弱、渡劫与飞升特殊行为  

## 0. 本轮结论

### 0.1 已定

1. 先完整拆解《一念逍遥》修炼母版，再做项目差异化。
2. 项目只有一条修炼主线，不分法修、体修、剑修、鬼修、儒修、血炼。
3. 角色等级就是小境界序号；每一级就是一个小境界。
4. 每个大境界固定10级，不随后期境界增加层数。
5. 每个大境界的阶段固定为：
   - 1—3级：前期。
   - 4—6级：中期。
   - 7—9级：后期。
   - 10级：圆满。
6. 每一个等级边界都需要一次小突破；第3、6、9级之后属于强化的小突破节点。
7. 每个大境界圆满后必须进行一次大境界突破。
8. 突破丹是可选辅助，不是突破门票；允许不吃丹直接突破。
9. 突破失败不扣修为、不清空大境界、不降低等级。
10. 突破失败进入虚弱期；虚弱期间不能再次突破，修为获取降低。
11. 虚弱自然恢复，也可使用恢复类丹药提前恢复。
12. 修为达到突破线但尚未突破时仍可继续增长；打坐修为速度降低，溢出修为保留。
13. 修为丹不采用现实自然日的固定服用次数，改用随游戏昼夜自然恢复的耐药负荷。
14. 离线修炼、相邻大境界修为倍率、阶段节奏保留。
15. 渡劫不是大境界，是大乘大成后的特殊行为。
16. 飞升不是大境界，是渡劫成功后的终局结果。

### 0.2 世界观裁定

项目大境界共8个：

`炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘`

终点状态：

`大乘十级 → 大乘·大成 → 特殊行为：渡劫 → 终局结果：飞升或留世`

裁定理由：

1. 三份世界观底层文档均使用炼虚，并赋予炼虚“借法则看见天界大阵痕迹”的独立质变，不能删除。
2. 三份世界观底层文档使用大乘，不使用大成作为独立大境界。
3. “大成”适合作为大乘十级完成后的状态名，表示修炼主线已经完成。
4. 世界观已经把丹田定义为灵气压缩仓，并明确灵气由气态、液态进入金丹固态；紫府没有不可替代的物质机制。
5. 紫府在部分家族修仙作品中位于筑基与金丹之间，在另一些作品中只是丹田、识海或内景的别称，不是修仙题材的统一大境界。
6. 本项目不增加紫府大境界。需要使用“紫府”一词时，只能作为筑基后期开辟内景的文学称呼，不进入等级和境界枚举。

### 0.3 丹药品质裁定

1. 丹药使用一品至九品，不使用下品、中品、上品、极品作为主品质轴。
2. 原因是世界观底层已经冻结丹药九品，并明确一、三、五、七、九品是主要品质跃迁点。
3. “下品/中品/上品/极品”可用于灵石或其他资源，不再与丹药九品并存，避免双品质轴。
4. 修为丹继续采用“等价基础修炼时长”计算，这是最容易控制和跨境界平衡的数值方式。

## 1. 《一念逍遥》修炼母版

本节只记录竞品母版，不代表项目最终规则。

### 1.1 结构

《一念逍遥》的修炼层级为：

`修炼方向 → 大境界 → 前/中/后期 → 重数 → 修为 → 瓶颈 → 突破`

特殊点：

1. 炼气/通脉使用十层制。
2. 后续大境界使用“前期/中期/后期+重数”。
3. 每一重都是小境界。
4. 修为达到当前重上限后，角色出现破境或突破入口。
5. 每次突破都可以服用一颗对应突破丹提高成功率。
6. 当前大境界内部突破使用本境界丹药。
7. 后期圆满突破到下一大境界使用下一大境界的突破丹。
8. 大境界提升后可刷新修为丹、吐纳等限次资源；该规则属于版本性设计。

### 1.2 当前境界母表

《一念逍遥》当前已出现法修、体修、御剑、驭鬼、圣儒、血炼六个修炼方向。项目删除方向差异，但完整母版仍保留法修/体修对应关系：

| 阶位 | 法修 | 体修 | 世界层级 | 版本状态 |
|---:|---|---|---|---|
| 0 | 江湖好手 | 凡人之躯 | 凡俗 | 起始状态 |
| 1 | 炼气 | 通脉 | 人界 | 十层制 |
| 2 | 筑基 | 锻骨 | 人界 | 前/中/后期+重 |
| 3 | 结丹 | 炼腑 | 人界 | 前/中/后期+重 |
| 4 | 元婴 | 元武 | 人界 | 前/中/后期+重 |
| 5 | 化神 | 神力 | 人界 | 前/中/后期+重 |
| 6 | 返虚 | 破虚 | 灵界 | 前/中/后期+重 |
| 7 | 合体 | 混元 | 灵界 | 前/中/后期+重 |
| 8 | 大乘 | 大成 | 灵界 | 前/中/后期+重 |
| 9 | 渡劫 | 涅槃 | 灵界 | 2021年后追加 |
| 10 | 真仙 | 仙体 | 仙界 | 仙界境界 |
| 11 | 金仙 | 金相 | 仙界 | 仙界境界 |
| 12 | 太乙 | 太上 | 仙界 | 2024年追加 |
| 13 | 大罗 | 罗天 | 仙界 | 大罗为官方；罗天为当前玩家资料名 |

版本口径：

1. 旧攻略中的道祖/道体列表是旧版本快照，不能直接插在金仙和太乙之间作为当前必经大境界。
2. 炼气/通脉可以确认是十层。
3. 筑基以后可以确认使用前期、中期、后期和重数。
4. 公开资料出现过结丹后期六重、元婴后期八重、化神后期十五重、大乘/渡劫二十重等不同快照。
5. 当前资料也出现前期二十重、中期二十重。
6. 因此不能把某一个版本的重数写成永久统一规则，也不能仅凭不同大境界的后期数字推导同一大境界前中后数量不等。
7. 项目不复制该动态扩层方式，统一收敛为每个大境界十级。

### 1.3 修为来源

《一念逍遥》的核心修为来源：

| 来源 | 规则 |
|---|---|
| 洞府打坐 | 按时间持续获得修为 |
| 离线修炼 | 离线继续按修炼规则积累 |
| 修为丹 | 立即增加对应修炼方向的修为 |
| 修为秘药 | 立即增加修为，通常不占普通修为丹次数 |
| 吐纳 | 主动操作获得修为，可触发倍率 |
| 洞府、聚灵阵、功法、古宝等 | 提升洞府灵气或吸收率 |
| 奋起 | 落后服务器前列时增加修炼速度 |

基础关系：

`修炼速度 = 洞府灵气 × 吸收率`

普通修为丹存在服用次数；历史公开资料常见每日20次，大境界突破后刷新。吐纳也存在限次与大境界刷新。具体次数发生过版本调整，母版记录机制，不把20写成项目永久值。

### 1.4 丹药分类

《一念逍遥》中与修炼相关的丹药至少分为：

| 类型 | 是否直接增加修为 | 作用 |
|---|:--:|---|
| 修为丹 | 是 | 立即增加修为 |
| 修为秘药 | 是 | 立即增加大量修为 |
| 突破丹 | 否 | 提高突破成功率 |
| 恢复类突破丹效果 | 否 | 缩短元神受损时间 |
| 气血/真元恢复丹 | 否 | 战斗恢复 |
| 永久属性丹 | 否 | 永久增加指定属性 |

不是所有丹药都会增加修为。只有物品效果明确写有“增加修为”的丹药才增加修为。

### 1.5 突破

《一念逍遥》的公开规则可以确认：

1. 小境界和大境界都存在主动突破。
2. 可以不服用突破丹直接尝试。
3. 突破丹提高成功率。
4. 突破失败会获得“元神受损”状态。
5. 元神受损期间不能再次突破。
6. 部分突破丹可以缩短元神恢复时间。
7. “瓶颈松动”等效果可以提高下一次突破成功率。
8. 公开资料对失败是否扣修为存在版本和来源冲突，不能作为固定竞品事实。

### 1.6 项目不复制的部分

| 《一念逍遥》内容 | 项目处理 |
|---|---|
| 多修炼方向 | 删除，只保留单主线 |
| 后期每期大量重数 | 删除，所有大境界固定10级 |
| 现实自然日服药次数 | 改为游戏昼夜驱动的耐药负荷 |
| 渡劫作为境界线中的独立阶段 | 改为大乘大成后的特殊行为 |
| 飞升作为境界推进节点 | 改为终局结果 |
| 方向专属修为丹 | 删除，只保留统一修为丹 |

## 2. 常见修仙小说规则归纳

修仙小说不存在统一境界和丹药标准，只能归纳常见结构。

### 2.1 修为来源

1. 打坐吐纳，吸收天地灵气。
2. 运转功法，将灵气转化为自身修为。
3. 服用修为丹、聚气丹、增元丹等直接补充灵气。
4. 炼化天材地宝、妖丹、灵物。
5. 接受传功、灌顶、机缘。
6. 在灵脉、洞府、聚灵阵等高灵气环境修炼。

项目核心只保留两种通用入口：

1. 打坐修炼。
2. 直接增加修为的丹药或秘药。

其他系统若奖励修为，统一调用“增加修为”入口，不在修炼系统内分别维护来源。

### 2.2 丹药常见作用

| 类型 | 常见作用 | 是否增加修为 |
|---|---|:--:|
| 修为丹 | 补充和凝练灵气 | 是 |
| 突破丹 | 稳定经脉、冲击瓶颈、提高成功率 | 否 |
| 淬体丹 | 提高肉身承载 | 否 |
| 凝神丹 | 提高神识或稳定心神 | 否 |
| 洗髓丹 | 改善资质或灵根 | 否 |
| 疗伤丹 | 恢复伤势 | 否 |
| 战斗丹 | 临时增加战斗能力 | 否 |
| 解毒丹 | 清除毒素、丹毒或魔气污染 | 否 |
| 养神丹 | 恢复突破失败造成的元神受损 | 否 |

### 2.3 过量服药的常见后果

1. 丹毒积累。
2. 药效递减。
3. 耐药性上升。
4. 经脉堵塞。
5. 根基虚浮。
6. 后续突破难度上升。

项目采用“耐药负荷+药效递减”，不采用永久损坏根基。

## 3. 等级、境界与阶段

### 3.1 推导公式

角色等级范围：

`1—80级`

大境界索引：

`大境界索引 = 向下取整((角色等级 - 1) ÷ 10)`

境界内等级：

`境界内等级 = ((角色等级 - 1) mod 10) + 1`

阶段：

| 境界内等级 | 阶段 |
|---:|---|
| 1—3 | 前期 |
| 4—6 | 中期 |
| 7—9 | 后期 |
| 10 | 圆满 |

### 3.2 突破节点

| 当前境界内等级 | 下一步 | 类型 |
|---:|---|---|
| 1、2、4、5、7、8 | 下一小境界 | 普通小突破 |
| 3 | 中期一层 | 阶段小突破 |
| 6 | 后期一层 | 阶段小突破 |
| 9 | 圆满 | 圆满小突破 |
| 10 | 下一大境界一层 | 大境界突破 |
| 大乘10 | 渡劫准备 | 终局特殊行为 |

每一级都是小境界。前期、中期、后期只是阶段标签，不额外占等级。

## 5. 修为规则

### 5.1 修为是累计值

1. 修为是角色长期积累的总进度。
2. 每个等级有一个累计修为突破线。
3. 修为不会因为升级而归零。
4. 突破不会消耗修为。
5. 突破失败不会扣修为。
6. 等级只在突破成功后提升。
7. 修为超过当前突破线时，超出部分全部保留。
8. 超出修为不能自动跨级，每一级仍必须分别突破。

### 5.2 打坐公式

每3秒结算一次：

`本次修为 = 当前等级基础修炼速率 × 外部修炼倍率 × 瓶颈倍率 × 虚弱倍率 × 时段倍率`

| 项 | 来源 |
|---|---|
| 当前等级基础修炼速率 | 等级境界配置 |
| 外部修炼倍率 | 外部属性/加成管理器统一汇总 |
| 瓶颈倍率 | 修为是否达到当前突破线 |
| 虚弱倍率 | 是否处于突破虚弱 |
| 时段倍率 | 游戏内昼夜时段 |

本系统不维护功法、装备、洞府、阵法、奇遇分别加多少。对应系统只需要把结果汇总到“修炼速度加成”属性，本系统结算时读取总值。

### 5.3 瓶颈后继续修炼

修为达到当前突破线但尚未突破：

1. 修为继续增加。
2. 打坐修为速度降为正常的25%。
3. 修为丹仍可使用，但受耐药效率和虚弱倍率影响。
4. 离线修炼同样按25%结算。
5. 突破成功后全部溢出修为保留。
6. 不设置溢出修为硬上限。
7. 无论溢出多少，都不能跳过突破节点。

`瓶颈倍率初值 = 0.25`

### 5.4 时段倍率

依据世界观昼夜规则：

| 时段 | 打坐倍率 |
|---|---:|
| 清晨 | 1.25 |
| 白昼 | 1.00 |
| 傍晚 | 0.90 |
| 夜间 | 1.10 |
| 深夜 | 0.85 |

此表只影响打坐，不影响修为丹。

## 6. 修为丹

### 6.1 基础公式

每颗修为丹绑定一个适用大境界。

## 7. 耐药性

### 7.1 状态定义

耐药负荷范围：

`0—100`

1. 0表示没有耐药。
2. 数值越高，丹药实际效果越低。
3. 服用丹药先按当前耐药负荷计算效果，再增加耐药负荷。
4. 耐药负荷可以到达100，但不会禁止服药。
5. 达到高耐药后继续服药只能获得极低收益。

### 7.2 药效公式

`耐药效率 = max(10%, (1 - 当前耐药负荷 ÷ 100)²)`

| 当前耐药负荷 | 实际效率 |
|---:|---:|
| 0 | 100% |
| 10 | 81% |
| 25 | 56.25% |
| 50 | 25% |
| 75 | 10% |
| 100 | 10% |

该曲线使连续嗑药快速进入低收益区，但不设置强制每日次数。

### 7.3 自然恢复

`经过游戏日数 = 经过现实秒数 ÷ 一昼夜现实秒数`

`恢复后的耐药负荷 = max(0, 原耐药负荷 - 经过游戏日数 × 每游戏日恢复值)`

测试初值：

`每游戏日恢复60点耐药负荷`

若一个完整昼夜为现实30分钟：

1. 100点耐药负荷完全恢复需要约1.67个游戏日。
2. 对应现实时间约50分钟。
3. 在线和离线都自然恢复。
4. 修改昼夜长度时不需要重写耐药规则。

### 7.4 丹药类型负荷

| 丹药类型 | 耐药负荷系数 |
|---|---:|
| 修为丹 | 1.00 |
| 修为秘药 | 1.50 |
| 突破丹 | 0.50 |
| 属性丹 | 1.00 |
| 战斗丹 | 0.40 |
| 疗伤丹 | 0.30 |
| 养神丹 | 0.50 |
| 解毒清心丹 | 减少耐药负荷，不增加 |

`实际增加负荷 = 品阶基础负荷 × 丹药类型负荷系数`

## 10. 突破失败与虚弱

### 10.1 固定规则

突破失败：

1. 不扣修为。
2. 不清空修为。
3. 不降低等级。
4. 不倒退大境界。
5. 保留全部溢出修为。
6. 已使用的突破丹和本次消耗材料不返还。
7. 获得“元神受损/破境虚弱”状态。
8. 虚弱期间不能进行任何小突破、大突破或特殊渡劫。
9. 虚弱期间打坐修为和修为丹收益降低。

### 10.2 虚弱强度

测试初值：

| 失败类型 | 持续时间 | 修为获取倍率 |
|---|---:|---:|
| 普通小突破失败 | 0.25游戏日 | 75% |
| 阶段小突破失败 | 0.50游戏日 | 60% |
| 圆满小突破失败 | 1.00游戏日 | 50% |
| 大境界突破失败 | 2.00游戏日 | 25% |
| 特殊渡劫失败 | 单独配置 | 单独配置 |

虚弱倍率同时作用于：

1. 打坐修为。
2. 离线修为。
3. 修为丹。
4. 修为秘药。
5. 其他直接增加修为的入口。

2. 在线与离线都恢复。
3. 养神丹可以缩短剩余虚弱时间。

## 11. 渡劫与飞升

### 11.1 渡劫

渡劫不是境界，不占等级。

开放条件：

1. 角色达到80级。
2. 境界状态为“大乘·大成”。
3. 完成渡劫准备条件。
4. 当前不处于虚弱。

渡劫是独立特殊行为，可采用九道雷劫、心魔或其他事件，但不改变1—80级境界枚举。

### 11.2 飞升

飞升不是境界，不占等级。

飞升是渡劫成功后的终局结果之一：

1. 飞升。
2. 留在人间。
3. 轮回。

具体终局分支由终局系统决定，修炼系统只提供“大乘大成”和“渡劫结果”。

## 12. 修炼节奏

### 12.1 相邻大境界

测试初值：

`下一大境界总修为需求 = 上一大境界总修为需求 × 2.2`

该倍率保留，但必须与基础修炼速率同步压测。不能只提高修为需求，不提高修炼能力。

### 12.2 境界内需求

境界内每个突破线相对上一线递增：

`下一突破线增量 = 当前突破线增量 × 1.12`

大境界突破线额外乘以1.5。

阶段体感目标：

| 阶段 | 占当前大境界总时间 |
|---|---:|
| 前期 | 20% |
| 中期 | 30% |
| 后期 | 40% |
| 圆满与大突破准备 | 10% |

### 12.3 离线

1. 离线修炼上限8小时。
2. 离线使用与在线相同的修炼公式。
3. 达到突破线后，剩余离线时间按25%瓶颈倍率结算。
4. 离线不自动突破。
5. 虚弱时间离线正常恢复。
6. 耐药负荷离线正常恢复。
7. 时段倍率按离线经过的游戏时段分段结算。

## 13. 配置表裁定

### 13.1 是否把突破配置合入境界表

结论：不合入，突破配置单独建表。

原因：

1. 境界等级是稳定静态数据。
2. 突破包含成功率、丹药、材料、失败虚弱、恢复、特殊事件等独立规则。
3. 大突破和小突破字段不同。
4. 后续调整突破不应改动80级境界主表。
5. 把突破字段塞进境界表会产生大量空值和重复值。

### 13.2 境界等级表

表名建议：`realm_level_config`

共80行。

| 字段 | 含义 |
|---|---|
| level | 角色等级1—80，主键 |
| realm_id | 大境界ID |
| realm_name | 大境界名称 |
| realm_sub_level | 境界内等级1—10 |
| phase | 前期/中期/后期/圆满/大成 |
| display_name | 完整显示名 |
| cult_threshold | 达到本级下一突破节点的累计修为线 |
| base_cult_rate | 本等级每3秒基础修炼速率 |
| next_level | 下一等级；80为空 |
| boundary_type | normal/stage/perfect/major/terminal |

### 13.3 突破表

表名建议：`breakthrough_config`

每一个突破边界一行。

| 字段 | 含义 |

### 13.6 “修炼效果配置”是什么意思

上一轮的“修炼效果配置”指：

1. 丹药限时加速。
2. 功法修炼加成。
3. 洞府、阵法、装备、奇遇加成。
4. 其他系统对修炼速度的临时或永久修改。

第二轮不再要求修炼系统维护这些来源。

处理方式：

1. 外部系统负责产生加成。
2. 属性/加成管理器负责汇总。
3. 修炼系统结算时只读取“修炼速度加成总值”。
4. 修炼系统不关心加成来自功法、装备、洞府还是活动。
5. 若某个限时效果需要配置，由产生该效果的系统维护，不再建立通用修炼效果大表。
