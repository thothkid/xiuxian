## §2 修为获取公式

### 2.1 核心公式

```
每 3 秒修为 = 境界基础速率 × (1 + A类) × (1 + B类) × 灵气效率 × 转换效率 + Σ(固定值)
```

| 乘区 | 来源 | 接口 |
|---|---|---|
| 境界基础速率 | realm_level_config | 只由境界决定，不开放加成 |
| A 类加成 | 灵根、先天道器（极少数）| `register_bonus(type=A, ...)` |
| B 类加成 | 功法、装备、丹药buff、聚灵阵、追赶 | `register_bonus(type=B, ...)` |
| 灵气效率 | 洞府灵气池存量→效率映射 | 内部计算 |
| 转换效率 | 默认 ×1.0，丹药/功法可改 | `set_convert_ratio(...)` |
| 固定值 | 吐纳、部分装备 | `register_bonus(type=flat, ...)` |

即时修为（丹药）不经过速率公式：`修为 += effect_value`。

### 2.2 加成注册接口（同 v2.3）

```
CultBonusManager.register(source_id, type, value, duration?, stack_policy?)
```
- type ∈ {"A", "B", "flat"}
- stack_policy ∈ {"replace", "stack"}
- 境界变化 → mark_dirty → 下次结算重算

### 2.3 修为来源分类

| 类型 | 来源 | 叠加规则 |
|---|---|---|
| 持续修炼 | 在线打坐、离线闭关 | 完整公式 |
| 即时修为 | 修为丹、秘药 | 直接累加 |
| 速率buff | 聚灵丹、吸收加速丹 | B类加成，限时 |
| 转化增效 | 转化丹 | 提升转换效率 |
| 追赶加成 | 奋起 | B类 |

## §3 洞府灵气系统

### 3.1 设计意图

洞府外效率极低。灵气自然汇聚慢（按真实天）、修炼消耗快（按真实小时），制造「每天高效修炼数小时 → 必须出门」的天然节律。

### 3.2 三条核心公式

**汇聚公式：**
```
灵气池存量(t) = min(容量上限, 存量(t₀) + 汇聚速率 × Δ游戏天数)
汇聚速率 = 1 天份/游戏天（基础，可提升）
容量上限 = 30 天份（基础，可扩充至 48）
```

**消耗公式：**
```
实际消耗灵气 = min(可用灵气, 基础吸收速度 × 吸收倍率 × Δ游戏日)
基础吸收速度 = 6 灵气日/游戏日（可被丹药/功法临时提升）
```

**吸收转化公式：**
```
灵气修为 = 实际消耗灵气 × 单位灵气修为值 × 转化效率
转化效率 = 1.0（基础，可被转化丹提升至 ×1.2~×2.0）
```

### 3.3 灵气效率（连续滑尺 + 四档参照）

采用**连续函数**映射存量比例→效率，同时标注**四档阈值**供 UI 展示：

```
灵气效率 = f(当前存量 / 池容量)

参考点：
  存量 100% → 室 1.00    充盈（绿）
  存量  20% → ≈0.60      稀薄（黄）
  存量   5% → ≈0.30      枯竭（橙）
  存量   0% →   0.10      干涸（灰）
```

> 连续滑尺（小龙方案）vs 离散四档（小G/小马方案）：连续更灵活，离散更直观。当前保留连续，离散档位仅用于 UI 颜色标识。**待 thoth 裁定。**

### 3.4 关键参数

| 参数 | 值 | 说明 |
|---|---|---|
| 池容量 | 30 天份 | 可扩充至 48 |
| 汇聚速率 | 1 天份/游戏日 | 1 天份/真实小时 |
| 满池时间 | 30 真实小时 | 空→满 |
| 满速吸收 | 6 灵气日/游戏日 | 净消耗 = 6-1 = 5/真实小时 |
| 满池吸空 | ≈6 真实小时 | 充盈档窗口 |
| 枯竭后效率 | 充盈的 1/10 | 5-10 倍效率差 |

### 3.5 修炼节律叙事（吸收自小马 §4.6）

```
卯时（清晨）   → 回洞府开打坐，灵气池有余量 → 充盈档
辰时-午时      → 持续打坐，效率最高
未时-申时      → 灵气池进入稀薄档，效率下降
酉时           → 出门历练：妖兽刷新、坊市扫货、任务
戌时-子时      → 深夜：魔气溢出、稀有怪概率翻倍
丑时-寅时      → 独有 BOSS 窗口、蓝门触发最高
次日卯时       → 灵气池自然汇聚恢复 → 回洞府 → 充盈档
```

### 3.6 修为满时的吸收惩罚

未突破时继续打坐：灵气仍消耗，吸收效率 ×0.30，修为入溢出池（上限=当前层需求的 20%）。

```
伤害倍率：1 / 1.2 / 1.5 / 2 / 3 / 4 / 5 / 7 / 10（Σ=34.7）
辅助：劫盾（橙，减伤60%）/ 灵盾（紫，减伤30%）
```

## §6 耐药性系统（吸收小G §7 平方曲线）

### 6.1 公式

```
耐药效率 = max(10%, (1 - 当前耐药值 ÷ 100)²)
```

| 耐药值 | 效率 |
|:--:|:--:|
| 0 | 100% |
| 10 | 81% |
| 25 | 56% |
| 50 | 25% |
| 75 | 10% |
| 100 | 10% |

### 6.2 参数

| 参数 | 值 |
|---|---|
| 耐药上限 | 100 |
| 每游戏日恢复 | 60 |
| 完全恢复 | ≈1.67 游戏日（≈100 现实分钟）|
| 作用范围 | 直接修为丹、聚灵丹、转化丹 |
| 不影响 | 突破丹、护脉丹 |

> 不同 item_id 耐药独立。一品满了改吃二品仍满效果。
