## 3. 修为获取

### 3.1 核心公式（沿用打坐修炼 v1.0）

```
每3秒获得修为 = 境界基础速率(3秒) × (1 + A类加成) × (1 + B类加成) + Σ(固定值)
```

即时修为（吃丹等）不经过速率公式，直接累加。

### 3.2 A类 / B类 / 固定值

| | A类 | B类 | 固定值 |
|---|---:|---|---|
| 是什么 | 先天稀有源，独立乘区 | 常规系统源，汇总乘区 | 直接累加 |
| 数量 | 极少（≤5个来源） | 几乎所有加成系统 | 不限 |
| 跨境界 | 永久不衰减 | 查 cult_effect_config 取当前境界系数 | 查表取值 |
| 例子 | 天灵根、先天道器 | 丹药buff、洞府灵气、功法、聚灵阵、装备词条、时段灵气 | 部分丹药、装备词条 |

### 3.3 修为来源分类

| 类型 | 典型来源 | 叠加规则 |
|---|---|---|
| 持续修炼 | 在线打坐、离线闭关 | A/B/flat 公式 |
| 即时丹药 | 修为丹（各品级） | 直接累加，不受速率影响 |
| 速率丹药 | 聚灵丹等 | B类加成，限时生效 |
| 永久加成 | 灵根、功法、洞府、聚灵阵 | A类或B类永久实例 |
| 追赶加成 | 奋起机制 | B类，按与标杆差距分档 |

### 3.4 修为存量 & 溢出池

1. 每个小境界有独立修为上限
2. 达到上限后，持续修炼产出进入"溢出修为池"
3. 溢出池上限 = 当前层修为需求的 20%
4. 突破成功后，溢出修为自动转入下一层
5. 圆满状态的溢出修为不能跨越大境界

## 4. 小境界推进与突破

### 4.1 突破类型总览

| 类型 | 范围 | 触发 | 材料 | 成功率 | 失败结果 |
|---|---|---|---:|---:|---|
| 自动晋升 | 炼气1-9层、筑基1-9层 | 修为满 | 无 | 100% | 无 |
| 小突破 | 金丹起 1-9层 | 修为满 | 小境界材料 | 递减 | 虚弱期 |
| 阶段突破 | 前期3→中期4 | 修为满+材料齐 | 阶段材料 | 高 | 虚弱期 |
| 阶段突破 | 中期6→后期7 | 修为满+材料齐 | 阶段材料 | 中 | 虚弱期 |
| 大境界突破 | 圆满→下一大境界一层 | 修为满+材料+仪式 | 核心材料+渡劫台 | 可变 | 虚弱期 |

**关键规则：突破失败只进虚弱期，不扣修为。**（thoth 指令）

- 虚弱期 = 一段时间内无法再次突破
- 虚弱期内修炼速度正常（不受影响），正常获取修为
- 突破材料消耗规则见各节

### 4.2 自动晋升（炼气、筑基）

炼气1→9层、筑基1→9层：修为满后自动晋升，无需操作。炼气突破至筑基走大境界突破流程。

### 4.3 小突破（金丹起）

- 金丹起每一层修为满后需执行小突破
- 同一大境界内的1-9层小突破：
  - 材料消耗随层数递增
  - 基础成功率逐层下降，**最低不低于60%**
  - 连续失败每次获得 +10% 保底，上限 +30%
  - 成功后保底清零

| 参数 | 值 |
|---|---|
| 失败结果 | 进入虚弱期（不扣修为） |
| 虚弱时长 | 30秒（金丹/元婴）→ 60秒（化神/合体）→ 90秒（大乘） |
| 材料损失 | 消耗材料（不保留） |
| 保底 | 连续失败每次+10%，上限+30%，成功后清零 |

### 4.4 阶段突破

前期→中期、中期→后期的阶段边界，强度高于普通小突破。

| 参数 | 前期→中期 | 中期→后期 |
|---|---|---|
| 基础成功率 | 85% | 75% |
| 保底 | +10%/次，上限+30% | +10%/次，上限+30% |
| 虚弱期 | 60秒 | 120秒 |
| 材料损失 | 辅料消耗，主料保留 | 辅料消耗，主料保留 |
| 成功收益 | 提高境界吸收率 + 开放新功法位 | +承载上限 + 新神通位 |

### 4.5 圆满（第10层）

- 第9层→第10层（圆满）走小突破规则
- 圆满 = 本大境界顶点，突破按钮变为"渡劫突破"（指向大境界突破流程）
- 圆满后持续修炼产出进入溢出池

## 5. 大境界突破

### 5.1 必要条件

1. 当前大境界圆满
2. 当前修为达到圆满上限
3. 持有对应核心突破材料（主药来自刷怪）
4. 完成渡劫台仪式事件

### 5.2 渡劫台事件

每个大境界的圆满→下一境界在渡劫台执行。渡劫台是地图上专门区域：

- **炼气→筑基**：简易祭坛，无雷劫，修为满+材料齐即成功
- **筑基→金丹**：小天劫，渡劫台上承受数波雷击
- **金丹→元婴**：心魔劫 + 雷劫，引入神识判定
- **元婴→化神**：雷劫 + 肉身劫，引入淬体判定
- **化神→合体**：天地大劫，多波雷击 + 心魔
- **合体→大乘**：九重雷劫，最高强度

### 5.3 成功率与失败

```
最终成功率 = 基础成功率 + 丹药加成 + 渡劫台等级加成 + 保底加成
下限：20%，上限：100%
```

| 突破 | 基础成功率 | 虚弱期 | 材料损失 | 备注 |
|---:|---:|---:|---|---|
| 炼气→筑基 | 100% | 无 | 无 | 新手保护 |
| 筑基→金丹 | 80% | 180秒 | 辅料消耗，主料保留 | |
| 金丹→元婴 | 70% | 300秒 | 辅料消耗，主料保留 | |
| 元婴→化神 | 60% | 480秒 | 辅料消耗，主料保留 | |
| 化神→合体 | 50% | 600秒 | 辅料消耗，主料保留 | |
| 合体→大乘 | 40% | 900秒 | 辅料消耗，主料保留 | |

- **失败不扣修为，只进虚弱期**（thoth 指令）
- 保底：每次失败+10%，成功后清零
- 虚弱期内可正常修炼、获取修为

### 5.4 成功结果

1. 进入下一大境界一层
2. 当前修为清零，溢出池修为转入
3. 提高境界基础灵气与基础吸收率
4. 刷新修为丹和吐纳当日次数
5. 解锁对应系统、区域、功法、神通和资源层级

### 5.5 大乘→渡劫（特殊）

大乘圆满后触发渡劫事件，不是常规大境界突破：

- 渡劫成功 → 进入飞升状态（终局内容）
- 渡劫失败 → 无虚弱期，需重新积累渡劫准备
- 飞升后开启终局玩法（轮回/周目），具体规则另案设计

## 6. 丹药系统

### 6.1 品级

所有丹药分四品：**下品 / 中品 / 上品 / 极品**。

| 品级 | 品质系数 | 来源 | 炼丹要求 |
|---|---:|---|---|
| 下品 | ×1.0 | 自动炼丹、商店 | 无门槛 |
| 中品 | ×1.5 | 手动炼丹 | 炼丹等级1 |
| 上品 | ×2.5 | 手动炼丹（概率出） | 炼丹等级3 |
| 极品 | ×4.0 | 手动炼丹（低概率出） | 炼丹等级5 |

同丹方不同品级的丹药，在配置表中为独立 item_id。品质系数作用于即时修为值或 buff 强度。

### 6.2 丹药类型

| 类型 | 效果 | 每日次数 | 是否受耐药性影响 |
|---|---|---|---|
| 修为丹 | 立即获得修为 | 有限次 | 是 |
| 聚灵丹 | B类修炼加成，持续N秒 | 不占修为丹次数 | 是 |
| 突破丹 | 提高突破成功率 | 每次突破限1枚 | 否 |
| 护脉丹 | 缩短虚弱期 | 虚弱期限1枚 | 否 |
| 秘药 | 大量即时修为 | 不占普通次数，来源稀缺 | 否 |

### 6.3 修为丹数值模型

修为丹的绝对数值按"当前大境界标准修炼时长 × 品质系数"换算：

| 品级 | 等价修炼时长 | 示例：筑基标准速率下 |
|---|---:|---|
| 下品 | 5分钟 × 1.0 = 5分钟 | ~1200点 |
| 中品 | 5分钟 × 1.5 = 7.5分钟 | ~1800点 |
| 上品 | 5分钟 × 2.5 = 12.5分钟 | ~3000点 |
| 极品 | 5分钟 × 4.0 = 20分钟 | ~4800点 |

### 6.4 丹药每日上限

| 大境界 | 修为丹每日上限 | 聚灵丹每日上限 |
|---|---|---|
| 炼气 | 10 | 3 |
| 筑基 | 8 | 5 |
| 金丹 | 6 | 5 |
| 元婴 | 5 | 5 |
| 化神 | 4 | 5 |
| 合体 | 3 | 5 |
| 大乘 | 3 | 5 |

每日次数在每日0点刷新。大境界突破成功后额外刷新一次当日修为丹次数。

## 7. 耐药性系统

### 7.1 核心规则

1. 同 item_id 的丹药每服用一次，该丹药的**耐药值**增加
2. 耐药值影响该丹药的**即时修为量**和 **buff 强度**
3. 耐药值随时间**自然衰减**
4. 不同丹药的耐药值互相独立

### 7.2 耐药值计算

```
耐药修正 = 1 - min(耐药值 / 耐药阈值, 衰减上限)
```

- 耐药阈值：统一为 100
- 衰减上限：0.70（即最多衰减70%效果）
- 每次服用：耐药值 +10
- 自然衰减：每在线1小时 -2，离线时也正常衰减

### 7.3 耐药值示例

```
培元丹下品：第1次服 → 效果×1.00
培元丹下品：第5次服 → 耐药值50 → 效果×0.50
培元丹下品：第10次服 → 耐药值100 → 效果×0.30（触底）
休养25在线小时后 → 耐药值50 → 效果×0.50
```

### 7.4 配置方式

耐药性是 CultBonusManager 的扩展模块：

- 维护 `{item_id → 耐药值}` 映射
- 在 recalc 时，取表值后 × 耐药修正再代入公式
- 即时修为（instant_cult）同样应用耐药修正
- 不同品级的同丹方 = 不同 item_id，耐药值独立
  - 上品丹耐药值满了 → 极品丹仍满效果

## 8. 洞府灵气系统

### 8.1 设计意图

玩家必须回到洞府内打坐才能获得正常修炼速度。野外/非洞府区域的打坐速度极低（基准值的5-10%）。洞府是修炼的核心场所，也是灵气汇聚的容器。

洞府灵气有"汇聚—消耗"周期：灵气温吞积累，修炼时快速消耗。每日灵气浓度随时间衰减分档，防止玩家24小时挂机打坐——修炼效率最高的几个小时后，继续修炼的收益急剧下降，自然驱赶玩家外出历练。

### 8.2 时间换算

| 单位 | 换算 |
|---|---|
| 1 游戏日 | 12 时辰 = 60 分钟（真实时间）|
| 1 真实日 | 24 游戏日 |
| 1 真实小时 | 1 游戏日 |

### 8.3 灵气池

洞府维持一个灵气池，是修炼效率的基础。

| 参数 | 默认值 | 说明 |
|---|---|---|
| 池容量 | 30 点 | 1 点 = 1 游戏日的灵气储备。可通过道具扩容 |
| 恢复速度 | +1 点 / 游戏日 | 即 +1 点 / 真实小时。可通过道具/洞府等级加速 |
| 充满时间 | 30 真实小时 | 空池→满池约 1.25 真实日 |
| 修炼消耗 | 修炼时消耗 | 修炼 1 真实小时消耗约 1 点（与修炼速度挂钩）|

- 灵气池存量为 0 时，洞府修炼效率降至基准值的 5%（与野外无异）
- 灵气池随真实时间持续恢复，玩家离线期间也正常恢复
- 道具可提升：池容量上限、恢复速度（灵脉升级/聚灵阵/天材地宝）

### 8.4 每日效率分档

以真实日的 0:00 为重置点，当日累计修炼时长决定灵气浓度档位。注意：此处的"修炼时长"是从灵气池扣除灵气后的实际有效修炼时间，非挂机时间——灵气池空了就修炼不了。

| 档位 | 当日累计修炼 | 灵气状态 | 效率系数 | 体感 |
|---|---:|---|---|
| 充沛 | 0 ~ 5 小时 | 灵气充裕 | ×1.0 | 效率最高，是策划设计修炼时长的基准 |
| 渐稀 | 5 ~ 8 小时 | 灵气渐薄 | ×0.7 | 效率打七折，玩家开始考虑是否该停 |
| 稀薄 | 8 ~ 12 小时 | 灵气稀薄 | ×0.4 | 修炼性价比骤降 |
| 枯竭 | 12 小时以上 | 灵气枯竭 | ×0.2 | 不如出去打怪积累其他资源 |

效率系数作为 B 类加成中的一个独立来源（source_id = 洞府灵气浓度），参与修炼速度公式：

```
洞府中每3秒修为 = 境界基础速率 × (1 + A) × (1 + B_其他 + B_灵气浓度) + flat
```

B_灵气浓度 = f(当日累计修炼时长)，按上表取值（充沛=基准值如0.50，渐稀=0.35，以此类推）。

### 8.5 野外打坐

非洞府区域也可以打坐，但基础灵气浓度极低：

| 地点 | 灵气浓度（B类） | 相当于洞府充沛的 |
|---|---|---|
| 宗门修炼室 | 洞府基准的 60% | 六折 |
| 野外安全区 | 洞府基准的 20% | 两折 |
| 野外危险区 | 洞府基准的 10% | 一折（不建议修炼）|
| 秘境/福地 | 特定区域可能有高浓度，具体配置 | |

宗门修炼室为无洞府玩家的过渡方案。一旦拥有洞府，修炼室仅作备用。

### 8.6 洞府升级方向

| 升级维度 | 效果 | 消耗 |
|---|---|---|
| 灵脉等级 | 提升灵气池容量上限（+5点/级）| 灵石 + 天地灵物 |
| 聚灵阵等级 | 提升灵气恢复速度（+0.5点/游戏日/级）| 灵石 + 阵法材料 |
| 灵气浓度 | 提升充沛档的效率系数上限 | 洞府装饰 + 特殊道具 |
| 洞府扩容 | 增加闭关位数量 | 灵石 + 建筑材料 |

## 9. 修炼节奏

### 9.1 单一大境界耗时分配

| 阶段 | 层数 | 占本大境界总时长 |
|---|---|---|
| 前期（1-3层） | 3 | 20% |
| 中期（4-6层） | 3 | 30% |
| 后期（7-9层） | 3 | 40% |
| 圆满准备（第10层+突破） | 1+事件 | 10% |

后期单层耗时约为前期单层的 2 倍。通过修为阈值递增实现，不增加层数。

### 9.2 相邻大境界倍率

1. 下一大境界总修为需求 ≈ 上一大境界的 2.2 倍
2. 境界基础吸收率同步提高，抵消约 35% 的纯时长增长
3. 新洞府、功法、装备继续抵消剩余增长
4. 实际体感增长主要来自突破材料收集和渡劫台事件，非纯数值墙

### 9.3 离线闭关（沿用 v1.0）

| 参数 | 值 |
|---|---|
| 上限 | 8小时（基础），可付费提至12/16小时 |
| 公式 | 同在线打坐公式 |
| 限时buff | 正常消耗 |
| 突破 | 离线不执行有失败率的突破 |
| 自动晋升 | 允许离线连续通过（炼气、筑基的100%层） |
| 灵气浓度 | 离线时段内的时间加权均值 |
| 结算 | 上线一次性结算 |

### 9.4 追赶

| 与标杆差距 | 修炼速度加成（B类） |
|---|---:|
| 0—5个统一序号 | 0% |
| 6—15个统一序号 | +25% |
| 16—30个统一序号 | +50% |
| 31—50个统一序号 | +80% |
| 51个以上 | +120% |

标杆取活跃玩家统一序号前10名的中位数。追赶只加快修为获取，不提高突破成功率，不免除材料条件。

|---|---|---|---|

## 11. 境界收益

### 11.1 每一层

1. 生命/灵力/主属性微增
2. 修为存量上限提升
3. 法力上限扩容
4. 对低境界怪的压制系数微增

### 11.2 每一阶段

| 阶段 | 核心收益 |
|---|---|
| 前期完成（3层→4层） | 稳定当前大境界能力，境界吸收率提升 |
| 中期完成（6层→7层） | +1功法位或神通位，淬体/神识承载提升 |
| 后期完成（9层→10层圆满） | 开放大境界突破材料与渡劫台 |

### 11.3 每一大境界

必须产生质变，至少包含以下三项中的两项：

1. 新战斗机制（如金丹的丹火、元婴的元婴出窍）
2. 新资源层级或地图区域
3. 新灵力/淬体/神识交互规则

禁纯数值换皮。
