## 三、修为获取

### 3.1 核心公式

```
每 3 秒获得修为 = 境界基础速率(3秒) × (1 + A类加成) × (1 + B类加成) × 灵气效率 × 转换效率 + Σ(固定值)
```

| 乘区 | 含义 | 来源 |
|---|---|---|
| 境界基础速率 | 当前小境界内置的修为产出 | realm_config |
| A 类加成 | 先天稀有源（独立乘区）| 天灵根、先天道器 |
| B 类加成 | 常规系统源（汇总乘区）| 功法、装备、聚灵阵 |
| **灵气效率** | 洞府灵气池存量→效率映射 | 灵气池系统（§四）|
| **转换效率** | 每点灵气→修为的转化比 | 默认×1.0，丹药/功法可提升 |
| 固定值 | 直接累加 | 部分装备、丹药 |

即时修为（吃修为丹）不经过速率公式：修为 += effect_value，当场查表。

### 3.2 修为来源分类

| 类型 | 典型来源 | 叠加规则 |
|---|---|---|
| 持续修炼 | 在线打坐、离线闭关 | 完整公式 |
| 即时修为 | 修为丹 | 直接累加，不经速率公式 |
| 速率 buff | 聚灵丹等 | B 类加成，限时 |
| 永久加成 | 灵根、功法 | A 类或 B 类永久实例 |
| 追赶加成 | 奋起机制 | B 类 |

### 3.3 CultBonusManager

不存数值，只存来源（source_id + 堆叠数 + 剩余时间）。每次 recalc 遍历活跃来源 × 当前境界 × 当场查 cult_effect_config。境界变化 → mark_dirty → 自动重算。同 item_id 可多实例（如连吃3颗丹药→3个独立倒计时）。

## 四、洞府灵气系统

### 4.1 设计意图

玩家必须回洞府打坐才能获得正常修炼速度。野外打坐效率极低。洞府灵气有"长周期汇聚 + 短周期快速消耗"的节奏：灵气温吞积累（按真实日计），修炼时快速消耗。无灵气时修炼效率仅 5-10 倍差距，自然驱赶玩家外出历练。

### 4.2 灵气池

| 参数 | 默认值 | 说明 |
|---|---|---|
| 池容量 | 30 点 | 1 点 = 1 游戏日的灵气储备（可按道具扩容）|
| 恢复速度 | +1 点 / 游戏日 | +1 点 / 真实小时。离线也恢复 |
| 充满时间 | 30 真实小时 | 空→满约 1.25 真实日 |
| 修炼消耗 | 按修炼时间消耗 | 打坐 1 真实小时 ≈ 消耗 1 点 |

- 灵气池存量为 0 → 效率跌至基准值
- 离线期间继续恢复

### 4.3 灵气效率映射（连续滑尺）

不存在离散分档。效率由灵气池**当前存量比例**决定，连续映射：

```
灵气效率 = 基准效率 × f(池当前存量 / 池容量)

f(x) 设计曲线（概念）：
  x=1.00（满）→ 效率 ×1.00
  x=0.70      → 效率 ×0.92
  x=0.50      → 效率 ×0.80
  x=0.30      → 效率 ×0.55
  x=0.10      → 效率 ×0.25
  x=0.00（空）→ 效率 ×0.10
```

核心：灵气充裕时修炼效率高（无灵气时的 5-10 倍）。随灵气消耗效率平滑下降。无灵气 = 效率降至最低档。具体曲线形状待数值策划拟合。

每日修炼时长 → 消耗灵气 → 池存量下降 → 效率自然下滑。当日不重置灵气池。

### 4.4 修为满时的吸收惩罚

当玩家修为已达到当前层上限但尚未突破时：

- 继续打坐：灵气仍从池中扣除
- 但吸收效率额外打折扣（如 ×0.30），修为进入溢出池
- 防止无意义挂机浪费灵气，鼓励立即突破

### 4.5 野外打坐

| 地点 | 灵气效率 | 说明 |
|---|---|---|
| 宗门修炼室 | 洞府基准的 60% | 无洞府过渡方案 |
| 野外安全区 | 洞府基准的 20% | 应急回蓝 |
| 野外危险区 | 洞府基准的 10% | 不建议修炼 |

秘境/福地可配置高浓度，具体按地图配置。

## 五、转换效率

**定义：** 每消耗 1 点灵气，实际转化为多少修为。

**默认值：** ×1.0。

**加成来源：**

| 来源 | 效果 | 类型 |
|---|---|---|
| 特定丹药 | 持续 N 秒，转化比 ×1.2~×2.0 | B 类 buff |
| 功法被动 | 永久转化比 +0.1~+0.5 | A 类或 B 类 |
| 洞府聚灵阵 | 转化比微增 | B 类永久 |

**与修炼公式的关系：**

```
实际修为产出 = 基础公式产出 × 转换效率
```

转换效率属于修炼公式最外层乘区（或并入 B 类加成，具体数值策划决定）。

**设计意图：** 灵气→修为转化的比例不是固定的，丹药和功法可以让"同样吸一口气，修为多长一点"。这是付费/深度玩法的核心差异化点之一。

## 六、突破规则

### 6.1 突破类型总览

| 类型 | 范围 | 触发 | 成功率 | 失败结果 |
|---|---|---|---|---|
| 自动晋升 | 炼气 1-9、筑基 1-9 | 修为满 | 100% | 无 |
| 小突破 | 金丹起 1-9 层 | 修为满 | 递减（≥60%）| 虚弱期 |
| 阶段突破 | 前期3→中期4 / 中期6→后期7 | 修为满+材料 | 85%/75% | 虚弱期 |
| 大境界突破 | 圆满→下一大境界 | 修为满+材料+渡劫台 | 可变 | 虚弱期 |

### 6.2 虚弱期

突破失败进入虚弱期。虚弱期内：

1. **无法吸收灵气**——修炼时灵气不从池中扣除，也不产生修为
2. 修炼效率降至**无灵气状态的再打折**（如基准值 ×0.05），即几乎无法通过打坐获取修为
3. 可服用修为丹获取修为（即时修为不经灵气池）
4. 无法再次尝试突破
5. 可使用护脉丹缩短虚弱期

**设计意图：** 虚弱期=修炼冻结。防止玩家突破失败后靠挂机弥补——必须等虚弱结束或用丹药解。

### 6.3 小突破（金丹起）

| 参数 | 值 |
|---|---|
| 材料消耗 | 随层数递增 |
| 基础成功率 | 逐层下降，最低 60% |
| 保底 | 每次失败 +10%，上限 +30%，成功后清零 |
| 虚弱时长 | 30秒(金丹/元婴) → 60秒(化神/合体) → 90秒(大乘) |
| 材料损失 | 消耗（不保留）|

### 6.4 大境界突破

必要条件：圆满 + 修为满 + 材料齐 + 渡劫台仪式。

| 突破 | 基础成功率 | 虚弱期 | 材料 |
|---|---|---|---|
| 炼气→筑基 | 100% | 无 | — |
| 筑基→金丹 | 80% | 180秒 | 辅料消耗/主料保留 |
| 金丹→元婴 | 70% | 300秒 | 辅料消耗/主料保留 |
| 元婴→化神 | 60% | 480秒 | 辅料消耗/主料保留 |
| 化神→合体 | 50% | 600秒 | 辅料消耗/主料保留 |
| 合体→大乘 | 40% | 900秒 | 辅料消耗/主料保留 |

最终成功率 = 基础 + 丹药 + 渡劫台 + 保底，下限 20%/上限 100%。失败不扣修为。

### 6.5 大乘→渡劫（特殊）

大乘圆满后触发渡劫事件。成功→飞升终局；失败→重新积累。飞升后内容另案设计。

## 八、耐药性系统

### 8.1 药效衰减公式

```
耐药修正 = 1 − min(耐药值 / 耐药阈值, 衰减上限)
```

| 参数 | 默认值 | 说明 |
|---|---|---|
| 耐药阈值 | 100 | 达到此值触底 |
| 衰减上限 | 0.70 | 最多衰减 70%（即最低 30% 效果）|
| 自然衰减 | −2 / 真实小时 | 在线离线均衰减 |
| 每次服用增加 | 按品级（见 §7.1）| 九品 +28，一品 +5 |

### 8.2 效果

耐药修正作用于：
- 修为丹的即时修为量
- 聚灵丹/转换丹的 buff 强度

不影响突破丹和护脉丹。

### 8.3 独立性

同 item_id 的丹药共享耐药值。不同品级 = 不同 item_id → 耐药值独立。一品丹耐药满了，改吃二品丹还是满效果。

### 8.4 示例

```
培元丹一品：1次  → 耐药值  5 → 效果 ×0.95
培元丹一品：10次 → 耐药值 50 → 效果 ×0.50
培元丹一品：20次 → 耐药值100 → 效果 ×0.30（触底）
停药 25 真实小时  → 耐药值 50 → 效果 ×0.50
```
