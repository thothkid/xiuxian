## 三、修为获取公式

### 3.1 核心公式

```
每3秒修为 = 境界基础速率 × (1 + A类) × (1 + B类) × 灵气效率 × 转换效率 + Σ(固定值)
```

| 乘区 | 含义 | 来源 | 接口 |
|---|---|---|---|
| 境界基础速率 | 当前小境界内置产出 | realm_config | — |
| A 类加成 | 先天稀有，独立乘区 | 天灵根、先天道器 | register_bonus(type=A, source_id, value) |
| B 类加成 | 常规系统，汇总乘区 | 功法、装备、丹药buff、聚灵阵、追赶 | register_bonus(type=B, source_id, value, duration) |
| 灵气效率 | 灵气池存量→效率映射 | 洞府灵气池 | 内部计算，不开放 |
| 转换效率 | 每点灵气→修为比值 | 默认×1.0，丹药/功法可改 | set_convert_ratio(source_id, multiplier, duration) |
| 固定值 | 直接累加 | 部分装备、丹药 | register_bonus(type=flat, source_id, value) |

即时修为（修为丹）不经过速率公式：`修为 += effect_value`，当场查表。

### 3.2 加成注册接口

外部系统通过统一接口挂入修炼公式：

```
CultBonusManager.register(source_id, type, value, duration?, stack_policy?)
```

| 参数 | 说明 |
|---|---|
| source_id | 唯一来源标识（物品ID / 技能ID / 系统名）|
| type | "A" / "B" / "flat" |
| value | 加成数值 |
| duration | 秒，0=永久。限时到期后自动移除 |
| stack_policy | "replace"（同source_id替换）/ "stack"（多实例独立）|

**实现规则：**

- Manager 只存 `(source_id, type, value, expires_at, stack_policy)`，不缓存最终数值
- `get_cult_speed()` 被调用时当场遍历所有活跃 source × 当前境界查 cult_effect_config
- 境界变化 → mark_dirty → 下次 get_cult_speed 时自动重算
- 同 source_id + stack_policy="stack" → 多个独立倒计时（如连吃3颗丹药）
- 同 source_id + stack_policy="replace" → 刷新 duration（如洞府聚灵阵）

### 3.3 修为来源分类

| 类型 | 来源 | 叠加规则 |
|---|---|---|
| 持续修炼 | 在线打坐、离线闭关 | 完整公式 |
| 即时修为 | 修为丹 | 直接累加，不经速率公式 |
| 速率buff | 聚灵丹等 | B类加成，限时 |
| 永久加成 | 灵根、功法 | A类/B类永久实例 |
| 追赶加成 | 奋起机制 | B类 |

## 四、洞府灵气系统

### 4.1 设计意图

玩家必须回洞府打坐才能获得正常修炼速度。野外效率极低。灵气"长周期汇聚（按真实日）+短周期快速消耗（修炼时）"。无灵气时效率仅满状态时的约 1/10，自然驱赶玩家外出历练。

### 4.2 灵气池

| 参数 | 默认值 | 说明 |
|---|---|---|
| 池容量 | 30 点 | 1点=1游戏日灵气储备，可扩容 |
| 恢复速度 | +1点/游戏日 | +1点/真实小时，离线也恢复 |
| 充满时间 | 30 真实小时 | 空→满约 1.25 真实日 |
| 修炼消耗 | 按修炼时间 | 打坐 1 真实小时 ≈ 消耗 1 点 |

池存量为 0 → 效率跌至 ×0.10（见 §4.3）。离线期间继续恢复。

### 4.3 灵气效率映射（连续滑尺）

效率由灵气池**当前存量比例**决定，连续映射（非离散分档）：

```
灵气效率 = f(当前存量 / 池容量)

f(x) 概念曲线：
  x=1.00 → ×1.00    满池：最高效率
  x=0.70 → ×0.92
  x=0.50 → ×0.80
  x=0.30 → ×0.55
  x=0.10 → ×0.25
  x=0.00 → ×0.10    空池：相当于无灵气时 5-10 倍差距
```

具体函数形状待数值策划拟合，存入 cultivation_global_config.efficiency_curve。

### 4.4 野外打坐

| 地点 | 灵气效率 | 说明 |
|---|---|---|
| 宗门修炼室 | ×0.60 | 无洞府过渡方案 |
| 野外安全区 | ×0.20 | 应急 |
| 野外危险区 | ×0.10 | 不建议修炼 |

秘境/福地可配置高浓度，按地图配置。

### 4.5 修为满时的吸收惩罚

未突破时继续打坐：灵气仍从池中扣除，但吸收效率 ×0.30，修为进入溢出池（上限=当前层需求的 20%）。防止挂机浪费灵气。

## 五、转换效率

每消耗 1 点灵气实际转化多少修为。默认 ×1.0。

| 来源 | 效果 | 类型 |
|---|---|---|
| 转换丹 | 持续 N 秒 ×1.2~×2.0 | B 类限时buff |
| 功法被动 | 永久 +0.1~+0.5 | A 类/B 类 |
| 洞府聚灵阵 | 微增 | B 类永久 |

```
最终每tick修为 = 公式计算值 × 转换效率
```

设计意图：丹药和功法让"同样吸一口气，修为多长一点"，是付费/深度差异化核心。

## 六、突破规则

### 6.1 突破类型总览

| 类型 | 范围 | 触发 | 成功率 | 失败 |
|---|---|---|---|---|
| 自动晋升 | 炼气1-9、筑基1-9 | 修为满 | 100% | 无 |
| 小突破 | 金丹起 1-9 层 | 修为满 | 递减（≥60%）| 虚弱期 |
| 阶段突破 | 前期3→中期4 / 中期6→后期7 | 修为满+材料 | 85%/75% | 虚弱期 |
| 大境界突破 | 圆满→下一大境界 | 修为满+材料+渡劫台 | 可变 | 虚弱期 |

### 6.2 虚弱期

突破失败进入虚弱期（参数见 weakness_config）：

1. **无法吸收灵气** — 修炼不扣池也不产修为
2. 修炼效率 ×0.05 — 几乎无法通过打坐获取修为
3. **可服用修为丹** — 即时修为不经灵气池
4. 无法再次突破
5. 护脉丹缩短虚弱期

设计意图：虚弱期=修炼冻结。突破失败后不能挂机弥补。

### 6.3 小突破（金丹起）

| 参数 | 值 |
|---|---|
| 材料消耗 | 随层数递增 |
| 基础成功率 | 逐层下降，最低 60% |
| 保底 | 每次失败 +10%，上限 +30%，成功后清零 |
| 虚弱时长 | 30s(金丹/元婴)→60s(化神/合体)→90s(大乘) |
| 材料损失 | 消耗，不保留 |

### 6.4 大境界突破

必要条件：圆满 + 修为满 + 材料齐 + 渡劫台仪式。

| 突破 | 基础成功率 | 虚弱期 | 材料 |
|---|---|---|---|
| 炼气→筑基 | 100% | 无 | — |
| 筑基→金丹 | 80% | 180秒 | 辅料消耗/主料保留 |
| 金丹→元婴 | 70% | 300秒 | 辅料消耗/主料保留 |
| 元婴→化神 | 60% | 480秒 | 辅料消耗/主料保留 |
| 化神→合体 | 50% | 600秒 | 辅料消耗/主料保留 |
| 合体→大乘 | 40% | 900秒 | 辅料消耗/主料保留 |

最终成功率=基础+丹药+渡劫台+保底，下限20%/上限100%。失败不扣修为。

### 6.5 大乘→渡劫（特殊）

渡劫=特殊事件，成功→飞升终局，失败→重新积累。飞升后内容另案设计。

## 八、耐药性系统

### 8.1 衰减公式

```
耐药修正 = 1 − min(耐药值 / 耐药阈值, 衰减上限)
```

| 参数 | 默认值 |
|---|---|
| 耐药阈值 | 100 |
| 衰减上限 | 0.70（最多衰减70%，即最低30%效果）|
| 自然衰减 | −2 / 真实小时（在线离线均衰减）|
| 每次服用增加 | 按品级（§7.1），一品+5 → 九品+28 |

### 8.2 作用范围

耐药修正作用于：修为丹即时修为、聚灵丹/转换丹 buff 强度。不影响突破丹和护脉丹。

### 8.3 独立性

不同 item_id → 耐药值独立。一品满了改吃二品仍满效果。

示例：
```
培元丹一品：1次→耐药5→效果×0.95  |  20次→耐药100→效果×0.30
停药25小时→耐药50→效果×0.50
```

## 十二、状态优先级与跨边界拆算

### 12.1 状态优先级

多个状态可能同时成立时，按以下优先级处理：

| 优先级 | 状态 | 行为 |
|:--:|---|---|
| 1 | 已飞升 | 不再参与修炼系统 |
| 2 | 虚弱期 | 无法吸灵气，打坐几乎无效 |
| 3 | 修为满+待突破 | 打坐效率×0.30，修为入溢出池 |
| 4 | 修炼中（正常）| 正常公式 |
| 5 | 离线 | 按离线结算 |

高优先级状态覆盖低优先级。虚弱期 > 修为满惩罚，取最严格限制。

### 12.2 跨边界拆算（离线/长时结算）

离线结算跨越境界边界时（如炼气9层→上线时筑基3层），按以下步骤拆算：

```
1. 取离线时长 T，灵气加权均值 P_avg
2. 以当前境界为起点，逐 tick 推进：
   a. 当前层修为满 → 自动晋升（仅炼气/筑基 100% 层）
   b. 当前层修为满+需突破 → 停止推进，剩余修为入溢出池
   c. 越过大境界边界 → 刷新当日丹药次数
3. 上线时弹窗展示结算结果：
   - 从 LvX 升至 LvY
   - 获得修为：Z
   - 突破 N 次（自动晋升）
   - 当前状态：正常 / 待突破 / 溢出池满
```

**关键约束：** 离线不执行小突破/阶段突破/大境界突破（有失败率）。到了"需突破"的层就停在溢出池上限。

## 十三、修炼信息展示接口

玩家 UI 需展示以下信息（策划定义，具体排版由 UI 设计负责）：

| 灵气池余量 | qi_pool_current | 每 tick |

| 虚弱倒计时 | weakness_remaining | 每秒 |
| 当日丹药剩余次数 | daily_pill_used vs limit | 使用后刷新 |
| 耐药值（当前丹药）| drug_resistance_map | 使用后刷新 |
| 离线结算弹窗 | 离线结算结果 | 上线时一次性 |
